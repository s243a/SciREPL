SciREPL Privacy Policy

Last updated: August 11, 2026

Summary

SciREPL is designed to be a privacy-respecting application. All code execution happens locally on your device. We do not collect, store, or transmit any personal data to our servers.

Local Data Storage

SciREPL stores data locally on your device using browser or app storage, including localStorage, IndexedDB, and caches:

  • Your session history (code cells and their types)
  • Command history for input recall
  • Preferences (e.g. cell counter state)
  • SharedVFS files, uploaded files, installed package files, and search paths
  • Downloaded runtimes, packages, and app resources kept in local caches

SciREPL does not send this local data to its servers. You can clear session and VFS data via Menu > Clear History, and downloaded caches via Menu > Memory & Storage.

Network Requests & Third-Party CDNs

SciREPL bundles its core interface and most language runtimes directly in the app. The following items describe what is bundled and what may be downloaded from third-party services:

  • Bundled language runtimes: Python (Pyodide), Prolog (SWI-Prolog WASM), ClojureScript (Scittle), Bash (brush-wasm), TypR, and JavaScript are included with the Free app and do not require a runtime download.
  • R (webR) — about 50 MB from webr.r-wasm.org, downloaded when R is first used and cached locally.
  • Lua (Fengari) — from cdn.jsdelivr.net or unpkg.com, downloaded when Lua is first used and cached locally.
  • DOCX export library — docx@9.6.0 from cdn.jsdelivr.net, downloaded when DOCX export is first used.
  • Runtime version checks — after network consent, opening Languages may query data.jsdelivr.com for package version metadata. If consent has not yet been given, tapping Check latest opens the consent dialog; no metadata request is sent unless you accept. It does not download or activate the runtime.
  • Optional catalog packages are downloaded from GitHub when you install them. Other packages and user-requested data may be fetched from package repositories or URLs when you request them, for example with install.packages(), %pip, or file-fetching commands.
  • Ko-fi support link — Help includes a normal link to ko-fi.com. No Ko-fi request is made unless you choose to open it.

When these resources are fetched, the CDN providers may receive:

  • Your IP address
  • Your device's user agent string (browser/OS information)
  • Timestamps of requests
  • URLs of requested resources

This is standard HTTP behavior and is not under our control. Caching is used to minimize repeat connections. After a runtime or package has been downloaded successfully, SciREPL uses the local cached copy when available.

jsDelivr's privacy policy is available at jsdelivr.com/terms/privacy-policy-jsdelivr-net.

Your code, session data, and exported files are not transmitted to a SciREPL server. Network requests occur only for the resources described above or when your code explicitly requests them.

Package Downloads

SciREPL includes a package catalog that allows you to download optional content packages from GitHub. When you choose to install a package, the app downloads the package file directly from GitHub's servers. GitHub may receive your IP address and standard HTTP headers during this download. SciREPL does not proxy, log, or monitor these requests. Package downloads are user-initiated and optional.

User-Initiated Network Requests

SciREPL provides a file-fetching feature that allows notebook code to download files from URLs you specify. When you use this feature (e.g., fetch_file in Prolog, or via the Prolog Settings panel), the request is made directly from your device to the specified URL. The remote server will receive your IP address and standard HTTP headers. SciREPL does not proxy, log, or monitor these requests.

Code Execution

Code you enter in the included Python, Prolog, Bash, JavaScript, R, Lua, TypR, and ClojureScript kernels is executed locally on your device. No code is sent to a SciREPL server for execution.

File Export

When you export a notebook (.ipynb), the file is created locally on your device. If you choose to share it (via the system share sheet), the destination is determined by your choice (e.g. local storage, email, cloud services). SciREPL does not control or monitor where you share exported files.

Analytics & Tracking

SciREPL does not include any analytics, crash reporting, advertising SDKs, or tracking mechanisms.

Children's Privacy

SciREPL does not knowingly collect any information from children. The app does not require account creation or collect personal information of any kind.

Future Changes

If a future release changes which runtimes or packages are bundled or downloaded, this policy will be updated to describe the resulting network requests and metadata exposure.
