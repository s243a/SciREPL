Aplikasi desktop Windows

Tampilan di Windows: apa yang berbeda

Aplikasi Windows, termasuk versi Microsoft Store, memiliki ☰ Menu → 🎨 Tampilan yang sama dengan Android. Tema, bahasa tampilan, ukuran tombol, dan pintasan 📦 Browse bekerja seperti yang dijelaskan dalam Panduan Tampilan. Halaman ini hanya membahas hal yang ditambahkan oleh jendela desktop.

  • Free
  • Aplikasi desktop Windows
  • Sekitar 2 menit

Lebar buku catatan

Pada jendela yang lebarnya minimal 1000 piksel, sel buku catatan dapat melebar hingga 1200 piksel. Pengaturan Lebar ini adalah bawaan. Untuk mengubahnya, buka ☰ Menu → 🎨 Tampilan, lalu di bagian Tata Letak pilih Lebar buku catatan:

  • Standar: kolom 720 piksel seperti sebelumnya.
  • Lebar: hingga 1200 piksel (bawaan).
  • Seluruh jendela: sel memakai seluruh lebar jendela.

Jendela yang lebih sempit selalu memakai kolom standar, apa pun pilihan Anda.

Zoom

Zoom memperbesar atau memperkecil halaman di dalam jendela:

  • Perbesar: Ctrl+= atau Ctrl+Shift+= (Ctrl dan tombol plus).
  • Perkecil: Ctrl+-. Kembali ke 100%: Ctrl+0.
  • Tahan Ctrl dan putar roda mouse, atau cubit pada touchpad.
  • Di bilah menu jendela: Tampilan → Perbesar, Perkecil, atau Ukuran Sebenarnya.

Penskalaan layar Windows atau zoom aplikasi?

Skala di pengaturan layar Windows (Pengaturan → Sistem → Layar) memperbesar semua yang ada di layar, termasuk bilah judul, bilah menu, dan kotak dialog SciREPL. Zoom aplikasi hanya memperbesar halaman di dalam jendela. Windows tidak memiliki pengaturan skala untuk satu aplikasi saja, jadi gunakan zoom bila hanya SciREPL yang perlu lebih besar atau lebih kecil.

Keduanya juga mengubah ukuran jendela bagi halaman. Misalnya, pada skala 150%, layar selebar 1920 piksel hanya selebar 1280 piksel bagi SciREPL. Lebar 1000 piksel di atas dan tinggi 500 piksel di bawah dihitung setelah penskalaan dan zoom.

Menyembunyikan panel sel baru

Jika jendela lebih lebar daripada tingginya dan tinggi halaman paling banyak 500 piksel, tombol ⌄ (Sembunyikan panel sel baru) muncul di panel sel baru di bagian bawah. Pada skala 150–200%, jendela laptop biasa bisa sependek itu, dan memperbesar zoom pun berefek sama. Klik ⌄ agar buku catatan mendapat seluruh tinggi jendela.

Selama panel disembunyikan, judul Sci REPL di kiri atas diganti dengan tombol kecil ⌃ (Tampilkan panel sel baru). Klik tombol itu untuk menampilkan panel lagi. Membuat jendela lebih tinggi, misalnya dengan memaksimalkannya, juga menampilkan panel kembali.

Bilah menu jendela

Jendela Windows memiliki bilah menunya sendiri di atas aplikasi: Berkas, Sunting, Tampilan, Runtime, dan Bantuan, dalam bahasa tampilan Anda. Tekan Alt untuk menjangkaunya dari keyboard. Runtime berisi:

  • Runtime yang diunduh… menampilkan besar ruang yang dipakai runtime Lua dan R yang diunduh, serta lokasi penyimpanannya.
  • Hapus runtime yang diunduh… menghapusnya setelah Anda mengonfirmasi; buku catatan dan berkas Anda tidak terpengaruh. Runtime yang sudah dimuat tetap berfungsi sampai Anda memulai ulang. Setelah itu, R dan Lua akan bertanya lagi sebelum diunduh, dan pengunduhan memerlukan koneksi internet.
  • Buka folder data aplikasi membuka folder data SciREPL di File Explorer.

Android tidak memiliki bilah menu jendela. Di sana, gunakan ☰ Menu → 📊 Memori & penyimpanan untuk memeriksa dan mengosongkan penyimpanan. Di Windows, panel itu tidak dapat melihat runtime yang diunduh, jadi gunakan menu Runtime untuk runtime tersebut.

Semua hal lainnya sama dengan Android: kembali ke Panduan Tampilan.
