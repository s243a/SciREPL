Belajar sambil praktik

Buat buku kerja pertama Anda

Ini adalah pendamping praktis yang lebih panjang untuk referensi antarmuka (Halaman referensi bahasa Inggris). Anda akan menjalankan satu sel Python, mengubahnya, dan menyimpan salinan yang Anda kendalikan. Tidak diperlukan akun AI atau kunci API.

  • Free + Pro
  • Langkah-langkah Android
  • Sekitar 5 menit

Tangkapan layar menampilkan SciREPL Free v1.3.2 pada ponsel Samsung Galaxy seri S24. Pelajaran ini juga berlaku untuk Pro, meskipun beberapa kontrol di sana mungkin terlihat berbeda.

Dalam pelajaran ini
  1. Temukan tempat Anda
  2. Tulis dan jalankan sel
  3. Edit sel yang tersimpan
  4. Ekspor salinan buku kerja
  5. Hal berikutnya untuk dicoba

Semua tutorial

Langkah 1

Temukan tempat Anda di aplikasi

Baris teratas adalah header. Ini mencakup Menu, Bantuan, dan lencana status. Pemilih buku kerja menentukan buku kerja mana yang terbuka.

Panel sel baru adalah tempat Anda mengetik sel berikutnya. Tombol tajuk opsional dapat menghilang saat layar sempit; tindakannya tetap tersedia dari Menu atau Bantuan jika berlaku.

Langkah 2

Tulis dan jalankan sel Python

Tunggu hingga lencana status bertuliskan siap sebelum penjalanan pertama.

  1. Di panel sel baru, pilih Python dari pemilih bahasa. Pada ponsel yang sempit, pemilih yang tertutup mungkin hanya menampilkan Py.
  2. Ketik program pendek ini: 
    print("Hello from SciREPL")
  3. Ketuk Jalankan. Sel yang tersimpan akan muncul di buku kerja. Di bawahnya, Anda akan melihat Hello from SciREPL.

Penjalanan pertama mungkin memerlukan waktu lebih lama. Runtime Python harus dimulai satu kali. Tunggu hingga status kembali ke siap; sel Python berikutnya biasanya menggunakan kembali runtime tersebut.

Jika pemberitahuan privasi muncul: Python biasanya dibundel, jadi contoh ini seharusnya tidak memerlukan pengunduhan runtime. Runtime jaringan, seperti R atau Lua di Free, mungkin akan menampilkan Kebijakan Privasi SciREPL terlebih dahulu; Python juga dapat menampilkannya jika salinan yang dibundel memerlukan cadangan jaringan. Baca kebijakan tersebut, gulir di dalam dialog ke bagian bawah, dan ketuk Saya Mengerti jika Anda setuju. Perintah Pengunduhan Runtime terpisah kemudian mungkin meminta Anda untuk mengetuk Unduh.

Lihat contoh dialog Kebijakan Privasi (Halaman referensi bahasa Inggris) (tangkapan layar menunjukkan bagian atasnya; tombol berada lebih jauh di bawah). Di Free 1.4.0 dan Pro 1.4.0, perintah %pip install yang valid juga membuka pemberitahuan ini jika Anda belum menerima pengungkapan jaringan saat ini, sebelum mencoba menginstal paket. Lihat privasi dan data lokal (Halaman referensi bahasa Inggris) sebelum menggunakan fitur jaringan.

Langkah 3

Edit sel yang tersimpan

  1. Ketuk pensil ✎ di tajuk sel yang tersimpan itu sendiri, di kanan atas tepat di sebelah kiri ✕. Ini akan membuka sel tersebut untuk diedit; mengetik di panel sel baru akan membuat sel lain.
  2. Ubah Hello from SciREPL menjadi Hello again.
  3. Pilih Jalankan untuk menyimpan dan menjalankan perubahan. Anda sekarang akan melihat Hello again di bawah sel tersebut.

Pintasan Pro: Pada layar sentuh, ketuk dua kali kode sel yang tersimpan untuk mengeditnya. Free saat ini menggunakan tombol ✎.

Jika Anda tidak sengaja membuka editor, gunakan Batal untuk menutupnya tanpa menjalankan. Pemilih bahasa di dalam sel tersimpan akan mengubah sel tersebut; pemilih sel baru tidak.

Langkah 4

Ekspor salinan buku kerja

  1. Buka Menu → Ekspor buku kerja & paket.
  2. Pilih Hanya tab saat ini atau Semua tab, lalu format SciREPL Buku kerja (.srwb) saat Anda ingin mempertahankan status khusus SciREPL.
  3. Ketuk Ekspor dan pilih tujuan yang Anda kendalikan.

Mengapa mengekspor? SciREPL memulihkan sesi lokal, tetapi penyimpanan lokal bukan cadangan dan tidak dibagikan secara otomatis antara aplikasi Android dan browser. Lihat berkas dan ekspor (Halaman referensi bahasa Inggris) untuk format lain, termasuk .ipynb dan PDF.

Langkah 5

Hal yang dapat dicoba berikutnya

Coba 2 + 2 di sel Python lain. Lalu gunakan pemilih buku kerja untuk beralih tab. Panduan buku kerja CSV dimulai dari Menu → Jelajahi paket, bundel & buku kerja, memasang contoh, dan menunjukkan cara sel-selnya bekerja dengan berkas lokal.

Panduan Markov Groups menunjukkan cara mencari katalog yang lebih luas, membuka buku kerja yang ada tentang gerakan kubus, menjalankan sel-selnya secara berurutan, dan mengubah satu parameter.

Untuk pengingat cepat tentang letak kontrol, kembali ke referensi antarmuka (Halaman referensi bahasa Inggris). Untuk mempelajari bahasa lain atau menambahkan paket, lanjutkan dengan Bahasa & paket (Halaman referensi bahasa Inggris).

Menggunakan Pro? Alur kerja dasarnya sama. Pro juga memiliki editor layar penuh dan fitur AI opsional; lihat Alur kerja AI dan layar penuh Pro (Halaman referensi bahasa Inggris) setelah Anda terbiasa dengan sel biasa.
