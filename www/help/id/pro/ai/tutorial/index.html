Dari saran offline hingga pengodean berbantuan AI

Mulailah dengan saran berbasis tabel cepat yang tidak memungut biaya per permintaan. Kemudian siapkan Asisten, minta alternatif online, coba model di perangkat, dan akhiri dengan sel AI Prompt terfokus yang menjelaskan kode Anda.

  • Hanya Pro
  • Pro 1.4.0 + kontrol eksekusi mendatang
  • Model lokal: Android

Sebagian besar tangkapan layar menampilkan aplikasi Android; beberapa merupakan tangkapan browser. Tata letak dapat bervariasi bergantung pada versi aplikasi Anda.

Periksa versi Anda. Perubahan eksekusi dalam lampiran direncanakan untuk usulan Pro 1.5.0, yang belum dirilis; nomor rilis final dapat berubah.

“Free” di sini berarti tanpa biaya API. Saran tabel dan model di perangkat tidak menagih penyedia. Hal itu tidak menjadikannya fitur edisi Free: panduan langkah demi langkah ini ditujukan untuk SciREPL Pro. Permintaan online menggunakan akun penyedia Anda sendiri dan dapat memerlukan biaya.

Dalam pelajaran ini
  1. Mulai dengan saran tabel offline
  2. Simpan kunci API
  3. Bangun contoh kecil dengan preset agen Open
  4. Minta penyelesaian berbasis API
  5. Coba model di perangkat
  6. Gunakan sel AI Prompt untuk memahami kode

Langkah 1 · Kunci API tidak diperlukan

Mulai dengan saran tabel offline

Temukan ☰ Menu di header aplikasi: ini adalah tombol dengan tiga garis horizontal. Buka Pelengkapan. Pemilih Bagian di dalamnya memisahkan Umum, Saran AI (online), dan Model lokal (di perangkat). Mulailah dengan General.

  1. Atur Pelengkapan kode lokal → Aktif. Jika tidak, default Otomatis (aktif di desktop, nonaktif di layar sentuh) akan membiarkannya nonaktif di ponsel.
  2. Atur Chip saran → Aktif dan pertahankan Saran → Di posisi kursor. Untuk mengisolasi tabel, atur Saran AI → Nonaktif di bagian online dan Gunakan model lokal → Nonaktif di bagian lokal, jika salah satunya sebelumnya telah diaktifkan. Kembali ke General.
  1. Tutup Completion. Dalam buku kerja latihan baru, pilih sel kode dan bahasa JavaScript. Ketik cons, dengan tanda sisip di bagian akhir dan tanpa pilihan teks. Huruf-huruf awal dari const ini disebut prefiks. Perhatikan const.
  2. Pada tangkapan layar di bawah ini, cons diikuti oleh t samar—teks bayangan inline. Ketuk Terima atau tekan Tab untuk menyisipkan saran, menghasilkan const. Jika chip const yang muncul, mengetuknya adalah cara lain untuk menerima kandidat tersebut. Selesaikan sendiri baris tersebut, misalnya const values = [12, 15, 18];.

Accept bukanlah Run. Menerima saran akan mengedit kode sumber; tindakan ini tidak mengeksekusi sel. Contoh JavaScript dan Python di bagian ini mendemonstrasikan pelengkapan otomatis saat mengedit. Menjalankan sel latihan ini bukan bagian dari bagian ini. Dengan hanya lapisan tabel offline yang diaktifkan, mengetikkan prefiks tidak akan mengirimkan permintaan API atau memulai runtime bahasa hanya untuk membuat saran.

Prefetch online di masa mendatang: mode keikutsertaan (opt-in) direncanakan dapat mengirimkan permintaan model saat Anda mengetik. Fitur ini belum tersedia, dan belum ada nomor rilis yang ditetapkan untuknya. Pernyataan tanpa permintaan di atas menjelaskan lapisan tabel offline saat ini, bukan mode masa mendatang ini.

Lihat dua tampilan offline di ponsel. Biarkan Chip saran → Aktif, pilih Python, dan ketik pri. nt samar setelah tanda sisip menawarkan print; itu bukan bagian dari sumber Anda sampai Anda menerimanya. Anda tidak perlu menonaktifkan chip untuk melihat teks bayangan. Kandidat tunggal dapat muncul sebagai teks bayangan, sedangkan chip menawarkan pilihan saat beberapa kandidat cocok. Tetap nonaktifkan Saran AI dan Gunakan model lokal untuk kedua contoh.

Dengan chip yang masih Aktif, ganti input latihan dengan tiga baris ini, dengan membiarkan tanda sisip berada setelah sample_m yang belum selesai. Baris tersebut menawarkan sample_mean dan sample_median dari nama-nama dalam kode sumber Anda sendiri. Ketuk chip untuk memilih kandidat; tidak seperti teks bayangan, baris ini menampilkan alternatif.

sample_mean = 0
sample_median = 0
sample_m

Baris tombol tambahan yang terlihat pada gambar ponsel Python dan warna sintaks saat mengetik adalah kontrol Pro opsional yang terpisah. Lihat Panduan tampilan: tombol tambahan dan warna sintaks untuk mengaktifkan atau menonaktifkan salah satunya, serta menemukan kotak centang penyorotan terpisah pada editor file.

Setelah mencoba tampilan penyelesaian ini, beralihlah kembali ke JavaScript dan biarkan chip tetap aktif untuk sisa pelajaran ini.

Chip offline yang ditampilkan di sini, yang diaktifkan di bawah Pelengkapan → Umum → Chip saran, menggabungkan tabel nama yang dikurasi dengan informasi kode lokal. Pada Python, hal tersebut mencakup variabel dan fungsi yang ditemukan dalam kode buku kerja serta nama kernel dan atribut objek yang di-cache, termasuk metode. Frekuensi dan riwayat penerimaan membantu menentukan peringkatnya. Bahasa lain memiliki cakupan berbeda: daftar statis, definisi yang belum dijalankan, atau snapshot usang mungkin menyarankan nama yang saat ini tidak tersedia dalam cakupan. Penyelesaian berbasis tabel bukanlah model bahasa dan tidak melakukan penalaran tentang tugas Anda.

Hanya di akhir sel merupakan alternatif jika saran di tengah sel mengganggu Anda. Pilihan teks, string, komentar, atau nama yang terpotong mungkin sengaja tidak menghasilkan saran. Dalam orientasi lanskap pendek, baris opsional dapat menghilang untuk menyisakan ruang bagi kode; lihat Pengaturan tampilan.

Langkah 2 · Penyiapan online

Simpan kunci API

Kunci API memungkinkan SciREPL menggunakan akun penyedia yang Anda kontrol. Dapatkan kunci dari penyedia tersebut, periksa harga saat ini dan batas akunnya, serta gunakan hanya buku kerja latihan kecil dengan data non-pribadi untuk pelajaran ini.

  1. Buka Menu → 🤖 AI Assistant (Pro). Ketuk ⚙ roda gigi pada panel untuk membuka AI Settings.

    Tidak melihat roda gigi tersebut? Keyboard dapat menggeser atau menggulir panel Asisten. Seret konten panel ke bawah untuk menggulir kembali ke arah atas dan menampilkan roda gigi; menutup keyboard juga dapat memberi Anda lebih banyak ruang.

  2. Atur Atur model untuk → Asisten AI. Pilih Backend (mis. OpenRouter) dan Model, lalu periksa endpoint jika backend Anda menggunakan endpoint yang dapat dikonfigurasi.
  3. Masukkan Kunci API yang cocok. Gunakan Kunci tersimpan untuk mengelola kunci bagi pasangan penyedia/endpoint lainnya. Kunci untuk satu tujuan tidak secara otomatis menjadi kunci untuk tujuan lain.
  4. Ketuk Simpan. Menyimpan pengaturan saja tidak akan membuat permintaan model. Biarkan panel tetap terbuka untuk langkah berikutnya.

Jauhkan kunci dari buku kerja. Jangan menempelkannya ke dalam sel, prompt, tangkapan layar, atau file yang diekspor. Kunci yang disimpan tetap berada di penyimpanan lokal aplikasi/browser, tanpa enkripsi tingkat aplikasi; lindungi perangkat dan jangan menjalankan kode yang tidak tepercaya. Kebijakan privasi Pro menjelaskan apa yang disimpan dan dikirimkan.

Model berbiaya rendah dan berkemampuan alat (tool-capable) adalah titik awal yang tepat untuk Asisten. Contoh yang dapat dibandingkan mencakup GLM 5.3 Flash, GPT-6 Luna, Claude Haiku 5.5, dan DeepSeek V4 Flash. ID model yang tepat, versi yang tersedia, dukungan alat, dan harga bergantung pada versi aplikasi dan penyedia Anda; periksa pemilih saat ini dan dokumentasi penyedia. Model yang baru diumumkan mungkin memerlukan pembaruan aplikasi sebelum muncul. Nantinya, Anda dapat memilih model terjangkau lainnya khusus untuk penyelesaian.

Model tidak ada dalam daftar? Di Pengaturan AI → Atur model untuk → Asisten AI, pilih Backend yang benar terlebih dahulu, lalu masukkan ID model API persis dari penyedia di Atau masukkan ID model khusus, di bawah pemilih Model, dan ketuk Simpan. Bidang ini sudah tersedia di Pro 1.4.0.

Verifikasi ID dengan penyedia yang Anda pilih, bukan hanya nama pemasaran model tersebut. Untuk OpenRouter, sertakan prefiks organisasi—misalnya, anthropic/claude-haiku-5.5 pada halaman modelnya. Masukkan ID tersebut, bukan URL halaman tersebut. ID kustom lebih diutamakan daripada menu drop-down; memilih model yang terdaftar lagi akan mengosongkan bidang kustom.

ID tidak menambahkan dukungan API. Model harus mendukung panggilan alat melalui API yang digunakan SciREPL. Periksa akses penyedia, kompatibilitas, dan harga saat ini; penyimpanan tidak memvalidasinya atau membuat permintaan model.

Langkah 3 · Penggunaan alat yang disengaja

Bangun contoh kecil dengan preset agen Open

Terbuka adalah preset keamanan paling permisif kedua, setelah Kontrol penuh. Secara default, preset ini mengizinkan pengeditan buku catatan, dengan lebih sedikit konfirmasi dibandingkan Cautious. Apakah eksekusi meminta izin bergantung pada versi dan pengaturan izin Anda; lihat lampiran persetujuan eksekusi mendatang. Gunakan secara sengaja dalam buku kerja latihan—bukan sebagai persyaratan untuk pelengkapan otomatis.

  1. Di AI Settings, pilih Tingkat Keamanan → Open dan Penulisan agen → Lembar kerja aktif. Biarkan penelusuran sumber nonaktif dan nonaktifkan Jalankan otomatis sel yang dibuat oleh AI. Di bawah Kernel…, atur JavaScript → Tanya, lalu simpan. Aturan kernel ini tetap meminta konfirmasi meskipun Allow pada alat eksekusi telah disimpan sebelumnya.

    Auto-run nonaktif bukanlah penguncian eksekusi. Ini menghentikan sel yang baru dibuat agar tidak berjalan secara otomatis; ini tidak menonaktifkan permintaan execute_cell atau run_cells terpisah. Default Open pada Pro 1.4.0 yang telah dirilis dapat mengizinkannya tanpa bertanya. Default Open mendatang akan meminta konfirmasi, tetapi Allow eksplisit pada alat atau kernel dapat mengubah default tersebut. Pengaturan AI → Kernel… → JavaScript → Tanya menjaga eksekusi JavaScript pada latihan ini tetap memerlukan konfirmasi. Tindakan Run sel secara manual oleh Anda sendiri tetap merupakan tindakan terpisah. Kontrol eksekusi rilis berikutnya dirinci dalam lampiran.

    Jika Anda menginginkan lebih banyak konfirmasi, gunakan Hati-hati sebagai gantinya. Open tetap mematuhi kontrol penelusuran sumber dan cakupan penulisan terpisah; Full control mengabaikan kedua kontrol kasar tersebut. Izin individual dan gerbang keamanan lainnya tetap penting. Peninjauan adalah pembatasan tambahan yang sebagian besar hanya-baca, yang akan menghambat demonstrasi pembuatan sel ini.

    Apa yang dilindungi—dan tidak dilindungi—oleh sandbox browser

    Eksekusi buku kerja normal berjalan di browser/WebView dan runtime bahasanya, dengan sistem file virtual alih-alih akses tanpa batas ke file ponsel Anda. Itu adalah batasan yang berguna, bukan jaminan bahwa kode tidak dapat membahayakan. JavaScript yang diizinkan dan jembatan ke sana dapat menjangkau data aplikasi dan kredensial yang disimpan; pembatasan jaringan bersifat best-effort setelah kode yang diizinkan dimulai, bukan batasan isolasi yang harus Anda percayai untuk menyimpan rahasia. Konfirmasi eksekusi mendatang menambahkan langkah persetujuan, bukan isolasi dari data aplikasi. Gunakan buku kerja latihan dan pastikan isinya bersifat non-pribadi.

    Terminal Remote/MCP berbeda: fitur ini dapat mengekspos shell sungguhan pada host broker, di luar sandbox lokal browser. Tetap nonaktifkan Remote dan Terminal di sini. Lihat Remote dan keamanan (Halaman referensi bahasa Inggris) sebelum mengaktifkannya. Kalimat sopan “jangan…” dalam prompt bukanlah kontrol keamanan.

  2. Di panel Asisten, pilih Buku kerja ini. Biarkan Review, Remote, dan Terminal nonaktif untuk contoh penyedia langsung ini.
  3. Kirim prompt latihan pada callout di bawah ini. Tombol Kirim pada panel sudah memulai perulangan alat agen: tidak ada tombol pengalih “Mode agen” tambahan di sini. Tombol Agen pada editor layar penuh merupakan alur kerja terpisah.

    Salin prompt ini. Tempelkan ke dalam kotak pesan Asisten, bukan sel kode, lalu ketuk Kirim.

    Dalam buku kerja latihan ini, tambahkan penjelasan Markdown yang diikuti
oleh satu sel JavaScript bernama summary_demo. Buat array input
berisi 10 bilangan bulat pseudorandom dari 1 hingga 20 inklusif.

  4. Baca penjelasan yang diusulkan dan sel summary_demo yang baru. Periksa apakah kode tersebut membuat input menggunakan aturan yang disebutkan dan menghitung ringkasan dari array tersebut. Jalankan sendiri sel tersebut, lalu bandingkan dengan pemeriksaan di bawah. Hasil yang diharapkan adalah jumlah 10, rata-rata 9.3, minimum 1, maksimum 20.

Periksa input serta ringkasannya

Seed mengunci urutan tersebut, sehingga input yang tampak acak ini dapat direproduksi. Dengan aturan pembaruan-sebelum-penarikan di atas, hasil yang diharapkan:

Input: [1, 11, 15, 6, 8, 4, 20, 11, 11, 6]
Count: 10
Mean: 9.3
Minimum: 1
Maximum: 20

Label output mungkin berbeda, tetapi angka-angkanya harus cocok. Menjalankan sel lagi akan menghasilkan input dan ringkasan yang sama. Seed yang berbeda mengubah latihan ini; generator kecil ini ditujukan untuk demonstrasi yang dapat direproduksi, bukan keacakan yang sensitif terhadap keamanan.

Sebelum Send: Asisten menyertakan percakapan yang dipilih dan pratinjau terbatas dari sel buku kerja saat ini (hingga 500 karakter pertama dari setiap sel, ditambah metadata). Alat yang diizinkan dapat mengirim lebih banyak. Menonaktifkan penelusuran sumber tidak menghentikan pratinjau buku kerja untuk dikirimkan. Hal itu berbeda dari muatan sel saat ini yang lebih kecil yang digunakan oleh penyelesaian di bawah. Perubahan konteks buku kerja yang direncanakan dijelaskan dalam lampiran.

Dijeda dengan tombol Continue? Batas agen (per eksekusi) → Langkah maks, yang disorot di bawah, mengontrol batas alokasi langkah untuk satu kali proses berbatas (bounded run). Agen mungkin mencapai batas tersebut sebelum selesai. Baca apa yang telah dilakukannya, lalu tekan Lanjutkan jika tugas belum selesai dan Anda menginginkan proses berbatas lainnya. Melanjutkan dapat menimbulkan lebih banyak biaya API; tindakan ini tidak diperlukan setelah Selesai.

Langkah 4 · Minta alternatif kapan pun Anda menginginkannya

Minta penyelesaian berbasis API

  1. Buka Menu → Pelengkapan, lalu pilih Bagian → Saran AI (online). Atur Saran AI → Saat diketuk.
  2. Pertahankan Model pelengkapan → Ikuti Asisten AI untuk mewarisi penyedia, endpoint, dan modelnya. Atau pilih Pilih penyedia dan model, pilih penyedia/endpoint yang disimpan dan model berbiaya rendah yang cocok untuk saran singkat. Tidak ada kunci yang dimasukkan pada layar ini; Buka Pengaturan AI memungkinkan Anda menambahkannya terlebih dahulu.
  3. Buka Lanjutan bagian ini untuk memeriksa batas waktu (timeout) balasan dan pengaman pengeluaran. Pengaturan default-nya adalah 6 detik, $0.25/hari, dan $5/bulan. Periksa harga sebelum menaikkannya.
  4. Kembali ke editor JavaScript dan masukkan cuplikan latihan ini: 
    const values = [12, 15, 18];
const average =
    Biarkan tanda sisip berada setelah baris const average = yang belum selesai. Ketuk … di akhir baris saran, gunakan tombol tambahan …AI, atau tekan Ctrl + Shift + Space.
  5. Tinjau muatan (payload) dan tujuan sebenarnya dari permintaan pertama sebelum mengirimkannya. Chip AI memiliki penanda ✦. Ketuk salah satu untuk menerimanya; chip yang terpotong atau multi-baris akan membuka pratinjau terlebih dahulu. Tinjau kode sumber yang dihasilkan sebelum Run.

Pilih kodenya, bukan hanya chip AI. Dalam permintaan ini, chip pertama mengusulkan values.reduce((a, b) => a + b, 0) / values.length;. Ketuk untuk memeriksa pratinjau lengkap: kode ini menjumlahkan array dan membaginya dengan panjangnya, menghasilkan 15 untuk contoh ini. Chip kedua mengusulkan eval(values.join(' + ')) / values.length;. Tolak alternatif eval yang tidak perlu tersebut: menghitung rata-rata tidak perlu mengubah string menjadi kode yang dapat dieksekusi. Periksa sendiri kode yang dikembalikan sebelum menerimanya, dan jalankan (Run) hanya setelah ditinjau.

Permintaan tersebut meminta hingga lima alternatif, tetapi layar Anda mungkin hanya memuat lebih sedikit. Ketukan berikutnya pertama-tama akan membuka halaman alternatif yang telah diterima; setelah semuanya habis, fitur ini dapat meminta lebih banyak. Ketuk saat permintaan sedang berputar untuk membatalkannya. Balasan yang datang terlambat akan dibuang saat waktu tunggu (timeout) habis, dan mengetik atau memindahkan tanda sisip akan membuat saran lama menjadi usang.

Independen berarti independen: pilihan penyelesaian yang terpisah akan tetap terpisah saat Anda mengubah model Asisten. Ini berguna saat Anda menginginkan agen yang andal tetapi pelengkapan otomatis yang murah. Mengikuti Asisten akan mewarisi identitasnya, bukan percakapan atau izin agennya.

Ketahui apa yang Anda bayar dan kirimkan

Penyelesaian online bersifat on demand (sesuai permintaan): pengetikan biasa tidak mengirimkan apa pun. Prefetch saat saya mengetik belum tersedia dalam alur kerja ini. Penyelesaian mengirimkan konteks sel saat ini yang dibatasi: paling banyak 1,500 karakter sebelum tanda sisip, 200 setelahnya, dan hingga 12 nama lokal—bukan obrolan Asisten atau seluruh buku kerja. Penyamaran rahasia bersifat best-effort, jadi tinjau sendiri muatannya.

Selalu izinkan memberikan persetujuan tetap untuk tujuan tersebut; perubahan penyedia, endpoint, atau model akan meminta persetujuan lagi. Kirim tanpa bertanya pada awalnya mengaktifkan pilihan tersebut tetapi tetap menampilkan muatan nyata pertama sekali. Pertahankan Tanyakan setiap kali saat sedang mempelajari fitur ini.

Jumlah harian/bulanan adalah pengaman pengeluaran fleksibel (soft spending guards) khusus penyelesaian, bukan batas penagihan penyedia yang dijamin dan bukan anggaran untuk permintaan Asisten atau AI Prompt. Kegagalan dan pembatalan dapat mempertahankan biaya yang dicadangkan. Menghapus riwayat pengeluaran tidak menyetel ulang total batas. Model tanpa harga yang tercantum memerlukan batas harga input/output eksplisit, atau aplikasi akan menolak untuk mengirimkan permintaan.

Langkah 5 · Unduhan Android opsional

Coba model di perangkat

Model opsional Qwen2.5-Coder 0.5B menyarankan kode secara lokal saat tabel tidak yakin. Ini adalah model pelengkapan kode kecil, bukan pengganti agen percakapan. Setelah diinstal, inferensi tidak mengirimkan kode yang diketik ke penyedia dan tidak dikenai biaya API.

  1. Pada ponsel Android yang memenuhi syarat dengan Pro terinstal dari Google Play, buka Menu → Pelengkapan → Bagian → Model lokal (di perangkat).
  2. Ketuk Instal dan berikan waktu serta penyimpanan untuk unduhan sekitar 400 MB. Penginstalan sideload saat ini tidak dapat mengunduh model melalui alur ini.
  3. Jika sudah siap, pertahankan Gunakan model lokal → Saat tidak yakin. Tabel menjawab kasus-kasus mudah; model berkontribusi saat tabel ragu. Selalu menjalankannya lebih sering; Nonaktif menghentikannya tanpa menghapus hasil unduhan.
  1. Kembali ke sel kode dan jeda pada nama atau baris yang belum selesai. Hasil bervariasi bergantung pada konteks; tidak setiap jeda menghasilkan saran. Terima teks bayangan atau chip yang sesuai, periksa kode sumber, lalu jalankan (Run) secara terpisah.

Ponsel mana yang nyaman digunakan?

Kelayakan minimum adalah Android ARM 64-bit dengan setidaknya 4 GB RAM, bukan jaminan performa yang mulus. Ponsel kelas Galaxy S24+ adalah target kenyamanan praktis: Samsung mencantumkan 12 GB RAM untuk S24+, memberikan ruang lebih luas bagi aplikasi, kernel, dan model. Ini adalah tingkat performa yang disarankan, bukan keharusan untuk membeli model tersebut. Spesifikasi seri S24 Samsung.

Sebuah Galaxy S10+ memiliki varian 8 GB atau 12 GB yang memenuhi syarat. Pengalaman informal pengelola menunjukkan bahwa penyelesaian lokal dapat berfungsi di sana tetapi terasa lebih lambat dibandingkan penyelesaian API; perbandingannya bergantung pada model dan jaringan. Tolok ukur engine lokal yang dicatat tidak mengukur S10+, jadi ini bukan perbandingan kecepatan terukur atau jaminan untuk setiap perangkat. Waspadai jeda (lag) atau aplikasi yang tidak responsif saat menggabungkan model dengan buku kerja besar dan kernel yang boros memori. Spesifikasi seri S10 Samsung.

Pengujian engine bawaan kelas S24+ sebelumnya mengukur median kata pertama saat warm sekitar 0.10 detik dan median kata pertama saat cold sekitar 0.24 detik, setelah pemuatan. Ini adalah contoh hasil tolok ukur, bukan jaminan: pemuatan awal tanpa cache memerlukan waktu beberapa detik. Model yang dimuat menambahkan sekitar 460–490 MB memori proses aplikasi, sebagai tambahan dari WebView, runtime Python/R, dan sistem operasi.

Jika ponsel lama menjadi lambat: atur Gunakan model lokal → Nonaktif dan gunakan tabel atau alternatif API saat diketuk sebagai gantinya. Di bawah Lanjutan lokal, menyetel Keep loaded after leaving the app → 0 akan melepaskannya saat Anda keluar; kontrol idle-unload dan baterai lemah juga membantu. Simpan/ekspor buku kerja Anda sebelum memecahkan masalah. Model tanpa biaya API tetap menggunakan penyimpanan, memori, dan baterai.

Langkah 6 · Pahami kode saat Anda membangunnya

Akhiri dengan sel AI Prompt yang terfokus

Asisten berguna untuk pekerjaan multi-langkah. Sel AI Prompt lebih baik untuk pertanyaan kecil dan dapat diulang tentang bagian kode tertentu: sel ini membuat satu permintaan terisolasi, tanpa riwayat Asisten atau alat. Gunakan sel ini untuk menanyakan mengapa suatu perhitungan berhasil sebelum mengembangkannya.

Di sini kita kembali ke Langkah 3 untuk sel summary_demo acak dengan seed. Kita meminta penjelasan tentang perhitungan yang sudah ada tersebut—bukan array acak lainnya, dan bukan contoh penyelesaian khusus-rata-rata dari Langkah 4.

  1. Tambahkan sel AI Prompt tepat setelah Langkah 3 pada sel summary_demo JavaScript—bukan cuplikan khusus-rata-rata dari Langkah 4—sehingga pertanyaan di bawah cocok dengan sumber yang dipilih. Pertahankan tipe sel sebagai kode, lalu pilih AI Prompt dari menu drop-down bahasa/mode. Jika tidak ada, aktifkan di bawah Menu → Bahasa dan mode.
  2. Tempelkan prompt di bawah ini ke dalam sel AI Prompt, bukan kotak pesan Asisten. Buka kontrol Konfigurasi miliknya. 
    Jelaskan sel JavaScript yang dipilih baris demi baris.
Bagaimana aturan generator dan seed 42 menentukan array inputnya?
Mengapa kode tersebut melaporkan jumlah 10, rata-rata 9.3, minimum 1, dan maksimum 20?
Mengapa menyetel ulang seed membuat hasilnya dapat diulang?
Jelaskan apa yang perlu diubah untuk array kosong.
Kembalikan penjelasan singkat saja; jangan menulis ulang kodenya.
  3. Atur Tempatkan respons akhir di → Output sel ini, yaitu default-nya. Di bawah Konteks untuk dikirim → Sertakan sumber dari, pilih Sel 1 sebelumnya. Hapus centang pada Sertakan teks output yang disimpan untuk latihan khusus sumber ini. Pastikan bahwa Pratinjau konteks mencantumkan nama summary_demo, lalu gulir ke bawah dan ketuk Simpan konfigurasi.
  4. Ketuk Jalankan pada sel AI Prompt. Periksa konteks yang dipilih dalam tinjauan, lalu pilih Kirim ke penyedia AI. Baca penjelasan di samping kode sumber dan bandingkan dengan hasil yang diketahui.

Cara untuk mengontrol biaya API dan meningkatkan pemahaman. AI Prompt yang terfokus dapat mengirimkan konteks yang lebih sedikit daripada percakapan agen yang terus berkembang serta menghindari loop alat multi-langkah, sehingga mengurangi token input dan berpotensi menurunkan tagihan. Mintalah penalaran yang ringkas, asumsi, dan output yang diharapkan saat Anda menulis kode. Penghematan tidak dijamin: tarif model, panjang respons, token penalaran, dan konteks yang Anda pilih tetap berpengaruh. Permintaan ini menggunakan penyedia/model Asisten, bukan model penyelesaian independen, dan berada di luar pengaman pengeluaran penyelesaian.

Contoh lain · Tinjau plot sebelum mengganti sel

Sekarang mintalah AI Prompt untuk menulis kode ke dalam sel yang berbeda, dengan tinjauan sebelum apa pun diganti. Kita akan membuat plot bagaimana estimasi varians berubah di banyak sampel kecil. Ini adalah sampel normal baru—bukan array bilangan bulat summary_demo sebelumnya. Tujuannya adalah untuk mempelajari Konfigurasikan → pratinjau → Terapkan → Jalankan, bukan untuk menguasai statistiknya.

Varians bukanlah t-Student. Untuk sampel normal independen berukuran 10, 9s² / σ² mengikuti distribusi chi-kuadrat dengan derajat kebebasan 9. Di sini varians sebenarnya σ² = 1. Sedangkan t-Student menjelaskan rata-rata sampel terstandardisasi (mean − μ) / (s / √10), menggunakan estimasi deviasi standar s; ini juga memiliki derajat kebebasan 9 di sini. NIST: varians · NIST: rata-rata.

  1. Dalam buku kerja latihan, buat sel JavaScript yang berisi // Reviewed plot code will go here. Jalankan komentar yang tidak berbahaya tersebut untuk menyimpan sel. Tekan lama pada label In[…] miliknya dan beri nama variance_plot. Pertahankan nama tersebut agar tetap unik di buku kerja; lihat penamaan sel.
  2. Tambahkan sel AI Prompt terpisah dan tempelkan permintaan ini ke dalamnya: 
    Kembalikan hanya kode sumber JavaScript lengkap, tanpa pembatas Markdown.
Buat histogram yang dapat direproduksi dari estimasi varians sampel.
Simulasikan 2,000 sampel baru, masing-masing berisi 10 nilai N(0,1) normal-standar.
Jangan gunakan kembali array bilangan bulat sebelumnya dari summary_demo.
Inisialisasi state = 42 sekali untuk seluruh proses, bukan per sampel. Sebelum setiap penarikan seragam, tetapkan state = (16807 * state) % 2147483647, lalu u = state / 2147483647.
Untuk setiap penarikan normal gunakan dua bilangan seragam berturut-turut: sqrt(-2 * log(u1)) * cos(2 * PI * u2). Jangan gunakan kembali hasil sinus cadangan atau menggunakan Math.random.
Untuk setiap sampel, hitung rata-ratanya, lalu varians tidak bias sum((x - mean)^2) / 9.
Gambarlah histogram canvas berlabel dengan 40 bin dengan lebar yang sama dari 0 hingga 4. Sumbu horizontal adalah estimasi varians; sumbu vertikal adalah jumlah sampel.
Tandai varians populasi sebenarnya 1 dengan garis vertikal berlabel. Gunakan latar belakang terang, teks gelap, dan label yang mudah dibaca.
Cetak ukuran sampel, pengulangan, seed, rata-rata estimasi varians, total histogram, dan jumlah luapan apa pun. Hitung luapan secara terpisah alih-alih menyembunyikannya.
Tampilkan canvas dengan window.renderImage(canvas.toDataURL("image/png")).
Jangan gunakan paket, jaringan, penyimpanan, atau pengeditan buku kerja apa pun.
  3. Buka bagian Konfigurasi pada AI Prompt. Atur Tempatkan respons akhir di → Pratinjau penggantian untuk sebuah sel, Bahasa sel hasil → Pertahankan bahasa target, Sel yang akan diganti → Sel bernama, dan Nama sel → variance_plot. Di bawah konteks, pertahankan Sertakan sumber dari → Tidak ada sel lain (default), lalu Simpan konfigurasi.
  4. Jalankan (Run) sel AI Prompt. Tinjau apa yang akan dikirim, lalu pilih Kirim ke penyedia AI. Opsi Tidak ada sel lain mengecualikan konteks buku kerja tambahan; penggantian tetap mengirimkan kode sumber lengkap dari sel target. Di sini, itu hanya komentar kami yang tidak berbahaya.
  5. Baca pratinjau Sebelum / Sesudah yang dikembalikan. Periksa JavaScript lengkap: seed 42, 2,000 sampel berukuran 10, varians dibagi 9, dan tidak ada jaringan atau penyimpanan yang tidak terduga. Pilih Terapkan penggantian hanya jika Anda menerima sumber tersebut; Batal membiarkan variance_plot tidak berubah. Menerapkan akan mengedit sel tujuan tetapi tidak menjalankannya.

  6. Peninjauan menemukan sedikit kelalaian. Respons model ini diakhiri dengan string laporan alih-alih mencetaknya. Setelah Apply, kami hanya mengedit laporan akhir tersebut menjadi console.log(…) sebelum Run. Periksa juga respons Anda: gambar saja tidak menunjukkan apakah totalnya benar. Baca kode sumber terkoreksi yang dijalankan.

    Temukan variance_plot dan ketuk tombol Run miliknya sendiri. Setiap bilah histogram menghitung estimasi varians sampel—bukan pengamatan individual. Dengan generator persis di atas, harapkan rata-rata estimasi varians mendekati 0.9852, total histogram sebesar 2,000, dan luapan 0. Varians sebenarnya adalah 1; simulasi berhingga tidak harus menghasilkan rata-rata tepat 1. Menjalankan ulang dari seed 42 akan mereproduksi plot yang sama.

Dua persetujuan terpisah: Kirim ke penyedia AI menyetujui pembagian permintaan yang ditinjau. Terapkan penggantian menyetujui pengeditan kode sumber target. Keduanya tidak menjalankan JavaScript yang diusulkan. Jangan pilih Sel baru yang tertaut untuk demonstrasi ini: opsi tersebut menyisipkan sel hasil yang belum dijalankan tanpa langkah persetujuan penggantian ini.

Tidak ada saran offline di ponsel
Pilih General → Local code completion → On alih-alih Auto. Periksa chip, posisi tanda sisip, bahasa, dan apakah baris opsional memiliki ruang.
Tidak ada permintaan online
Periksa On tap, kunci yang disimpan untuk penyedia/endpoint yang tepat, entri atau batas harga model yang dipilih, persetujuan, dan total pengeluaran. Open tidak diperlukan untuk penyelesaian. Konteks browser yang aman dan Web Locks diperlukan; konteks yang tidak didukung akan menolak permintaan.
Asisten meminta izin sebelum menjalankan sel—atau tidak meminta izin

Penyelesaian tidak memahami sel lain

Install tidak tersedia
Alur model lokal bawaan ditujukan untuk instalasi Android Google Play yang memenuhi syarat, bukan untuk desktop/browser atau distribusi sideload saat ini. Memenuhi batas minimum RAM tidak menjamin kecepatan.
Jawaban yang dihasilkan tampak masuk akal tetapi salah
Bandingkan dengan contoh-contoh kecil yang telah diketahui. Periksa impor, satuan, perilaku input kosong, dan efek samping sebelum menjalankan. Respons model bukanlah bukti kebenaran.

Lampiran · Persetujuan eksekusi mendatang · usulan Pro 1.5.0

Belum dirilis: kontrol-kontrol ini menjelaskan implementasi rilis berikutnya, bukan janji bahwa penginstalan 1.4.0 Anda memilikinya. Nomor rilis bersifat sementara.

  • Pengaturan AI → Keamanan… → execute_cell / run_cells sudah menawarkan Default / Allow / Ask / Deny. Pembaruan ini mengubah Default turunan dari Open menjadi Tanya; Full control tetap mempertahankan Allow. Aturan alat atau kernel eksplisit dapat menggantikan default turunan; jika keduanya eksplisit, aturan yang lebih aman yang akan berlaku. Biarkan Default atau Ask saat sedang belajar. Allow adalah pengabaian (override), bukan sandbox yang lebih kuat; Ask/Deny kernel, Review, dan penonaktifan JavaScript global tetap berlaku.
  • Baca permintaan eksekusi sebelum memilih Jalankan; biarkan Izinkan eksekusi sel Asisten di masa mendatang tanpa bertanya tidak dicentang untuk menyetujui permintaan itu saja. Mencentangnya akan mengubah aturan alat eksekusi bersama di semua buku kerja hingga disetel ulang—bukan hanya untuk sel, percakapan, atau penyedia ini. Aturan kernel Ask yang eksplisit akan menyembunyikan opsi tersebut.
  • Prompt inspeksi namespace dan sel yang baru dibuat tidak dapat membuat izin tetap tersebut. Prompt eksekusi sel yang baru dibuat menyertakan pratinjau kode yang dibatasi; pratinjau yang panjang diakhiri dengan elipsis. Jika terpotong, pilih Cancel, periksa kode sumber lengkap sel yang baru dibuat, dan jalankan (Run) sendiri hanya jika Anda memercayainya. Allow eksekusi yang disimpan sebelumnya masih dapat mengizinkan autorun sel yang dibuat saat Auto-run aktif, jadi tetap nonaktifkan Auto-run di sini.
  • Jika Anda memilih preset selain Full control saat Allow pada alat eksekusi yang disimpan tetap berlaku, peringatan akan menawarkan Atur ulang ke Bawaan, Pertahankan Izinkan, atau Batal. Reset akan memulihkan aturan alat dari preset yang dipilih tanpa menghapus pengabaian kernel. Keep mempertahankan pengabaian tersebut. Cancel memulihkan pilihan preset sebelumnya. Reset dan Keep tetap berupa perubahan draf hingga Anda menyimpan Pengaturan (Settings).

Persetujuan eksekusi bukanlah izin menyeluruh untuk membagikan data. Output alat eksekusi dapat dikembalikan ke model Asisten, dan kode yang diizinkan dapat menggunakan jaringan. Selalu izinkan pada penyelesaian online, peninjauan konteks AI Prompt, dan pengungkapan privasi Remote/MCP tetap terpisah. Eksekusi buku catatan MCP menggunakan pemeriksaan eksekusi yang sama; pemeriksaan tersebut tidak memasukkan shell Terminal broker ke dalam sandbox.

Lampiran · Konteks dan riwayat buku kerja yang direncanakan

Hanya proposal desain: fitur-fitur ini belum diimplementasikan atau ditetapkan ke suatu rilis. Fitur ini terpisah dari perubahan persetujuan eksekusi mendatang di atas dan tidak memblokir rilis saat ini.

  • Ambil ringkasan buku kerja saat diperlukan. Rencana ini menggantikan pratinjau sumber otomatis yang berulang dengan alat direktori khusus metadata: nama sel, deskripsi opsional, bahasa, dan tipe, ditambah revisi buku kerja. Alat yang diusulkan adalah list_cells dengan view: "metadata"; Asisten akan membaca kode sumber yang dipilih secara terpisah. Ini adalah gambaran umum berbatas, bukan penjelasan AI yang dibuat secara otomatis.
  • Lampirkan sekali alih-alih pada setiap Send. Kotak centang Attach workbook summary this time yang diusulkan dapat diawali dalam kondisi tercentang untuk percakapan baru dan tidak dicentang setelah lampiran tersebut benar-benar terkirim. Anda dapat menghapus centangnya sebelum mengirim atau mencentangnya lagi untuk gambaran umum baru. Pengaturan default awalnya masih memerlukan tinjauan privasi dan kegunaan. Kelanjutan percakapan tidak akan menambahkan ringkasan lain, dan beralih tab tidak akan mengaktifkannya kembali secara diam-diam. Pratinjau dan izin baca/privasi yang ada tetap berlaku; buku kerja yang besar mungkin memerlukan halaman lebih lanjut.
  • Tidak dicentang tidak menghapus riwayat. Tindakan ini akan menghentikan lampiran otomatis yang baru, bukan menghapus ringkasan yang sudah ada di percakapan atau mencegah pembacaan alat yang diizinkan. Kontrol konteks Agen layar penuh, AI Prompt, dan penyelesaian yang sudah ada akan tetap terpisah.
  • Perubahan antar-pengiriman adalah opsi di masa mendatang. Pembaruan ringkas akan memerlukan garis dasar konteks terkirim yang diketahui dan revisi yang andal. Pengeditan oleh manusia dapat disorot, tetapi pengeditan agen, impor, dan perubahan yang tidak diketahui juga penting. Pengeditan sumber tidak akan secara otomatis menulis ulang deskripsi sel; riwayat yang hilang atau usang akan memerlukan gambaran umum baru alih-alih pembaruan tebakan.
  • Riwayat lokal opsional dan sinkronisasi GitHub adalah ide jangka panjang Pro. Titik pemeriksaan (checkpoint) Send lokal dapat mendukung diff berbasis Git tanpa membagikan apa pun. Sinkronisasi independen dapat memublikasikan buku kerja ke Gist atau file yang dipilih di repositori, dengan pratinjau muatan dan otorisasi tersendiri. Mengaktifkan riwayat tidak akan melakukan push ke GitHub atau mengirimkan diff ke AI. Git menampilkan perubahan konten, bukan bukti bahwa manusialah yang membuatnya.

Gist rahasia tidak bersifat privat. Siapa pun yang memiliki URL-nya dapat membacanya; gunakan repositori privat saat akses harus dibatasi. Jauhkan rahasia dari kode sumber dan deskripsi buku kerja sebelum memublikasikannya. Dokumentasi visibilitas Gist GitHub.
