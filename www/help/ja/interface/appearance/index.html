インターフェースを自分好みにカスタマイズする

「ブラウズ」を表示して「外観」を調整する

📦 BrowseショートカットをSciREPL Freeのヘッダーに配置し、使いやすいボタンやライトまたはダークテーマを選択します。共有の外観設定はProでも役立ちます。全画面編集、追加キー、ライブ構文カラーリングについては、別のPro専用セクションで説明しています。これはワークブックのセルを変更したり実行したりすることなく行えます。

  • Free + Pro（ラベルを参照）
  • Androidのスクリーンショット
  • 約3分

五枚のスクリーンショットは、SciREPL Free 1.4.0-debugをSamsung Galaxy S24+で実行し、6日 十月 2026年に実際に撮影したものです。これらはPlay Storeからのインストールではなく、デバッグ署名されたアプリを示しています。図示されている手順ではFree 1.4.0のコントロールを使用しています。「ブラウズ」のヘッダーショートカットはFree専用です。Proのユーザーはメニューから同じカタログを開くことができます。以下のPro専用テキストはPro 1.4.0のコードベースと照合して検証されています。それらのコントロールはこれらのFreeの画像には図示されておらず、古いメニューでは異なる場合があります。

このレッスンで学ぶこと
  1. 「外観」を開く
  2. 「ブラウズ」ショートカットを表示する
  3. ボタンと「実行」を調整する
  4. Pro専用：全画面編集、追加キー、ライブカラー
  5. テーマを選択する
  6. 任意のAndroid用スペースと復元

すべてのチュートリアル

ステップ1

メニュー → 外観 を開く

  1. アプリ上部のヘッダーにある三本線のボタン、☰ Menuを見つけます。
  2. それをタップし、🎨 外観を選択します。メニューが画面に収まらない場合は、メニュー内をスクロールして項目を探してください。

変更は選択するとすぐに適用されます。以下の通常のコントロールには「保存」や「適用」ボタンは必要ありません。×で「外観」を閉じても変更はキャンセルされず、選択した内容は次回のアプリ起動時にも保持されます。

ステップ2

Free 1.4.0：📦「ブラウズ」ショートカットを表示

Proをご利用ですか？このショートカット設定はスキップして、メニュー → パッケージ、バンドル、ワークブックを参照を使用してください。以降のセクションでは共有の「外観」コントロールについて説明します。

  1. メニュー → 外観を開き、ヘッダーのショートカットまでスクロールします。
  2. 参照のショートカットを表示を見つけて常に表示を選択します。
  3. ×で「外観」を閉じます。ヘッダーに📦ボタンが表示されるので、タップしてパッケージ、バンドル、ワークブックを参照を開きます。

それぞれの選択肢には異なる目的があります：

  • 常に表示：ヘッダーが別の行を必要とする場合でも、ショートカットを表示したままにします。
  • スペースがある場合：「ブラウズ」のデフォルト設定です。収まる場合にのみ表示されます。画面が狭い場合やボタンが大きい場合、またはステータスメッセージが長い場合は非表示になることがあります。
  • 表示しない：ヘッダーショートカットを非表示にします。

↑および↓ボタンは、スペースが狭いときにどのオプションのショートカットが最初に場所を譲るかを変更します。ショートカットを上に移動すると長く保持され、下に移動すると早く非表示になります。これらはヘッダー内のアイコンの位置ではなく、優先度を変更します。

📦ボタンがありませんか？ショートカットが非表示になっている場合や、お使いのバージョンで提供されていない場合でも、メニューからの手順は機能します。コンパクトなヘッダーにするには、すべてのオプションのショートカットを強制的に表示し続けるのではなく、「ブラウズ」を余裕があるときに戻します。

ワークブックを見つけるためにここに来た場合は、ここでマルコフグループのウォークスルーに戻り、カタログを検索できます。

ステップ 3

使いやすいボタンと「実行」ラベルを選択する

メニュー → 外観を再度開き、ボタンを見つけます。ボタンのサイズスライダーを動かすと、そのパーセンテージと近くのプレビューがすぐに変化します。デフォルトは100%です。ヘッダーボタンを大きくするとタップしやすくなりますが、オプションのショートカット用のスペースが狭くなります。

実行ボタンドロップダウンは、保存済みセルエディタ内の「実行」ボタンではなく、新規セルパネル内の「実行」を制御します：

  • 自動（スペースが狭い場合はアイコンのみ）：デフォルト設定です。収まる場合はラベルを保持し、入力スペースを確保するために▶アイコンのみを使用することもできます。
  • アイコンのみ：常にコンパクトな▶ボタンを使用します。
  • 常にラベルを表示：狭い画面でもテキストを表示したままにします。

「外観」にはテキスト拡大スライダーはありません。ボタンのサイズは一般的なフォントサイズ設定ではありません。Free 1.4.0およびPro 1.3.0は、Androidのシステムテキスト拡大に合わせてコンパクトなヘッダーコントロールを自動的に拡大します。

オプション · Proのみ

Proのみ：フルスクリーン編集、追加のキー、および構文の色

これらはSciREPL Pro 1.4.0のエディタコントロールであり、上記のFreeのスクリーンショットに示されているコントロールではありません。追加のキーとライブカラーは別の設定です。

全画面編集を開始する

  1. 新しいセル：新しいセルのコードフィールドにある⤢ Full screenボタンをタップします。外側を向いた斜めの矢印はエディタの拡大を意味します。
  2. 保存済みセル：そのセルの✎ pencilをタップして編集し、次にそのセルのコードフィールドの隅にある⤢をタップします。

より多くのコードを表示できるように、エディタが画面全体に広がります。有効化された追加キーやサジェスチョンチップはキーボード上部に引き続き表示され、シンタックスカラーには以下で説明する同じ設定が使用されます。全画面にしてもコードは実行されません。

上部のエディタラベルをタップすると、下書きを開いたままワークブックに戻ります。戻るまたはEscでも全画面モードを終了できます。保存済みセルの場合、完了は実行せずに下書きを適用し、キャンセルは編集を破棄します。新しいセルの場合、DoneとCancelはいずれも下書きを消去したりセルを作成したりせずに全画面を終了します。Runは別の操作です。

「Panels use the full screen」とは異なります。その独立したAppearanceオプションはパネルやダイアログの上部余白を制御するもので、全画面コードエディタを開くわけではありません。

追加キー行を表示する

メニュー → 補完 → セクション → 全般を開きます。キーボード上の追加キー → オンを設定します。デフォルトはオフです。この行にはEsc、Tab、インデント解除、矢印、Home、End、Run、句読点があります。収まりきらないキーには横にスワイプしてアクセスします。Onを選択してもコードは実行されませんが、この行の▶ 実行キーは実行されるため、タップする前にソースを確認してください。

同じセクションで、縦向きのチップと横向きのチップは専用の行または追加キーを置き換えるを選択します。デフォルトは縦向きでOwn row、横向きでReplace extra keysです。候補が表示されている間、候補が一時的にキーの場所を占有することがあります。追加キーがオフの場合、チップは専用の行を使用します。横向きの追加行にはオフ、余裕があるとき（デフォルト）、常に表示があります。When there is roomは表示するコード行数の下限（初期値は8）を使用するため、高さの低い横向き表示ではオプション行を非表示にできます。

入力時のシンタックスカラーのオン／オフを切り替える

メニュー → 外観 → 入力中のシンタックスカラーを開きます。編集時に対象コードを色付けするにはオンを選択し、プレーンテキストにするにはオフを選択します。デフォルトの自動（デスクトップではオン、タッチ操作ではオフ）は、デスクトップブラウザで色付けを有効にし、スマートフォンではオフのままにします。入力の反応が鈍く感じられる場合はOffを選択してください。処理速度の遅いデバイスでは色付けによって入力速度が低下することがあります。6000文字を超える長さのコードは、Onにしていても色付けされません。

色付けによってコードの検証や実行が行われたり、APIリクエストが送信されたり、補完が有効になったりすることはありません。この設定の変更は直ちに反映され、ソースが改変されることはありません。

Files & Storageには個別の切り替えがあります

テキストファイルの場合は、メニュー → Files & Storage (VFS / Paths)を使用してファイルを選択し、全画面表示を選択します。そのエディタの構文の強調表示チェックボックスはAppearanceの入力時色付け設定から独立しており、デフォルトでオフになっています。認識できないファイル形式や100,000文字を超えるファイルでは利用できません。その追加キーはCompletion設定を共有しますが、ファイルエディタの空きスペースが少なすぎると非表示になることがあります。ファイル保存によって編集内容が書き込まれます。色付けを切り替えるだけでは書き込まれません。

ステップ4

ライト、ダーク、またはシステムテーマを選択する

テーマまでスクロールして、ダーク、ライト、またはシステムに従うを選択します。Darkがデフォルトです。Match systemはお使いのデバイスのライト／ダーク設定に従います。これはご自身で選択するものであり、デフォルトではありません。

このレッスンではカスタム、カスタマイズ…、テーマJSONエディター、高度な設定: カスタムCSSは不要です。これらの高度なオプションは、この初心者向けウォークスルーの対象外です。

任意の仕上げ

Androidの余白とデフォルトへの復帰

レイアウトの下で、上部マージン → 自動を選択したままにします。端末から報告されたセーフエリアに従うため、ヘッダーの上部に適切な余白が確保されます。ピクセル値を推測する必要はありません。

Androidアプリでは、Android のステータスバーを隠すに以下の設定があります:

  • しない: デフォルトです。時計と通知ステータスバーを表示したままにします。
  • 横向き時: スマートフォンが横向きの間はそのバーを非表示にし、縦向きで元に戻します。
  • 常に: どちらの向きでも非表示にします。

この設定はAndroidのステータスバーにのみ影響し、ナビゲーションバーやジェスチャーバーには影響しません。ブラウザ/PWAおよびWindowsのインターフェースにはありません。Pro 1.3.0には代わりに横向き時にAndroidステータスバーを非表示という名前のチェックボックスがあります。

外観の変更を元に戻したいですか？ デフォルトに戻すを使用すると、デフォルトのテーマ、ヘッダーボタンのサイズ、上部マージン、ショートカット、ステータスバーの設定が復元され、カスタムテーマやCSSの選択が削除されます。ワークブックのセルは消去されません。個別の実行ボタンやインターフェース言語の設定はリセットされません。必要に応じて、実行の自動オプションをご自身で選択してください。

完了したら×で外観を閉じます。続けてMarkov Groupsワークブックのウォークスルーに進むか、簡潔なインターフェースリファレンス (英語のリファレンスページ)に戻ってください。
