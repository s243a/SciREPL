Windows デスクトップアプリ

Windows での外観：異なる点

Windows アプリ（Microsoft Store 版を含む）には、Android と同じ ☰ メニュー → 🎨 外観 があります。テーマ、表示言語、ボタンのサイズ、📦 Browse ショートカットは外観のウォークスルーのとおりに動作します。このページでは、デスクトップのウィンドウで加わる点だけを説明します。

  • Free
  • Windows デスクトップアプリ
  • 約 2 分

ノートブックの幅

幅が 1000 ピクセル以上のウィンドウでは、ノートブックのセルは最大 1200 ピクセルまで広がります。この ワイド が既定の設定です。変更するには ☰ メニュー → 🎨 外観 を開き、レイアウト の ノートブックの幅 を選びます。

  • 標準：従来の 720 ピクセルの列。
  • ワイド：最大 1200 ピクセル（既定）。
  • ウィンドウ全体：セルがウィンドウの幅全体を使います。

それより狭いウィンドウでは、どれを選んでも常に標準の列になります。

ズーム

ズームでウィンドウ内のページを拡大・縮小できます。

  • 拡大：Ctrl+= または Ctrl+Shift+=（Ctrl とプラスキー）。
  • 縮小：Ctrl+-。100% に戻す：Ctrl+0。
  • Ctrl を押しながらマウスホイールを回すか、タッチパッドでピンチ操作をします。
  • ウィンドウのメニューバーから：表示 → 拡大、縮小、実際のサイズ。

Windows の表示スケールか、アプリのズームか

Windows のディスプレイ設定（設定 → システム → ディスプレイ）の拡大縮小は、SciREPL のタイトルバー、メニューバー、ダイアログを含め、画面上のすべてを拡大します。アプリのズームは、ウィンドウ内のページだけを拡大します。Windows には 1 つのアプリだけを拡大縮小する設定がないので、SciREPL だけを大きく（または小さく）したいときはズームを使ってください。

どちらも、ページから見たウィンドウの大きさを変えます。たとえば 150% のスケールでは、幅 1920 ピクセルの画面は SciREPL にとって幅 1280 ピクセルです。上記の幅 1000 ピクセルと下記の高さ 500 ピクセルは、スケールとズームを適用した後の値です。

新規セルパネルを隠す

ウィンドウが縦より横に長く、ページの高さが 500 ピクセル以下のときは、下部の新規セルパネルに ⌄ ボタン（新規セルパネルを隠す）が表示されます。150–200% のスケールでは普通のノートパソコンのウィンドウでもこの高さになることがあり、ズームで拡大しても同じです。⌄ をクリックすると、ノートブックが高さ全体を使えます。

パネルを隠している間は、左上の Sci REPL というタイトルの代わりに小さな ⌃ ボタン（新規セルパネルを表示）が表示されます。これをクリックするとパネルが戻ります。最大化するなどしてウィンドウを高くしても、パネルは戻ります。

ウィンドウのメニューバー

Windows のウィンドウには、アプリの上に独自のメニューバーがあります：ファイル、編集、表示、ランタイム、ヘルプ（表示言語で表示されます）。キーボードからは Alt を押して移動できます。ランタイム には次の項目があります。

  • ダウンロード済みランタイム…：ダウンロードした Lua と R のランタイムが使っている容量と、保存場所を表示します。
  • ダウンロード済みランタイムを消去…：確認のうえで削除します。ノートブックやファイルには影響しません。すでに読み込まれたランタイムは再起動するまで使えます。その後、R と Lua はダウンロードの前に再び確認を求めます。ダウンロードにはインターネット接続が必要です。
  • アプリケーション データ フォルダを開く：SciREPL のデータフォルダをエクスプローラーで開きます。

Android にはウィンドウのメニューバーはありません。Android では ☰ メニュー → 📊 メモリとストレージ でストレージを確認・消去します。Windows ではこのパネルからダウンロード済みランタイムが見えないため、ランタイムには ランタイム メニューを使ってください。

そのほかはすべて Android と共通です。外観のウォークスルーに戻る。
