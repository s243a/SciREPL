実践しながら学ぶ

最初のワークブックを作成する

これは、インターフェースリファレンス (英語のリファレンスページ)の実践的な詳細ガイドです。ひとつのPythonセルを実行し、それを変更して、自身で管理できるコピーを保存します。AIアカウントやAPIキーは不要です。

  • Free + Pro
  • Androidの手順
  • 約5分

スクリーンショットは、SciREPL Free v1.3.2をSamsung Galaxy S24シリーズのスマートフォンで表示した画面です。一部の操作部が異なって見える場合がありますが、このレッスンはProにも適用されます。

このレッスンで学ぶこと
  1. 配置を確認する
  2. セルを作成して実行する
  3. 保存したセルを編集する
  4. ワークブックのコピーをエクスポートする
  5. 次に試すこと

すべてのチュートリアル

ステップ1

アプリ内での配置を確認する

最上部の行はヘッダーです。メニュー、ヘルプ、ステータスバッジが含まれます。ワークブックセレクターで、開くワークブックを選択します。

新しいセル用パネルは、次のセルを入力する場所です。画面幅が狭い場合、任意のヘッダーボタンが非表示になることがありますが、該当する操作はメニューまたはヘルプから引き続き利用できます。

ステップ 2

Python セルの作成と実行

初回実行の前に、ステータスバッジに 準備完了 と表示されるまでお待ちください。

  1. 新しいセル用パネルで、言語セレクターから Python を選択します。幅の狭いスマートフォンでは、閉じた状態のセレクターに Py とのみ表示される場合があります。
  2. 次の短いプログラムを入力します: 
    print("Hello from SciREPL")
  3. 実行 をタップします。ワークブックに保存されたセルが表示されます。その下に Hello from SciREPL が表示されるはずです。

初回実行には時間がかかる場合があります。 Python のランタイムを一度起動する必要があります。ステータスが 準備完了 に戻るまでお待ちください。その後の Python セルは通常、そのランタイムを再利用します。

プライバシーに関する通知が表示された場合: 通常は Python が同梱されているため、この例ではランタイムのダウンロードは不要なはずです。R や Lua（Free 内）などのネットワークランタイムでは、最初に SciREPL のプライバシーポリシーが表示される場合があります。Python でも、同梱版でネットワークフォールバックが必要な場合に表示されることがあります。内容をお読みになり、ダイアログの内側を一番下までスクロールして、同意される場合は I Understand をタップしてください。その後、別の「ランタイムのダウンロード」プロンプトで ダウンロード のタップを求められることがあります。

プライバシーポリシーダイアログの例を見る (英語のリファレンスページ)（スクリーンショットには上部のみが示されており、ボタンはさらに下にあります）。Free 1.4.0 および Pro 1.4.0 では、パッケージのインストールを試みる前に、現在のネットワーク開示に同意していない場合、有効な %pip install コマンドでもこの通知が開きます。ネットワーク機能を使用する前に、プライバシーとローカルデータ (英語のリファレンスページ)をご確認ください。

ステップ 3

保存されたセルの編集

  1. 保存されたセル自体のヘッダーにある鉛筆 ✎（右上の ✕ のすぐ左）をタップします。そのセルが編集用に開きます。新しいセル用パネルに入力すると別のセルが作成されてしまいます。
  2. Hello from SciREPL を Hello again に変更します。
  3. 変更を保存して実行するには 実行 を選択します。これで、そのセルの下に Hello again が表示されるはずです。

Pro のショートカット: タッチ画面では、保存されたセルのコードをダブルタップして編集できます。Free では現在、✎ ボタンを使用します。

誤ってエディタを開いた場合は、キャンセルを使用して実行せずに閉じます。保存されたセル内の言語セレクターはそのセルを変更しますが、新規セル用のセレクターは変更しません。

ステップ 4

ワークブックのコピーをエクスポート

  1. メニュー → ワークブックとパッケージをエクスポートを開きます。
  2. 現在のタブのみまたはすべてのタブを選択し、SciREPL形式のワークブック (.srwb)は、SciREPL固有の状態を保持したい場合に選択します。
  3. エクスポートをタップし、自身が管理する保存先を選択します。

エクスポートする理由 SciREPLはローカルセッションを復元しますが、ローカルストレージはバックアップではなく、Androidアプリとブラウザ間で自動的には共有されません。ファイルとエクスポート (英語のリファレンスページ)を参照して、.ipynbやPDFを含む他の形式を確認してください。

ステップ 5

次に試すこと

2 + 2を別のPythonセルで試します。次に、ワークブックセレクターを使用してタブを切り替えます。CSVワークブックのウォークスルーは、メニュー → パッケージ、バンドル、ワークブックを参照から開始し、サンプルをインストールして、そのセルがローカルファイルとどのように連携するかを示します。

Markov Groupsのウォークスルーでは、より広範なカタログを検索し、キューブの操作に関する既存のワークブックを開き、そのセルを順番に実行して、単一のパラメータを変更する方法を示します。

各操作の配置をすぐに確認したい場合は、インターフェースリファレンス (英語のリファレンスページ)に戻ってください。別の言語を学ぶかパッケージを追加するには、言語とパッケージ (英語のリファレンスページ)に進んでください。

Proをお使いですか？ 基本的なワークフローは同じです。ProにはフルスクリーンエディタとオプションのAI機能も用意されています。詳細については、 ProのAIおよびフルスクリーンワークフロー (英語のリファレンスページ) 通常のセルに慣れた後に確認してください。
