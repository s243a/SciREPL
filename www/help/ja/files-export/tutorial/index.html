実践して学ぶ

ワークブック内のCSVを調べる

パッケージ、バンドル、ワークブックを参照から始めます。小さなサンプルをインストールし、セルを実行し、CSVを編集してから、データとともにワークブックをエクスポートして再度開きます。データは架空のものであり、Pythonコードに追加のパッケージやAIアカウントは不要です。

  • Free + Pro
  • Android向けの手順
  • 約15分

スクリーンショットはSamsung Galaxy S24シリーズのスマートフォンで撮影されました。「参照」と初期出力の画像はFreeを示しています。新しいファイルエディターとパッケージ選択の画像はPro 1.4.0を示しており、以下にラベルが付けられています。Proでは、直接のワークブックダウンロードと「ファイルをインポート」のパスを使用できます。周囲のコントロールは異なる場合があり、この新しい「参照」項目はそこには存在しない可能性があります。

Browseにこのワークブックがまだ表示されませんか？ このサンプルはFree 1.4.0以降に組み込まれています。インストール済みの古いアプリやキャッシュされたPWAには表示されない場合があります。ワークブックを直接ダウンロードし、メニュー → Import Fileを使用して開いてください。これで、このレッスンの残りを進めることができます。

このレッスンで学ぶこと
  1. Browseからサンプルをインストールする
  2. そのPythonセルを実行する
  3. Files & Storageで測定値を変更する
  4. CSVファイルをインポートする
  5. ワークブックとデータをエクスポートする
  6. パッケージを再度開いてデータを確認する

すべてのチュートリアル

ステップ1

Browseでワークブックを見つける

  1. メニュー → パッケージ、バンドル、ワークブックを参照を開きます。オプションの📦ヘッダーショートカットが表示されている場合は、それを使用して同じ画面を開くこともできます。
  2. CSV Basicsを検索します。ワークブックの下にあるCSV Basics: Seedling Heightsを見つけます。これは組み込みの英語サンプルであり、Pythonへのインストールが必要なパッケージではありません。
  3. インストールをタップします。通常、ワークブックが選択されたタブになります。自動切り替えを無効にしている場合は、ワークブックセレクターを使用して選択してください。

プライバシーポリシーが表示された場合: Browseはオンラインで検証済みカタログを確認することがあります。開示事項を読み、ダイアログ内を一番下までスクロールして、同意する場合にのみI Understandをタップしてください。代わりに通知を閉じて組み込みエントリを引き続き使用することもできますが、その場合リモートカタログは利用できなくなります。このサンプル自体には外部データセットやPythonパッケージは不要です。

ワークブックをインストールするとそのセルが追加されますが、セルが実行されるわけではありません。これにより、コードを実行する前に確認できます。

ステップ2

セルを順番に実行する

冒頭の文でサンプルについて説明しています。三つのPythonセルにはそれぞれcreate_csv、read_csv、compare_groupsという名前が付いています。保存されたセルについては、その✎鉛筆をタップしてエディタを開き、そのセルの実行をタップします。Proでは、セルのコードをダブルタップして編集することもできます。

  1. create_csvを実行します。/shared/data/seedling-heights.csvに六行の架空のデータが書き込まれます。Saved 6 fictional rowsが表示されるはずです。
  2. read_csvを実行します。作成されたばかりのファイルが開き、全六行が出力されます。
  3. compare_groupsを実行します。日なたの平均13.0 cm、日陰の平均8.0 cm、およびその差5.0 cmが出力されます。

このファイルはメニュー → ファイルとストレージでも確認できます。そこで読むことも、編集と保存を使って直接変更することもできます。次の手順でその方法を説明します。

最終的な出力は次のようになります。

Light mean: 13.0 cm
Shade mean: 8.0 cm
Difference: 5.0 cm

初回実行が遅いですか？ Pythonの初期化に少し時間がかかることがあります。セルが完了したかどうかを判断する前に、ステータスバッジに準備完了と表示されるまで待ってください。後続のセルは通常、読み込まれたランタイムを再利用します。ランタイムのダウンロードに同意が必要な場合は、同意する前にプライバシーに関する通知をお読みください。このワークブックは%pip installを呼び出しません。

これらの架空の数値は読み取りと計算を説明するためのものであり、光と植物の成長に関する科学的な結論を示すものではありません。

ステップ3

ひとつの値を変更して再実行

データを変更するためにPythonセルを編集する必要はありません。CSV自体を開きます。

  1. メニュー → ファイルとストレージを選択します（メニュー名にVFS / Pathsが追加されている場合があります）。
  2. / (永続ストレージ)またはすべてのファイルシステムを選択します。/shared/data/seedling-heights.csvまでスクロールし、ダウンロードや削除のアイコンではなく、ファイル名をタップします。
  3. 編集をタップします。行light,14をlight,15に変更します。ヘッダーgroup,height_cm、カンマ、およびその他の行は変更しないでください。
  4. 保存をタップし、Files & Storageを閉じます。ファイルを保存してもコードは実行されません。

read_csvとcompare_groupsのみを再実行します。日なたの平均は約13.3 cm、差は約5.3 cmになります。決してcreate_csvを再実行しないでください。そのセルにまだ残っている値でファイルの編集内容が上書きされてしまいます。

または、create_csvをその✎ 鉛筆で編集し、その測定値14を15に変更して、三つすべてのPythonセルを順番に実行します。これにより、ファイル単体ではなく、ファイルを生成するコードが変更されます。

なぜ後続のセルを再実行するのでしょうか。保存されている出力は前回の実行記録であり、ファイルを変更しても以前の結果が自動的に再計算されることはありません。各セルは、実行時にファイルを読み込みます。

Pro: フルスクリーンでのファイル編集と任意のハイライト表示

ファイルプレビューで全画面表示をタップすると、より大きなエディタが表示されます。CSVはプレーンテキストのままであるため、その構文の強調表示チェックボックスは無効になっています。

対応しているコードファイルでは、シンタックスハイライトは任意であり、デフォルトでオフになっています。ノートブックの外観設定ではなく、このファイルエディタ内のチェックボックスを使用してオンにします。拡張子によって言語が選択されます。例えば、.pyはPython、.jsはJavaScript、.RはR、そして.plはPerlではなくPrologになります。未知の拡張子はプレーンテキストのままになります。

保存はファイルを書き込み、エディタを開いたままにします。Files & Storageに戻るには× 閉じるを使用します。未保存の変更を破棄する前に確認メッセージが表示されます。ファイルの編集や保存によってファイルが実行されることはありません。

プレーンテキストとしてCSVが開かれている同じ全画面エディタを確認してください。

ステップ4

オリジナルのCSVをインポート

  1. お使いの端末のファイルピッカーで開くことができるフォルダに、オリジナルのサンプルCSV (英語のリファレンスページ)をダウンロードします。
  2. SciREPLで、メニュー → Import Fileを選択し、seedling-heights.csvを選択します。確認メッセージに、それが/shared/data/seedling-heights.csvにアップロードされたと表示されるはずです。
  3. これにより、変更されたローカルファイルが元の六行に置き換わります。read_csvとcompare_groupsを再実行すると、二つの平均値は13.0および8.0 cmに戻るはずです。

重要: 上書きする意図がない限り、同じ名前の別のファイルをインポートした後にcreate_csvを再実行しないでください。ご自身のCSVについては、正確な確認パスを書き留め、読み込みセル内のpathをそのファイル名に変更してください。ファイルピッカーには、Android Downloads、クラウドプロバイダ、またはその両方が表示される場合があります。

ステップ5

ポータブルコピーを保存

メニュー → ワークブックとパッケージをエクスポートを開きます。セルのみが必要な場合は、ワークブック (.srwb)と現在のタブのみを選択します。.srwbには含まれないのは、SharedVFS内の個別のCSVです。

ワークブックをそのデータとともに移動するには、パッケージ (アーカイブ)を選択し、.zipをそのままにします。コンテンツツリーで、以下を選択します:

  • ワークブックCSV_Basics__Seedling_Heights.ipynb（notebooks/配下）。パッケージエクスポートはセルをJupyterノートブック形式で保存します。
  • ファイルseedling-heights.csv（shared/data/配下）。

無関係なワークブックやファイルのチェックを外します。必要に応じて矢印でフォルダを展開します。現在のタブのみによってパッケージの内容が制限されると思い込まないでください。このレッスンでは、余分なshared/notebooks/のコピーは不要です。Proでは、意図して共有したい場合を除き、AI会話を含めるのチェックを外したままにしておきます。

エクスポートをタップします。Androidでは共有シートが開きます。ご自身のドライブやファイルマネージャーの保存先など、後で見つけられる場所にアーカイブを保存してください。ブラウザではファイルがダウンロードされます。推奨されるファイル名はscirepl_package.zipです。これをseedling-project.zipに変更すると識別しやすくなります。

ローカルリカバリはバックアップではありません。 Androidアプリのストレージ、ChromeのPWA、および別のブラウザ間でこれらのファイルが自動的に共有されることはありません。エクスポートしたコピーはご自身で管理できる場所に保管してください。他の形式についてはファイル、インポート、およびエクスポート (英語のリファレンスページ)を参照してください。

ステップ6

パッケージを再度開き、両方の部分を確認する

バックアップを信頼する前に、開くことができるか確認してください。これは別のSciREPL環境またはブラウザプロファイルで行うことができます。ここへのインポートは別のワークブックを追加します。また、パッケージの配置先パスにあるファイルを置き換えるため、古いパッケージをインポートする前に、より新しいファイルの個別のコピーを保持してください。

  1. メニュー → Import Package (.zip / .tar.gz)を選択し、保存したアーカイブを選択します。このレッスンでは.zipであり、個別のCSVや.srwbのダウンロードではありません。
  2. 新しくインポートされたCSV Basics: Seedling Heightsワークブックが自動的に選択されない場合は、それを選択します。同じアプリにインポートした場合、古いタブと新しいタブが同じ名前になることがあります。
  3. メニュー → ファイルとストレージを開き、/shared/data/seedling-heights.csvを確認します。その六行はエクスポートしたファイルと一致するはずです。確認後にプレビューを閉じてください。
  4. 二番目のPythonセル（read_csvコード）を実行し、次に三番目のPythonセル（compare_groupsコード）を実行します。パッケージのエクスポートにはJupyter形式が使用され、セル名が保持されない場合があります。これらを順序とコードで識別してください。ステップ4の元のCSVの後では、13.0 cm、8.0 cm、および5.0 cmを見込みます。代わりに編集済みのlight,15ファイルをエクスポートした場合は、13.3 cm、8.0 cm、および5.3 cmを見込みます。

この復元確認のためにcreate_csvを再実行しないでください。インポートされたデータがコード内の値で上書きされます。復元されたCSVを最初に読み取ることで、データがワークブックと一緒に移動したことが証明されます。古い保存済み出力だけではそれは証明されません。

ファイルが見つからないか、ワークブックが存在しない場合は、ステップ5に戻り、両方のエントリが選択されていたことを確認してください。通常のワークブックのエクスポートではCSVを一緒に保持することはできません。

次のステップ

ご自身でCSVを試してみてください。列groupとheight_cmを維持し、数値の高さを使用して、少なくとも一行のlightと一行のshadeを含めるか、compare_groups内の二つのグループフィルターを適合させます。メニュー → ファイルとストレージでローカルファイルを検査できます。ここで使用されるスマートフォンの操作については、最初のワークブックのインターフェースウォークスルーを参照してください。
