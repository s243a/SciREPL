実践しながら学ぶ

カタログからワークブックを探索する

既存のMarkov Groups: A Random Walk on Cube Movesワークブックを見つけ、その四つのPythonセルを実行し、ランダムウォークを短縮して、独自のコピーを保存します。ここではSciREPLの使用に焦点を当てているため、行列代数を知っている必要やルービックキューブを解く必要はありません。

アプリの使い方を学ぶためにお越しですか？ ステップ1～5に従って、ワークブックを見つけ、開き、実行し、編集してエクスポートします。ステップ5の後に終了してもかまいません。任意の数学の解説はその後に続きますが、このチュートリアルを完了するのに必須ではありません。

  • Free + Pro
  • Androidの手順
  • 約15分

実際のスマートフォンのスクリーンショットは、SciREPL Pro 1.4.0-debugをSamsung Galaxy S24+上で表示したもので、6日、十月、2026年に撮影されました。これらは公開されたProビルドではなく、共有ワークブックのワークフローを示しています。Freeや他のバージョンでは、一部のコントロールの配置が異なる場合があります。この例は、SciREPLカタログv0.4.0の英語版ワークブックです。

このレッスンで学ぶこと

まずメニューを見つける

  1. 閲覧、絞り込み、検索
  2. ワークブックを開く
  3. セルを順番に実行する
  4. 一つの値を変更して再実行する
  5. ワークブックのコピーをエクスポートする

任意：キューブの例の背後にある数学

すべてのチュートリアル

始める前に

メニューを見つける

SciREPLのアプリ上部のヘッダー行で☰ Menuボタンを探します。そのアイコンは、下で黄色く強調表示されている三本の水平線です。タップしてアプリのメニューを開きます。選択するメニュー項目はステップ1に示されています。

ステップ1

閲覧、絞り込み、検索

  1. メニュー → パッケージ、バンドル、ワークブックを参照を開きます。Freeでは、表示されている場合、オプションの📦ヘッダーショートカットからも同じ画面が開きます。有効にする方法は外観のウォークスルーに記載されています。
  2. リストを参照するか、フィルターを使用します。この英語の例では、Englishを使用言語で、Pythonをカーネルで選択します。すべての使用言語やカーネルのすべてオプションも機能しますが、表示される項目が多くなります。
  1. 検索欄にMarkov Groupsと入力します。ワークブックの下にあるMarkov Groups: A Random Walk on Cube Movesを見つけてください。インストールする前に完全なタイトルを確認してください。これはワークブックのテンプレートであり、Pythonに追加するパッケージではありません。
  2. キーボードで結果が隠れている場合は、キーボードを非表示にするボタンを使うか、Androidの戻るを一度押して閉じます。Browseを開いたまま、一致するワークブックまでスクロールしてください。

他には何が利用できますか？ GitHub上のワークブック一覧（英語）をご覧ください。レッスンの言語版は個別の項目であり、異なるレッスンではありません。

GitHubのリンク先には最新の開発内容が表示されます。SciREPLは通常、最新の安定版カタログリリースを使用するため、GitHubに表示されている一部のワークブックはBrowseにまだ表示されない場合があります。SciREPLで検索をクリアし、CSV、Prolog、Lua、またはstatisticsを試してみてください。他の言語を調べる際はKernelですべてを選択してください。

プライバシーに関する通知が表示された場合：リモートカタログの取得または更新にはネットワーク接続が必要です。開示事項を読み、ダイアログ内を一番下までスクロールして、同意する場合にのみI Understandをタップしてください。通知を閉じるとそのネットワーク更新は行われませんが、組み込みの項目や以前キャッシュされたカタログ項目は引き続き表示される場合があります。プライバシーとローカルデータ (英語のリファレンスページ)を参照してください。

一致するワークブックがありませんか？言語とカーネルのフィルターを確認し、カタログの更新操作部を使用してください。古いアプリには同じカタログ操作部がない場合があります。または、固定されたv0.4.0ワークブックファイルを端末に保存し、メニュー → Import Fileを選択してmarkov-groups.srwbを選びます。ブラウザでファイルがテキストとして表示される場合は、ブラウザの保存/ダウンロード機能を使用して.srwb拡張子を維持してください。手動でのワークブックインポート手順では、GitHubのmainブランチにあるSimpson's Paradoxを使用した手順を説明しています。このレッスンを続けるには、上記のMarkovファイルを選択してください。

ステップ 2

ワークブックを開いてセルを確認する

  1. ワークブックカードのインストールをタップします。ボタンがすでにインストール済みと表示されている場合は、Browseメニューを終了し、代わりにワークブックセレクターから既存のワークブックを選択してください。
  2. 通常、ワークブックが選択されたタブになります。Browseメニューが開いたままの場合は終了してください。自動切り替えがオフになっている場合は、 Markov Groups: A Random Walk on Cube Moves から ワークブックセレクター の隣の SciREPL （ヘッダー内）。
  3. 冒頭の文章を読み、セルをスクロールしてください。Markdownセルはレッスンを説明し、Pythonセルには実行するコードが含まれています。見つけやすいように、各Pythonセルには名前が付いています。

インストールは実行を意味しません。このリモートカタログワークブックをインストールすると、そのPythonコードを実行せずにセルが追加されます。v0.4.0テンプレートには保存されたPython出力がないため、コードを確認してご自身で実行してください。AIアカウント、APIキー、外部データセット、追加パッケージのインストールは不要です。コードはNumPyを使用し、SciREPLのPythonランタイムで動作します。

ステップ3

四つのPythonセルを順番に実行

保存されたセルの場合、そのセルのヘッダーにある✎ 鉛筆をタップし、次にそのセル自体の実行をタップします。これにより既存のセルが実行されます。下部にある新規セルパネルは別のセルを作成します。

Proのショートカット： 保存されたコードをダブルタップしてエディタを開き、そのセル自体の 実行。Freeでは ✎ 鉛筆 をこのウォークスルーで使用します。

これらの名前は何を意味していますか？ cube_movesとcheck_movesはセルに表示される名前であり、入力するコマンドではありません。該当する名前を見つけ、そのセルの鉛筆と実行を使用してください。名前付きセルと言語間パスのチュートリアルでは、名前を割り当てて/nb/cube_moves/.codeなどの参照として使用する方法を説明しています。

  1. cube_movesを実行します。操作とヘルパーを定義します。想定される結果：Built six clockwise quarter-turn matrices with fixed face centres.
  2. check_movesを実行します。ステッカーが失われていないこと、中心が固定されたままであること、および各四分の一回転を四回繰り返すと最初に戻ることを確認します。合格行が六行表示された後、All six moves passed. U and R do not commute.が表示されるはずです。
  1. show_turnを実行します。Uターンのサイクルと、回転前後のステッカーラベルが出力されます。前面の最上段が[19, 20, 21]から[46, 47, 48]に変化します。比較U then R equals R then U: Falseは、操作の順序が重要であることを示しています。

出力結果の一部：

U cycles, shown as one-based sticker positions:
1 -> 3 -> 9 -> 7 -> 1
2 -> 6 -> 8 -> 4 -> 2
19 -> 37 -> 28 -> 46 -> 19
20 -> 38 -> 29 -> 47 -> 20
21 -> 39 -> 30 -> 48 -> 21

F top row labels before U: [19, 20, 21]
F top row labels after U:  [46, 47, 48]

U then R equals R then U: False

面の文字の長いリストはここでは省略されています。サイクルの行では一から始まる位置が使用され、行の比較ではステッカーラベルが示されます。揃った状態のキューブでは最初これらに一致する番号が付けられていますが、これらは異なる意味を持っています。

  1. random_walkを実行します。単一ステッカーの確率の合計である1.0、12ステップのサンプリングされたパス、最終的な面の文字ラベル、およびすべてのステッカーラベルと六つの中心すべてが保持されたことを確認するメッセージが出力されます。

Pythonセルはすでに必要な順序で配置されています。順序を変更しないでください。後続のセルはcube_movesの定義を再利用します。複数のセルを一度に実行するには、これより下をすべて実行およびすべてのセルを実行を参照してください。

初回実行が遅いですか？ Pythonの初期化に時間がかかる場合があり、ランタイムのダウンロードやネットワークフォールバックに同意が必要になることがあります。ステータスバッジが準備完了に戻るのを待ち、セルの出力にエラーがないか確認してください。再起動後に以降のセルで未定義の名前が報告された場合は、最初からPythonセルを実行してください。保存された出力はライブのPython定義と同じではありません。

このワークブックはテキストと面の文字リストを出力します。立方体の描画やアニメーション表示は行わず、シード値による短い経路は一様に混合されたスクランブルの証拠ではありません。

ステップ4

ウォークを短縮して保存されたセルを再実行する

  1. random_walkを見つけて、その ✎ 鉛筆をタップします。
  2. この行を見つけて、次のみを変更します size=12 変更後: size=6: 
    moves = rng.choice(MOVE_OPTIONS, size=12).tolist()

    np.random.default_rng(7)は変更しないでください。シードにより、この例の再現性が確保されます。

  3. その保存されたセルのエディタで実行ボタンをタップします。出力が更新され、Sampled moves:の行には十二個ではなく六個の選択肢が含まれるようになります。Iは立方体を静止させたままですが、選択肢の一つとしてカウントされます。

この変更では、以前の定義が読み込まれている間にrandom_walkのみを再実行してください。代わりにcube_movesを編集した場合は、以降のPythonセルも再実行してください。出力には前回の実行が記録され、別のセルが変更されても自動的には再計算されません。

誤ってエディタを開いた場合は、キャンセルを選択してください。元の例に戻すには、size=6をsize=12に戻してセルを再度実行します。

ステップ5

独自のワークブックのコピーをエクスポートする

  1. Markov Groups ワークブックを選択したまま、「ドキュメントのエクスポート」ではなく メニュー → ワークブックとパッケージをエクスポート を開きます。
  2. ワークブック (.srwb)と現在のタブのみを選択します。
  3. エクスポートをタップし、ご自身が管理する場所にコピーを保存します。Android では共有/保存フローが開き、ブラウザではファイルがダウンロードされます。.srwb拡張子はそのまま保持してください。

このワークブックには個別のデータファイルが不要なため、このレッスンでは.srwbのコピーで十分です。メニュー → Import File で再度開くことができます。新しいランタイムを開始するときは、そのPythonセルを最初から実行してください。

ローカル復旧はバックアップではありません。アプリやサイトのストレージを消去したり、アンインストールしたりすると、ローカルの作業内容が削除される可能性があります。Androidとブラウザのセッション間で編集内容は自動的に共有されません。エクスポートしてもカタログに変更は公開されず、別のコピーが作成されます。

保存済みセルの編集の基本については、最初のワークブックのインターフェースウォークスルーをご覧ください。独立したデータファイルを読み込んで保持する例については、CSVワークブックウォークスルーをお試しください。ワークブックリファレンス (英語のリファレンスページ)では、セルの種類と不変のセル名について説明しています。

下をすべて実行とすべてのセルを実行

  • 下をすべて実行：保存済みセルをその✎ 鉛筆で開き、これ以降をすべて実行を選択します（コンパクトアイコンは▶↓です）。これにより、そのセルおよびその下にあるすべてのセルが順番に実行されます。
  • メニュー → すべてのセルを実行：選択したワークブックを最初のセルから最後のセルまで実行します。すべてのワークブックタブを実行するコマンドではありません。

最初にコードを確認し、バッチの実行中はこのワークブックを選択したままにしてください。新しいPythonセッションの後は、以降のセルで定義が利用できるようにcube_movesから開始してください。これらの操作はコードを実行します。説明を「任意」と呼んでも、アプリがそのコードセルをスキップすることはありません。

キューブの例の背後にある数学

出力結果が持つ意味

このワークブックは、単に六つの色だけでなく、54個の個別にラベル付けされたステッカーを追跡します。正当な操作によってそれらのラベルが並べ替えられます。一つの四分の一回転を四回繰り返すと元の配置に戻りますが、異なる面を回転させる場合は、その順序が変わると異なる結果が生じる可能性があります。

ランダムウォークは13個の選択肢から選択します。静止（I）、六つの四分の一回転、およびそれらの六つの逆操作です。その54×54の確率行列は、キューブ全体のすべての配置ではなく、一枚のステッカーの位置を表します。確率の合計が1.0であることは、このステッカーの位置確率の総和が一であることを意味しますが、キューブが一様にスクランブルされていることを証明するものではありません。

面の向きについて興味がありますか？ワークブックのcoordinatesセルは、全体座標軸と各面の右方向、上方向、および外向きの法線を示します。写真、図、数式のチュートリアルでは、そのような説明をワークブックに組み込む方法を紹介しています。座標図はカタログの開発版に追加中であり、上記の固定されたv0.4.0のコピーには含まれていません。

任意：改訂されたステージ4のプレビュー

上記の手順とスマートフォンのスクリーンショットでは、安定版のv0.4.0ワークブックを使用しています。改訂版ワークブックのダウンロードは開発プレビューであり、まだ安定版カタログには含まれていません。より短く、説明とコードセルが交互に配置された構成を試したい場合は、メニュー → ファイルのインポートからインポートしてください。

そのプレビューでは、上記と同様にまずcube_moves、check_moves、show_turnを実行します。その後：

  1. transition_matrixを実行します。これによりTが構築されます。これは、一様に選ばれた一つの選択肢（I、面の四分の一回転、またはその逆操作）の後における一枚のステッカーの位置の確率行列です。
  2. sticker_stepを実行します。これはステッカーラベル1を追跡するもので、このステッカーは最初ゼロ起算の位置0にあります。その位置確率の合計は1.0になります。下のグラフは、そのセルによって計算された移動先確率を示しています。
移動先の位置確率
07/13 ≈ 53.85%
2、6、18、35、42、47（それぞれ）1/13 ≈ 7.69%
他のすべての47箇所の位置0
  1. random_walkを実行します。これは12通りの選択肢のパスをキューブ全体についてサンプリングし、transition_matrixの定義を使用します。これは上記の一つのステッカーの確率とは異なります。ステップ4のsize=12の編集は、どちらのエディションでもこのセルで機能します。
