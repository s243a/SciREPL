ワークブックファイルをご自身でインポートする

すでにワークブックファイルをお持ちの場合、またはBrowseでレッスンが見つからない場合は、端末にファイルを保存し、メニュー → Import Fileを使用してSciREPLに追加します。この短いチュートリアルでは、Simpson's ParadoxをカタログのGitHub mainブランチから使用します。インポートするためにパッケージをインストールしたりコードを書いたりする必要はありません。

SciREPLは二つのノートブック形式をインポートします。独自のワークブック形式である.srwbと、Jupyterノートブック形式である.ipynbです。この例では.srwbを使用します。以下の形式に関する注意事項で、Jupyterインポートの異なる実行動作について説明しています。

  • Free + Pro
  • Android + ブラウザの手順
  • 約3分

MenuのスクリーンショットはSamsung Galaxy S24+での実際のAndroidキャプチャであり、PlayストアのインストールではなくSciREPL Free 1.4.0-debugを示しています。インポートされたワークブックのスクリーンショットは、別のChromiumブラウザによるFree 1.4.0のモバイルサイズビューポートでのキャプチャであり、Androidのファイルピッカーによるインポートの証明ではありません。どちらも6日 十月 2026年に撮影されました。他のエディション、バージョン、およびファイルピッカーでは、コントロールの配置が異なる場合があります。この例は、本ガイド向けに確認された英語のsimpsons-paradox.srwbファイルであり、SciREPLカタログのmainブランチからのものです。そのブランチは変更される可能性があります。キャプチャとソースの詳細 (英語のリファレンスページ)には、正確な画像サイズと確認されたファイルのハッシュが記録されています。

すべてのチュートリアル

ステップ 1

ワークブックファイルをお使いの端末に保存する

GitHub の main ブランチには、Browse で表示される最新の安定版カタログリリースにはまだ含まれていないワークブックや更新が含まれている場合があります。カタログリリースはアプリのリリースとは無関係に変更されます。ファイルを直接インポートすることで、Browse に表示されるのを待たずに信頼できるワークブックを試すことができます。

  1. GitHub で Simpson's Paradox を表示し、次に実際のワークブックファイル（.srwb）をダウンロードします。二つ目のリンクは GitHub のウェブページではなく、RAW ファイルを開きます。
  2. ブラウザがファイルをダウンロードせずにテキストとして表示する場合は、ブラウザの保存/ダウンロード操作を使用してください。スクリーンショットや HTML ページではなく、ワークブックファイルそのものを保存してください。
  3. ファイル名 simpsons-paradox.srwb とその拡張子 .srwb はそのまま保持してください。保存先を確認してください。Android では通常 Downloads が使用され、デスクトップでは Downloads または選択したフォルダになります。

これは固定されたリリースのダウンロードではありません。 main は開発ブランチです。これらのスクリーンショットが撮影された後に、ファイルの内容やセルが変更されている可能性があります。保存したファイルはローカルコピーであり、その後に GitHub で行われた変更がインポート済みのタブに自動的に反映されることはありません。

ダウンロードはインポートではありません。 ファイルを保存すると端末に配置されますが、SciREPL でワークブックがまだ開かれるわけではありません。テキストエディタで開いたり、SciREPL の Files ビューに配置したりする必要はありません。次のステップで、ダウンロードしたそのファイルを選択します。

他の人から提供された信頼できる .srwb ファイルがすでにある場合は、サンプルのダウンロードをスキップしてそのファイルを使用してください。ワークブックのタイトルとセル数は、ステップ 3 の確認内容とは異なります。

ステップ 2

Menu を見つけて Import File を選択する

  1. SciREPL に戻ります。アプリ上部のヘッダー行で、☰ Menu（三本の水平線のボタン）を見つけてタップまたはクリックします。
  2. 📂 ファイルをインポート (例: .srwb, .ipynb, .csv, .py, .zip) を選択します。メニューが画面の高さを超えている場合は、メニュー内をスクロールして見つけてください。
  1. Android の場合：システムファイルピッカーが開きます。Downloads を確認するか、ファイルを保存した場所まで移動します。simpsons-paradox.srwb を選択します。ピッカーは Android の機能であるため、そのレイアウトや最終的な Open または選択操作は端末によって異なります。
  2. デスクトップの場合：ファイル選択ダイアログを使用して、ダウンロード時に選択したフォルダを見つけます。simpsons-paradox.srwb を選択し、選択を確定します。Android の Downloads 画面を探す代わりに、この手順を使用してください。
  3. SciREPL に戻り、インポートが完了するまで待ちます。メニューがまだ開いている場合は、閉じてワークブックを表示します。

ワークブックはデータファイルのアップロードではありません。 .srwbファイルをインポートすると、そのワークブックが別のタブとして追加されます。ファイルに複数のワークブックが含まれている場合は複数のタブとして追加されます。既存のタブは保持されます。ワークブックがファイルビューに配置されることはなく、現在のワークブックが置き換えられることもありません。

ステップ 3

何も実行する前に新しいワークブックを確認する

  1. ワークブックセレクターでSimpson's Paradoxを探します。その新しいタブがまだ選択されていない場合は選択してください。その導入部にはSimpson's Paradox: When Every Group Disagrees with the Totalという見出しが付いています。
  2. 導入部を読み、セルをスクロールして確認します。これらのスクリーンショットで確認されたバージョンには七つのセルがあります。三つのテキストセル、三つのRセル、そして一つのJavaScriptセルです。main上の新しいバージョンでは異なる場合があります。
  3. その順序でdata、compute、vizと名付けられたRセルを見つけます。JavaScriptセルはjs_checkと名付けられており、別のオプションの確認です。コードだけでなく説明文も読んでください。

.srwbにおいてインポートは実行を意味しません。 他のインポートで自動実行が有効になっている場合でも、SciREPLは.srwbファイルをインポートしたときにコードを実行しません。見慣れない、または信頼できないソースからのコードは、実行またはすべてのセルを実行を選択する前に検査してください。

通常の.srwbインポートでは、ファイルに出力が含まれている場合でも、現在保存されているコードセルの出力は破棄されます。Markdownテキストは保持されてレンダリングされるため、導入部はすぐに表示されます。グラフやその他のコード生成画像を再生成するには、依存するセルを順番に再度実行してください。インポートによってアクティブなRやその他のランタイム変数が復元されることはありません。

ステップ 4

任意：インポートしたレッスンを実行する

手動インポートは完了しました。コードの実行は別のステップです。シンプソンのパラドックスでは、グループ内の比較が全体の比較とどのように一致しないかを示すために教育用の合成データを使用しています。確認するには、保存されたコードセルの✎ 鉛筆をタップしてコードを検査し、そのセルの 実行ボタンを使用します。

  1. Rセルdataを実行し、テキストセルpauseを読んで予測を立ててからcomputeを実行します。続けてvizを実行してグラフを生成します。後続のRセルは先行するセルに依存しています。これらはベースRを使用しているため、追加のRパッケージをインストールする必要はありません。
  2. 別のJavaScriptチェックを行いたい場合は、js_checkを実行します。これはスタンドアロンであり、Rセルに依存せず、Rを起動する必要もありません。

初回のR実行： SciREPLのwebRランタイムをダウンロードして初期化する必要がある場合があります。ネットワークおよびプライバシーに関する通知が表示されることがあります。内容を確認し、続行する場合にのみ同意してください。ランタイムの準備が完了するまで待ち、セルにエラーがないか確認します。ワークブックをインポートしただけでは、そのR定義はロードされていません。

実行と編集のより詳細なチュートリアルを含む別の例については、マルコフグループのレッスンを参照してください。これは四つのPythonセルを持つ別のワークブックであり、そのエクスポート手順では、編集したワークブックのコピーを保存する方法も説明されています。

ご自身で管理できるコピーを保持してください。 ダウンロードしたファイルは元のワークブックのコピーであり、それ以降の編集内容のバックアップではありません。変更を保存するにはワークブックのコピーをエクスポートしてください。アプリやブラウザのストレージを消去するとローカルの作業が削除される可能性があり、Androidとブラウザのセッション間で変更内容は自動的には共有されません。

その他の形式と安全性

ファイルに含まれる内容を把握する

Jupyterノートブック (.ipynb)もメニュー → ファイルをインポートを使用しますが、その実行挙動は.srwbとは異なります。ワークブックのインポート時にセルを自動実行が有効になっている場合、.ipynbのインポートによって、保存された出力のないコードセルが自動的に実行されることがあります。

信頼できるソースからのみノートブックファイルをインポートしてください。 .ipynbをインポートする前に、メニュー → 設定 → インポートと編集を開き、ワークブックのインポート時にセルを自動実行がオフ（チェックが外れた状態）になっていることを確認してください。デフォルトではオフになっていますが、現在の設定を確認してください。オフにしても任意のノートブックが安全であると保証されるわけではありません。実行するかどうかを明示的に判断する前に、信頼できるノートブックのコードを点検してください。

個別のデータファイル：通常の.srwbエクスポートでは、個別のCSVファイルや、SciREPLの仮想ファイルシステム（ファイルビュー）に保存されている他のデータは保持されません。このバージョンのシンプソンのパラドックスはコード内で合成データを作成するため、個別のデータファイルを必要としません。CSVを読み込むワークブックの場合は、CSVウォークスルーのパッケージアーカイブのエクスポートと再オープン手順に従って、ワークブックとそのデータの両方を保持して復元してください。パッケージアーカイブと.zipのインポートは、この短いワークブックファイルのレッスン対象外です。

表示に問題がある場合

ファイルと選択したタブを確認する

  • ピッカーでファイルが見つからない場合：ブラウザのダウンロードリストを確認して保存先を確認し、そのフォルダに移動してください。パソコンでダウンロードしても、スマートフォンのダウンロードフォルダにはファイルが配置されません。
  • ファイル名の末尾が .txt または .html になっている場合：ワークブックのダウンロードリンクに戻り、.srwb拡張子を持つ実際のファイルを保存してください。HTMLページの名前を.srwbに変更しても、ワークブックには変換されません。
  • 古いワークブックがまだ表示されている場合：メニューを閉じて、ワークブックセレクターで新しいタイトルを確認してください。既存のタブは保持されます。
  • 二回インポートした場合：再度インポートすると別のコピーが追加され、以前のタブが更新または置換されることはありません。変更を加える前に、どちらのコピーを編集しているか確認してください。
  • タイトルまたはセルが一致しない場合：別のダウンロードや他のレッスンのファイルではなく、simpsons-paradox.srwbを選択したことを確認してください。main上のファイルは変更される可能性があります。お持ちのコピーを現在のGitHubファイルと比較し、見慣れないコードを実行する前に点検してください。

ワークブックのタブと保存されたセルの編集の基本については、最初のワークブックインターフェースのウォークスルーを参照してください。ワークブックリファレンス (英語のリファレンスページ)では、ワークブックの構造とセルの種類について説明しています。
