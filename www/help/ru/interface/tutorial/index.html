Все руководства

Шаг 1

Ориентация в приложении

Верхняя строка — это заголовок. Он включает меню, справку и значок состояния. Селектор рабочих книг выбирает, какая рабочая книга открыта.

Панель новой ячейки — это место, где вы вводите следующую ячейку. Необязательные кнопки заголовка могут исчезать на узком экране; их действия остаются доступными через Меню или Справку, где применимо.

Шаг 2

Напишите и запустите ячейку Python

Перед первым запуском дождитесь, пока значок статуса не покажет готово.

  1. На панели новой ячейки выберите Python в списке выбора языка. На узком телефоне закрытый селектор может показывать только Py.
  2. Введите эту короткую программу: 
    print("Hello from SciREPL")
  3. Нажмите Выполнить. В рабочей книге появится сохраненная ячейка. Под ней вы должны увидеть Hello from SciREPL.

Первый запуск может занять больше времени. Среда выполнения Python должна запуститься один раз. Дождитесь возвращения статуса к готово; последующие ячейки Python обычно повторно используют эту среду выполнения.

Если появится уведомление о конфиденциальности: Python обычно поставляется в комплекте, поэтому для этого примера загрузка среды выполнения не требуется. Сетевая среда выполнения, такая как R или Lua в Free, может сначала показать Политику конфиденциальности SciREPL; Python также может ее показать, если для встроенной копии требуется резервный вариант через сеть. Прочитайте ее, прокрутите внутри диалогового окна вниз и нажмите Я понимаю, если согласны. Отдельный запрос на загрузку среды выполнения может затем предложить нажать Скачать.

Посмотрите пример диалогового окна Политики конфиденциальности (Справочная страница на английском языке) (на снимке экрана показана его верхняя часть; кнопка находится ниже). В Free 1.4.0 и Pro 1.4.0 допустимая команда %pip install также открывает это уведомление, если вы еще не приняли текущее соглашение о сети, перед попыткой установить пакет. См. конфиденциальность и локальные данные (Справочная страница на английском языке) перед использованием сетевых функций.

Шаг 3

Отредактируйте сохраненную ячейку

  1. Нажмите на карандаш ✎ в заголовке самой сохраненной ячейки, в правом верхнем углу сразу слева от ✕. Это откроет ячейку для редактирования; ввод текста на панели новой ячейки создал бы другую ячейку.
  2. Замените Hello from SciREPL на Hello again.
  3. Выберите Выполнить, чтобы сохранить и применить изменение. Теперь под этой ячейкой должно отображаться Hello again.

Pro — быстрый способ: На сенсорном экране дважды коснитесь кода сохраненной ячейки, чтобы отредактировать его. В Free в настоящее время используется кнопка ✎.

Если вы случайно открыли редактор, используйте Отмена, чтобы закрыть его без запуска. Селектор языка внутри сохраненной ячейки меняет эту ячейку; селектор новой ячейки — нет.

Шаг 4

Экспорт копии рабочей книги

  1. Откройте Меню → Экспорт книг и пакетов.
  2. Выберите Только текущая вкладка или Все вкладки, затем SciREPL формат Книга (.srwb), если хотите сохранить состояние, специфичное для SciREPL.
  3. Нажмите Экспорт и выберите место назначения, которое вы контролируете.

Зачем выполнять экспорт? SciREPL восстанавливает локальные сеансы, но локальное хранилище не является резервной копией и не синхронизируется автоматически между приложением Android и браузером. См. раздел файлы и экспорт (Справочная страница на английском языке) для других форматов, включая .ipynb и PDF.

Шаг 5

Что попробовать дальше

Попробуйте 2 + 2 в другой ячейке Python. Затем используйте селектор рабочей книги для переключения вкладок. Руководство по рабочей книге CSV начинается с Меню → Обзор пакетов, коллекций и книг, устанавливает пример и показывает, как его ячейки работают с локальным файлом.

Руководство Markov Groups показывает, как искать по расширенному каталогу, открыть существующую рабочую книгу о движениях кубика, последовательно запустить ее ячейки и изменить один параметр.

Для быстрого напоминания о расположении элементов управления вернитесь к справочнику по интерфейсу (Справочная страница на английском языке). Чтобы изучить другой язык или добавить пакеты, перейдите к разделу Языки и пакеты (Справочная страница на английском языке).
