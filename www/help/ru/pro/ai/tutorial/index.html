От офлайн-подсказок к написанию кода с помощью ИИ

Начните с быстрых табличных подсказок, которые не требуют оплаты за запросы. Затем настройте Ассистента, запросите онлайн-варианты, попробуйте модель на устройстве и завершите специализированными ячейками AI Prompt, объясняющими ваш код.

  • Только в Pro
  • Pro 1.4.0 + будущие элементы управления выполнением
  • Локальная модель: Android

Большинство снимков экрана сделаны в приложении для Android, некоторые — в браузере. Интерфейс может отличаться в зависимости от версии приложения.

Проверьте версию. Изменения в механизме выполнения, описанные в приложении, запланированы для предлагаемой Pro 1.5.0, которая еще не выпущена; окончательный номер версии может измениться.

«Free» здесь означает отсутствие оплаты за API. Табличные подсказки и модель на устройстве не тарифицируются провайдером. Это не делает их функциями редакции Free: это руководство предназначено для SciREPL Pro. Онлайн-запросы используют вашу собственную учетную запись у провайдера и могут стоить денег.

Шаг 1 · Ключ API не требуется

Начните с офлайн-подсказок по таблицам

Найдите ☰ Меню в заголовке приложения: это кнопка с тремя горизонтальными линиями. Откройте Автодополнение. Его переключатель Раздел разделяет Общие, ИИ-подсказки (онлайн) и Локальная модель (на устройстве). Начните с General.

  1. Установите Локальное автодополнение кода → Вкл.. Значение по умолчанию Авто (включено на компьютере, выключено для сенсорного ввода) иначе оставило бы функцию выключенной на телефоне.
  2. Установите Чипы подсказок → Вкл. и сохраните Подсказки → У курсора. Чтобы изолировать таблицы, установите Подсказки ИИ → Отключено в онлайн-разделе и Использовать локальную модель → Отключено в локальном разделе, если какой-либо из этих параметров был включен ранее. Вернитесь в General.
  1. Закройте Completion. В новой тренировочной рабочей тетради выберите ячейку код и язык JavaScript. Введите cons, расположив курсор в конце без выделения текста. Эти первые буквы const называются префиксом. Обратите внимание на появление const.
  2. На снимке экрана ниже за cons следует полупрозрачный t — встроенный полупрозрачный текст. Коснитесь Принять или нажмите Tab, чтобы вставить предложение и получить const. Если вместо этого появится чип const, нажатие на него — еще один способ принять этот вариант. Завершите строку самостоятельно, например: const values = [12, 15, 18];.

Accept — это не Run. Принятие подсказки изменяет исходный код; оно не выполняет ячейку. Примеры на JavaScript и Python в этом разделе демонстрируют автодополнение при редактировании. Выполнение этих практических ячеек не входит в задачи раздела. Когда включен только уровень офлайн-таблиц, ввод префикса не отправляет запрос к API и не запускает среду выполнения языка только ради генерации подсказок.

Будущая онлайн-предвыборка: планируется подключаемый режим, который сможет отправлять запросы к модели по мере ввода. Он пока недоступен, и номер выпуска ему не присвоен. Утверждение об отсутствии запросов выше относится к текущему уровню офлайн-таблиц, а не к этому будущему режиму.

Посмотрите два варианта офлайн-отображения на телефоне. Оставьте Чипы подсказок → Вкл., выберите Python и введите pri. Полупрозрачный фрагмент nt после курсора предлагает print; он не станет частью исходного кода, пока вы его не примете. Вам не нужно отключать чипы, чтобы видеть полупрозрачный текст. Одиночный кандидат может отображаться полупрозрачным текстом, тогда как чипы предлагают выбор, если подходит несколько вариантов. Оставьте Подсказки ИИ и Использовать локальную модель выключенными для обоих примеров.

Пока чипы по-прежнему находятся в состоянии Вкл., замените тренировочный ввод этими тремя строками, оставив курсор после незавершенного sample_m. Строка предложит sample_mean и sample_median из имен вашего собственного исходного кода. Коснитесь чипа, чтобы выбрать вариант; в отличие от полупрозрачного текста, эта строка показывает альтернативы.

sample_mean = 0
sample_median = 0
sample_m

Строка дополнительных клавиш, видимая на изображениях телефона с Python, и цвета синтаксиса при вводе — это отдельные, необязательные элементы управления Pro. См. Практическое руководство по внешнему виду: дополнительные клавиши и цвета синтаксиса, чтобы включить или отключить их, а также найти отдельный флажок подсветки в редакторе файлов.

Опробовав эти варианты отображения автодополнения, переключитесь обратно на JavaScript и оставьте чипы включенными до конца урока.

Показанные здесь офлайн-чипы, включенные в Автодополнение → Общие → Чипы подсказок, объединяют подготовленные таблицы имен с локальной информацией о коде. В Python сюда входят переменные и функции, найденные в коде рабочей тетради, а также кэшированные имена ядра и атрибуты объектов, включая методы. Частота и история принятия помогают их ранжировать. В других языках охват отличается: статические списки, невыполненные определения или устаревшие снимки могут предложить имя, которое в данный момент недоступно в области видимости. Табличное дополнение не является языковой моделью и не анализирует вашу задачу.

Только в конце ячейки — альтернатива, если подсказки в середине ячейки вас отвлекают. Выделение, строка, комментарий или разделенное имя могут намеренно не давать подсказок. В компактной альбомной ориентации необязательные строки могут исчезать, чтобы сохранить место для кода; см. Настройки внешнего вида.

Шаг 2 · Онлайн-настройка

Сохраните ключ API

Ключ API позволяет SciREPL использовать подконтрольную вам учетную запись у провайдера. Получите ключ у этого провайдера, ознакомьтесь с актуальными тарифами и лимитами учетной записи и используйте для этого урока только небольшую практическую рабочую тетрадь с неконфиденциальными данными.

  1. Откройте Меню → 🤖 AI Assistant (Pro). Нажмите на панели значок ⚙ шестеренки , чтобы открыть AI Settings.

    Не видите шестеренку? Клавиатура может сместить или прокрутить панель Ассистента. Потяните содержимое панели вниз, чтобы прокрутить ее к началу и увидеть шестеренку; закрытие клавиатуры также освободит место.

  2. Установите Настроить модель для → ИИ-ассистент. Выберите Бэкенд (например, OpenRouter) и Модель, а также проверьте конечную точку (endpoint), если ваш бэкенд поддерживает ее настройку.
  3. Введите соответствующий Ключ API. Используйте Сохранённые ключи для управления ключами других пар провайдера и эндпоинта. Ключ для одного назначения не подходит автоматически для другого.
  4. Нажмите Сохранить. Само по себе сохранение настроек не отправляет запрос к модели. Оставьте панель открытой для следующего шага.

Не храните ключ в рабочей тетради. Не вставляйте его в ячейку, запрос, снимок экрана или экспортированный файл. Сохраненные ключи остаются в локальном хранилище приложения/браузера без шифрования на уровне приложения; защищайте устройство и не выполняйте ненадежный код. В политике конфиденциальности Pro объясняется, что именно сохраняется и передается.

Недорогая модель с поддержкой инструментов — разумная отправная точка для Ассистента. Примеры для сравнения включают GLM 5.3 Flash, GPT-6 Luna, Claude Haiku 5.5 и DeepSeek V4 Flash. Точные идентификаторы моделей, доступные версии, поддержка инструментов и цены зависят от версии вашего приложения и провайдера; сверяйтесь с текущим списком выбора и документацией провайдера. Для появления недавно анонсированной модели может потребоваться обновление приложения. Позже вы сможете выбрать другую недорогую модель специально для автодополнений.

Модели нет в списке? В Настройки ИИ → Настроить модель для → ИИ-ассистент сначала выберите правильный Бэкенд, затем укажите точный идентификатор модели API в Или введите пользовательский ID модели под списком выбора Model и нажмите Сохранить. Это поле уже доступно в Pro 1.4.0.

Сверяйте идентификатор с выбранным провайдером, а не просто с маркетинговым названием модели. Для OpenRouter укажите префикс организации — например, anthropic/claude-haiku-5.5 на странице этой модели. Вводите именно идентификатор, а не URL этой страницы. Пользовательский идентификатор имеет приоритет над выпадающим списком; повторный выбор модели из списка очищает пользовательское поле.

Идентификатор не добавляет поддержку API. Модель должна поддерживать вызовы инструментов через API, который использует SciREPL. Проверяйте доступ у провайдера, совместимость и текущие цены; сохранение не проверяет их и не отправляет запрос к модели.

Шаг 3 · Осознанное использование инструментов

Создайте небольшой пример с предустановкой агента Open

Открытый — это второй по уровню разрешений пресет безопасности после Полный контроль. По умолчанию он разрешает редактирование блокнота с меньшим количеством запросов подтверждения, чем Cautious. Запрашивается ли подтверждение выполнения, зависит от вашей версии и настроек разрешений; см. приложение о будущей системе подтверждения выполнения. Используйте его осознанно в тренировочной рабочей тетради, а не как обязательное требование для автодополнения.

  1. В AI Settings выберите Security Level → Open и Запись агента → Активный лист. Оставьте просмотр исходного кода выключенным и отключите Автозапуск ячеек, созданных ИИ. В разделе Kernels…, установите JavaScript → Ask, затем сохраните. Это правило для ядра все равно будет запрашивать подтверждение, даже если ранее для инструмента выполнения было сохранено значение Allow.

    Отключение автозапуска — это не блокировка выполнения. Оно останавливает автоматический запуск вновь созданных ячеек, но не отключает отдельные запросы execute_cell или run_cells. В выпущенной версии Pro 1.4.0 значение Open по умолчанию может разрешать их без запроса подтверждения. В будущей версии значение Open по умолчанию будет запрашивать подтверждение, однако явное разрешение (Allow) для инструмента или ядра может изменить это поведение по умолчанию. Настройка Настройки ИИ → Ядра… → JavaScript → Спрашивать сохраняет выполнение JavaScript в этом упражнении под защитой подтверждения. Ваш собственный ручной запуск ячейки Run остается отдельным действием. Элементы управления выполнением в следующей версии подробно описаны в приложении.

    Если вы предпочитаете больше подтверждений, используйте вместо этого Осторожный. Режим Open по-прежнему соблюдает отдельные параметры просмотра исходного кода и области записи; Full control обходит эти два общих ограничения. Индивидуальные разрешения и другие защитные барьеры по-прежнему действуют. Просмотр представляет собой дополнительное ограничение преимущественно для чтения, которое помешало бы этой демонстрации создания ячеек.

    Что изолированная среда браузера защищает — а что нет

    Обычное выполнение рабочей тетради происходит в браузере/WebView и его средах выполнения языков с виртуальной файловой системой, а не с неограниченным доступом к файлам вашего телефона. Это полезный рубеж, но не гарантия того, что код не может нанести вред. Разрешенный код JavaScript и мосты к нему могут получить доступ к данным приложения и сохраненным учетным данным; ограничения сети действуют по принципу наилучших усилий после запуска разрешенного кода, а не как изолирующий барьер, которому следует доверять секреты. Будущий запрос на выполнение добавляет шаг подтверждения, а не изоляцию от данных приложения. Используйте тренировочную рабочую тетрадь и не храните в ней конфиденциальные данные.

    Удаленный терминал / терминал MCP устроен иначе: он может предоставить доступ к реальной командной оболочке на хосте брокера за пределами локальной песочницы браузера. Оставьте Remote и Terminal выключенными здесь. Ознакомьтесь с разделом Удаленный доступ и безопасность (Справочная страница на английском языке) перед их включением. Вежливая просьба «не делай...» в запросе не является мерой безопасности.

  2. На панели Ассистента выберите This workbook. Оставьте параметры Review, Remote и Terminal выключенными для этого примера с прямым подключением к провайдеру.
  3. Отправьте тренировочный промпт из врезки ниже. Кнопка панели Send уже запускает агентный цикл инструментов: здесь нет дополнительного переключателя «Agent mode». Кнопка полноэкранного редактора Agent представляет собой отдельный рабочий процесс.

    Скопируйте этот промпт. Вставьте его в поле сообщения Ассистента, а не в ячейку с кодом, затем нажмите Отправить.

    В этой практической рабочей тетради добавьте пояснение на Markdown, за которым следует
одна ячейка JavaScript с именем summary_demo. Сгенерируйте входной
массив из 10 псевдослучайных целых чисел от 1 до 20 включительно.
Используйте генератор Парка — Миллера с начальным state 42. Для каждого
значения сначала обновите state = (16807 * state) % 2147483647;
затем добавьте 1 + Math.floor(20 * state / 2147483647).
Сгенерируйте массив по этому правилу; не прописывайте его значения жестко в коде
и не используйте Math.random. Сбрасывайте state на 42 при каждом запуске ячейки (Run).
Выведите сгенерированный входной массив, затем вычислите количество элементов (длину
массива), среднее арифметическое, минимум и максимум. Выведите каждый
результат на отдельной строке с меткой с помощью console.log.
Используйте обычные массивы JavaScript, арифметику и Math.floor,
без сторонних пакетов.
Не запускайте ячейки и не изменяйте существующие. Не используйте файлы,
хранилище, API DOM или сетевые запросы. Объясните ожидаемые
результаты, чтобы я мог проверить код.
  4. Прочтите предложенное пояснение и новую ячейку summary_demo. Убедитесь, что она генерирует входные данные по указанному правилу и вычисляет сводные показатели на основе этого массива. Запустите эту ячейку самостоятельно, затем сравните с приведенной ниже проверкой. Ожидаемые результаты: количество элементов 10, среднее 9.3, минимум 1, максимум 20.

Проверьте входные данные и сводные показатели

Семя (seed) фиксирует последовательность, поэтому эти кажущиеся случайными входные данные воспроизводимы. При соблюдении описанного выше правила «обновление перед выборкой» ожидаются следующие значения:

Input: [1, 11, 15, 6, 8, 4, 20, 11, 11, 6]
Count: 10
Mean: 9.3
Minimum: 1
Maximum: 20

Текстовые метки вывода могут отличаться, но числа должны совпадать. Повторный запуск ячейки должен давать те же входные данные и сводные показатели. Другое начальное значение seed изменит ход упражнения; этот небольшой генератор предназначен для воспроизводимой демонстрации, а не для криптографически безопасной случайности.

Перед нажатием Send: Ассистент включает выбранную беседу и ограниченный предварительный просмотр ячеек текущей рабочей тетради (до первых 500 символов каждой ячейки плюс метаданные). Разрешенные инструменты могут передавать больше данных. Отключение просмотра исходного кода не останавливает отправку предварительного просмотра рабочей тетради. Это отличается от передачи меньшего объема данных текущей ячейки, используемой автодополнением ниже. Планируемые изменения контекста рабочей тетради описаны в приложении.

Работа приостановлена с кнопкой Continue? Параметр Ограничения агента (за запуск) → Макс. шагов, выделенный ниже, управляет лимитом шагов для одного ограниченного запуска. Агент может достичь этого лимита до завершения задачи. Ознакомьтесь с тем, что он уже выполнил, затем нажмите Продолжить, если задача не завершена и вам требуется еще один ограниченный запуск. Продолжение может повлечь дополнительные расходы на API; оно не требуется после статуса Готово.

Шаг 4 · Запрашивайте альтернативы, когда они вам нужны

Запросите автодополнения на основе API

  1. Откройте Меню → Автодополнение, затем выберите Раздел → ИИ-подсказки (онлайн). Установите Подсказки ИИ → По нажатию.
  2. Оставьте Модель автодополнения → Использовать настройки ИИ-ассистента, чтобы унаследовать его провайдера, конечную точку и модель. Или выберите Выбрать провайдера и модель, укажите сохраненную пару провайдера и эндпоинта, а также недорогую модель, подходящую для коротких подсказок. На этом экране ключ не вводится; Открыть настройки ИИ позволяет предварительно добавить его.
  3. Откройте Дополнительно этого раздела, чтобы проверить время ожидания ответа и лимиты расходов. Значения по умолчанию составляют 6 с, $0.25/день и $5/месяц. Проверяйте цены перед их увеличением.
  4. Вернитесь в редактор JavaScript и введите этот практический фрагмент: 
    const values = [12, 15, 18];
const average =
    Оставьте курсор после незавершенной строки const average = . Нажмите … в конце строки подсказок, используйте дополнительную клавишу …AI или нажмите Ctrl + Shift + Space.
  5. Проверьте фактическую полезную нагрузку и назначение первого запроса перед его отправкой. Чипы ИИ отмечены значком ✦. Коснитесь одного из них, чтобы принять его; сокращенный или многострочный чип сначала откроет предварительный просмотр. Проверьте полученный исходный код перед выполнением (Run).

Выбирайте код, а не просто чип ИИ. В этом запросе первый чип предложил values.reduce((a, b) => a + b, 0) / values.length;. Нажмите на него, чтобы просмотреть полный предпросмотр: он суммирует массив и делит на его длину, что дает 15 для этого примера. Второй чип предложил eval(values.join(' + ')) / values.length;. Отклоните эту ненужную альтернативу с eval: для вычисления среднего значения не требуется превращать строку в исполняемый код. Проверяйте возвращенный код перед принятием и запускайте Run только после проверки.

Запрашивается до пяти вариантов, но на вашем экране может поместиться меньше. Повторное нажатие сначала перелистывает уже полученные варианты; когда они заканчиваются, можно запросить новые. Коснитесь во время анимации выполнения запроса, чтобы отменить его. Запоздалые ответы отбрасываются по истечении времени ожидания, а ввод текста или перемещение курсора делают старые подсказки неактуальными.

Независимый означает независимый: отдельный выбор модели для автодополнения сохраняется при смене модели Ассистента. Это удобно, когда вам нужен мощный агент, но недорогое автодополнение. Следование за Ассистентом наследует только его конфигурацию, а не его историю бесед или разрешения агента.

Знайте, за что вы платите и что отправляете

Онлайн-автодополнение работает по запросу: обычный ввод текста ничего не отправляет. Режим Prefetch while I type пока недоступен в этом рабочем процессе. Автодополнение отправляет ограниченный контекст текущей ячейки: не более 1,500 символов до курсора, 200 после него и до 12 локальных имен, но не чат Ассистента и не всю рабочую тетрадь целиком. Маскирование секретов работает по принципу наилучших усилий, поэтому проверяйте полезную нагрузку самостоятельно.

Всегда разрешать предоставляет постоянное согласие для этого назначения; при смене провайдера, эндпоинта или модели запрос будет показан снова. Отправлять не спрашивая изначально активирует этот выбор, но все же однократно показывает первую реальную полезную нагрузку. Оставьте Спрашивать каждый раз на этапе обучения.

Лимиты на день и месяц представляют собой мягкие ограничители расходов только для автодополнения, а не гарантированные лимиты биллинга у провайдера и не бюджет для запросов Ассистента или AI Prompt. Сбои и отмены могут сохранять зарезервированную сумму списания. Очистка истории расходов не сбрасывает значения установленных лимитов. Для модели без указанной цены необходимо явно задать пределы цен на ввод и вывод, иначе приложение откажется отправлять запрос.

Шаг 5 · Необязательная загрузка для Android

Попробуйте модель на устройстве

Необязательная модель Qwen2.5-Coder 0.5B локально предлагает варианты кода, когда таблицы не дают уверенного ответа. Это небольшая модель автодополнения кода, а не замена диалоговому агенту. После установки выполнение инференса не отправляет вводимый код провайдеру и не влечет расходов на API.

  1. На поддерживаемом телефоне Android с версией Pro, установленной из Google Play, откройте Меню → Автодополнение → Раздел → Локальная модель (на устройстве).
  2. Нажмите Установить и выделите время и место в хранилище для загрузки объемом примерно 400 МБ. Текущие версии, установленные из сторонних источников (sideload), не могут загрузить модель через этот процесс.
  3. После завершения оставьте Использовать локальную модель → Когда нет уверенности. Таблицы отвечают на простые случаи, а модель подключается, когда они не дают однозначного ответа. Значение Всегда запускает ее чаще; Отключено отключает ее без удаления загруженных файлов.
  1. Вернитесь в ячейку с кодом и сделайте паузу на незавершенном имени или строке. Результаты зависят от контекста; не каждая пауза вызывает появление подсказки. Примите подходящий полупрозрачный текст или чип, проверьте исходный код, а затем выполните ячейку (Run) отдельным действием.

На каком телефоне работать комфортно?

Минимальным требованием является 64-разрядный ARM Android минимум с 4 ГБ оперативной памяти, что не гарантирует безупречной плавности. Практическим ориентиром комфортной работы служит телефон уровня Galaxy S24+: Samsung указывает для S24+ объем 12 ГБ ОЗУ, что оставляет больше запаса для приложения, ядер и модели. Это рекомендуемый уровень производительности, а не требование покупать именно эту модель. Спецификации устройств серии Samsung S24.

Модель Galaxy S10+ имеет подходящие варианты с 8 ГБ или 12 ГБ ОЗУ. По неофициальному опыту разработчика, локальное автодополнение может работать на этом устройстве, но ощущаться медленнее, чем дополнение через API; сравнение зависит от модели и сети. В записанном тесте локального движка S10+ не измерялся, поэтому это не точное сравнение скорости и не гарантия для каждого устройства. Обращайте внимание на задержки или зависание приложения при сочетании модели с большими рабочими тетрадями и требовательными к памяти ядрами. Спецификации устройств серии Samsung S10.

Предыдущий тест нативного движка на устройстве класса S24+ показал медианное время первого слова при «горячем» старте около 0.10 с и при «холодном» старте около 0.24 с после загрузки. Это примерные результаты тестов, а не гарантии: начальная загрузка без кэша занимала несколько секунд. Загруженная модель добавляла примерно 460–490 МБ к памяти процесса приложения в дополнение к WebView, средам выполнения Python/R и операционной системе.

Если старый телефон начинает работать медленно: установите Использовать локальную модель → Отключено и используйте вместо этого таблицы или варианты API по нажатию. В разделе локальных настроек Дополнительно установка параметра Keep loaded after leaving the app → 0 выгружает ее при выходе из приложения; параметры выгрузки при простое и низком заряде батареи также помогают. Сохраните или экспортируйте рабочую тетрадь перед устранением неполадок. Модель без оплаты за API все равно потребляет память, хранилище и заряд аккумулятора.

Шаг 6 · Понимайте код в процессе его создания

Завершите специализированной ячейкой AI Prompt

Ассистент удобен для многоэтапной работы. Ячейка AI Prompt лучше подходит для небольшого воспроизводимого вопроса о конкретном фрагменте кода: она выполняет один изолированный запрос, без истории Ассистента или инструментов. Используйте ее, чтобы узнать, почему вычисление работает, прежде чем расширять его.

Здесь мы возвращаемся к созданной на шаге 3 ячейке summary_demo с фиксированным сидом. Мы запрашиваем объяснение этого существующего вычисления — а не еще один случайный массив и не пример автодополнения только среднего значения из шага 4.

Оставьте тип ячейки код, затем выберите AI Prompt в выпадающем списке языков и режимов. Если он отсутствует, включите его в Меню → Языки и режимы.

Способ контролировать расходы на API и улучшить понимание кода. Специализированный AI Prompt может отправлять меньше контекста, чем растущий диалог с агентом, и избегать многошагового цикла инструментов, снижая объем входных токенов и потенциальные расходы. Экономия не гарантируется: тарифы модели, длина ответа, токены рассуждения и выбранный контекст по-прежнему имеют значение. Эти запросы используют провайдера и модель Ассистента, а не независимую модель автодополнения, и на них не распространяются защитные лимиты расходов на автодополнение.

Еще один пример · Проверка графика перед заменой ячейки

Теперь попросите AI Prompt написать код в другую ячейку с обязательной проверкой перед заменой чего-либо. Мы построим график того, как выборочная дисперсия меняется по множеству небольших выборок. Это новые выборки из нормального распределения, а не прежний массив целых чисел summary_demo. Цель состоит в том, чтобы освоить цепочку Настроить → предпросмотр → Применить → Выполнить, а не овладеть статистикой.

Дисперсия — это не t-распределение Стьюдента. Для независимых нормальных выборок объема 10 величина 9s² / σ² подчиняется распределению хи-квадрат с 9 степенями свободы. Здесь истинная дисперсия σ² = 1. Распределение Стьюдента описывает стандартизированное выборочное среднее (mean − μ) / (s / √10) с использованием выборочного стандартного отклонения s; здесь оно также имеет 9 степеней свободы. NIST: дисперсия · NIST: среднее.

  1. В практической рабочей тетради создайте ячейку JavaScript, содержащую // Reviewed plot code will go here.. Выполните этот безобидный комментарий, чтобы сохранить ячейку. Удерживайте нажатой ее метку In[…] и назовите ее variance_plot. Сохраняйте это имя уникальным в рабочей тетради; см. именование ячеек.
  2. Добавьте отдельную ячейку AI Prompt и вставьте в нее следующий запрос: 
    Верните только полный исходный код JavaScript, без блоков разметки Markdown.
Постройте воспроизводимую гистограмму оценок выборочной дисперсии.
Смоделируйте 2,000 новых выборок, каждая из которых содержит 10 стандартных нормальных значений N(0,1).
Не используйте повторно ранее созданный массив целых чисел из summary_demo.
Инициализируйте state = 42 один раз для всего прогона, а не для каждой выборки. Перед каждой равномерной выборкой задайте state = (16807 * state) % 2147483647, затем u = state / 2147483647.
Для каждой нормальной выборки используйте два последовательных равномерных значения: sqrt(-2 * log(u1)) * cos(2 * PI * u2). Не используйте повторно оставшийся результат синуса и не применяйте Math.random.

Отобразите canvas с помощью window.renderImage(canvas.toDataURL("image/png")).

Ни то, ни другое действие не выполняет предложенный код JavaScript. Не выбирайте Новую связанную ячейку для этой демонстрации: эта опция вставляет невыполненную ячейку результата без данного этапа подтверждения замены.

Если что-то не работает

Нет офлайн-подсказок на телефоне
Выберите General → Local code completion → On вместо Auto. Проверьте включение чипов, положение курсора, язык и достаточно ли места для дополнительной строки.
Онлайн-запрос не отправляется
Проверьте параметр On tap, сохраненный ключ для точной пары провайдера и эндпоинта, указание цен или пределов стоимости для выбранной модели, согласие и общие суммы расходов. Пресет Open не требуется для автодополнения. Необходимы безопасный контекст браузера и API Web Locks; в неподдерживаемых контекстах запросы отклоняются.
Ассистент запрашивает подтверждение перед выполнением ячейки — или не запрашивает
Проверьте версию приложения, разрешения на выполнение в Security… и правила в Kernels…. Будущее значение Open по умолчанию — Ask; в версии Pro 1.4.0 по умолчанию выполнение может разрешаться. Отключение Auto-run не является запретом (Deny) для инструмента выполнения. Параметр Always allow для онлайн-дополнения не дает разрешения на выполнение ячеек; см. подтверждение выполнения.
Автодополнение не учитывает другую ячейку
Онлайн-варианты используют ограниченный контекст текущей ячейки, а не весь ваш блокнот. Используйте AI Prompt с явно выбранным исходным кодом или Ассистента, если вам требуется более широкое объяснение.

Приложение · Будущая система подтверждения выполнения · предлагаемая Pro 1.5.0

Еще не выпущено: эти элементы управления описывают реализацию в следующем релизе, а не обещание того, что они есть в вашей версии 1.4.0. Номер выпуска является предварительным.

  • Меню Настройки ИИ → Безопасность… → execute_cell / run_cells уже предлагает варианты Default / Allow / Ask / Deny. Это обновление меняет унаследованное значение Default для пресета Open на Спрашивать; для Full control сохраняется значение Allow. Явные правила для инструментов или ядра могут заменять унаследованные значения по умолчанию; если оба правила заданы явно, приоритет имеет более безопасное. На этапе обучения оставьте Default или Ask. Значение Allow — это переопределение, а не усиленная изоляция; правила ядра Ask/Deny, режим Review и глобальное отключение JavaScript по-прежнему применяются.
  • Прочтите запрос на выполнение перед выбором Выполнить; оставьте пункт Разрешить дальнейшее выполнение ячеек Ассистента без запроса неотмеченным, чтобы подтвердить только этот запрос. Установка этого флажка изменяет общее правило инструмента выполнения для всех рабочих тетрадей до сброса — а не только для этой ячейки, беседы или провайдера. Явное правило ядра Ask скрывает этот параметр.
  • Запросы на инспекцию пространства имен и выполнение вновь созданных ячеек не могут создать такое постоянное разрешение. Запрос на выполнение созданной ячейки содержит ограниченный предварительный просмотр кода; длинный предпросмотр заканчивается многоточием. Если он сокращен, выберите Cancel, изучите полный исходный код созданной ячейки и запускайте ее (Run) самостоятельно, только если доверяете ей. Ранее сохраненное разрешение Allow на выполнение все еще может разрешать автозапуск созданных ячеек при включенном Auto-run, поэтому держите Auto-run выключенным.
  • Если вы выберете пресет, отличный от Full control, в то время как сохранено действующее разрешение Allow для инструмента выполнения, предупреждение предложит Сбросить по умолчанию, Оставить «Разрешить» или Отмена. Reset восстанавливает правило инструмента для выбранного пресета без сброса переопределений ядра. Keep сохраняет переопределение. Cancel восстанавливает предыдущий выбранный пресет. Варианты Reset и Keep остаются черновиками изменений до сохранения настроек (Settings).

Подтверждение выполнения не является безоговорочным разрешением на передачу данных. Вывод инструмента выполнения может возвращаться в модель Ассистента, а разрешенный код может использовать сеть. Параметр онлайн-дополнения Всегда разрешать, проверка контекста в AI Prompt и раскрытие конфиденциальности для Remote/MCP остаются раздельными. Выполнение блокнота через MCP использует те же проверки выполнения; эти проверки не изолируют командную оболочку Terminal на брокере.

Приложение · Планируемый контекст и история рабочей тетради

Только проектное предложение: эти функции не реализованы и не привязаны к какому-либо релизу. Они не связаны с описанными выше изменениями системы подтверждения выполнения и не задерживают текущий выпуск.

  • Получение сводки рабочей тетради по мере необходимости. План предусматривает замену регулярных автоматических предварительных просмотров исходного кода инструментом каталога, содержащим только метаданные: имена ячеек, необязательные описания, языки и типы, а также номер редакции рабочей тетради. Предлагаемый инструмент — list_cells с параметром view: "metadata"; выбранный исходный код Ассистент считывал бы отдельно. Это ограниченный обзор структуры, а не автоматически сгенерированное объяснение ИИ.
  • Прикреплять один раз, а не при каждой отправке (Send). Предлагаемый флажок Attach workbook summary this time мог бы быть изначально отмечен для новой беседы и сниматься после фактической отправки этого вложения. Вы могли бы снять его перед отправкой или установить снова для получения свежего обзора. Его начальное состояние по умолчанию еще требует оценки конфиденциальности и удобства использования. Продолжение беседы не добавляло бы новую сводку, а переключение вкладок не приводило бы к его скрытому повторному включению. Предварительный просмотр и существующие разрешения на чтение и конфиденциальность продолжали бы действовать; для большой рабочей тетради могли бы потребоваться дополнительные страницы.
  • Снятие флажка не удаляет историю. Это предотвратило бы новое автоматическое прикрепление, но не удалило бы сводки, уже имеющиеся в беседе, и не заблокировало бы разрешенные операции чтения инструментами. Существующие элементы управления контекстом в полноэкранном режиме Agent, ячейках AI Prompt и автодополнении оставались бы раздельными.
  • Изменения между отправками — возможность на перспективу. Компактные обновления потребовали бы известной базовой линии отправленного контекста и надежных редакций. Правки пользователя можно было бы выделять, но изменения агента, импорты и неизвестные правки также имеют значение. Редактирование исходного кода не приводило бы к автоматической перезаписи описания ячейки; при отсутствии истории или ее устаревании потребовался бы свежий обзор, а не обновление на основе догадок.
  • Необязательная локальная история и синхронизация с GitHub — долгосрочные идеи для Pro. Локальные контрольные точки отправки могли бы поддерживать сравнение изменений (diff) на базе Git без передачи каких-либо данных. Независимая синхронизация могла бы публиковать рабочую тетрадь в Gist или в выбранный файл репозитория с собственным предпросмотром полезной нагрузки и авторизацией. Включение истории не приводило бы к отправке изменений в GitHub или передаче diff модели ИИ. Git показывает изменения содержимого, а не подтверждение того, что их сделал человек.

Секретный Gist не является приватным. Любой пользователь, имеющий URL-адрес, может прочитать его; используйте приватный репозиторий, если доступ необходимо ограничить. Удаляйте конфиденциальные данные из исходного кода и описаний рабочей тетради перед публикацией. Документация GitHub о видимости Gist.
