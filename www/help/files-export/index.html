Files, import, and export

  • Web/PWA (Free)

  • Verified: Free 1.3.2 · Pro 1.3.0

SharedVFS

SharedVFS is SciREPL’s persistent virtual filesystem for data used across languages. Common paths include:

  • /shared/data/ for datasets
  • /shared/lib/python/ for Python modules
  • /shared/lib/prolog/ for Prolog modules
  • /shared/lib/wasm/ for WebAssembly modules
  • /tmp/ for temporary working files

Open Menu → Files & Storage to browse or upload. Python can use ordinary open() paths; R, Prolog, Lua, Bash, and JavaScript expose language-specific helpers.

Notebook VFS

Notebook VFS exposes cells as files beneath /nb/. The available properties include .code, .output, .language, .type, and .name. Name cells when another cell depends on them; names are more stable than numeric positions.

Import formats

  • .srwb: SciREPL-native workbook state, including multiple tabs and SciREPL-specific cell information.
  • .ipynb: one Jupyter-compatible notebook. Supported saved outputs are shown without automatically rerunning imported code.
  • .py / .pl: source imports for Python and Prolog.
  • Package archives: install only archives you trust; they can contain notebooks, data, and modules.

Export formats

FormatBest for
.srwbBackup or move a complete SciREPL workbook
.ipynbExchange with Jupyter-compatible software
HTMLSelf-contained readable results
MarkdownText repositories and GitHub
PDFPrinting or fixed-layout sharing
DOCXWord editing, including supported equations
LaTeXAcademic document workflows

There is no automatic cloud synchronization. Seeing similar content in the Android app and a browser can be a coincidence or a shared browser-data context; do not treat it as a backup promise. Explicitly export to your chosen destination.

In Pro: workbook exports can optionally include a saved AI conversation. It is off by default. See saved conversations and Clear.
