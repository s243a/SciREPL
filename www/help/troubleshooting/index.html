Recover without guessing

Troubleshooting

  • Free + Pro
  • Android
  • Web/PWA (Free)
  • Windows preview
  • Verified: Free 1.3.2 · Pro 1.3.0

The first cell is slow

The first cell in a language initializes its runtime and may restore or fetch packages. Wait for ready, then try a second simple cell. If the second run is fast, the delay was warm-up rather than code execution.

  • Keep the app foregrounded while a large runtime starts.
  • Use Memory & Storage to check whether a runtime or cache was cleared.
  • A downloaded runtime can work offline only after its required assets have finished caching.

A cell does not run

  1. Confirm the saved cell’s language, not only the new-cell selector.
  2. Wait until the status badge is ready.
  3. Run the smallest language-specific expression from Languages and packages.
  4. Read the cell’s error before installing packages; a missing import and a missing package are different problems.

The PWA looks old

Use Menu → Reload App. On desktop you can also force-reload. A reload updates the app shell but does not replace your explicitly exported files.

Android cannot select a cloud file

Android’s document provider decides which files an app can select. Ensure the file has a recognized extension such as .srwb or .ipynb, and that the cloud provider has downloaded enough metadata to expose it. As a fallback, download it locally first, then import from Downloads.

Layout is cramped

Try portrait orientation, reduce Button size under Appearance, allow optional header shortcuts to show only when there is room, and use gesture navigation or a shorter keyboard. Pro 1.3.0 and newer Free builds enlarge compact controls with Android text zoom; tagged Free 1.3.2 does not yet include that scaling fix.

Local data is missing

Different browsers, Android app editions, and Windows profiles use different storage. An uninstall or “clear storage” operation removes local data. Restore from an exported workbook when available.

Report a reproducible problem

Include the edition, version shown in Help, platform/Android version, language runtime, exact steps, visible error, and whether the second run behaves differently from the first. Remove API keys, broker tokens, private notebook content, and sensitive URLs from screenshots or logs.

Pro networking: a policy block, ordinary browser failure, and optional isolated Android connection failure are distinct. See network controls and error meaning.
