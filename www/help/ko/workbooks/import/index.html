통합 문서 파일 직접 가져오기

이미 통합 문서 파일이 있거나 찾아보기에서 단원을 찾을 수 없나요? 기기에 파일을 저장한 다음 메뉴 → 파일 가져오기를 사용하여 SciREPL에 추가하세요. 이 간단한 단계별 안내에서는 Simpson's Paradox을 사용하며, 이는 카탈로그의 GitHub main 브랜치에서 가져온 것입니다. 이를 가져오기 위해 패키지를 설치하거나 코드를 작성할 필요가 없습니다.

SciREPL에서는 두 가지 노트북 형식을 가져옵니다: 자체 통합 문서 형식인 .srwb와 Jupyter 노트북 형식인 .ipynb입니다. 이 예제에서는 .srwb를 사용하며, 아래의 형식 참고 사항에서 Jupyter 가져오기의 서로 다른 실행 동작을 설명합니다.

  • Free + Pro
  • Android 및 브라우저 단계
  • 약 3분

메뉴 스크린샷은 Samsung Galaxy S24+에서 실제로 캡처한 Android 화면으로, Play 스토어 설치본이 아닌 SciREPL Free 1.4.0-debug를 보여줍니다. 가져온 통합 문서 스크린샷은 Chromium 브라우저에서 모바일 크기 뷰포트로 Free 1.4.0을 별도로 캡처한 것이며, Android 파일 선택기 가져오기의 증거는 아닙니다. 둘 다 6일 시월 2026년에 촬영되었습니다. 다른 에디션, 버전 및 파일 선택기에서는 컨트롤이 다르게 배치될 수 있습니다. 해당 예제는 본 가이드를 위해 검토된 영어 simpsons-paradox.srwb 파일로, SciREPL 카탈로그의 main 브랜치에서 가져온 것이며 해당 브랜치는 변경될 수 있습니다. 캡처 및 소스 세부사항 (영어 참조 페이지)에 정확한 이미지 크기와 검토된 파일 해시가 기록되어 있습니다.

모든 튜토리얼

단계 1

기기에 워크북 파일 저장하기

GitHub의 main 브랜치에는 둘러보기에 표시되는 최신 안정 카탈로그 릴리스에 아직 포함되지 않은 워크북이나 업데이트가 포함되어 있을 수 있습니다. 카탈로그 릴리스는 앱 릴리스와 독립적으로 변경됩니다. 직접 파일을 가져오면 해당 워크북이 둘러보기에 나타날 때까지 기다리지 않고도 신뢰할 수 있는 워크북을 사용해 볼 수 있습니다.

  1. GitHub에서 심슨의 역설 보기를 확인한 다음, 실제 워크북 파일(.srwb)을 다운로드하세요. 두 번째 링크는 GitHub 웹 페이지가 아닌 원본 파일을 엽니다.
  2. 브라우저에서 파일을 다운로드하지 않고 텍스트로 표시하는 경우 브라우저의 저장/다운로드 동작을 사용하세요. 스크린샷이나 HTML 페이지가 아닌 워크북 파일 자체를 저장해야 합니다.
  3. 파일명 simpsons-paradox.srwb 및 .srwb 확장자를 그대로 유지하세요. 저장된 위치를 확인하세요. Android에서는 보통 다운로드 폴더를 사용하며, 데스크톱에서는 다운로드 폴더 또는 직접 선택한 폴더일 수 있습니다.

이것은 고정된 릴리스 다운로드가 아닙니다. main 브랜치는 개발 브랜치이므로, 이 스크린샷을 찍은 이후 파일의 내용과 셀이 변경될 수 있습니다. 저장한 파일은 로컬 복사본이며, 나중에 GitHub에서 변경되더라도 가져온 탭이 자동으로 업데이트되지는 않습니다.

다운로드는 가져오기가 아닙니다. 파일을 저장하면 기기에 저장될 뿐, SciREPL에서 워크북이 바로 열리지는 않습니다. 텍스트 편집기에서 열거나 SciREPL의 파일 보기에 넣을 필요는 없습니다. 다음 단계에서 다운로드한 해당 파일을 선택합니다.

다른 사람에게서 받은 신뢰할 수 있는 .srwb 파일이 이미 있다면 예제 다운로드를 건너뛰고 해당 파일을 사용하세요. 워크북 제목과 셀 개수는 3단계의 확인 내용과 다를 수 있습니다.

단계 2

메뉴를 찾아 파일 가져오기 선택하기

  1. SciREPL(으)로 돌아갑니다. 앱 상단의 헤더 행에서 ☰ 메뉴(가로줄 세 개가 있는 버튼)를 찾아 탭하거나 클릭하세요.
  2. 📂 파일 가져오기 (예: .srwb, .ipynb, .csv, .py, .zip)을(를) 선택합니다. 메뉴가 화면보다 길면 메뉴 내부를 스크롤하여 찾으세요.
  1. Android의 경우: 시스템 파일 선택기가 열립니다. 다운로드에서 찾거나 파일을 저장한 위치로 이동하세요. simpsons-paradox.srwb을(를) 선택합니다. 파일 선택기는 Android 시스템 기능이므로 레이아웃이나 최종 열기 또는 선택 컨트롤은 기기에 따라 다를 수 있습니다.
  2. 데스크톱의 경우: 파일 선택기를 사용하여 다운로드할 때 선택한 폴더를 찾으세요. simpsons-paradox.srwb을(를) 선택하고 선택 항목을 확인합니다. Android의 다운로드 화면을 찾는 대신 이 방법을 사용하세요.
  3. SciREPL(으)로 돌아와 가져오기가 완료될 때까지 기다립니다. 메뉴가 여전히 열려 있다면 메뉴를 닫아 워크북을 확인하세요.

통합 문서는 데이터 파일 업로드가 아닙니다. .srwb 파일을 가져오면 해당 통합 문서가 별도의 탭으로 추가되며, 파일에 여러 통합 문서가 포함된 경우에는 별도의 여러 탭으로 추가됩니다. 기존 탭은 유지됩니다. 통합 문서를 파일 보기에 넣지 않으며, 현재 통합 문서를 대체하지도 않습니다.

단계 3

아무것도 실행하기 전에 새 통합 문서를 확인하세요

  1. 통합 문서 선택기에서 Simpson's Paradox을 찾으세요. 해당 새 탭이 아직 선택되지 않은 경우 선택하세요. 소개 제목은 Simpson's Paradox: When Every Group Disagrees with the Total입니다.
  2. 소개를 읽고 셀들을 스크롤하여 살펴보세요. 이 스크린샷들을 위해 검토된 버전에는 일곱 개의 셀이 있습니다: 세 개의 텍스트 셀, 세 개의 R 셀, 그리고 한 개의 JavaScript 셀입니다. main의 이후 버전은 다를 수 있습니다.
  3. data, compute, viz 순서대로 명명된 R 셀을 찾으세요. JavaScript 셀의 이름은 js_check이며 별도의 선택적 확인 단계입니다. 코드뿐만 아니라 설명 텍스트도 읽어보세요.

.srwb 파일의 경우 가져오기가 실행을 의미하지는 않습니다. 다른 가져오기에 대해 자동 실행이 활성화되어 있더라도 SciREPL에서는 .srwb 파일을 가져올 때 코드를 실행하지 않습니다. 실행 또는 모든 셀 실행을 선택하기 전에 낯설거나 신뢰할 수 없는 출처의 코드를 검사하세요.

일반적인 .srwb 가져오기는 파일에 저장된 코드 셀 출력이 포함되어 있더라도 현재 이를 삭제합니다. Markdown 텍스트는 유지되어 렌더링되므로 소개가 즉시 표시됩니다. 차트나 기타 코드로 생성된 이미지를 다시 생성하려면 종속 셀들을 순서대로 하여 해당 코드 셀들을 다시 실행하세요. 가져오기를 수행해도 활성 R 또는 기타 런타임 변수는 복원되지 않습니다.

단계 4

선택 사항: 가져온 레슨 실행하기

수동 가져오기가 완료되었습니다. 코드를 실행하는 것은 별도의 단계입니다. Simpson's Paradox는 합성 교육용 데이터를 사용하여 집단 내 비교가 전체 비교와 어떻게 다를 수 있는지 보여줍니다. 이를 살펴보려면 저장된 코드 셀의 ✎ 연필을 탭하고 코드를 살펴본 다음, 해당 셀의 실행 버튼을 사용하세요.

  1. R 셀 data을 실행한 다음, 텍스트 셀 pause을 읽고 예측을 수행한 후 compute을 실행하세요. 계속해서 viz을 실행하여 차트를 생성하세요. 이후의 R 셀들은 이전 셀들에 종속됩니다. 이 셀들은 기본 R을 사용하므로 추가 R 패키지를 설치할 필요가 없습니다.
  2. 별도의 JavaScript 확인을 원하시면 js_check을 실행하세요. 이는 독립적이어서 R 셀에 의존하지 않으며 R을 시작할 필요도 없습니다.

최초 R 실행: SciREPL의 webR 런타임을 다운로드하고 초기화해야 할 수 있습니다. 네트워크/개인정보 보호 고지가 표시될 수 있습니다. 이를 읽고 계속 진행하려는 경우에만 동의하세요. 런타임이 준비될 때까지 기다린 다음 셀에 오류가 있는지 확인하세요. 통합 문서를 가져오는 것만으로는 해당 R 정의가 로드되지 않습니다.

보다 완전한 실행 및 편집 절차를 다룬 또 다른 예를 보려면 Markov Groups 레슨을 참조하세요. 그것은 네 개의 Python 셀이 있는 다른 통합 문서이며, 해당 내보내기 단계에서는 편집된 통합 문서 복사본을 저장하는 방법도 설명합니다.

직접 제어할 수 있는 사본을 보관하세요. 다운로드한 파일은 이후의 편집본을 백업한 것이 아니라 원본 워크북 사본입니다. 변경 사항을 저장하려면 워크북 사본을 내보내세요. 앱이나 브라우저 저장공간을 지우면 로컬 작업 내용이 삭제될 수 있으며, Android와 브라우저 세션 간에는 변경 사항이 자동으로 공유되지 않습니다.

기타 형식 및 보안

파일에 포함된 내용 파악하기

Jupyter notebooks (.ipynb) 역시 메뉴 → Import File을 사용하지만, 실행 동작은 .srwb와 다릅니다. 워크북 가져올 때 셀 자동 실행 설정이 활성화되어 있으면, .ipynb 가져오기 시 저장된 출력이 없는 코드 셀이 자동으로 실행될 수 있습니다.

신뢰할 수 있는 출처의 노트북 파일만 가져오세요. .ipynb을 가져오기 전에 메뉴 → 설정 → 가져오기 및 편집 메뉴를 열고 워크북 가져올 때 셀 자동 실행 항목이 off(선택 해제) 상태인지 확인하세요. 기본적으로 꺼져 있지만 현재 설정을 확인하는 것이 좋습니다. 이 설정을 끈다고 해서 임의의 노트북이 안전하다는 보장은 없습니다. 실행 여부를 명시적으로 결정하기 전에 신뢰할 수 있는 노트북 코드를 검토하세요.

별도의 데이터 파일: 일반적인 .srwb 내보내기는 별도의 CSV 파일이나 SciREPL의 가상 파일 시스템(Files 뷰)에 저장된 기타 데이터를 포함하지 않습니다. Simpson's Paradox의 이번 버전은 코드 내에서 가상 데이터를 생성하므로 별도의 데이터 파일이 필요하지 않습니다. CSV 파일을 읽는 워크북의 경우, 워크북과 데이터를 함께 보관하고 복원하려면 CSV 안내의 패키지 아카이브 내보내기 및 다시 열기 단계를 따르세요. 패키지 아카이브 및 .zip 가져오기는 이 짧은 워크북 파일 학습 과정의 범위를 벗어납니다.

문제가 발생하는 경우

파일 및 선택한 탭 확인

  • 선택 도구에서 파일을 찾을 수 없는 경우: 브라우저의 다운로드 목록에서 파일이 저장된 위치를 확인한 다음 해당 폴더로 이동하세요. 데스크톱에서 다운로드해도 휴대전화의 다운로드 폴더에는 파일이 저장되지 않습니다.
  • 파일 이름이 .txt 또는 .html로 끝나는 경우: 워크북 다운로드 링크로 돌아가서 .srwb 확장자를 가진 실제 파일을 저장하세요. HTML 페이지 이름을 .srwb로 바꾼다고 해서 워크북으로 변환되지는 않습니다.
  • 이전 워크북이 계속 표시되는 경우: 메뉴를 닫고 워크북 선택기에서 새 제목을 확인하세요. 기존 탭은 그대로 유지됩니다.
  • 두 번 가져온 경우: 다시 가져오면 사본이 하나 더 추가되며, 이전 탭이 업데이트되거나 대체되지 않습니다. 변경하기 전에 어떤 사본을 편집하고 있는지 확인하세요.
  • 제목이나 셀이 일치하지 않는 경우: 다른 다운로드 파일이나 다른 학습 과정의 파일이 아닌 simpsons-paradox.srwb을 선택했는지 확인하세요. main에 있는 파일은 변경될 수 있으므로 사본을 현재 GitHub 파일과 비교하고 익숙하지 않은 코드는 실행하기 전에 살펴보세요.
