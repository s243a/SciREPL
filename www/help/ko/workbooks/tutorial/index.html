  1. cube_moves을 실행하세요. 이동 동작과 헬퍼를 정의합니다. Built six clockwise quarter-turn matrices with fixed face centres. 출력이 예상됩니다.

먼저 코드를 점검하고 일괄 실행이 진행되는 동안 이 워크북을 선택된 상태로 유지하십시오. 새로운 Python 세션 후에는 뒷부분의 셀에 필요한 정의가 적용되도록 cube_moves부터 시작하십시오. 이러한 작업은 코드를 실행합니다. 설명이 “선택 사항”이라고 해서 앱이 해당 코드 셀을 건너뛰지는 않습니다.

큐브 예제 이면의 수학

출력 결과에 담긴 의미

이 워크북은 단순히 여섯 가지 색상이 아니라 54개의 개별 라벨이 붙은 스티커를 추적합니다. 올바른 이동은 이러한 라벨을 재배치합니다. 사분의 일 회전을 네 번 반복하면 시작 배치로 돌아가지만, 서로 다른 면을 회전할 때는 순서가 바뀌면 다른 결과가 나올 수 있습니다.

무작위 행보는 13가지 옵션 중에서 선택합니다. 제자리에 있기(I), 여섯 가지 사분 회전 및 그에 대응하는 여섯 가지 역회전입니다. 해당 54×54 확률 행렬은 전체 큐브 구성이 아닌 하나의 스티커 위치를 설명합니다. 확률 총합이 1.0이라는 것은 이 스티커의 위치 확률 합계가 일임을 의미하며, 큐브가 균일하게 섞였음을 증명하지는 않습니다.

면의 방향이 궁금하신가요? 워크북의 coordinates 셀은 전체 좌표축과 각 면의 오른쪽, 위쪽, 바깥쪽 법선을 제공합니다. 그림, 다이어그램, 수식 튜토리얼에서 이러한 설명을 워크북에 추가하는 방법을 보여줍니다. 좌표 다이어그램은 카탈로그의 개발 사본에 추가되는 중이며, 위에 고정된 v0.4.0 사본에는 포함되어 있지 않습니다.

선택 사항: 개정된 단계 4 미리보기

위의 단계와 휴대폰 스크린샷은 안정적인 v0.4.0 워크북을 사용합니다. 개정된 워크북 다운로드는 개발 미리보기이며, 아직 안정적인 카탈로그가 아닙니다. 더 짧고 서로 번갈아 나오는 설명 및 코드 셀을 사용해 보려면 메뉴 → 파일 가져오기로 가져오십시오.

해당 미리보기에서 위와 마찬가지로 cube_moves, check_moves 및 show_turn를 먼저 실행합니다. 그런 다음:

  1. transition_matrix을 실행합니다. 이것은 T을 생성하며, 이는 균일하게 선택된 한 가지 옵션(즉 I, 한 면의 사분 회전 또는 그 역회전) 이후의 단일 스티커 위치에 대한 확률 행렬입니다.
  2. sticker_step을 실행합니다. 이 셀은 스티커 라벨 1을 추적하며, 이는 초기에 영 기준 위치 0에 있습니다. 해당 스티커의 위치 확률 합계는 1.0이 됩니다. 아래 차트는 해당 셀에서 계산한 도착 확률을 보여줍니다.
