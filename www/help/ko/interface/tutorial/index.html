첫 번째 통합 문서 만들기

이 문서는 인터페이스 참조 (영어 참조 페이지)의 더 길고 실용적인 실습 안내서입니다. 하나의 Python 셀을 실행하고 변경한 다음, 직접 관리할 수 있는 복사본을 저장하게 됩니다. AI 계정이나 API 키는 필요하지 않습니다.

  • Free + Pro
  • Android 단계
  • 약 5분

스크린샷은 SciREPL Free v1.3.2 버전을 Samsung Galaxy S24 시리즈 스마트폰에서 보여줍니다. 이 학습 내용은 Pro에도 적용되지만, 일부 컨트롤은 다르게 보일 수 있습니다.

이번 학습 내용
  1. 앱 내 위치 찾기
  2. 셀 작성 및 실행
  3. 저장된 셀 편집
  4. 통합 문서 사본 내보내기
  5. 다음으로 시도해 볼 작업

모든 자습서

1단계

앱에서 위치 찾기

맨 위 행은 헤더입니다. 여기에는 메뉴, 도움말 및 상태 배지가 포함되어 있습니다. 통합 문서 선택기를 통해 열려 있는 통합 문서를 선택합니다.

새 셀 패널은 다음 셀을 입력하는 곳입니다. 화면이 좁을 때는 선택적 헤더 버튼이 사라질 수 있지만, 해당 동작은 해당되는 경우 메뉴 또는 도움말에서 계속 사용할 수 있습니다.

단계 2

Python 셀 작성 및 실행

첫 실행 전에 상태 배지에 준비 완료 표시가 나타날 때까지 기다리세요.

  1. 새 셀 패널의 언어 선택기에서 Python 항목을 선택하세요. 화면이 좁은 휴대폰에서는 닫힌 선택기에 Py만 표시될 수 있습니다.
  2. 다음과 같은 간단한 프로그램을 입력하세요: 
    print("Hello from SciREPL")
  3. 실행 버튼을 탭하세요. 저장된 셀이 워크북에 나타납니다. 그 아래에 Hello from SciREPL 표시가 보여야 합니다.

첫 실행은 시간이 더 걸릴 수 있습니다. Python 런타임이 한 번 시작되어야 합니다. 상태가 준비 완료 상태로 돌아올 때까지 기다리세요. 이후의 Python 셀은 대개 해당 런타임을 재사용합니다.

개인정보 보호 안내가 나타나는 경우: Python 버전은 보통 함께 제공되므로 이 예제에서는 런타임 다운로드가 필요하지 않습니다. R이나 Lua(Free의)과 같은 네트워크 런타임은 먼저 SciREPL 개인정보 처리방침을 표시할 수 있으며, Python 역시 번들 복사본에 네트워크 폴백이 필요한 경우 그럴 수 있습니다. 내용을 읽고 대화상자 내부에서 맨 아래로 스크롤한 후, 동의하면 이해했습니다를 탭하세요. 이후 별도의 런타임 다운로드 메시지가 표시되면 다운로드 버튼을 탭하라는 안내가 나타날 수 있습니다.

개인정보 처리방침 대화상자의 예를 확인하세요 (영어 참조 페이지) (스크린샷에는 상단이 표시되어 있으며 버튼은 더 아래에 있습니다). Free 1.4.0 및 Pro 1.4.0에서는 유효한 %pip install 명령 역시 패키지 설치를 시도하기 전에 현재 네트워크 고지를 수락하지 않은 경우 이 안내를 엽니다. 네트워크 기능을 사용하기 전에 개인정보 및 로컬 데이터 (영어 참조 페이지) 항목을 확인하세요.

단계 3

저장된 셀 편집

  1. 저장된 셀 자체 헤더에서 연필 ✎ 모양을 탭하세요. 오른쪽 상단 ✕ 바로 왼쪽에 위치합니다. 이렇게 하면 해당 셀이 편집을 위해 열립니다. 새 셀 패널에 입력하면 또 다른 셀이 생성됩니다.
  2. Hello from SciREPL을(를) Hello again로 변경하세요.
  3. 변경사항을 저장하고 실행하려면 실행 항목을 선택하세요. 이제 해당 셀 아래에 Hello again 내용이 표시됩니다.

Pro 단축 기능: 터치스크린에서는 저장된 셀의 코드를 두 번 탭하여 편집할 수 있습니다. 현재 Free 버전에서는 ✎ 버튼을 사용합니다.

실수로 편집기를 열었다면 취소을 사용하여 실행하지 않고 닫으세요. 저장된 셀 내부의 언어 선택기는 해당 셀을 변경하지만, 새 셀 선택기는 변경하지 않습니다.

4단계

워크북 사본 내보내기

  1. 메뉴 → 워크북 및 패키지 내보내기 열기.
  2. 현재 탭만 또는 모든 탭을 선택한 후, SciREPL 형식의 워크북 (.srwb)을 선택하세요(SciREPL 관련 상태를 유지하려는 경우).
  3. 내보내기을 탭하고 직접 제어할 수 있는 저장 위치를 선택하세요.

왜 내보내야 하나요? SciREPL은 로컬 세션을 복원하지만, 로컬 저장소는 백업이 아니며 Android 앱과 브라우저 간에 자동으로 공유되지 않습니다. 파일 및 내보내기 (영어 참조 페이지)에서 다른 형식을 확인하세요(.ipynb 및 PDF 포함).

5단계

다음으로 시도해 볼 사항

2 + 2을 다른 Python 셀에서 실행해 보세요. 그런 다음 워크북 선택기를 사용하여 탭을 전환하세요. CSV 워크북 둘러보기는 메뉴 → 패키지, 번들 및 워크북 찾아보기에서 시작하여 예제를 설치하고 해당 셀이 로컬 파일과 어떻게 작동하는지 보여줍니다.

Markov Groups 둘러보기에서는 더 넓은 카탈로그를 검색하고, 큐브 이동에 관한 기존 워크북을 열고, 셀을 순서대로 실행하며, 하나의 매개변수를 변경하는 방법을 보여줍니다.

컨트롤 위치를 빠르게 다시 확인하려면 인터페이스 참조 (영어 참조 페이지)로 돌아가세요. 다른 언어를 배우거나 패키지를 추가하려면 언어 및 패키지 (영어 참조 페이지)로 계속 진행하세요.

Pro 사용 중이신가요? 기본 워크플로는 동일합니다. Pro에는 전체 화면 편집기와 선택적 AI 기능도 제공됩니다. 다음을 참조하세요: Pro AI 및 전체 화면 워크플로 (영어 참조 페이지) 일반 셀에 익숙해진 후에 확인하세요.
