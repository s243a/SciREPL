Windows 데스크톱 앱

Windows의 모양: 달라지는 점

Microsoft Store 버전을 포함한 Windows 앱에도 Android와 같은 ☰ 메뉴 → 🎨 모양 및 화면이 있습니다. 테마, 표시 언어, 버튼 크기, 📦 Browse 바로 가기는 모양 둘러보기에서 설명한 대로 작동합니다. 이 페이지에서는 데스크톱 창에서 더해지는 점만 다룹니다.

  • Free
  • Windows 데스크톱 앱
  • 약 2분

노트북 너비

너비가 1000픽셀 이상인 창에서는 노트북 셀이 최대 1200픽셀까지 넓어집니다. 이 넓게 설정이 기본값입니다. 바꾸려면 ☰ 메뉴 → 🎨 모양 및 화면을 열고 레이아웃에서 노트북 너비를 고르세요.

  • 표준: 예전의 720픽셀 열.
  • 넓게: 최대 1200픽셀(기본값).
  • 창 전체: 셀이 창의 전체 너비를 사용합니다.

그보다 좁은 창에서는 무엇을 선택하든 항상 표준 열을 사용합니다.

확대/축소

확대/축소는 창 안의 페이지를 크게 또는 작게 만듭니다.

  • 확대: Ctrl+= 또는 Ctrl+Shift+=(Ctrl과 더하기 키).
  • 축소: Ctrl+-. 100%로 되돌리기: Ctrl+0.
  • Ctrl을 누른 채 마우스 휠을 돌리거나 터치패드에서 손가락을 오므리거나 벌립니다.
  • 창의 메뉴 표시줄에서: 보기 → 확대, 축소, 실제 크기.

Windows 디스플레이 배율인가요, 앱 확대/축소인가요?

Windows 디스플레이 설정(설정 → 시스템 → 디스플레이)의 배율은 SciREPL의 제목 표시줄, 메뉴 표시줄, 대화 상자를 포함해 화면의 모든 것을 크게 합니다. 앱 확대/축소는 창 안의 페이지만 크게 합니다. Windows에는 앱 하나만 배율을 바꾸는 설정이 없으므로, SciREPL만 크게 또는 작게 하려면 확대/축소를 사용하세요.

두 가지 모두 페이지가 보는 창의 크기도 바꿉니다. 예를 들어 배율이 150%이면 너비 1920픽셀 화면이 SciREPL에는 1280픽셀 너비로 보입니다. 위의 1000픽셀 너비와 아래의 500픽셀 높이는 배율과 확대/축소를 적용한 뒤의 값입니다.

새 셀 패널 숨기기

창이 세로보다 가로로 길고 페이지 높이가 500픽셀 이하이면, 아래쪽 새 셀 패널에 ⌄ 버튼(새 셀 패널 숨기기)이 나타납니다. 배율이 150–200%이면 평범한 노트북 컴퓨터의 창도 이만큼 낮을 수 있고, 확대해도 같은 효과가 납니다. ⌄를 클릭하면 노트북이 전체 높이를 사용합니다.

패널이 숨겨져 있는 동안에는 왼쪽 위의 Sci REPL 제목 대신 작은 ⌃ 버튼(새 셀 패널 표시)이 표시됩니다. 이 버튼을 클릭하면 패널이 다시 나타납니다. 창을 최대화하는 등 창을 더 높게 만들어도 패널이 돌아옵니다.

창의 메뉴 표시줄

Windows 창에는 앱 위에 자체 메뉴 표시줄이 있습니다: 파일, 편집, 보기, 런타임, 도움말(표시 언어로 표시됨). 키보드로는 Alt를 눌러 이동합니다. 런타임에는 다음 항목이 있습니다.

  • 다운로드된 런타임…: 다운로드한 Lua와 R 런타임이 차지하는 공간과 저장 위치를 보여 줍니다.
  • 다운로드된 런타임 삭제…: 확인을 받은 뒤 삭제합니다. 노트북과 파일에는 영향이 없습니다. 이미 불러온 런타임은 다시 시작할 때까지 계속 작동합니다. 그 뒤 R과 Lua는 다운로드하기 전에 다시 묻고, 다운로드에는 인터넷 연결이 필요합니다.
  • 애플리케이션 데이터 폴더 열기: 파일 탐색기에서 SciREPL 데이터 폴더를 엽니다.

Android에는 창 메뉴 표시줄이 없습니다. Android에서는 ☰ 메뉴 → 📊 메모리 및 스토리지에서 저장 공간을 확인하고 비웁니다. Windows에서는 이 패널이 다운로드한 런타임을 볼 수 없으므로, 런타임은 런타임 메뉴에서 관리하세요.

나머지는 모두 Android와 같습니다. 모양 둘러보기로 돌아가세요.
