둘러보기 표시 및 모양 조정

📦 둘러보기 바로가기를 SciREPL Free의 헤더에 배치한 다음, 편안한 버튼과 밝은 테마 또는 어두운 테마를 선택하세요. 공통 모양 제어 기능은 Pro에서도 유용하며, 별도의 Pro 전용 섹션에서 전체 화면 편집, 추가 키 및 실시간 구문 색상을 다룹니다. 워크북 셀을 변경하거나 실행하지 않고도 이 작업을 수행할 수 있습니다.

  • Free + Pro (레이블 참조)
  • Android 스크린샷
  • 약 3분

다섯 장의 스크린샷은 SciREPL Free 1.4.0-debug 버전을 Samsung Galaxy S24+에서 6일 시월 2026년에 실제로 캡처한 것입니다. 이는 Play Store에서 설치한 것이 아니라 디버그 서명된 앱을 보여줍니다. 그림에 나와 있는 단계는 Free 1.4.0 제어 기능을 사용합니다. 둘러보기의 헤더 바로가기는 Free 전용이며, Pro 사용자는 메뉴에서 동일한 카탈로그를 열 수 있습니다. 아래의 Pro 전용 텍스트는 Pro 1.4.0 코드베이스를 기준으로 검증되었습니다. 해당 제어 기능은 이 Free 사진들에는 설명되어 있지 않으며, 이전 메뉴는 다를 수 있습니다.

모든 튜토리얼

1단계

메뉴 → 모양 열기

  1. 앱 상단 헤더에서 세 개의 가로줄 버튼인 ☰ 메뉴를 찾으세요.
  2. 해당 버튼을 탭한 다음 🎨 모양 및 화면을(를) 선택하세요. 메뉴가 화면보다 길면 메뉴 내부를 스크롤하여 항목을 찾으세요.

변경 사항은 선택하는 즉시 적용됩니다. 아래의 일반적인 제어 기능에는 저장 또는 적용 버튼이 필요하지 않습니다. × 기호로 모양 창을 닫아도 변경 사항이 취소되지 않으며 선택한 항목은 다음 앱 실행 시에도 유지됩니다.

2단계

Free 1.4.0: 📦 둘러보기 바로가기 표시

Pro을(를) 사용 중이신가요? 이 바로가기 설정을 건너뛰고 메뉴 → 패키지, 번들 및 워크북 찾아보기을(를) 사용하세요. 다음 섹션에서는 공통 모양 제어 기능을 다룹니다.

  1. 메뉴 → 모양 및 화면을(를) 연 다음, 헤더 바로가기까지 스크롤하세요.
  2. 찾아보기 바로가기 표시을(를) 찾아 항상을(를) 선택하세요.
  3. × 기호로 모양 창을 닫으세요. 이제 헤더에 📦 버튼이 표시되며, 이를 탭하여 패키지, 번들 및 워크북 찾아보기을(를) 열 수 있습니다.

각 선택 항목은 서로 다른 용도를 가집니다:

  • 항상: 헤더에 다른 행이 필요하더라도 바로가기를 계속 표시합니다.
  • 공간이 있을 때: 둘러보기의 기본값입니다. 공간이 충분할 때만 표시되며, 화면이 더 좁아지거나 버튼이 커지거나 상태 메시지가 길어지면 사라질 수 있습니다.
  • 표시 안 함: 헤더 바로가기를 숨깁니다.

↑ 및 ↓ 버튼은 공간이 부족할 때 어떤 선택적 바로가기가 먼저 자리를 양보할지를 변경합니다. 바로가기를 위로 이동하면 더 오래 유지되고, 아래로 이동하면 더 빨리 사라집니다. 이 버튼은 헤더 내 아이콘 위치가 아니라 우선순위를 변경합니다.

📦 버튼이 없나요? 바로가기가 숨겨져 있거나 사용 중인 버전에서 제공하지 않는 경우에도 메뉴 경로는 계속 작동합니다. 간결한 헤더를 위해 모든 선택적 바로가기를 강제로 표시하는 대신 둘러보기를 공간이 있을 때(으)로 되돌리세요.

워크북을 찾으러 오셨다면, 이제 Markov Groups 연습으로 돌아가 카탈로그를 검색할 수 있습니다.

3단계

편리한 버튼과 실행 레이블 선택

메뉴 → 모양 및 화면을 다시 열고 버튼을(를) 찾으세요. 버튼 크기 슬라이더를 움직이면 백분율과 근처의 미리보기이(가) 즉시 변경됩니다. 기본값은 100%입니다. 헤더 버튼이 더 크면 탭하기는 쉬워질 수 있지만, 선택적 바로가기를 위한 공간이 줄어듭니다.

실행 버튼 드롭다운은 저장된 셀 편집기 내부의 실행 버튼이 아니라 새 셀 패널의 실행을 제어합니다:

  • 자동(공간이 부족할 때 아이콘만 표시): 기본값입니다. 공간이 충분할 때는 레이블을 유지하고, 입력 공간을 남기려면 ▶ 아이콘만 사용합니다.
  • 아이콘만: 항상 간결한 ▶ 버튼을 사용합니다.
  • 항상 레이블 표시: 화면이 좁더라도 텍스트를 항상 유지합니다.

모양에는 텍스트 확대 슬라이더가 없습니다. 버튼 크기은(는) 일반적인 글꼴 크기 설정이 아닙니다. Free 1.4.0 및 Pro 1.3.0에서는 Android의 시스템 텍스트 확대를 수용하기 위해 작은 헤더 컨트롤을 자동으로 확대합니다.

선택 사항 · Pro 전용

Pro 전용: 전체 화면 편집, 추가 키 및 구문 색상

이 컨트롤은 SciREPL Pro 1.4.0 편집기 컨트롤이며, 위의 Free 스크린샷에 표시된 컨트롤이 아닙니다. 추가 키와 실시간 색상은 별도의 설정입니다.

전체 화면 편집 시작하기

  1. 새 셀: 새 셀 코드 필드에서 ⤢ Full screen 버튼을 누르세요. 바깥쪽 대각선 화살표는 편집기 확장을 의미합니다.
  2. 저장된 셀: 편집하려는 해당 셀의 ✎ pencil 아이콘을 누른 다음, 해당 셀의 코드 필드 모서리에 있는 ⤢ 아이콘을 누르세요.

더 많은 코드가 표시되도록 편집기가 화면 전체를 차지합니다. 활성화된 추가 키와 추천 칩은 키보드 위에 계속 표시되며, 구문 색상은 아래에 설명된 것과 동일한 설정을 사용합니다. 전체 화면으로 전환해도 코드가 실행되지는 않습니다.

작성 중인 초안을 열어 둔 채 워크북으로 돌아가려면 상단의 편집기 라벨을 누르세요. 이전 또는 Esc 버튼으로도 전체 화면 모드에서 나갈 수 있습니다. 저장된 셀의 경우, 완료 버튼은 코드를 실행하지 않고 초안을 적용하는 반면, 취소 버튼은 편집 내용을 취소합니다. 새 셀의 경우 Done과 Cancel 모두 초안을 지우거나 셀을 만들지 않고 전체 화면을 종료하며, Run은 별도의 동작입니다.

“패널에 전체 화면 사용”과 동일하지 않습니다. 이 별도의 모양 옵션은 패널과 대화 상자의 상단 여백을 제어하며, 전체 화면 코드 편집기를 열지 않습니다.

추가 키 행 표시

메뉴 → 자동완성 → 섹션 → 일반 메뉴를 엽니다. 키보드 위 추가 키 → 켜기 항목을 설정하세요. 기본값은 꺼짐입니다. 이 행은 Esc, Tab, 들여쓰기 삭제, 화살표, Home, End, Run 및 구두점을 제공합니다. 화면에 맞지 않는 키를 보려면 옆으로 스와이프하세요. On을 선택해도 코드가 실행되지는 않지만, 해당 행의 ▶ 실행 키는 코드를 실행하므로 누르기 전에 소스를 검토하세요.

동일한 섹션에서 세로 모드의 칩 및 가로 모드의 칩 항목은 별도 줄 또는 추가 키 대체 옵션을 선택합니다. 기본값은 세로 모드에서 Own row, 가로 모드에서 Replace extra keys입니다. 후보가 나타나는 동안 키의 자리를 일시적으로 대체할 수 있습니다. 추가 키가 꺼져 있으면 칩이 전용 행을 사용합니다. 가로 화면의 추가 행 항목은 꺼짐, 공간이 있을 때(기본값) 또는 항상 옵션을 제공합니다. When there is room 옵션은 표시할 최소 코드 줄 수 설정을 사용하며(초기값 8), 높이가 낮은 가로 보기에서 선택적 행을 숨길 수 있습니다.

실시간 구문 색상 켜기 또는 끄기

메뉴 → 모양 및 화면 → 입력 중 구문 색상 표시 메뉴를 엽니다. 편집 중에 지원되는 코드에 색상을 적용하려면 켜기을, 일반 텍스트로 보려면 꺼짐를 선택하세요. 기본값인 자동(데스크톱에서 켜짐, 터치에서 꺼짐)는 데스크톱 브라우저에서는 색상을 활성화하고 스마트폰에서는 비활성화합니다. 입력 반응이 느리게 느껴지면 Off를 선택하세요. 성능이 낮은 기기에서는 색상 표시로 인해 입력 속도가 느려질 수 있습니다. 6000자를 초과하는 코드는 On 상태에서도 색상이 적용되지 않은 상태로 유지됩니다.

색상 표시는 코드를 유효성 검사하거나 실행하지 않고, API 요청을 보내거나 자동 완성을 켜지도 않습니다. 이 설정을 변경하면 즉시 적용되며 소스 코드는 변경되지 않습니다.

Files & Storage에는 별도의 스위치가 있습니다

텍스트 파일의 경우 메뉴 → Files & Storage (VFS / Paths) 메뉴를 사용하여 파일을 선택한 다음 전체 화면을 선택하세요. 해당 편집기의 구문 강조 표시 체크박스는 모양 설정의 실시간 색상 설정과 독립적이며 기본적으로 꺼져 있습니다. 인식할 수 없는 파일 형식이거나 100,000자를 초과하는 파일에는 사용할 수 없습니다. 추가 키는 자동 완성 환경설정을 공유하지만, 파일 편집기 공간이 너무 부족하면 숨겨질 수 있습니다. 파일 저장 동작은 편집 내용을 저장하지만, 색상 전환만으로는 저장되지 않습니다.

단계 4

라이트, 다크 또는 시스템 테마 선택

테마 항목으로 스크롤하여 다크, 라이트 또는 시스템 설정 따름을 선택하세요. 다크가 기본값입니다. Match system은 기기의 라이트/다크 설정을 따르며, 기본값이 아니라 사용자가 직접 선택하는 옵션입니다.

이번 단원에서는 사용자 지정, 사용자 지정…, 테마 JSON 편집기 또는 고급: 사용자 지정 CSS이 필요하지 않습니다. 이러한 고급 옵션은 이 초보자용 안내서의 범위를 벗어납니다.

선택적 마무리 작업

Android 여백 및 기본값으로 복원

레이아웃 아래에서 상단 여백 → 자동 선택 상태를 그대로 유지합니다. 기기에서 보고된 안전 영역을 따르므로 헤더 위에 적절한 공간이 확보되며, 픽셀 값을 직접 추측할 필요가 없습니다.

Android 앱의 Android 상태 표시줄 숨기기에서는 다음 옵션을 제공합니다.

  • 안 함: 기본값이며, 시계와 알림 상태 표시줄을 계속 표시합니다.
  • 가로 모드일 때: 휴대전화를 가로로 놓았을 때 해당 표시줄을 숨기고 세로 모드에서 다시 표시합니다.
  • 항상: 두 방향 모두에서 표시줄을 숨깁니다.

이 설정은 Android 상태 표시줄에만 영향을 주며 탐색 또는 제스처 바에는 영향을 주지 않습니다. 브라우저/PWA 및 Windows 인터페이스에는 이 설정이 없습니다. 대신 Pro 1.3.0에는 Hide Android status bar in landscape라는 확인란이 있습니다.

모양 변경 사항을 취소하시겠습니까? 기본값으로 복원을 사용하면 기본 테마, 헤더 버튼 크기, 위쪽 여백, 단축키, 상태 표시줄 환경설정이 복원되고 사용자 지정 테마/CSS 선택 항목이 제거됩니다. 통합 문서 셀은 지워지지 않습니다. 별도의 실행 버튼이나 인터페이스 언어 환경설정은 재설정되지 않으므로, 필요한 경우 실행의 자동 옵션을 직접 선택하십시오.

완료되면 ×로 모양 설정을 닫습니다. Markov Groups 통합 문서 둘러보기를 계속 진행하거나, 간략한 인터페이스 참조 (영어 참조 페이지)로 돌아가십시오.
