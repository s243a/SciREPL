시작 텍스트는 샘플을 설명합니다. 세 개의 Python 셀에는 각각 다음과 같은 이름이 있습니다: create_csv, read_csv, 그리고 compare_groups. 저장된 셀의 경우 편집기를 열려면 해당 셀의 ✎ 연필을(를) 탭한 다음 해당 셀의 실행을(를) 탭하세요. Pro에서는 셀의 코드를 두 번 탭하여 편집할 수도 있습니다.

  1. create_csv을(를) 실행합니다. /shared/data/seedling-heights.csv에 여섯 개의 가상 행을 작성합니다. Saved 6 fictional rows이(가) 표시되어야 합니다.
  2. read_csv을(를) 실행합니다. 방금 생성된 파일을 열고 여섯 개의 행을 모두 출력합니다.
  3. compare_groups을(를) 실행합니다. 이는 밝은 조건 평균 13.0 cm, 그늘 조건 평균 8.0 cm, 그리고 차이 5.0 cm을(를) 출력합니다.

메뉴 → 파일 및 스토리지에서도 해당 파일을 볼 수 있습니다. 거기서 파일을 읽거나, 편집 및 저장을(를) 사용하여 직접 변경할 수 있습니다. 다음 단계에서 방법을 안내합니다.

최종 출력은 다음과 같이 표시되어야 합니다:

Shade mean: 8.0 cm
Difference: 5.0 cm

첫 실행이 더 느린가요? Python을(를) 초기화하는 데 잠시 시간이 걸릴 수 있습니다. 셀 실행이 완료되었는지 판단하기 전에 상태 배지에 준비 완료이(가) 표시될 때까지 기다리세요. 이후 셀은 일반적으로 로드된 런타임을 재사용합니다. 런타임 다운로드에 동의가 필요한 경우 수락하기 전에 개인정보 처리방침을 읽어보세요. 이 통합 문서는 %pip install을(를) 호출하지 않습니다.

이 가상의 값들은 읽기와 계산을 보여주기 위한 것일 뿐, 빛과 식물 성장에 관한 과학적 결론은 아닙니다.

3단계

값 하나를 변경하고 다시 실행

데이터를 변경하기 위해 Python 셀을 편집할 필요는 없습니다. CSV 파일 자체를 여세요:

  1. 메뉴 → 파일 및 스토리지을(를) 선택합니다(메뉴 이름에 VFS / Paths가 추가되어 있을 수 있습니다).
  2. / (영구 스토리지) 또는 모든 파일 시스템을(를) 선택합니다. /shared/data/seedling-heights.csv 위치로 스크롤한 다음 다운로드나 삭제 아이콘이 아닌 파일 이름을 탭합니다.
  3. 편집을(를) 탭합니다. light,14 행을 light,15(으)로 변경합니다. 헤더 group,height_cm, 쉼표 및 다른 행은 변경하지 않고 그대로 유지합니다.
  4. 저장을(를) 탭한 다음 Files & Storage를 닫습니다. 파일을 저장해도 코드가 실행되지는 않습니다.

read_csv 및 compare_groups만 다시 실행합니다. 이제 양지 평균은 약 13.3 cm이며 차이는 약 5.3 cm입니다. 절대 create_csv을(를) 다시 실행하지 마세요. 해당 셀에 여전히 남아 있는 값으로 파일 편집 내용이 덮어써집니다.

또는 create_csv을(를) ✎ 연필 아이콘으로 편집하여 측정값 14을(를) 15(으)로 변경한 다음 세 개의 Python 셀을 모두 순서대로 실행할 수도 있습니다. 이렇게 하면 파일만 변경하는 대신 파일을 생성하는 코드가 변경됩니다.

이후 셀들을 다시 실행하는 이유는 무엇인가요? 저장된 출력은 이전 실행 기록일 뿐이며, 파일을 변경하더라도 이전 결과가 자동으로 다시 계산되지는 않습니다. 각 셀은 실행할 때 파일을 읽습니다.

Pro: 전체 화면 파일 편집 및 선택적 강조 표시

파일 미리보기에서 더 큰 편집기를 사용하려면 전체 화면을(를) 탭합니다. CSV 파일은 일반 텍스트 상태를 유지하므로 구문 강조 표시 확인란이 비활성화됩니다.

지원되는 코드 파일의 경우 구문 강조 표시는 선택 사항이며 기본적으로 꺼져 있습니다. 전자필기장의 모양 설정이 아닌 이 파일 편집기의 확인란을 사용하여 켜세요. 확장자에 따라 언어가 선택됩니다. 예를 들어 .py은(는) Python, .js은(는) JavaScript, .R은(는) R, 그리고 .pl은(는) Perl이 아닌 Prolog입니다. 알 수 없는 확장자는 일반 텍스트로 유지됩니다.

저장은(는) 파일을 저장하고 편집기를 열린 상태로 유지합니다. Files & Storage로 돌아가려면 × Close를 사용하세요. 저장되지 않은 변경 사항을 삭제하기 전에 확인 메시지가 표시됩니다. 파일을 편집하거나 저장해도 실행되지는 않습니다.

CSV 파일이 일반 텍스트로 열려 있는 동일한 전체 화면 편집기를 확인하세요.
