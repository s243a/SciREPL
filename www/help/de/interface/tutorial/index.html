Lernen durch Ausprobieren

Erstellen Sie Ihre erste Arbeitsmappe

Dies ist die ausführlichere, praktische Ergänzung zur Referenz der Benutzeroberfläche (Englische Referenzseite). Sie führen eine Python-Zelle aus, ändern sie und speichern eine Kopie, die Sie kontrollieren. Es ist kein KI-Konto oder API-Schlüssel erforderlich.

  • Free + Pro
  • Schritte für Android
  • Etwa 5 Minuten

Screenshots zeigen SciREPL Free v1.3.2 auf einem Smartphone der Samsung-Galaxy-S24-Reihe. Die Lektion gilt auch für Pro, auch wenn manche Steuerelemente dort anders aussehen können.

In dieser Lektion
  1. Orientierung finden
  2. Eine Zelle schreiben und ausführen
  3. Die gespeicherte Zelle bearbeiten
  4. Eine Kopie der Arbeitsmappe exportieren
  5. Was Sie als Nächstes ausprobieren können

Alle Anleitungen

Schritt 1

Orientieren Sie sich in der App

Die oberste Zeile ist die Kopfzeile. Sie enthält Menü, Hilfe und ein Statusabzeichen. Die Arbeitsmappenauswahl bestimmt, welche Arbeitsmappe geöffnet ist.

Im Bereich für neue Zellen geben Sie die nächste Zelle ein. Optionale Kopfzeilen-Schaltflächen können ausgeblendet werden, wenn der Bildschirm schmal ist; ihre Aktionen bleiben gegebenenfalls über das Menü oder die Hilfe verfügbar.

Schritt 2

Eine Python-Zelle schreiben und ausführen

Warten Sie vor der ersten Ausführung, bis die Statusanzeige fertig anzeigt.

  1. Wählen Sie im Bereich für neue Zellen Python aus der Sprachauswahl. Auf einem schmalen Smartphone zeigt die geschlossene Auswahl möglicherweise nur Py an.
  2. Geben Sie dieses kurze Programm ein: 
    print("Hello from SciREPL")
  3. Tippen Sie auf Ausführen. Eine gespeicherte Zelle erscheint im Arbeitsbuch. Darunter sollten Sie Hello from SciREPL sehen.

Die erste Ausführung kann länger dauern. Die Laufzeitumgebung von Python muss einmalig starten. Warten Sie, bis der Status wieder auf fertig wechselt; spätere Python-Zellen verwenden diese Laufzeitumgebung üblicherweise wieder.

Wenn ein Datenschutzhinweis erscheint: Python ist normalerweise mitgeliefert, sodass dieses Beispiel keinen Download einer Laufzeitumgebung erfordern sollte. Eine Netzwerk-Laufzeitumgebung wie R oder Lua in Free zeigt möglicherweise zuerst die Datenschutzerklärung von SciREPL an; Python kann dies ebenfalls tun, wenn die mitgelieferte Kopie ein Netzwerk-Fallback benötigt. Lesen Sie diese durch, scrollen Sie innerhalb des Dialogs ganz nach unten und tippen Sie auf I Understand, wenn Sie zustimmen. Eine separate Aufforderung zum Herunterladen der Laufzeitumgebung fordert Sie danach möglicherweise auf, auf Herunterladen zu tippen.

Sehen Sie ein Beispiel für den Dialog der Datenschutzerklärung (Englische Referenzseite) (der Screenshot zeigt den oberen Teil; die Schaltfläche befindet sich weiter unten). In Free 1.4.0 und Pro 1.4.0 öffnet ein gültiger %pip install-Befehl diese Benachrichtigung ebenfalls, wenn Sie den aktuellen Netzwerkhinweis noch nicht akzeptiert haben, bevor versucht wird, ein Paket zu installieren. Beachten Sie Datenschutz und lokale Daten (Englische Referenzseite), bevor Sie Netzwerkfunktionen nutzen.

Schritt 3

Die gespeicherte Zelle bearbeiten

  1. Tippen Sie auf den Bleistift ✎ in der Kopfzeile der gespeicherten Zelle, oben rechts direkt links von ✕. Dadurch wird diese Zelle zur Bearbeitung geöffnet; eine Eingabe im Bereich für neue Zellen würde eine weitere Zelle erstellen.
  2. Ändern Sie Hello from SciREPL in Hello again.
  3. Wählen Sie Ausführen, um die Änderung zu speichern und auszuführen. Sie sollten nun Hello again unter dieser Zelle sehen.

Pro-Kurzbefehl: Tippen Sie auf einem Touchscreen doppelt auf den Code der gespeicherten Zelle, um ihn zu bearbeiten. Free verwendet derzeit die Schaltfläche ✎.

Wenn Sie den Editor versehentlich öffnen, nutzen Sie Abbrechen, um ihn ohne Ausführung zu schließen. Die Sprachauswahl innerhalb einer gespeicherten Zelle ändert diese Zelle; die Auswahl für neue Zellen nicht.

Schritt 4

Arbeitsmappenkopie exportieren

  1. Menü → Arbeitsmappen & Pakete exportieren öffnen.
  2. Wählen Sie Nur aktuelle Registerkarte oder Alle Registerkarten und dann das SciREPL-Format Arbeitsmappe (.srwb), wenn Sie den SciREPL-spezifischen Zustand behalten möchten.
  3. Tippen Sie auf Exportieren und wählen Sie ein Ziel, das Sie kontrollieren.

Warum exportieren? SciREPL stellt lokale Sitzungen wieder her, aber lokaler Speicher ist keine Sicherung und wird nicht automatisch zwischen der Android-App und einem Browser geteilt. Siehe Dateien und Export (Englische Referenzseite) für andere Formate, einschließlich .ipynb und PDF.

Schritt 5

Was Sie als Nächstes ausprobieren können

Versuchen Sie 2 + 2 in einer anderen Python-Zelle. Verwenden Sie dann die Arbeitsmappenauswahl, um zwischen Tabs zu wechseln. Die CSV-Arbeitsmappen-Anleitung beginnt bei Menü → Pakete, Bündel & Arbeitsmappen durchsuchen, installiert ein Beispiel und zeigt, wie ihre Zellen mit einer lokalen Datei funktionieren.

Die Markov-Gruppen-Anleitung zeigt, wie Sie den weiteren Katalog durchsuchen, eine vorhandene Arbeitsmappe über Würfelzüge öffnen, deren Zellen der Reihe nach ausführen und einen Parameter ändern.

Für eine kurze Erinnerung daran, wo sich Steuerelemente befinden, kehren Sie zur Oberflächenreferenz (Englische Referenzseite) zurück. Um eine andere Sprache zu lernen oder Pakete hinzuzufügen, fahren Sie mit Sprachen & Pakete (Englische Referenzseite) fort.

Verwenden Sie Pro? Der grundlegende Ablauf ist derselbe. Pro bietet außerdem einen Vollbild-Editor und optionale KI-Funktionen; siehe Pro KI- und Vollbild-Workflows (Englische Referenzseite) sobald Sie mit gewöhnlichen Zellen vertraut sind.
