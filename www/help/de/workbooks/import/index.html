Eine Arbeitsbuchdatei selbst importieren

Sie haben bereits eine Arbeitsbuchdatei oder können eine Lektion nicht unter „Durchsuchen“ finden? Speichern Sie die Datei auf Ihrem Gerät und verwenden Sie dann Menü → Datei importieren, um sie zu SciREPL hinzuzufügen. Diese kurze Anleitung verwendet Simpson's Paradox aus dem GitHub-main-Branch des Katalogs; Sie müssen kein Paket installieren oder Code schreiben, um sie zu importieren.

SciREPL importiert zwei Notebook-Formate: .srwb, sein eigenes Arbeitsbuchformat, und .ipynb, das Jupyter-Notebook-Format. Dieses Beispiel verwendet .srwb; die Hinweise zum Format weiter unten erklären das abweichende Ausführungsverhalten von Jupyter-Importen.

  • Free + Pro
  • Schritte für Android + Browser
  • Etwa 3 Minuten

Der Menü-Screenshot ist eine echte Android-Aufnahme auf einem Samsung Galaxy S24+, die SciREPL Free 1.4.0-debug zeigt, keine Installation aus dem Play Store. Der Screenshot des importierten Arbeitsbuchs ist eine separate Chromium-Browser-Aufnahme von Free 1.4.0 in einem Darstellungsbereich in Mobilgröße; er ist kein Beleg für einen Import über die Android-Dateiauswahl. Beide wurden am 6. Oktober 2026 aufgenommen. Andere Editionen, Versionen und Dateiauswahldialoge ordnen Steuerelemente möglicherweise anders an. Das Beispiel ist die englische simpsons-paradox.srwb-Datei aus dem SciREPL-Katalog, Branch main, wie für diesen Leitfaden geprüft; dieser Branch kann sich ändern. Schritt 1

Arbeitsmappendatei auf Ihrem Gerät speichern

Der GitHub-Zweig main kann Arbeitsmappen oder Aktualisierungen enthalten, die noch nicht in der neuesten stabilen Katalogversion enthalten sind, die von Browse angezeigt wird. Katalogversionen ändern sich unabhängig von der App-Version. Ein direkter Dateiimport ermöglicht es Ihnen, eine vertrauenswürdige Arbeitsmappe auszuprobieren, ohne darauf zu warten, dass sie in Browse erscheint.

  1. Simpson-Paradoxon auf GitHub ansehen, dann die eigentliche Arbeitsmappendatei (.srwb) herunterladen. Der zweite Link öffnet die Rohdatei, nicht die GitHub-Webseite.
  2. Wenn Ihr Browser die Datei als Text anzeigt, anstatt sie herunterzuladen, verwenden Sie die Aktion Speichern/Herunterladen des Browsers. Speichern Sie die Arbeitsmappendatei selbst, keinen Screenshot oder eine HTML-Seite.
  3. Behalten Sie den Dateinamen simpsons-paradox.srwb und seine Erweiterung .srwb bei. Merken Sie sich, wo sie gespeichert wurde: Android verwendet üblicherweise Downloads; auf dem Desktop ist es möglicherweise Downloads oder ein von Ihnen gewählter Ordner.

Dies ist kein Download eines festgepinnten Releases. main ist ein Entwicklungszweig: Der Inhalt und die Zellen der Datei können sich ändern, nachdem diese Screenshots aufgenommen wurden. Die von Ihnen gespeicherte Datei ist eine lokale Kopie; eine spätere Änderung auf GitHub aktualisiert Ihren importierten Tab nicht automatisch.

Herunterladen ist nicht gleich Importieren. Durch das Speichern der Datei befindet sie sich auf Ihrem Gerät; es wird dadurch noch keine Arbeitsmappe in SciREPL geöffnet. Sie müssen sie nicht in einem Texteditor öffnen oder in der Datei-Ansicht von SciREPL ablegen. Im nächsten Schritt wird diese heruntergeladene Datei ausgewählt.

Wenn Sie bereits eine vertrauenswürdige .srwb-Datei von jemand anderem haben, verwenden Sie stattdessen diese Datei und überspringen Sie den Beispieldownload. Der Titel der Arbeitsmappe und die Zellenzahl weichen von den Prüfungen in Schritt 3 ab.

Schritt 2

Menü suchen und Datei importieren wählen

  1. Kehren Sie zu SciREPL zurück. Suchen Sie in der Kopfzeile oben in der App nach ☰ Menü, der Schaltfläche mit drei horizontalen Linien, und tippen oder klicken Sie darauf.
  2. Wählen Sie 📂 Datei importieren (z. B. .srwb, .ipynb, .csv, .py, .zip). Wenn das Menü höher als der Bildschirm ist, scrollen Sie innerhalb des Menüs, um es zu finden.
  1. Unter Android: Die Dateiauswahl des Systems wird geöffnet. Suchen Sie in Downloads oder navigieren Sie zu dem Ort, an dem Sie die Datei gespeichert haben. Wählen Sie simpsons-paradox.srwb aus. Die Dateiauswahl gehört zu Android, daher hängen ihr Layout und eine abschließende Schaltfläche wie Öffnen oder Auswählen von Ihrem Gerät ab.
  2. Auf dem Desktop: Verwenden Sie die Dateiauswahl, um den Ordner zu finden, den Sie beim Herunterladen ausgewählt haben. Wählen Sie simpsons-paradox.srwb aus und bestätigen Sie die Auswahl. Nutzen Sie diesen Weg, anstatt nach dem Downloads-Bildschirm von Android zu suchen.
  3. Warten Sie zurück in SciREPL, bis der Import abgeschlossen ist. Wenn das Menü noch geöffnet ist, schließen Sie es, um die Arbeitsmappe zu sehen.

Ein Arbeitsbuch ist kein Hochladen einer Datei. Das Importieren einer .srwb-Datei fügt ihr Arbeitsbuch als separaten Tab hinzu, oder als separate Tabs, falls die Datei mehrere Arbeitsbücher enthält. Ihre vorhandenen Tabs bleiben erhalten. Es verschiebt das Arbeitsbuch nicht in die Dateiansicht und ersetzt Ihr aktuelles Arbeitsbuch nicht.

Schritt 3

Überprüfen Sie das neue Arbeitsbuch, bevor Sie etwas ausführen

  1. Suchen Sie in der Arbeitsbuchauswahl nach Simpson's Paradox. Wählen Sie diesen neuen Tab aus, falls er nicht bereits ausgewählt ist. Seine Einführung ist mit Simpson's Paradox: When Every Group Disagrees with the Total überschrieben.
  2. Lesen Sie die Einführung und scrollen Sie durch die Zellen. Die für diese Screenshots geprüfte Version enthält sieben Zellen: drei Textzellen, drei R-Zellen und eine JavaScript-Zelle. Eine spätere Version auf main kann abweichen.
  3. Suchen Sie die R-Zellen namens data, compute und viz in dieser Reihenfolge. Die JavaScript-Zelle heißt js_check und ist eine separate, optionale Prüfung. Lesen Sie sowohl den erklärenden Text als auch den Code.

Importieren bedeutet bei .srwb nicht Ausführen. SciREPL führt den Code beim Importieren einer .srwb-Datei nicht aus, selbst wenn die automatische Ausführung für andere Importe aktiviert ist. Prüfen Sie Code aus einer unbekannten oder nicht vertrauenswürdigen Quelle, bevor Sie Ausführen oder Alle Zellen ausführen wählen.

Beim gewöhnlichen .srwb-Import werden gespeicherte Ausgaben von Code-Zellen derzeit verworfen, selbst wenn die Datei diese enthält. Markdown-Text bleibt erhalten und wird gerendert, weshalb die Einführung sofort angezeigt wird. Um Diagramme oder andere durch Code erzeugte Bilder neu zu erstellen, führen Sie deren Code-Zellen erneut aus, und zwar abhängige Zellen der Reihe nach. Durch den Import werden aktive R- oder andere Laufzeitvariablen nicht wiederhergestellt.

Schritt 4

Optional: die importierte Lektion ausführen

Ihr manueller Import ist abgeschlossen; das Ausführen von Code ist ein separater Schritt. Simpson's Paradox verwendet synthetische Lehrdaten, um zu zeigen, wie Vergleiche innerhalb von Gruppen dem Gesamtvergleich widersprechen können. Um dies zu erkunden, tippen Sie auf den ✎ Bleistift einer gespeicherten Code-Zelle, prüfen Sie den Code und nutzen Sie dann für diese Zelle die Schaltfläche Ausführen.

  1. Führen Sie die R-Zelle data aus, lesen Sie dann die Textzelle pause und treffen Sie deren Vorhersage, bevor Sie compute ausführen. Fahren Sie mit viz fort, um das Diagramm zu erstellen. Die späteren R-Zellen hängen von den früheren ab. Sie verwenden Basis-R; Sie müssen keine zusätzlichen R-Pakete installieren.
  2. Wenn Sie eine separate JavaScript-Prüfung wünschen, führen Sie js_check aus. Sie ist eigenständig: Sie hängt nicht von den R-Zellen ab und erfordert keinen Start von R.

Erster R-Lauf: In SciREPL muss die webR-Laufzeit möglicherweise heruntergeladen und initialisiert werden. Möglicherweise wird ein Netzwerk-/Datenschutzhinweis angezeigt; lesen Sie diesen und stimmen Sie nur zu, wenn Sie fortfahren möchten. Warten Sie, bis die Laufzeit bereit ist, und prüfen Sie die Zelle auf Fehler. Durch das reine Importieren des Arbeitsbuchs wurden dessen R-Definitionen noch nicht geladen.

Ein weiteres Beispiel mit einer ausführlicheren Anleitung zum Ausführen und Bearbeiten finden Sie in der Lektion zu Markov Groups. Das ist ein anderes Arbeitsbuch mit vier Python-Zellen; sein Exportschritt veranschaulicht außerdem, wie eine bearbeitete Kopie des Arbeitsbuchs gespeichert wird.

Behalten Sie eine Kopie, die Sie kontrollieren. Die heruntergeladene Datei ist die ursprüngliche Arbeitsmappenkopie, keine Sicherung späterer Bearbeitungen. Exportieren Sie eine Arbeitsmappenkopie, um Ihre Änderungen zu speichern. Das Löschen des App- oder Browserspeichers kann lokale Arbeit entfernen, und Android- sowie Browsersitzungen teilen Ihre Änderungen nicht automatisch.

Andere Formate und Sicherheit

Wissen, was Ihre Datei enthält

Jupyter-Notebooks (.ipynb) verwenden ebenfalls Menü → Datei importieren, aber ihr Ausführungsverhalten unterscheidet sich von .srwb. Wenn Zellen beim Import der Arbeitsmappe automatisch ausführen aktiviert ist, kann ein .ipynb-Import automatisch Codezellen ausführen, die keine gespeicherten Ausgaben haben.

Importieren Sie Notebook-Dateien nur aus Quellen, denen Sie vertrauen. Öffnen Sie vor dem Importieren eines .ipynb Menü → Einstellungen → Import und Bearbeitung und stellen Sie sicher, dass Zellen beim Import der Arbeitsmappe automatisch ausführen aus (deaktiviert) ist. Es ist standardmäßig ausgeschaltet, aber überprüfen Sie Ihre aktuelle Einstellung. Das Ausschalten ist keine Garantie dafür, dass ein beliebiges Notebook sicher ist; prüfen Sie vertrauenswürdigen Notebook-Code, bevor Sie explizit entscheiden, ob Sie ihn ausführen.

Separate Datendateien: Ein normaler .srwb-Export überträgt keine separaten CSV-Dateien oder andere im virtuellen Dateisystem von SciREPL gespeicherten Daten (die Ansicht Dateien). Diese Version von Simpsons Paradoxon erstellt ihre synthetischen Daten im Code, benötigt also keine separate Datendatei. Folgen Sie für eine Arbeitsmappe, die eine CSV liest, den Schritten zum CSV-Paketarchivexport und erneuten Öffnen der Anleitung, um sowohl die Arbeitsmappe als auch ihre Daten zu übertragen und wiederherzustellen. Paketarchive und .zip-Importe liegen außerhalb dieser kurzen Lektion zu Arbeitsmappendateien.

Wenn etwas falsch aussieht

Überprüfen Sie die Datei und den ausgewählten Tab

  • Die Dateiauswahl kann die Datei nicht finden: Überprüfen Sie die Download-Liste Ihres Browsers, um zu sehen, wo sie gespeichert wurde, und navigieren Sie dann zu diesem Ordner. Das Herunterladen auf einem Desktop platziert die Datei nicht im Download-Ordner Ihres Telefons.
  • Der Dateiname endet auf .txt oder .html: Kehren Sie zum Download-Link der Arbeitsmappe zurück und speichern Sie die eigentliche Datei mit ihrer Dateiendung .srwb. Das Umbenennen einer HTML-Seite in .srwb macht daraus keine Arbeitsmappe.
  • Sie sehen immer noch Ihre alte Arbeitsmappe: Schließen Sie das Menü und überprüfen Sie die Arbeitsmappenauswahl auf den neuen Titel. Bestehende Tabs bleiben erhalten.
  • Sie haben es zweimal importiert: Ein weiterer Import fügt eine weitere Kopie hinzu; er aktualisiert oder ersetzt den früheren Tab nicht. Überprüfen Sie vor dem Vornehmen von Änderungen, welche Kopie Sie bearbeiten.
  • Der Titel oder die Zellen stimmen nicht überein: Überprüfen Sie, ob Sie simpsons-paradox.srwb ausgewählt haben und nicht einen anderen Download oder eine Datei aus einer anderen Lektion. Die Datei auf main kann sich ändern; vergleichen Sie Ihre Kopie mit der aktuellen GitHub-Datei und überprüfen Sie unbekannten Code, bevor Sie ihn ausführen.

Die Grundlagen zu Arbeitsmappen-Tabs und der Bearbeitung gespeicherter Zellen finden Sie in der Einführung in die Benutzeroberfläche der ersten Arbeitsmappe. Die Arbeitsmappen-Referenz (Englische Referenzseite) erläutert die Struktur von Arbeitsmappen und Zelltypen.
