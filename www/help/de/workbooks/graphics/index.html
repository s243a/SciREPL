Lernen durch Ausprobieren

Bilder, Diagramme und Gleichungen hinzufügen

Eine Arbeitsmappe kann eine Idee sowohl mit einem Bild als auch mit Code erklären. Probieren Sie drei Möglichkeiten aus, um dasselbe einfache Koordinatensystem darzustellen: ein statisches Bild in Markdown, ein von JavaScript gezeichnetes Bild und eine mit KaTeX gesetzte Gleichung. Sie benötigen weder Python noch R, keine Paketinstallation und kein KI-Konto.

  • Free + Pro Arbeitsablauf
  • Im Browser überprüfte Beispiele
  • Etwa 10 Minuten

Die Beispiele und Screenshots wurden in der SciREPL Free-Browserversion am 6. Oktober 2026 überprüft. Screenshots verwenden einen schmalen Browser-Viewport; es sind keine Android-Aufnahmen. Unter Android werden dieselben Steuerelemente verwendet, ihre Position kann jedoch abweichen. Pro und jede veröffentlichte App-Version wurden für diesen Leitfaden nicht getestet.

Alle Anleitungen

Schritt 1

Beispiel-Arbeitsmappe öffnen

Die Begleitdatei enthält die vollständigen Beispiele, einschließlich eines eingebetteten PNG. Sie behält alles in einer kleinen Arbeitsmappe, sodass Sie keine lange Base64-Bildzeichenfolge eingeben müssen.

  1. Laden Sie die Grafik-Beispiel-Arbeitsmappe (.srwb) herunter. Speichern Sie die eigentliche Datei und behalten Sie ihre Dateiendung .srwb bei. Wenn Ihr Browser Text anzeigt, verwenden Sie dessen Speicher- oder Download-Aktion. Notieren Sie sich den Ordner, in dem Sie sie gespeichert haben.
  2. Öffnen Sie SciREPL. Suchen Sie in der Kopfzeile oben in der App nach ☰ Menü, der Schaltfläche mit drei horizontalen Linien. Tippen oder klicken Sie darauf.
  3. Wählen Sie 📂 Datei importieren (z. B. .srwb, .ipynb, .csv, .py, .zip). Scrollen Sie bei Bedarf innerhalb des Menüs. Wählen Sie in der Dateiauswahl Ihres Geräts workbook-graphics.srwb aus dem Ordner „Downloads“ oder dem von Ihnen gewählten Ordner.
  4. Schließen Sie das Menü, falls es geöffnet bleibt, und wählen Sie den neuen Tab Workbook Graphics in der Arbeitsmappenauswahl. Ihre bestehenden Tabs bleiben erhalten.
  5. Suchen Sie die vier Zellen namens static_axes, embedded_png, canvas_axes und math_axes. Lesen Sie diese, bevor Sie Code ausführen. Die statischen Diagramme und Gleichungen erscheinen aus ihrer Markdown-Quelle; das JavaScript-Bild erscheint erst, nachdem Sie dessen Zelle ausführen.

Importieren bedeutet nicht Ausführen. Ein .srwb-Import führt dessen Code nicht aus, selbst wenn die automatische Ausführung aktiviert ist. In dieser Lektion erfordert nur canvas_axes eine JavaScript-Ausführung. Es gibt keinen Alle Zellen ausführen-Schritt.

Benötigen Sie weitere Details zum Download oder zur Dateiauswahl? Folgen Sie der Anleitung zum manuellen Importieren von Arbeitsmappen. Die oben genannten Namen erscheinen auf den gespeicherten Zellen; die Anleitung zu Pfaden benannter Zellen erklärt, wie man diese zuweist und verwendet. Sie können diese Beispiele auch in einer bereits geöffneten Arbeitsmappe anhand der folgenden Schritte erstellen.

Schritt 2 · Methode 1

Ein statisches Diagramm in Markdown behalten

Stellen Sie sich ein Blatt Papier vor, das Ihnen zugewandt ist. r zeigt entlang des Papiers nach rechts, u zeigt daran nach oben und n zeigt aus dem Papier heraus auf Sie zu. Ein Kreis mit einem Punkt stellt diese nach außen gerichtete Richtung dar, ähnlich wie die Spitze eines Pfeils, der auf Sie zukommt.

Das importierte Diagramm bearbeiten

  1. Suchen Sie static_axes. Tippen Sie auf dessen ✎ Bleistift in der Kopfzeile dieser gespeicherten Zelle, nahe ✕. Dies öffnet den Quelltext der vorhandenen Zelle; das Panel für neue Zellen würde eine weitere Zelle erstellen.
  2. Lassen Sie die Zelltyp-Schaltfläche auf Md eingestellt. Ändern Sie im SVG-Text r: right zu r: across.
  3. Tippen Sie auf die Schaltfläche ▶ Ausführen dieser Zelle, um das Markdown erneut zu speichern und zu rendern. Bei einer Md-Zelle rendert diese Schaltfläche Text; sie führt kein JavaScript aus und startet keine Sprachlaufzeit.

Oder erstellen Sie Ihre eigene Markdown-Zelle

  1. Suchen Sie das Panel für neue Zellen, in dem Sie die nächste Zelle eingeben. Falls es eingeklappt ist, verwenden Sie die Schaltfläche ⌃ Show new-cell panel nahe dem App-Titel.
  2. Tippen Sie auf die mit Code beschriftete Zelltyp-Schaltfläche, sodass sie zu Md wechselt. Markdown ist ein Zelltyp, kein Eintrag im Sprach-Dropdown-Menü.
  3. Kopieren Sie das vollständige SVG unten in das Textfeld, ohne Markdown-Codeblöcke hinzuzufügen (```). Lassen Sie eine Leerzeile zwischen dem umgebenden Fließtext und dem SVG.
  4. Tippen Sie auf ▶ Ausführen, um die gerenderte Markdown-Zelle hinzuzufügen. Sie sollten das Papier und alle drei Richtungsbeschriftungen sehen.
<svg xmlns="http://www.w3.org/2000/svg"
     viewBox="0 0 360 220" width="100%" height="220"
     role="img" aria-label="Right, up and outward normal on paper">
  <title>A paper coordinate frame</title>
  <rect x="20" y="18" width="320" height="184"
        rx="6" fill="#ffffff" stroke="#526170" stroke-width="2" />
  <path d="M110 145 H280" fill="none" stroke="#075d69" stroke-width="3" />
  <polygon points="280,145 267,138 267,152" fill="#075d69" />
  <path d="M110 145 V48" fill="none" stroke="#064d91" stroke-width="3" />
  <polygon points="110,48 103,61 117,61" fill="#064d91" />
  <circle cx="110" cy="145" r="10" fill="#ffffff" stroke="#14191f" stroke-width="2" />
  <circle cx="110" cy="145" r="3" fill="#14191f" />
  <text x="204" y="168" fill="#14191f" font-size="16">r: right</text>
  <text x="124" y="62" fill="#14191f" font-size="16">u: up</text>
  <text x="42" y="190" fill="#14191f" font-size="16">n: toward you</text>
</svg>

SciREPL bereinigt Markdown. Dieses Beispiel verwendet gewöhnliche SVG-Formen, Text und explizite fill/stroke-Attribute. Seine Pfeilspitzen sind Polygone: Verlassen Sie sich nicht darauf, dass marker-end="url(...)", ein <style>-Block, Skripte oder Animationen die Bereinigung überstehen.

Stattdessen ein eingebettetes PNG verwenden

Die andere statische Option ist ein PNG, dessen Base64-Daten direkt in der Markdown-Quelle gespeichert sind. Die standardmäßige Markdown-Bildsyntax sieht so aus:

![Paper axes](data:image/png;base64,PASTE_THE_COMPLETE_BASE64_PNG_HERE)

Diese Zeile zeigt das Format, kein funktionierendes Bild: Ersetzen Sie den Platzhalter durch das vollständige codierte PNG oder verwenden Sie die bereits funktionierende embedded_png-Zelle. Der Teil nach base64, besteht aus Bilddaten, nicht aus einem Dateinamen. Behalten Sie alles in einer Zeile.

Für ein Bild, das auf einem kleinen Bildschirm in die Zelle passt, verwendet die embedded_png-Begleitzelle das unten stehende entsprechende Inline-HTML mit width="100%". Es wird weiterhin in Markdown gespeichert, nicht als Code-Ausgabe:

<img alt="Paper axes" width="100%"
     src="data:image/png;base64,PASTE_THE_COMPLETE_BASE64_PNG_HERE">

Wählen Sie einen statischen Weg: Verwenden Sie ein Inline-SVG-Element für ein kleines bearbeitbares Diagramm oder ein data:image/png;base64,...-Bild für ein Rasterbild. Eine SVG-Daten-URL wie data:image/svg+xml,... ist nicht dasselbe wie Inline-SVG und wird im geprüften Build blockiert. Externe Bild-URLs werden dort ebenfalls blockiert. Diese zwei in sich geschlossenen Beispiele erfordern beim Anzeigen keinen Bild-Download.

Beide statischen Beispiele befinden sich im Markdown-Quelltext. Sie können nach dem Importieren der Arbeitsmappe ohne Ausführung von Code angezeigt werden.

Schritt 3 · Methode 2

Ein Bild mit JavaScript zeichnen

Ein statisches Bild bleibt unverändert, bis Sie dessen Quelltext bearbeiten. Verwenden Sie für ein Bild, das von einem Programm berechnet oder gezeichnet wird, eine Code-Zelle und wählen Sie JS - JavaScript. Dieses Beispiel zeichnet auf ein Canvas, konvertiert es in ein PNG und sendet dieses Bild an die Ausgabe der Zelle.

  1. Tippen Sie in der importierten Arbeitsmappe auf den ✎ Stift bei canvas_axes. Vergewissern Sie sich, dass der Zelltyp Code ist und die Sprache JS - JavaScript lautet (die kompakte Auswahl zeigt möglicherweise nur JS an).
  2. Lesen Sie den unten stehenden Code, der das vollständige Programm in dieser Zelle darstellt. Er benötigt keine andere Zelle, Datei, kein Paket und keine Netzwerkanfrage.
  3. Tippen Sie auf das dieser Zelle zugehörige ▶ Ausführen. Unter dem JavaScript-Quellcode sollte ein Bild erscheinen.

Um stattdessen eine neue Zelle zu erstellen, öffnen Sie das Panel für neue Zellen, ändern Sie bei Bedarf Md zurück zu Code und wählen Sie im Sprach-Dropdown JS - JavaScript. Fügen Sie den Code ein und tippen Sie anschließend auf ▶ Ausführen. Falls JavaScript ausgeblendet ist, suchen Sie ☰ Menü → Sprachen und aktivieren Sie es.

(() => {
  const canvas = document.createElement('canvas');
  canvas.width = 360;
  canvas.height = 220;
  const ctx = canvas.getContext('2d');
  ctx.fillStyle = '#ffffff';
  ctx.fillRect(0, 0, 360, 220);
  ctx.strokeStyle = '#526170';
  ctx.lineWidth = 2;
  ctx.strokeRect(20, 18, 320, 184);

  function arrow(x1, y1, x2, y2, color) {
    const angle = Math.atan2(y2 - y1, x2 - x1);
    ctx.strokeStyle = color;
    ctx.fillStyle = color;
    ctx.lineWidth = 3;
    ctx.beginPath();
    ctx.moveTo(x1, y1);
    ctx.lineTo(x2, y2);
    ctx.stroke();
    ctx.beginPath();
    ctx.moveTo(x2, y2);
    ctx.lineTo(x2 - 14 * Math.cos(angle - 0.5),
               y2 - 14 * Math.sin(angle - 0.5));
    ctx.lineTo(x2 - 14 * Math.cos(angle + 0.5),
               y2 - 14 * Math.sin(angle + 0.5));
    ctx.closePath();
    ctx.fill();
  }
  arrow(110, 145, 280, 145, '#075d69'); // right
  arrow(110, 145, 110, 48, '#064d91');  // up
  ctx.fillStyle = '#ffffff';
  ctx.strokeStyle = '#14191f';
  ctx.lineWidth = 2;
  ctx.beginPath();
  ctx.arc(110, 145, 10, 0, 2 * Math.PI);
  ctx.fill();
  ctx.stroke();
  ctx.fillStyle = '#14191f';
  ctx.beginPath();
  ctx.arc(110, 145, 3, 0, 2 * Math.PI);
  ctx.fill();
  ctx.font = '16px sans-serif';
  ctx.fillText('r: right', 204, 168);
  ctx.fillText('u: up', 124, 62);
  ctx.fillText('n: toward you', 42, 190);
  window.renderImage(canvas.toDataURL('image/png'));
})();

Versuchen Sie, r: right in ctx.fillText(...) zu ändern, und führen Sie die Zelle dann erneut aus. Der Funktions-Wrapper (() => { ... })(); hält die Variablen dieses Beispiels lokal, sodass Sie es erneut ausführen können, ohne Variablen auf oberster Ebene in const neu deklarieren zu müssen.

Der Anzeigeaufruf ist wichtig. Behalten Sie window.renderImage(canvas.toDataURL('image/png')) am Ende bei. Die Rückgabe einer gewöhnlichen Zeichenkette wie '<svg>...</svg>' aus JavaScript zeigt Text an; sie verwandelt diese Zeichenkette nicht in ein Inline-Diagramm. Sie müssen das Canvas nicht in die Seite der App einfügen.

Schritt 4 · Methode 3

Das Bild mit Gleichungen erklären

Verwenden Sie eine Markdown (Md)-Zelle für Mathematik im TeX-Stil. Die Richtungen der Diagramme bilden ein rechtshändiges System: rechts × oben = äußere Normale. In der unten stehenden Matrix ist die erste Zeile r, die zweite u und die dritte n; die Indizes sind ihre Komponenten in einem gewählten x-, y-, z-Koordinatensystem.

  1. Tippen Sie auf den ✎ Stift bei math_axes oder erstellen Sie eine neue Zelle über Code → Md im Panel für neue Zellen.
  2. Verwenden Sie den unten stehenden vollständigen Text. Die $$-Trennzeichen gehören in den Markdown-Quelltext; schließen Sie ihn nicht in einen Code-Block ein.
  3. Tippen Sie auf ▶ Ausführen, um das Markdown zu speichern und zu rendern. Sie sollten eine Kreuzprodukt-Gleichung und eine dreizeilige Matrix sehen, keine reinen Backslash-Befehle. Für diese Zelle wird kein Sprach-Kernel ausgeführt.
Right, up and outward normal form a right-handed frame.

$$\mathbf{r} \times \mathbf{u} = \mathbf{n}$$

Rows of the frame matrix: right, up, then outward normal.

$$
M = \begin{pmatrix}
r_x & r_y & r_z \\
u_x & u_y & u_z \\
n_x & n_y & n_z
\end{pmatrix}
$$

KaTeX ist kein vollständiger TeX-Compiler. Es rendert unterstützte mathematische Notation, kompiliert jedoch weder TikZ-Diagramme noch ein ganzes LaTeX-Dokument. Obwohl KaTeX \includegraphics auflistet, erfordert dies eine Trust-Option, die SciREPL im geprüften Renderer nicht aktiviert; es ist hier kein Weg zum Einfügen von Bildern. Verwenden Sie Markdown-SVG/PNG oder JavaScript-Canvas für Bilder.

Konsultieren Sie für andere Symbole und mathematische Befehle die KaTeX-Support-Tabelle; die Dokumentation beschreibt möglicherweise Funktionen, die neuer sind als die in SciREPL gebündelte Version. Für eine Arbeitsmappe, die diese Richtungen zur Erklärung von Würfelzügen verwendet, siehe die Markov Groups-Anleitung.

Schritt 5

Eine Kopie speichern und wissen, was erneut auszuführen ist

  1. Öffnen Sie ☰ Menü → Arbeitsmappen & Pakete exportieren.
  2. Wählen Sie Arbeitsmappe (.srwb) und Nur aktuelle Registerkarte für diese Arbeitsmappe und tippen Sie dann auf Exportieren. Speichern Sie die Datei an einem Ort, den Sie kontrollieren.
  3. Um diese Kopie erneut zu öffnen, verwenden Sie Menü → Import File. Dies fügt einen weiteren Arbeitsmappen-Tab hinzu; es ersetzt Ihren bestehenden nicht.
  4. Überprüfen Sie das statische SVG, das eingebettete PNG und die Gleichungen. Sie stammen aus der gespeicherten Markdown-Quelle und erfordern keine Code-Ausführung. Überprüfen Sie canvas_axes und führen Sie diese JavaScript-Zelle erneut aus, um ihr Bild neu zu erzeugen.

Generierte Ausgabe ist nicht dasselbe wie Quelltext. Im geprüften Free-Browser-Build kann der .srwb-Export eine JavaScript-Bildausgabe speichern, aber das manuelle Menü → Import File stellt diese Code-Ausgabe nicht wieder her. Der JavaScript-Quelltext bleibt erhalten, führen Sie ihn also erneut aus. Das Inline-SVG, das eingebettete PNG und die Gleichungen sind Markdown-Quelltext und werden beim Importieren angezeigt. Verwenden Sie eine zuvor sichtbare Ausgabe nicht als Beweis dafür, dass Code gerade ausgeführt wurde.

Diese Prüfungen decken die obigen Arbeitsmappen-Beispiele ab, nicht die Bildtreue in jedem Exportformat. Gehen Sie nicht davon aus, dass PDF-, DOCX-, Markdown- und andere Dokumentexporte jedes Bild auf dieselbe Weise beibehalten; überprüfen Sie Ihr exportiertes Dokument. Siehe Dateien und Export (Englische Referenzseite) für die verfügbaren Formate.

Das Exportieren Ihrer bearbeiteten Arbeitsmappe erstellt eine Sicherungskopie Ihrer Änderungen; das ursprünglich heruntergeladene Beispiel wird nicht aktualisiert, wenn Sie eine Zelle bearbeiten. Der lokale App-Speicher ist kein Backup, und Android- und Browser-Sitzungen teilen ihre Arbeit nicht automatisch.

Wenn etwas nicht richtig aussieht

Zelltyp und Quelltext überprüfen

  • Sie sehen SVG-Code statt eines Diagramms: Überprüfen Sie, ob der Zelltyp Md ist, entfernen Sie alle umgebenden Codeblöcke und rendern Sie die Zelle erneut. Verwenden Sie das vollständige Inline-<svg>...</svg>-Beispiel, keine SVG-Daten-URL.
  • Das PNG fehlt: Verwenden Sie die embedded_png-Begleitzelle oder überprüfen Sie, ob Sie die gesamte data:image/png;base64,...-Zeichenkette ohne Leerzeichen oder Zeilenumbrüche eingefügt haben. Ein lokaler Dateiname sind keine eingebetteten Bilddaten.
  • Der Canvas-Code wird nicht ausgeführt: Setzen Sie dessen Zelltyp auf Code und die Sprache auf JS - JavaScript, nicht auf Python. Behalten Sie den gesamten Funktions-Wrapper und den abschließenden Aufruf von window.renderImage(...) bei.
  • Eine importierte JavaScript-Zelle hat kein Bild: Das Importieren dieser Arbeitsmappe führt sie nicht aus und stellt ihre Code-Ausgabe nicht wieder her. Überprüfen Sie canvas_axes und führen Sie es erneut aus.
  • Sie sehen reinen TeX-Code oder einen mathematischen Fehler: Verwenden Sie Md, fügen Sie sowohl öffnende als auch schließende $$ ein und prüfen Sie jeden Backslash und jede geschweifte Klammer anhand des Beispiels. Jede Matrixzeile außer der letzten endet mit zwei Backslashes, \\.
  • Durch das Bearbeiten wurde eine zusätzliche Zelle erstellt: Das Panel für neue Zellen fügt Zellen hinzu. Verwenden Sie den ✎ Stift der gespeicherten Zelle, um diese vorhandene Zelle zu ändern, und danach ihre eigene ▶ Ausführen-Schaltfläche. Verwenden Sie Abbrechen, falls Sie deren Editor versehentlich geöffnet haben.

Für eine bebilderte Tour zu gespeicherten Zellen, dem Stift und dem Panel für neue Zellen siehe die Anleitung zur ersten Arbeitsmappen-Benutzeroberfläche. Kehren Sie zur Arbeitsmappen-Referenz (Englische Referenzseite) zurück, um eine kurze Übersicht über die Zelltypen zu erhalten.
