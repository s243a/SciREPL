Lernen durch Ausprobieren

Alle SciREPL-Tutorials

Wählen Sie eine schrittweise Anleitung. Lernen Sie die Bedienelemente kennen, finden Sie eine Arbeitsmappe, probieren Sie Dateien und Bilder aus oder erkunden Sie die KI und Vervollständigung von Pro. Jedes Tutorial gibt an, mit welcher App-Version und Plattform es geprüft wurde, und kennzeichnet alle Funktionen, die nur in Pro verfügbar sind.

  • Free-Arbeitsabläufe
  • Pro-Unterschiede gekennzeichnet
  • Beispiele für Smartphone und Browser

Neu bei SciREPL? Beginnen Sie mit der Einführung in die Benutzeroberfläche und suchen sowie starten Sie eine Katalog-Arbeitsmappe. Die Würfelmathematik in dieser zweiten Lektion ist optional; Sie können aufhören, sobald Sie den Arbeitsablauf der App kennengelernt haben.

Hier beginnen

Ihre erste Arbeitsmappe

Finden Sie das Menü, geben Sie Code ein und führen Sie ihn aus, bearbeiten Sie eine gespeicherte Zelle und exportieren Sie Ihre Arbeit.

Platz auf dem Bildschirm schaffen

Einstellungen für das Erscheinungsbild

Wählen Sie ein Design, passen Sie Größen sowie Kopfzeilen-Tastenkürzel an, blenden Sie Durchsuchen ein und verwalten Sie den Android-Bildschirmplatz.

Arbeitsmappen und Dateien

Ein Beispiel durchsuchen und ausführen

Markov-Gruppen im Katalog finden

Suchen Sie nach einer Arbeitsmappe, installieren Sie diese, führen Sie ihre Zellen aus, ändern Sie ein Beispiel und exportieren Sie eine Kopie. Die Mathematik ist optional.

Eine Arbeitsmappe selbst herunterladen

Manueller Arbeitsmappen-Import

Laden Sie Simpson’s Paradox von GitHub herunter und importieren Sie es. Lernen Sie den Unterschied zwischen .srwb- und .ipynb-Dateien sowie zwischen Importieren und Ausführen kennen.

Daten erstellen, prüfen und sichern

CSV-Dateien und Paketexport

Erstellen und lesen Sie eine CSV-Datei, zeigen Sie sie unter Dateien & Speicher an und bearbeiten Sie sie dort, exportieren Sie anschließend ein Paket mit Arbeitsmappe und Daten und öffnen Sie es erneut.

Bilder und sprachübergreifendes Arbeiten

Ihre Arbeitsmappe illustrieren

Bilder, Diagramme und Gleichungen

Binden Sie statische Bilder in Markdown ein, zeichnen Sie ein JavaScript-Canvas-Bild und schreiben Sie KaTeX-Gleichungen. Enthält eine kleine Beispiel-Arbeitsmappe.

Zellen und Sprachen verbinden

Benannte Zellen und freigegebene Dateien

Benennen Sie Zellen, lesen Sie deren Quelltext und Ausgabe über virtuelle Pfade, tauschen Sie JSON über freigegebene Dateien aus und erzeugen Sie Code für eine andere Zelle.

KI und Vervollständigung (Pro)

Nur Pro · Lokales Modell erfordert Android

Von Offline-Vorschlägen zu KI-unterstützter Programmierung

Beginnen Sie mit Tabellen ohne API-Kosten, richten Sie einen Schlüssel sowie die Agent-Voreinstellung „Offen“ ein, wählen Sie ein Online-Vervollständigungsmodell, probieren Sie lokale Vorschläge aus und nutzen Sie KI-Prompt-Zellen, um Code zu verstehen.
