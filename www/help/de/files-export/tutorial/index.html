Eine CSV in einer Arbeitsmappe erkunden

Beginnen Sie in Pakete, Bündel & Arbeitsmappen durchsuchen. Installieren Sie ein kleines Beispiel, führen Sie dessen Zellen aus, bearbeiten Sie dessen CSV, exportieren Sie dann die Arbeitsmappe mit ihren Daten und öffnen Sie sie erneut. Die Daten sind fiktiv und der Python-Code erfordert keine zusätzlichen Pakete oder ein KI-Konto.

  • Free + Pro
  • Schritte für Android
  • Etwa 15 Minuten

Die Screenshots wurden auf einem Smartphone der Samsung-Galaxy-S24-Reihe aufgenommen. Die Abbildungen zu „Durchsuchen“ und der anfänglichen Ausgabe zeigen Free; die Abbildungen zum neuen Datei-Editor und zur Paketauswahl zeigen Pro 1.4.0 und sind unten beschriftet. In Pro können Sie den direkten Arbeitsmappen-Download und den Pfad „Datei importieren“ verwenden; die umgebenden Steuerelemente können abweichen, und dieser neue Eintrag „Durchsuchen“ ist dort möglicherweise nicht vorhanden.

Sie sehen diese Arbeitsmappe noch nicht in Browse? Das Beispiel ist in Free 1.4.0 und neuer integriert; eine ältere installierte App oder zwischengespeicherte PWA listet sie möglicherweise nicht auf. Laden Sie die Arbeitsmappe direkt herunter, und nutzen Sie dann Menü → Datei importieren, um sie zu öffnen. Sie können dem Rest dieser Lektion jetzt folgen.

In dieser Lektion
  1. Das Beispiel aus Browse installieren
  2. Dessen Python-Zellen ausführen
  3. Eine Messung in Files & Storage ändern
  4. Eine CSV-Datei importieren
  5. Die Arbeitsmappe und Daten exportieren
  6. Das Paket erneut öffnen und dessen Daten prüfen

Schritt 1

Die Arbeitsmappe in Browse finden

  1. Öffnen Sie Menü → Pakete, Bündel & Arbeitsmappen durchsuchen. Das optionale 📦-Kopfzeilen-Kürzel öffnet denselben Bildschirm, sofern es sichtbar ist.
  2. Suchen Sie nach CSV Basics. Finden Sie unter Arbeitsmappen den Eintrag CSV Basics: Seedling Heights. Es handelt sich um ein integriertes englisches Beispiel, nicht um ein Paket, das in Python installiert werden muss.
  3. Tippen Sie auf Installieren. Die Arbeitsmappe wird normalerweise zum ausgewählten Tab. Wenn Sie das automatische Wechseln deaktiviert haben, verwenden Sie die Arbeitsmappenauswahl, um sie auszuwählen.

Falls eine Datenschutzerklärung erscheint: Browse prüft den verifizierten Katalog möglicherweise online. Lesen Sie den Hinweis, scrollen Sie im Dialogfenster ganz nach unten und tippen Sie nur dann auf I Understand, wenn Sie einverstanden sind. Sie können den Hinweis stattdessen schließen und weiterhin integrierte Einträge nutzen; der Remote-Katalog ist dann nicht verfügbar. Dieses Beispiel selbst benötigt keinen externen Datensatz oder ein Python-Paket.

Das Installieren einer Arbeitsmappe fügt deren Zellen hinzu; es führt sie nicht aus. Dadurch können Sie den Code vor der Ausführung überprüfen.

Schritt 2

Die Zellen der Reihe nach ausführen

Der einleitende Text erklärt das Beispiel. Die drei Python-Zellen tragen jeweils einen Namen: create_csv, read_csv und compare_groups. Um eine gespeicherte Zelle zu bearbeiten, tippen Sie auf deren ✎ Stift, um den Editor zu öffnen, und tippen Sie dann auf Ausführen dieser Zelle. In Pro können Sie auch doppelt auf den Code der Zelle tippen, um ihn zu bearbeiten.

  1. Führen Sie create_csv aus. Dadurch werden sechs fiktive Zeilen in /shared/data/seedling-heights.csv geschrieben. Sie sollten Saved 6 fictional rows sehen.
  2. Führen Sie read_csv aus. Dadurch wird die gerade erstellte Datei geöffnet und alle sechs Zeilen werden ausgegeben.
  3. Führen Sie compare_groups aus. Es gibt einen Licht-Mittelwert von 13.0 cm, einen Schatten-Mittelwert von 8.0 cm und eine Differenz von 5.0 cm aus.

Die Datei ist auch unter Menü → Dateien & Speicher sichtbar. Sie können sie dort lesen oder Bearbeiten und Speichern verwenden, um sie direkt zu bearbeiten. Der nächste Schritt zeigt, wie das geht.

Die endgültige Ausgabe sollte so aussehen:

Light mean: 13.0 cm
Shade mean: 8.0 cm
Difference: 5.0 cm

Erster Durchlauf langsamer? Python benötigt möglicherweise einen Moment zur Initialisierung. Warten Sie, bis das Status-Badge fertig anzeigt, bevor Sie beurteilen, ob eine Zelle fertiggestellt ist. Spätere Zellen verwenden normalerweise die geladene Laufzeitumgebung wieder. Falls ein Download der Laufzeitumgebung eine Zustimmung erfordert, lesen Sie den Datenschutzhinweis vor dem Akzeptieren; dieses Arbeitsbuch ruft %pip install nicht auf.

Diese frei erfundenen Werte veranschaulichen das Einlesen und Berechnen, nicht eine wissenschaftliche Schlussfolgerung über Licht und Pflanzenwachstum.

Schritt 3

Einen Wert ändern und erneut ausführen

Sie müssen die Python-Zelle nicht bearbeiten, um ihre Daten zu ändern. Öffnen Sie die CSV selbst:

  1. Wählen Sie Menü → Dateien & Speicher (das Menü fügt dem Namen möglicherweise VFS / Paths hinzu).
  2. Wählen Sie / (Dauerhafter Speicher) oder Alle Dateisysteme. Scrollen Sie zu /shared/data/seedling-heights.csv und tippen Sie auf den Dateinamen, nicht auf das Symbol zum Herunterladen oder Entfernen.
  3. Tippen Sie auf Bearbeiten. Ändern Sie die Zeile light,14 zu light,15. Behalten Sie die Kopfzeile group,height_cm, Kommas und andere Zeilen unverändert bei.
  4. Tippen Sie auf Speichern und schließen Sie dann Files & Storage. Das Speichern einer Datei führt keinen Code aus.

Führen Sie nur read_csv und compare_groups erneut aus. Der Licht-Mittelwert beträgt jetzt ungefähr 13.3 cm und die Differenz ungefähr 5.3 cm. Führen Sie nicht create_csv erneut aus: Dadurch würde Ihre Dateibearbeitung mit den Werten überschrieben, die sich noch in dieser Zelle befinden.

Alternativ können Sie create_csv mit dem ✎ Stift bearbeiten, den Messwert 14 in 15 ändern und alle drei Python-Zellen der Reihe nach ausführen. Dies ändert den Code, der die Datei erzeugt, anstatt nur die Datei.

Warum die späteren Zellen erneut ausführen? Ihre gespeicherte Ausgabe ist ein Protokoll der vorherigen Ausführung; das Ändern einer Datei führt nicht automatisch zu einer Neuberechnung früherer Ergebnisse. Jede Zelle liest die Datei ein, wenn Sie sie ausführen.

Pro: Dateibearbeitung im Vollbildmodus und optionale Hervorhebung

Tippen Sie in der Dateivorschau auf Vollbild, um einen größeren Editor zu öffnen. Die CSV bleibt Reiner Text, daher ist das Kontrollkästchen für Syntaxhervorhebung deaktiviert.

Bei unterstützten Codedateien ist die Syntaxhervorhebung optional und standardmäßig deaktiviert. Aktivieren Sie sie über das Kontrollkästchen in diesem Dateieditor, nicht über die Darstellungseinstellungen des Notebooks. Die Dateiendung bestimmt die Sprache: Zum Beispiel ist .py Python, .js ist JavaScript, .R ist R und .pl ist Prolog, nicht Perl. Unbekannte Dateiendungen bleiben einfacher Text.

Speichern schreibt die Datei und lässt den Editor geöffnet. Verwenden Sie × Close, um zu Files & Storage zurückzukehren; vor dem Verwerfen nicht gespeicherter Änderungen erfolgt eine Nachfrage. Das Bearbeiten oder Speichern der Datei führt diese niemals aus.

Den gleichen Vollbild-Editor mit der als Klartext geöffneten CSV ansehen.

Schritt 4

Die ursprüngliche CSV importieren

  1. Laden Sie die ursprüngliche Beispiel-CSV herunter (Englische Referenzseite) in einen Ordner, den die Dateiauswahl Ihres Geräts öffnen kann.
  2. Wählen Sie in SciREPL Menü → Datei importieren und wählen Sie seedling-heights.csv aus. In der Bestätigung sollte stehen, dass der Upload nach /shared/data/seedling-heights.csv erfolgt ist.
  3. Dadurch wird die geänderte lokale Datei durch die ursprünglichen sechs Zeilen ersetzt. Führen Sie read_csv und compare_groups erneut aus; die beiden Mittelwerte sollten wieder 13.0 und 8.0 cm betragen.

Wichtig: Führen Sie create_csv nach dem Importieren einer anderen Datei mit demselben Namen nicht erneut aus, es sei denn, Sie beabsichtigen, diese zu überschreiben. Notieren Sie sich für Ihre eigenen CSV den genauen Bestätigungspfad und ändern Sie path in den lesenden Zellen in diesen Dateinamen. Die Dateiauswahl zeigt möglicherweise Android Downloads, einen Cloud-Anbieter oder beides an.

Schritt 5

Eine portable Kopie speichern

Öffnen Sie Menü → Arbeitsmappen & Pakete exportieren. Wenn Sie nur die Zellen möchten, wählen Sie Arbeitsmappe (.srwb) und Nur aktuelle Registerkarte. Ein .srwb enthält nicht die separate CSV in SharedVFS.

Um das Arbeitsbuch mit seinen Daten zu verschieben, wählen Sie Paket (Archiv) und behalten Sie .zip bei. Wählen Sie in der Struktur Inhalt Folgendes aus:

  • Das Arbeitsbuch CSV_Basics__Seedling_Heights.ipynb unter notebooks/. Der Paketexport speichert die Zellen im Jupyter-Notebook-Format.
  • Die Datei seedling-heights.csv unter shared/data/.

Deaktivieren Sie nicht zugehörige Arbeitsbücher und Dateien. Erweitern Sie Ordner bei Bedarf über deren Pfeil; gehen Sie nicht davon aus, dass Nur aktuelle Registerkarte den Inhalt eines Pakets begrenzt. Sie benötigen die zusätzlichen Kopien in shared/notebooks/ für diese Lektion nicht. Lassen Sie in Pro KI-Unterhaltung einschließen deaktiviert, es sei denn, Sie möchten diese ausdrücklich teilen.

Tippen Sie auf Exportieren. Unter Android öffnet dies das Teilen-Menü: Speichern Sie das Archiv an einem Ort, den Sie wiederfinden können, beispielsweise auf Ihrem eigenen Laufwerk oder an einem Speicherziel Ihres Dateimanagers. In einem Browser wird eine Datei heruntergeladen. Der vorgeschlagene Dateiname lautet scirepl_package.zip; das Umbenennen in seedling-project.zip erleichtert das Wiedererkennen.

Die lokale Wiederherstellung ist kein Backup. Der Android-App-Speicher, die PWA in Chrome und ein anderer Browser teilen diese Dateien nicht automatisch. Bewahren Sie die exportierte Kopie an einem Ort auf, den Sie kontrollieren. Weitere Formate finden Sie unter Dateien, Import und Export (Englische Referenzseite).

Schritt 6

Das Paket erneut öffnen und beide Teile überprüfen

Bevor Sie einer Sicherung vertrauen, prüfen Sie, ob Sie sie öffnen können. Sie können dies in einer anderen SciREPL-Installation oder einem anderen Browserprofil tun. Das Importieren hier fügt ein weiteres Arbeitsbuch hinzu; es ersetzt auch Dateien an den Zielpfaden des Pakets. Behalten Sie daher eine separate Kopie jeder neueren Datei, bevor Sie ein älteres Paket importieren.

  1. Wählen Sie Menü → Import Package (.zip / .tar.gz) und wählen Sie das gespeicherte Archiv aus. Für diese Lektion ist es ein .zip, nicht der separate CSV- oder .srwb-Download.
  2. Wählen Sie das neu importierte Arbeitsbuch CSV Basics: Seedling Heights, falls es nicht automatisch ausgewählt wird. Wenn Sie in dieselbe App importiert haben, haben die alte und die neue Registerkarte möglicherweise denselben Namen.
  3. Öffnen Sie Menü → Dateien & Speicher und überprüfen Sie /shared/data/seedling-heights.csv. Seine sechs Zeilen sollten mit der von Ihnen exportierten Datei übereinstimmen. Schließen Sie die Vorschau nach der Überprüfung.
  4. Führen Sie die zweite Python-Zelle (den read_csv-Code) aus, danach die dritte Python-Zelle (den compare_groups-Code). Der Paketexport verwendet das Jupyter-Format und behält die Zellennamen möglicherweise nicht bei; identifizieren Sie diese anhand ihrer Reihenfolge und ihres Codes. Nach Schritt 4 mit der ursprünglichen CSV sind 13.0 cm, 8.0 cm und 5.0 cm zu erwarten. Wenn Sie stattdessen die bearbeitete light,15-Datei exportiert haben, erwarten Sie 13.3 cm, 8.0 cm und 5.3 cm.

Führen Sie create_csv für diese Wiederherstellungsprüfung nicht erneut aus. Dadurch werden die importierten Daten mit den Werten in seinem Code überschrieben. Das vorrangige Lesen der wiederhergestellten CSV beweist, dass die Daten mit dem Arbeitsbuch übertragen wurden; eine alte gespeicherte Ausgabe allein beweist das nicht.

Wenn die Datei fehlt oder das Arbeitsbuch nicht vorhanden ist, kehren Sie zu Schritt 5 zurück und überprüfen Sie, ob beide Einträge ausgewählt waren. Ein einfacher Arbeitsbuchexport kann die CSV nicht für Sie mitführen.

Wie geht es weiter?

Versuchen Sie eine eigene CSV. Behalten Sie die Spalten group und height_cm bei, verwenden Sie numerische Höhen und binden Sie mindestens eine light- und eine shade-Zeile ein – oder passen Sie die zwei Gruppenfilter in compare_groups an. Sie können die lokale Datei unter Menü → Dateien & Speicher einsehen. Informationen zu den hier verwendeten Smartphone-Bedienelementen finden Sie in der Einführung in die Benutzeroberfläche des ersten Arbeitsbuchs.
