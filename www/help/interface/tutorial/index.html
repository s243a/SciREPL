Learn by doing

Make your first workbook

This is the longer, practical companion to the interface reference. You will run one Python cell, change it, and save a copy you control. No AI account or API key is needed.

  • Free + Pro
  • Android steps
  • About 5 minutes

Screenshots show SciREPL Free v1.3.2 on a Samsung Galaxy S24-series phone. The lesson also applies to Pro, though some controls there may look different.

In this lesson
  1. Find your place
  2. Write and run a cell
  3. Edit the saved cell
  4. Export a workbook copy
  5. What to try next

Step 1

Find your place in the app

The top row is the header. It includes Menu, Help, and a status badge. The workbook selector chooses which workbook is open. Below it is the workbook: saved cells and their results.

The new-cell panel is where you type the next cell. Optional header buttons can disappear when the screen is narrow; their actions remain available from Menu or Help where applicable.

Step 2

Write and run a Python cell

Wait until the status badge says ready before the first run.

  1. In the new-cell panel, choose Python from the language selector. On a narrow phone, the closed selector may show only Py.
  2. Type this short program: 
    print("Hello from SciREPL")
  3. Tap Run. A saved cell appears in the workbook. Beneath it, you should see Hello from SciREPL.

The first run may take longer. Python's runtime has to start once. Wait for the status to return to ready; later Python cells usually reuse that runtime.

If a privacy notice appears: Python is normally bundled, so this example should not need a runtime download. A network runtime, such as R or Lua in Free, may first show SciREPL's Privacy Policy; Python can too if its bundled copy needs a network fallback. Read it, scroll inside the dialog to the bottom, and tap I Understand if you agree. A separate Runtime Download prompt may then ask you to tap Download.

See an example of the Privacy Policy dialog (the screenshot shows its top; the button is farther down). A %pip install may fetch Python packages, but does not itself show this notice. See privacy and local data before using network features.

Step 3

Edit the saved cell

  1. Use the saved cell's Edit control. This is different from typing in the new-cell panel, which creates another cell.
  2. Change Hello from SciREPL to Hello again.
  3. Choose Run to save and run the change. You should now see Hello again below that cell.

If you open the editor by mistake, use Cancel to leave the saved code unchanged. The language selector inside a saved cell changes that cell; the new-cell selector does not.

Step 4

Export a workbook copy

  1. Open Menu → Export Workbooks & Packages.
  2. Choose Current tab only or All tabs, then the SciREPL format Workbook (.srwb) when you want to keep SciREPL-specific state.
  3. Tap Export and choose a destination you control.

Why export? SciREPL restores local sessions, but local storage is not a backup and is not automatically shared between the Android app and a browser. See files and export for other formats, including .ipynb and PDF.

Step 5

What to try next

Try 2 + 2 in another Python cell. Then use the workbook selector to switch tabs, or browse an example workbook from Menu → Browse Packages, Bundles & Workbooks.

For a quick reminder of where controls live, return to the interface reference. To learn another language or add packages, continue with Languages & packages.

Using Pro? The basic workflow is the same. Pro also has a full-screen editor and optional AI features; see Pro AI and full-screen workflows after you are comfortable with ordinary cells.
