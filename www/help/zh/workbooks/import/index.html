亲自动手导入工作簿文件

已经拥有工作簿文件，或者在“浏览”中找不到课程？将文件保存到您的设备，然后使用 菜单 → Import File 将其添加到 SciREPL。本简短操作指南使用 Simpson's Paradox，该示例来自目录的 GitHub main 分支；您无需安装任何包或编写代码即可导入它。

SciREPL 支持导入两种笔记本格式：其自带的工作簿格式 .srwb，以及 Jupyter 笔记本格式 .ipynb。本示例使用 .srwb；下文的格式说明解释了 Jupyter 导入的不同执行行为。

  • Android 和浏览器操作步骤
  • 约 3 分钟

菜单截图是在 Samsung Galaxy S24+ 上截取的真实 Android 界面，显示的是 SciREPL Free 1.4.0-debug，而非 Play 商店安装版本。导入工作簿的截图则是单独在 Chromium 浏览器中以移动设备视口截取的 Free 1.4.0；它不能作为 Android 文件选择器导入的证明。两者均截取于 6 日（十月 2026 年）。其他版本、型号以及文件选择器的控件排列可能有所不同。示例选用的是英文 simpsons-paradox.srwb 文件，源自本指南审查时的 SciREPL Catalog 的 main 分支；该分支后续可能会更改。截图与来源详情 (英文参考页面)记录了确切的图片尺寸和审查时的文件哈希值。

步骤 1

将工作簿文件保存到您的设备

GitHub 的 main 分支可能包含尚未出现在“浏览”所显示的最新稳定目录版本中的工作簿或更新。目录版本的更新独立于应用程序版本。直接导入文件可让您尝试受信任的工作簿，而无需等待其出现在“浏览”中。

  1. 在 GitHub 上查看 Simpson's Paradox，然后下载实际的工作簿文件 (.srwb)。第二个链接打开的是原始文件，而不是 GitHub 网页。
  2. 如果您的浏览器将该文件显示为文本而非直接下载，请使用浏览器的保存/下载操作。请保存工作簿文件本身，而不是屏幕截图或 HTML 页面。
  3. 请保留文件名 simpsons-paradox.srwb 及其 .srwb 扩展名。注意文件的保存位置：Android 通常保存在 Downloads；在桌面设备上可能是“下载”文件夹或您选择的某个文件夹。

这并非固定发布版本的下载。 main 是开发分支：截取这些屏幕截图后，文件的内容和单元格可能会发生变化。您保存的文件是本地副本；后续 GitHub 的更改不会自动更新您已导入的标签页。

下载并不等于导入。 保存文件只是将其存放在您的设备上，尚未在 SciREPL 中打开工作簿。您不需要在文本编辑器中打开它，也不需要将其放入 SciREPL 的“文件”视图中。下一步将选择该已下载的文件。

如果您已经从他人处获得了受信任的 .srwb 文件，可以直接使用该文件并跳过示例下载。其工作簿标题和单元格数量将与步骤 3 中的检查项有所不同。

步骤 2

找到 Menu 并选择 Import File

  1. 返回 SciREPL。在应用程序顶部的标题行中，找到 ☰ Menu（即带有三条水平线的按钮），然后点按或点击它。
  2. 选择 📂 导入文件（如 .srwb、.ipynb、.csv、.py、.zip）。如果菜单高度超过屏幕，请在菜单内部滚动以找到它。
  1. 在 Android 上：系统文件选择器将打开。查看 Downloads，或浏览到您保存该文件的位置。选择 simpsons-paradox.srwb。该选择器属于 Android 系统，因此其布局以及最终的打开或选择控件取决于您的设备。
  2. 在桌面设备上：使用文件选择器找到您在下载时选择的文件夹。选择 simpsons-paradox.srwb 并确认选择。请使用此途径，而不是寻找 Android 的 Downloads 界面。
  3. 返回 SciREPL，等待导入完成。如果菜单仍处于打开状态，请将其关闭以查看工作簿。

工作簿并非数据文件上传。导入 .srwb 文件会将其工作簿作为一个独立的标签页添加；如果文件包含多个工作簿，则添加为多个独立标签页。您现有的标签页都会保留。它不会将工作簿放入“文件”视图，也不会替换您当前的工作簿。

步骤 3

在运行任何内容前检查新工作簿

  1. 在工作簿选择器中寻找 Simpson's Paradox。如果尚未选中该新标签页，请将其选中。其简介标题为 Simpson's Paradox: When Every Group Disagrees with the Total。
  2. 阅读简介并滚动浏览各单元格。截取这些截图时审查的版本包含七个单元格：三个文本单元格、三个 R 单元格和一个 JavaScript 单元格。main 上的后续版本可能会有所不同。
  3. 依次找到名为 data、compute 和 viz 的 R 单元格。JavaScript 单元格名为 js_check，是一个独立的可选检查项。请同时阅读说明文本与代码。

对于 .srwb，导入并不意味着运行。 SciREPL 在导入 .srwb 文件时不会执行代码，即使已为其他导入启用了自动执行。在选择 运行 或 运行所有单元格 之前，请先检查来自不熟悉或不可信来源的代码。

普通 .srwb 导入目前会丢弃已保存的代码单元格输出，即使文件中包含这些输出也是如此。Markdown 文本会被保留并渲染，这就是简介能立即显示的原因。若要重新生成图表或其他由代码生成的图像，请按顺序重新运行相关的代码单元格及其依赖单元格。导入操作不会恢复活动的 R 或其他运行时变量。

步骤 4

可选：运行已导入的课程

您的手动导入已完成；运行代码是一个单独的步骤。Simpson's Paradox 使用教学用合成数据来展示组内比较如何与整体比较产生分歧。若要探索该课程，请点按已保存代码单元格的 ✎ 铅笔图标，检查代码，然后使用该单元格的 运行 按钮。

  1. 运行 R 单元格 data，然后阅读文本单元格 pause 并在运行 compute 之前作出预测。接着运行 viz 以生成图表。后面的 R 单元格依赖于前面的单元格。它们使用的是基础 R；您不需要安装额外的 R 包。
  2. 如果您想进行单独的 JavaScript 检查，请运行 js_check。它是独立的：既不依赖于 R 单元格，也不需要启动 R。

首次运行 R： SciREPL 的 webR 运行时可能需要下载并初始化。可能会出现网络/隐私提示；请仔细阅读，仅在您希望继续时同意。等待运行时就绪并检查单元格是否有错误。仅导入工作簿并不会加载其 R 定义。

有关包含更完整运行与编辑演练的另一个示例，请参见马尔可夫组课程。那是另一个不同的工作簿，包含四个 Python 单元格；其导出步骤还演示了如何保存已编辑的工作簿副本。

保留一份由您控制的副本。 下载的文件是原始工作簿副本，而不是后续编辑的备份。导出工作簿副本以保存您的更改。清除应用或浏览器存储可能会移除本地工作内容，并且 Android 和浏览器会话不会自动共享您的更改。

其他格式与安全性

了解您的文件所包含的内容

Jupyter 笔记本 (.ipynb) 也使用 菜单 → Import File，但它们的执行行为与 .srwb 不同。如果启用了 导入工作簿时自动执行单元格，导入 .ipynb 时可能会自动运行没有已保存输出的代码单元格。

仅从您信任的来源导入笔记本文件。 在导入 .ipynb 之前，打开 菜单 → 设置 → 导入与编辑 并确保 导入工作簿时自动执行单元格 处于关闭状态（未勾选）。该选项默认处于关闭状态，但请检查您当前的设置。将其关闭并不能保证任意笔记本都是安全的；在明确决定是否运行之前，请务必检查受信任笔记本的代码。

独立数据文件： 普通的 .srwb 导出不包含独立的 CSV 文件或存储在 SciREPL 虚拟文件系统（Files 视图）中的其他数据。此版本的 Simpson's Paradox 在代码中创建其合成数据，因此不需要单独的数据文件。对于读取 CSV 的工作簿，请遵循 CSV 操作指南的“打包归档导出”和重新打开步骤，以同时携带并恢复工作簿及其数据。软件包归档和 .zip 导入不在本篇简短的工作簿文件课程范围之内。

如果出现异常

检查文件和选中的标签页

  • 选择器找不到文件： 检查浏览器的下载列表以查看文件的保存位置，然后浏览到该文件夹。在桌面设备上下载并不会将文件保存到手机的 Downloads 文件夹中。
  • 文件名以 .txt 或 .html 结尾： 返回工作簿下载链接，并保存带有 .srwb 扩展名的实际文件。将 HTML 页面重命名为 .srwb 并不能将其变为工作簿。
  • 仍显示旧的工作簿： 关闭菜单并在工作簿选择器中查找新标题。现有标签页均会被保留。
  • 导入了两次： 再次导入会添加另一份副本；它不会更新或替换先前的标签页。在进行更改之前，请确认您正在编辑的是哪一份副本。
  • 标题或单元格不匹配： 请检查您选择的是否为 simpsons-paradox.srwb，而非其他下载文件或来自其他课程的文件。main 上的文件可能会发生更改；请将您的副本与当前的 GitHub 文件进行对比，并在运行前检查不熟悉的代码。

有关工作簿标签页和已保存单元格编辑的基础知识，请参见首个工作簿界面演练。工作簿参考 (英文参考页面)解释了工作簿结构和单元格类型。
