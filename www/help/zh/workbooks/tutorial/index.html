边做边学

从目录中探索工作簿

找到现有的 Markov Groups: A Random Walk on Cube Moves 工作簿，运行其四个 Python 单元格，缩短其随机游走，并保存您自己的副本。重点在于使用 SciREPL；您不需要了解矩阵代数或会还原魔方。

想学习如何使用此应用？ 请按照步骤 1–5 操作：查找、打开、运行、编辑并导出工作簿。您可以在步骤 5 之后停止。选读的数学内容在后面；完成本操作指南并不需要它。

  • Free + Pro
  • Android 步骤
  • 约 15 分钟

开始之前

找到菜单

在 SciREPL 的应用顶部标题行中寻找 ☰ Menu 按钮。它的图标是三条水平横线，在下方以黄色高亮显示。点击它可打开该应用的菜单；步骤 1 会说明应选择哪个菜单项。

步骤 1

浏览、筛选和搜索

  1. 打开 菜单 → 浏览软件包、合辑与工作簿。在 Free 中，可选的 📦 标题快捷方式在可见时也会打开相同的屏幕。外观操作指南介绍了如何启用它。
  2. 浏览列表或使用其筛选器。对于此英文示例，请选择 English（在 自然语言 下），以及 Python（在 内核 下）。所有自然语言 与内核的 全部 选项同样有效，但会显示更多条目。
  1. 在搜索字段中键入 Markov Groups。在 工作簿 下找到 Markov Groups: A Random Walk on Cube Moves。安装前请核对完整标题：这是一个工作簿模板，而不是要添加到 Python 的软件包。
  2. 如果键盘遮挡了结果，请使用其隐藏键盘按钮或按一次 Android 上一步 将其关闭。保持“浏览”处于打开状态，并滚动到匹配的工作簿。

还有哪些可用内容？ 在 GitHub 上浏览工作簿列表（English）。同一课程的不同语言版本是单独的条目，而不是不同的课程。

GitHub 链接显示最新的开发内容。SciREPL 通常使用最新的稳定目录版本，因此在 GitHub 上显示的一些工作簿可能尚未出现在“浏览”中。在 SciREPL 中，清除搜索并尝试 CSV、Prolog、Lua 或 statistics；在探索其他语言时，请在内核下选择 全部。

如果出现隐私提示：获取或刷新远程目录需要网络连接。请阅读告知内容，在对话框内滚动到底部，仅在您同意的情况下点击我已了解。关闭提示将阻止网络刷新；内置条目和之前缓存的目录条目可能仍会显示。请参阅隐私和本地数据 (英文参考页面)。

没有匹配的工作簿？请检查语言和内核筛选器，然后使用目录的 刷新 控件。较旧版本的应用可能没有相同的目录控件。或者，将固定的 v0.4.0 工作簿文件保存到您的设备，然后选择 菜单 → 导入文件 并选择 markov-groups.srwb。如果您的浏览器将该文件显示为文本，请使用其保存/下载操作并保留 .srwb 扩展名。手动工作簿导入操作指南展示了使用来自 GitHub 的 main 分支中的辛普森悖论（Simpson's Paradox）的操作步骤；选择上面的马尔可夫文件即可继续本课。

步骤 2

打开工作簿并检查其单元格

  1. 点击工作簿卡片上的 安装。如果按钮已显示为 已安装，请退出“浏览”菜单，改从工作簿选择器中选择现有的工作簿。
  2. 工作簿通常会成为当前选中的标签页。如果“浏览”菜单仍处于打开状态，请将其退出。如果自动切换已关闭，请选择 Markov Groups: A Random Walk on Cube Moves ，从 工作簿选择器 旁边，位于 SciREPL 标题行中。
  3. 阅读开篇文本，然后浏览各个单元格。Markdown 单元格用于解释课程；Python 单元格包含您将要运行的代码。每个 Python 单元格都有一个名称以帮助您找到它。

“安装”并不代表“运行”。安装此远程目录工作簿会添加其单元格，但不会执行其 Python 代码。v0.4.0 模板没有保存的 Python 输出，因此请检查代码并自行运行。不需要 AI 账号、API 密钥、外部数据集或安装额外软件包；代码使用 NumPy 以及 SciREPL 的 Python 运行时。

步骤 3

按顺序运行这四个 Python 单元格

对于已保存的单元格，点击该单元格标题中的 ✎ 铅笔，然后点击该单元格自带的 运行。这会执行现有的单元格；底部的新建单元格面板则用于创建不同的单元格。

Pro 快捷方式： 双击已保存的代码以打开其编辑器，然后点击该单元格自带的 运行。Free 在本操作指南中使用 ✎ 铅笔 图标。

这些名称是什么意思？cube_moves 和 check_moves 是显示在单元格上的名称，而不是要键入的命令。找到匹配的名称，然后使用该单元格的铅笔和“运行”。命名单元格与跨语言路径教程展示了如何分配名称并将其用作诸如 /nb/cube_moves/.code 的引用。

  1. 运行 cube_moves。它定义了转动和辅助函数。预期输出 Built six clockwise quarter-turn matrices with fixed face centres.
  2. 运行 check_moves。它会检查没有贴纸丢失、中心块保持固定，并且每个四分之一转重复四次后回到初始状态。在六行通过的检查之后，预期输出 All six moves passed. U and R do not commute.
  1. 运行 show_turn。它会打印 U 层转动循环以及转动前后的贴纸标签。前顶行从 [19, 20, 21] 变为 [46, 47, 48]。对比 U then R equals R then U: False 表明转动顺序至关重要。

部分打印输出：

U cycles, shown as one-based sticker positions:
1 -> 3 -> 9 -> 7 -> 1
2 -> 6 -> 8 -> 4 -> 2
19 -> 37 -> 28 -> 46 -> 19
20 -> 38 -> 29 -> 47 -> 20
21 -> 39 -> 30 -> 48 -> 21

F top row labels before U: [19, 20, 21]
F top row labels after U:  [46, 47, 48]

U then R equals R then U: False

此处省略了长面的字母列表。循环行使用从一开始的位置；行对比显示贴纸标签。尽管复原状态下的魔方最初赋予它们匹配的编号，但它们的含义不同。

  1. 运行 random_walk。它会打印单贴纸概率总和 1.0、一条 12 步的采样路径、最终的面字母标签，以及一条确认每个贴纸标签和所有六个中心块均得以保留的消息。

这些 Python 单元格已按所需顺序排列。请勿重新排序：后面的单元格会重用来自 cube_moves 的定义。如需一次运行多个单元格，请参阅“运行下方全部”与“运行所有单元格”。

首次运行较慢？Python 可能需要时间进行初始化，且运行时下载或网络回退可能需要您的同意。等待状态徽标恢复为 就绪 并检查单元格的输出是否有错误。如果重启后后面的单元格报告未定义的名称，请从头开始运行 Python 单元格；已保存的输出并不等同于活动的 Python 定义。

此工作簿打印文本和面字母列表。它不会绘制魔方或制作魔方动画，并且其带种子的短路径并不是均匀混合打乱的证据。

步骤 4

缩短游走并重新运行已保存的单元格

  1. 找到 random_walk 并点击其 ✎ 铅笔。
  2. 找到这一行并仅将 size=12 更改为 size=6: 
    moves = rng.choice(MOVE_OPTIONS, size=12).tolist()

    保持 np.random.default_rng(7) 不变。随机种子使此示例具有可重现性。

  3. 点击该已保存单元格编辑器中的 运行 按钮。输出已刷新；Sampled moves: 行现在包含六个选项而不是十二个。即使 I 让魔方保持不动，它也算作一个选项。

对于本次更改，在较早的定义已加载的情况下，只需重新运行 random_walk。如果您改为编辑 cube_moves，则也需要重新运行后面的 Python 单元格。输出记录的是其上一次执行的结果；当另一个单元格发生变化时，它们不会自动重新计算。

如果您误打开了编辑器，请选择 取消。要恢复到原始示例，请将 size=6 改回 size=12 并再次运行该单元格。

步骤 5

导出您自己的工作簿副本

  1. 保持选中马尔可夫群工作簿，然后打开 菜单 → 导出工作簿与软件包，而不是“导出文档”。
  2. 选择 工作簿 (.srwb) 和 仅当前标签页。
  3. 点击 导出 并将副本保存到您控制的位置。Android 会打开共享/保存流程；浏览器会下载文件。请保留 .srwb 扩展名。

该工作簿不需要单独的数据文件，因此对于本课而言，一份 .srwb 副本就足够了。您可以使用 菜单 → 导入文件 重新打开它；启动新的运行时时，请从头开始运行其 Python 单元格。

本地恢复并非备份。清除应用/网站存储空间或卸载应用可能会移除本地工作成果。Android 和浏览器会话不会自动共享您的编辑内容。“导出”不会将您的更改发布到目录中；它会为您提供一份独立的副本。

有关已保存单元格编辑的基础知识，请参阅首个工作簿界面操作指南。有关读取并携带单独数据文件的示例，请尝试 CSV 工作簿操作指南。工作簿参考 (英文参考页面)涵盖了单元格类型和持久单元格名称。

运行下方全部与运行所有单元格

  • 运行下方全部：使用已保存单元格的 ✎ 铅笔 打开它，然后选择 运行下方所有单元格（紧凑图标为 ▶↓）。它会按顺序运行该单元格以及其下方的每个单元格。
  • 菜单 → 运行所有单元格：从第一个单元格到最后一个单元格运行选定的工作簿。它不是运行每个工作簿标签页的命令。

批量运行期间，请先检查代码并保持选中此工作簿。在全新的 Python 会话之后，请从 cube_moves 开始，以便后面的单元格具有其定义。这些操作会执行代码；将某个解释称为“选读”并不会让应用跳过其代码单元格。

您已完成 SciREPL 操作指南。您已经找到、打开、运行、编辑并导出了工作簿。如果您只是想学习如何使用该应用，可以在此停止。如果您想探索魔方数学和开发工作簿，请继续阅读下方内容。

魔方示例背后的数学原理

输出背后的深层含义

该工作簿追踪 54 个单独标记的贴纸，而不仅仅是六种颜色。合法的转动会重新排列这些标签。同一个四分之一转重复四次会回到初始排列，但是当转动不同面的顺序发生改变时，可能会产生不同的结果。

随机游走在 13 个选项中进行选择：保持静止（I）、六个四分之一转以及它们的六个逆转动。其 54×54 概率矩阵描述的是单个贴纸的位置，而不是魔方的每个完整配置。概率总和为 1.0 意味着该贴纸的位置概率之和为一；这并不能证明魔方已被均匀打乱。

想了解面的方向吗？工作簿的 coordinates 单元格给出了全局坐标轴以及每个面的向右、向上和向外法向量。图片、图表与公式教程展示了如何将这类解释放入工作簿中。坐标图正在添加到目录的开发副本中；上面固定的 v0.4.0 副本不包含它们。

选读：预览修订后的阶段 4

上面的步骤和手机截图使用的是稳定的 v0.4.0 工作簿。修订后的工作簿下载是一个开发预览版，尚不是稳定目录版本。如果您想尝试其更简短的、交错排列的说明与代码单元格，请使用 菜单 → 导入文件 将其导入。

在该预览版中，如上文所述首先运行 cube_moves、check_moves 和 show_turn。然后：

  1. 运行 transition_matrix。它会构建 T，即在均匀随机选择一个选项（I、某个面的四分之一转或其逆转动）后单个贴纸位置的概率矩阵。
  2. 运行 sticker_step。它跟踪贴纸标签 1，其初始位置为从零开始的位置 0。其位置概率总和为 1.0。下方的图表显示了该单元格计算出的目标位置概率。
目标位置概率
07/13 ≈ 53.85%
2、6、18、35、42、47（各）1/13 ≈ 7.69%
所有其他 47 个位置0
  1. 运行 random_walk。它采样一条包含 12 个选项的路径，该路径针对整个魔方，并使用来自 transition_matrix 的定义。这与上述单个贴纸的概率不同。步骤 4 的 size=12 编辑在任一版本中的该单元格内均可正常工作。
