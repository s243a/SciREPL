定制属于您的专属界面

显示“浏览”并调整“外观”

将 📦 浏览 快捷方式放置在 SciREPL Free 的顶栏中，然后选择舒适的按钮以及浅色或深色主题。通用的外观控件在 Pro 中也很有用；另外专门针对 Pro 的独立章节介绍了全屏编辑、额外按键和实时语法颜色。您无需更改或运行任何工作簿单元格即可完成此操作。

所有教程

步骤 1

打开“菜单”→“外观”

  1. 找到应用顶部顶栏中的三条横线按钮 ☰ 菜单。
  2. 点按它，然后选择 🎨 外观。如果菜单高度超过屏幕，可在其内部滚动以找到该条目。

更改会在您选择时立即生效。 下方的常规控件无需“保存”或“应用”按钮。通过 × 关闭“外观”不会取消您的更改，并且您的选择会在下次访问应用时保留。

步骤 2

Free 1.4.0：显示 📦“浏览”快捷方式

使用的是 Pro？ 请跳过此快捷方式设置，改用 菜单 → 浏览软件包、合辑与工作簿。接下来的几节将介绍通用的外观控件。

  1. 打开 菜单 → 外观，然后滚动至 页眉快捷方式。
  2. 找到 显示浏览快捷方式 并选择 始终显示。
  3. 使用 × 关闭“外观”。此时顶栏中会出现 📦 按钮；点按它即可打开 浏览软件包、合辑与工作簿。

这些选项各有不同用途：

  • 始终：保持快捷方式可见，即使顶栏需要增加一行。
  • 有空间时：“浏览”的默认设置。仅在空间合适时显示；屏幕较窄、按钮较大或状态消息较长都可能导致其消失。
  • 从不：隐藏顶栏快捷方式。

↑ 和 ↓ 按钮用于更改当空间紧张时哪个可选快捷方式优先让出位置。将快捷方式上移可使其保持显示更久，下移则让其更早消失。它们改变的是优先级，而非图标在顶栏中的显示位置。

没有 📦 按钮？ 当快捷方式被隐藏或您的版本未提供该功能时，“菜单”途径仍然有效。若想保持顶栏紧凑，请将“浏览”恢复为 空间足够时，而不要强行让每个可选快捷方式都保持可见。

如果您来到这里是为了查找工作簿，现在可以返回马尔可夫群演练并搜索该目录。

步骤 3

选择舒适的按钮与“运行”标签

重新打开 菜单 → 外观 并找到 按钮。移动 按钮大小 滑块；其百分比和旁边的 预览 会立即变化。默认值为 100%。较大的顶栏按钮可能更容易点按，但会给可选快捷方式留下更少的空间。

运行按钮 下拉菜单控制的是新建单元格面板中的“运行”，而不是已保存单元格编辑器内部的“运行”按钮：

  • 自动（空间紧张时仅显示图标）：默认设置。空间合适时保留标签，或者仅使用 ▶ 图标以为键入腾出空间。
  • 仅图标：始终使用紧凑的 ▶ 按钮。
  • 始终显示标签：即使在窄屏上也保留文字。

“外观”中没有文本缩放滑块。按钮大小 不是通用的字号设置。Free 1.4.0 和 Pro 1.3.0 会自动放大紧凑的顶栏控件，以适应 Android 的系统文本缩放。

可选 · 仅限 Pro

仅限 Pro：全屏编辑、额外按键和语法颜色

这些是 SciREPL Pro 1.4.0 编辑器控件，而非上方 Free 屏幕截图中展示的控件。额外按键和实时颜色是独立的设置。

进入全屏编辑

  1. 新建单元格：点按新建单元格代码字段中的 ⤢ 全屏 按钮。其向外的对角箭头表示展开编辑器。
  2. 已保存单元格：点按该单元格的 ✎ 铅笔 进行编辑，然后点按该单元格代码字段角落的 ⤢。

编辑器将占据整个屏幕，以便容纳更多代码。已启用的额外按键和建议条在键盘上方仍然可用；语法颜色使用下文所述的相同设置。进入全屏不会运行代码。

点按顶部的编辑器标签即可返回工作簿并保留草稿打开状态；上一步 或 Esc 也能退出全屏模式。对于已保存的单元格，完成 会应用草稿而不运行它，而 取消 则会放弃本次编辑。对于新建单元格，“完成”和“取消”都会退出全屏，既不清除草稿也不创建单元格；“运行”是一项独立操作。

与“面板使用全屏”不同。“外观”中的该独立选项控制的是面板和对话框的上边距；它不会打开全屏代码编辑器。

显示额外按键行

打开 菜单 → 补全 → 分区： → 通用。设置 键盘上方的附加按键： → 开启；默认值为 关闭。该行提供 Esc、Tab、取消缩进、箭头、Home、End、运行以及标点符号。向侧方滑动可访问未完全显示出来的按键。选择“开启”并不会运行代码，但该行中的 ▶ 运行 键会运行——在点按它之前请检查源代码。

在同一部分中，竖屏中的候选项： 和 横屏中的候选项： 可选择 独立一行 或 替换附加按键。默认设置为竖屏时“独立行”，横屏时“替换额外按键”：当候选词出现时，它们可以暂时取代按键的位置。关闭额外按键后，建议条将使用独立行。横屏附加工具行： 提供 关闭、空间足够时（默认）或 始终显示。“有空间时”会使用 最少可见代码行数：（初始为 8），因此较矮的横屏视图可以隐藏可选行。

开启或关闭实时语法颜色

打开 菜单 → 外观 → 输入时语法着色。选择 开启 可在编辑时为支持的代码着色，选择 关闭 则显示为纯文本。默认设置 自动（桌面端开启，触控端关闭） 会在桌面浏览器中启用颜色，而在手机上保持关闭。如果键入时感觉不够流畅，请选择“关闭”；在性能较低的设备上着色会影响键入速度。超过 6000 个字符的代码即使在“开启”状态下也不会着色。

着色不会验证或执行代码，不会发送 API 请求，也不会开启补全功能。更改此设置会立即生效，并且不会更改您的源代码。

“文件与存储”包含单独的开关

对于文本文件，请使用 菜单 → 文件与存储 (VFS / Paths)，选择该文件，然后选择 全屏。该编辑器的 语法高亮 复选框独立于“外观”的实时颜色设置，且默认处于关闭状态。它不适用于无法识别的文件类型或超过 100,000 个字符的文件。其额外按键共用“补全”偏好设置，但在文件编辑器空间不足时可能会隐藏。文件 保存 会写入您的编辑；仅切换颜色则不会。

步骤 4

选择浅色、深色或系统主题

滚动到 主题 并选择 深色、浅色 或 跟随系统。深色为默认选项。“跟随系统”会遵循您设备上的浅色/深色偏好；这是由您做出的选择，并非默认项。

在本课中，您不需要 自定义、自定义…、主题 JSON 编辑器或 高级：自定义 CSS。这些高级选项不属于本新手演练的范围。

可选的收尾调整

Android 空间与恢复默认设置

在 布局 下，保持选中 顶部边距 → 自动。它会遵循设备报告的安全区域，使顶栏上方留有适当的空间；您无需猜测像素值。

在 Android 应用中，隐藏 Android 状态栏 提供：

  • 从不：默认设置；保持时钟和通知状态栏可见。
  • 横屏时：手机处于横屏状态时隐藏该栏；竖屏时恢复显示。
  • 始终：在两种屏幕方向下均予以隐藏。

此设置仅影响 Android 状态栏，不影响导航栏或手势栏。该设置在浏览器/PWA 以及 Windows 界面中不存在。Pro 1.3.0 则代之以一个名为 横屏时隐藏 Android 状态栏 的复选框。

想要撤销外观更改？ 恢复默认设置 可恢复默认主题、顶栏按钮大小、上边距、快捷方式以及状态栏偏好设置，并移除自定义主题/CSS 选项。它不会清除您的工作簿单元格。它不会重置独立的“运行”按钮或界面语言偏好设置；如有需要，请自行选择“运行”的 自动 选项。
