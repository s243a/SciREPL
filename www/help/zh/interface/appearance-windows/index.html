Windows 桌面应用

Windows 上的外观：有何不同

Windows 应用（包括 Microsoft Store 版本）与 Android 一样有 ☰ 菜单 → 🎨 外观。主题、界面语言、按钮大小和 📦 Browse 快捷方式的用法与外观演练中所述相同。本页只介绍桌面窗口新增的内容。

  • Free
  • Windows 桌面应用
  • 约 2 分钟

笔记本宽度

在宽度至少为 1000 像素的窗口中，笔记本单元格最宽可达 1200 像素。这个 宽 设置是默认值。如需更改，请打开 ☰ 菜单 → 🎨 外观，在 布局 下选择 笔记本宽度：

  • 标准：以前的 720 像素列。
  • 宽：最宽 1200 像素（默认）。
  • 整个窗口：单元格使用窗口的全部宽度。

较窄的窗口无论如何选择，始终使用标准列宽。

缩放

缩放会放大或缩小窗口内的页面：

  • 放大：Ctrl+= 或 Ctrl+Shift+=（Ctrl 加上加号键）。
  • 缩小：Ctrl+-。恢复到 100%：Ctrl+0。
  • 按住 Ctrl 并转动鼠标滚轮，或在触控板上双指捏合。
  • 在窗口的菜单栏中：视图 → 放大、缩小 或 实际大小。

Windows 显示缩放还是应用缩放？

Windows 显示设置（设置 → 系统 → 屏幕）中的缩放会放大屏幕上的所有内容，包括 SciREPL 的标题栏、菜单栏和对话框。应用缩放只放大窗口内的页面。Windows 没有只针对单个应用的缩放设置，因此如果只想让 SciREPL 变大或变小，请使用应用缩放。

两者都会改变页面所感知的窗口大小。例如，在 150% 缩放下，宽 1920 像素的屏幕对 SciREPL 来说只有 1280 像素宽。上文的 1000 像素宽度和下文的 500 像素高度都是在缩放之后计算的。

隐藏新建单元格面板

当窗口宽度大于高度且页面高度不超过 500 像素时，底部的新建单元格面板中会出现一个 ⌄ 按钮（隐藏新建单元格面板）。在 150–200% 缩放下，普通的笔记本电脑窗口也可能这么矮；放大页面也有同样的效果。点击 ⌄，笔记本即可使用全部高度。

面板隐藏期间，左上角的 Sci REPL 标题会被一个小的 ⌃ 按钮（显示新建单元格面板）取代。点击它即可恢复面板。把窗口拉高（例如最大化）也会让面板恢复。

窗口的菜单栏

Windows 窗口在应用上方有自己的菜单栏：文件、编辑、视图、运行环境 和 帮助，以您的界面语言显示。按 Alt 可用键盘进入菜单栏。运行环境 包含：

  • 已下载的运行环境…：显示已下载的 Lua 和 R 运行环境占用多少空间，以及存放位置。
  • 清除已下载的运行环境…：确认后删除它们；您的笔记本和文件不受影响。已加载的运行环境在重新启动前仍可使用。之后，R 和 Lua 会在下载前再次询问，下载需要联网。
  • 打开应用程序数据文件夹：在文件资源管理器中打开 SciREPL 的数据文件夹。

Android 没有窗口菜单栏。在 Android 上，请使用 ☰ 菜单 → 📊 内存与存储 查看和清理存储空间。在 Windows 上，该面板看不到已下载的运行环境，因此请使用 运行环境 菜单管理它们。
