边做边学

创建你的第一个工作簿

这是 界面参考 (英文参考页面) 篇幅较长且注重实践的配套内容。你将运行一个 Python 单元格，对其进行修改，并保存一份由你控制的副本。无需 AI 账号或 API 密钥。

  • Free + Pro
  • Android 步骤
  • 约 5 分钟

屏幕截图显示了 SciREPL Free v1.3.2 在 Samsung Galaxy S24 系列手机上的界面。本课内容同样适用于 Pro，不过其中的部分控件外观可能有所不同。

本课内容
  1. 找到你的位置
  2. 编写并运行单元格
  3. 编辑已保存的单元格
  4. 导出工作簿副本
  5. 后续尝试内容

所有教程

步骤 1

在应用中找到你的位置

顶部一行是顶栏。它包含菜单、帮助和状态徽标。工作簿选择器用于选择打开哪个工作簿。

新建单元格面板是输入下一个单元格的地方。当屏幕变窄时，可选的标题按钮可能会消失；在适用的情况下，它们的操作仍可从“菜单”或“帮助”中获取。

步骤 2

编写并运行 Python 单元格

在首次运行前，请等待状态徽标显示为 就绪。

  1. 在新建单元格面板中，从语言选择器中选择 Python。在较窄的手机屏幕上，闭合的选择器可能仅显示 Py。
  2. 输入这段简短的程序： 
    print("Hello from SciREPL")
  3. 轻点 运行。工作簿中会出现一个已保存的单元格。在其下方，你应该会看到 Hello from SciREPL。

首次运行可能需要更长时间。 Python 的运行时必须启动一次。请等待状态恢复为 就绪；后续的 Python 单元格通常会复用该运行时。

如果出现隐私声明： Python 通常是内置捆绑的，因此本示例应该不需要下载运行时。网络运行时（例如 R 或 Lua 在 Free 中）可能会先显示 SciREPL 的隐私政策；如果 Python 的内置副本需要网络回退，也可能会如此。请阅读该政策，在对话框内部滚动到底部，并在同意时轻点我已了解。随后可能会出现一个单独的运行时下载提示，要求你轻点 下载。

查看隐私政策对话框示例 (英文参考页面)（屏幕截图显示的是其顶部；按钮在更下方）。在 Free 1.4.0 与 Pro 1.4.0 中，如果你尚未接受当前的网络披露说明，一条有效的 %pip install 命令在尝试安装软件包之前也会打开此声明。在使用网络功能之前，请参阅隐私和本地数据 (英文参考页面)。

步骤 3

编辑已保存的单元格

  1. 轻点已保存单元格自身标题栏中的铅笔图标 ✎，它位于右上角 ✕ 的左侧。这会打开该单元格以供编辑；在新建单元格面板中输入则会创建另一个单元格。
  2. 将 Hello from SciREPL 改为 Hello again。
  3. 选择 运行 以保存并运行更改。现在你应该可以在该单元格下方看到 Hello again。

Pro 快捷方式： 在触摸屏上，双击已保存单元格的代码即可进行编辑。Free 目前使用 ✎ 按钮。

如果你误打开了编辑器，可以使用 取消 将其关闭而不运行。已保存单元格内部的语言选择器会更改该单元格；新建单元格选择器则不会。

步骤 4

导出工作簿副本

  1. 打开 菜单 → 导出工作簿与软件包。
  2. 选择 仅当前标签页 或 所有标签页，然后选择 SciREPL 格式 工作簿 (.srwb)，如果你想要保留特定于 SciREPL 的状态。
  3. 轻点 导出 并选择一个由你控制的目标位置。

为什么要导出？ SciREPL 会恢复本地会话，但本地存储并不是备份，且不会在 Android 应用与浏览器之间自动共享。请参阅文件与导出 (英文参考页面)以了解其他格式，包括 .ipynb 和 PDF。

步骤 5

后续尝试内容

尝试将 2 + 2 用于另一个 Python 单元格。然后使用工作簿选择器切换标签页。CSV 工作簿演练从 菜单 → 浏览软件包、合辑与工作簿 开始，会安装一个示例，并展示其单元格如何配合本地文件工作。

马尔可夫群演练展示了如何搜索更广泛的目录、打开一个关于魔方转动的现有工作簿、按顺序运行其单元格并更改一个参数。

若要快速回顾控件的位置，请返回界面参考 (英文参考页面)。若要学习另一种语言或添加软件包，请继续阅读语言与软件包 (英文参考页面)。
