边做边学

在工作簿中探索 CSV

从 浏览软件包、合辑与工作簿 开始。安装一个小型示例，运行其单元格，编辑其 CSV，然后导出并重新打开带有其数据的工作簿。数据纯属虚构，Python 代码不需要额外的包或 AI 账户。

  • Free + Pro
  • Android 操作步骤
  • 约 15 分钟

屏幕截图截取自三星 Galaxy S24 系列手机。“浏览”和初始输出的图片展示的是 Free；新的文件编辑器和数据包选择图片展示的是 Pro 1.4.0，并在下方标注。在 Pro 中，您可以使用直接下载工作簿和“导入文件”路径；周围的控件可能会有所不同，并且此新的“浏览”条目可能不会出现在那里。

还没有在“浏览”中看到此工作簿？ 该示例内置于 Free 1.4.0 及更高版本中；较旧的已安装应用或缓存的 PWA 可能不会列出它。直接下载工作簿，然后使用 菜单 → 导入文件 打开它。您现在即可继续阅读本课的后续内容。

所有教程

步骤 1

在“浏览”中找到工作簿

  1. 打开 菜单 → 浏览软件包、合辑与工作簿。如果可见，可选的 📦 顶部快捷方式也会打开相同的屏幕。
  2. 搜索 CSV Basics。在 工作簿 下，找到 CSV Basics: Seedling Heights。这是一个内置的英文示例，而不是需要安装到 Python 中的包。
  3. 点按 安装。工作簿通常会成为当前选中的标签页。如果您关闭了自动切换功能，请使用工作簿选择器来选择它。

如果出现隐私权政策：“浏览”可能会在线检查已验证的目录。阅读披露信息，在对话框内部滚动到底部，仅在您同意时点按我已了解。您也可以关闭该通知并继续使用内置条目；此时远程目录将不可用。此示例本身不需要外部数据集或 Python 包。

安装工作簿会添加其单元格；它不会运行这些单元格。这样可以让您在执行代码之前对其进行检查。

步骤 2

按顺序运行单元格

开头的文本对示例进行了说明。这三个 Python 单元格分别有一个名称：create_csv、read_csv 和 compare_groups。对于已保存的单元格，点按其 ✎ 铅笔打开编辑器，然后点按该单元格的 运行。在 Pro 中，您也可以双击单元格的代码来编辑它。

  1. 运行 create_csv。它会将六行虚构数据写入 /shared/data/seedling-heights.csv。您应该会看到 Saved 6 fictional rows。
  2. 运行 read_csv。它会打开刚创建的文件并输出所有六行内容。
  3. 运行 compare_groups。它会输出光照平均值 13.0 cm、遮阴平均值 8.0 cm 以及差值 5.0 cm。

该文件也可以在 菜单 → 文件与存储 中看到。您可以在那里读取它，或者使用 编辑 和 保存 直接修改它。下一步将展示具体操作方法。

最终输出应该如下所示：

Light mean: 13.0 cm
Shade mean: 8.0 cm
Difference: 5.0 cm

首次运行较慢？ Python 初始化可能需要稍等片刻。在判断单元格是否执行完毕之前，请等待状态徽标显示为 就绪。后续单元格通常会复用已加载的运行时。如果运行时下载需要许可，请在接受之前阅读隐私声明；此工作簿不会调用 %pip install。

这些编造的数值仅用于演示数据读取和计算，并不代表关于光照与植物生长的科学结论。

步骤 3

更改一个数值并重新运行

您无需编辑 Python 单元格来更改其数据。直接打开 CSV 本身：

  1. 选择 菜单 → 文件与存储（菜单可能会在该名称中附加 VFS / Paths）。
  2. 选择 / (持久存储) 或 所有文件系统。滚动至 /shared/data/seedling-heights.csv 并点按文件名，而不是其下载或移除图标。
  3. 点按 编辑。将数据行 light,14 改为 light,15。保持表头 group,height_cm、逗号和其他数据行不变。
  4. 点按 保存，然后关闭“文件与存储”。保存文件不会运行任何代码。

仅重新运行 read_csv 和 compare_groups。光照平均值现在约为 13.3 cm，差值约为 5.3 cm。切勿重新运行 create_csv：它会用该单元格中仍保留的数值覆盖您对文件的编辑。

或者，使用 create_csv 的 ✎ 铅笔对其进行编辑，将其测量值从 14 改为 15，然后按顺序运行全部三个 Python 单元格。这将更改生成文件的代码，而不仅仅是更改文件本身。

为什么要重新运行后面的单元格？它们保存的输出是先前执行的记录；更改文件不会自动重新计算早先的结果。每个单元格仅在您运行它时才会读取该文件。

Pro：全屏文件编辑与可选语法高亮

在文件预览中，点按 全屏 可打开更大的编辑器。CSV 仍保持为 纯文本，因此其 语法高亮 复选框处于停用状态。

对于受支持的代码文件，语法高亮是可选的，并且默认处于关闭状态。请使用此文件编辑器中的复选框将其开启，而不是通过笔记本的外观设置。扩展名决定了语言类型：例如 .py 对应 Python，.js 对应 JavaScript，.R 对应 R，而 .pl 对应 Prolog 而不是 Perl。未知扩展名仍将保持为纯文本。

保存 会写入文件并保持编辑器打开。使用 × 关闭 可返回“文件与存储”；在放弃未保存的更改之前系统会进行提示。编辑或保存文件绝不会执行该文件。

查看以纯文本形式打开 CSV 的同一全屏编辑器。

步骤 4

导入原始 CSV

  1. 将原始示例 CSV 下载 (英文参考页面)到您设备的文件选取器可以打开的文件夹中。
  2. 在 SciREPL 中，选择 菜单 → 导入文件 并选择 seedling-heights.csv。确认信息应显示已上传至 /shared/data/seedling-heights.csv。
  3. 这会用原始的六行内容替换已更改的本地文件。重新运行 read_csv 和 compare_groups；这两个平均值应恢复为 13.0 和 8.0 cm。

重要提示：在导入同名的不同文件后，除非您打算覆盖它，否则请勿重新运行 create_csv。对于您自己的 CSV，请注意确切的确认路径，并将读取单元格中的 path 更改为该文件名。文件选取器可能会显示 Android 下载内容、云存储服务提供商或两者兼有。

步骤 5

保存便携式副本

打开 菜单 → 导出工作簿与软件包。如果您只需要单元格，请选择 工作簿 (.srwb) 和 仅当前标签页。.srwb不包含 SharedVFS 中的独立 CSV。

要将工作簿连同其数据一起移动，请选择 软件包（归档） 并保留 .zip。在 内容 树中，选择：

  • 工作簿 CSV_Basics__Seedling_Heights.ipynb，位于 notebooks/ 下。数据包导出以 Jupyter notebook 格式存储单元格。
  • 文件 seedling-heights.csv，位于 shared/data/ 下。

取消勾选无关的工作簿和文件。如有需要，使用箭头展开文件夹；不要假定 仅当前标签页 会限制数据包的内容。本课不需要额外的 shared/notebooks/ 副本。在 Pro 中，除非您特意想要共享，否则请取消勾选 包含 AI 对话。

点按 导出。在 Android 上这会打开分享面板：请将归档保存到您可以再次找到的地方，例如您自己的云端硬盘或文件管理器的保存目标位置。在浏览器中它会下载一个文件。建议的文件名是 scirepl_package.zip；将其重命名为 seedling-project.zip 会更容易识别。

本地恢复不是备份。 Android 应用存储、Chrome 中的 PWA 以及其他浏览器不会自动共享这些文件。请将导出的副本保存在您自己控制的地方。有关其他格式，请参见文件、导入与导出 (英文参考页面)。

步骤 6

重新打开数据包并检查这两个部分

在信任备份之前，请先检查您是否能打开它。您可以在另一个 SciREPL 安装或浏览器个人资料中执行此操作。在此处导入会添加另一个工作簿；它还会替换数据包目标路径下的文件，因此在导入旧数据包之前，请为任何较新的文件单独保留一份副本。

  1. 选择 菜单 → 导入数据包 (.zip / .tar.gz) 并选择您保存的归档。在本课中，它是一个 .zip，而不是单独下载的 CSV 或 .srwb。
  2. 如果未自动选中，请选择新导入的 CSV Basics: Seedling Heights 工作簿。如果您导入到同一个应用中，旧标签页和新标签页的名称可能会相同。
  3. 打开 菜单 → 文件与存储 并检查 /shared/data/seedling-heights.csv。它的六行内容应与您导出的文件相匹配。检查完毕后关闭预览。
  4. 运行第二个 Python 单元格（read_csv 代码），然后运行第三个 Python 单元格（compare_groups 代码）。数据包导出使用 Jupyter 格式，可能不会保留单元格名称；请通过它们的顺序和代码来进行识别。在执行步骤 4 的原始 CSV 后，结果预计为 13.0 cm、8.0 cm 和 5.0 cm。如果您导出的是编辑后的 light,15 文件，结果预计为 13.3 cm、8.0 cm 和 5.3 cm。

进行此项恢复检查时切勿重新运行 create_csv。它会用其代码中的数值覆盖导入的数据。先读取恢复后的 CSV 可以证明数据随工作簿一同迁移；单凭旧的已保存输出无法证明这一点。

如果文件丢失或工作簿不存在，请返回步骤 5 并检查是否同时选中了两个条目。普通工作簿导出无法为您携带 CSV。

后续步骤

尝试创建您自己的 CSV。保留列 group 和 height_cm，使用数值型高度，并至少包含一行 light 和一行 shade——或者调整 compare_groups 中的两个分组筛选条件。您可以在 菜单 → 文件与存储 下检查本地文件。有关此处使用的手机端控件，请参见首个工作簿界面演练。
