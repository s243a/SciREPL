Which AI surface should I use?

SurfaceUse it forContext and tools
AI AssistantConversation, workbook building, debugging, and multi-step tool useSaved workbook or Global conversation; a bounded cell preview; tools allowed by your permissions
AI Prompt cellA short, repeatable, user-controlled transformation or explanationOne isolated request; only the prompt, reviewed target, and selected cell context; no tools
Full-screen AskAsk about the draft you are editingContext selected and reviewed for that request
Full-screen EditPropose a replacement that you explicitly applyContext selected and reviewed; no silent replacement
Full-screen AgentLet the Assistant use tools while working on the open draftProvider mode only; Remote is currently unavailable for this surface
RemoteTalk to a compatible external coding agent through your brokerBroker and agent receive data/tools allowed by your settings
AI output still needs review. Inspect generated code, assumptions, dependencies, and results. A successful model response is not proof that an analysis is correct.
