Direct AI provider

AI setup and workflows

  • Pro only
  • Android
  • Windows preview
  • Verified: Pro 1.3.0

Configure a provider

  1. Open Menu → AI Assistant (Pro), then select the gear.
  2. Under the AI Assistant scope, choose the provider, endpoint if applicable, model, and reasoning setting.
  3. Enter your own API key. Saving settings does not itself send a model request.
  4. Review the security preset and individual tool permissions before asking the Assistant to change a workbook.

New setup suggestions use OpenRouter and GLM 5.3 Flash because that is an inexpensive agent-capable starting point. Availability, prices, and provider terms can change; the model actually selected in your settings is authoritative.

Security levels and Review

The default Cautious preset allows reads and asks before writes or execution. Open is useful for deliberately building a workbook with fewer interruptions, but it allows notebook tools and kernels by default. Guarded asks more often; Paranoid denies by default; Full control is the broadest. Review is an additional read-mostly restriction.

Individual permissions override the preset where shown. “Default” means inherit from the selected security level. Kernel execution, source browsing, whole-workbook import/export, and actions outside the open full-screen draft have separate controls.

Review what is sent

Direct Assistant messages include a bounded preview of current cells. Approved tools can send complete cells, outputs, files, or an explicitly enabled workbook export. A review dialog shows optional context for AI Prompt and full-screen requests. Fixed system/runtime guidance may also frame a request; a future disclosure improvement is tracked for that text.

AI Prompt cells

An AI Prompt cell makes one isolated request. It does not include the Assistant conversation or use Assistant tools. Open Configure on the cell to choose:

  • This cell’s output (default)
  • a linked new result cell in a selected language
  • a replacement preview for this, the previous/next, a named, or a chosen cell
  • no other-cell context, previous 1/3/5 cells, a selected range, or the entire workbook
  • whether selected saved text output is included

Generated or replaced code receives brief language-specific runtime/package guidance. Generated code never runs automatically. Replacements require a separate Apply action and detect target changes.

Selected output means saved text, including text extracted from HTML/SVG. Images and raw rich-output markup are not automatically attached.

Full-screen Ask, Edit, and Agent

  • Ask answers a question about the open draft; you can copy or insert the reply.
  • Edit proposes a complete replacement; you decide whether to Apply it.
  • Agent hands the task to the Assistant and may use allowed tools. Draft edits can be undone to the run-start snapshot.

The gear chooses source, selection, caret, visible completion chips, neighbours, and outputs. You review the context before sending.

Current limitation: full-screen Agent is disabled while Remote is on because the Remote route cannot yet receive the reviewed editor context or use the local draft tools. Ordinary Remote chat still works.

Saved conversations and Clear

The Assistant keeps one bounded conversation for each workbook plus a separate Global conversation. The selector in the panel chooses which one is active. In Direct mode, Clear deletes the selected saved conversation and resets its provider/tool context. If Remote context may exist, Clear requires a second confirmation and an acknowledgement from a compatible broker before clearing workbook and Global conversations.

Ordinary exports exclude the conversation unless you enable Include AI conversation. AI Prompt cells never use the Assistant conversation.

Autocomplete status

Pro ships local, offline Python prefix completion, suggestion chips, and optional extra keys. AI autocomplete is not shipped. The scoped AI setting for it is a disabled preview rather than an active model route.
