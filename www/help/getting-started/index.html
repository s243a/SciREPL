First workbook

Getting started

  • Free + Pro
  • Android
  • Web/PWA (Free)
  • Windows preview
  • Verified: Free 1.3.2 · Pro 1.3.0

Run your first cell

  1. Choose a language in the new-cell panel. Python is a good first choice.
  2. Enter print("Hello from SciREPL").
  3. Select Run. The cell is added to the workbook and its output appears below it.
  4. Edit a saved cell with its edit control, then select Run to save and rerun it or Cancel to discard the draft.

The first run can be slower

Each programming language has its own runtime. The first cell in a language may initialize WebAssembly, restore packages, or download an optional component. Later cells normally reuse the loaded runtime and are much faster.

If a runtime download needs your consent, read the scrollable Privacy Policy, scroll to the bottom, and tap I Understand if you agree. A separate prompt may then ask you to tap Download. Python is normally bundled; R and Lua in Free may need a download. A valid %pip install also asks for the current network disclosure before trying to install a package if you have not accepted it. The illustrated first-workbook tutorial shows the notice.

Before judging performance: wait for the status badge to return to ready, then run a second simple cell in the same language. See first-run troubleshooting if loading does not finish.

Your work is local

SciREPL automatically restores its local session, but that is not a cloud backup. Browser storage, Android app data, and Windows profile data are separate. Export important workbooks to a location you control.

  • .srwb preserves SciREPL-specific workbook state and can contain multiple notebook tabs.
  • .ipynb is useful for sharing supported notebook cells and outputs with Jupyter-compatible tools.
  • Document exports include HTML, Markdown, PDF, DOCX, and LaTeX.

Install an example

Open Menu → Browse Packages, Bundles & Workbooks, choose a verified catalogue channel, and install a workbook. By default the installed workbook becomes the selected tab so you can inspect it immediately; you can turn off Switch to workbook on install under Menu → Settings → Import & Editing.

In Pro: AI surfaces are optional and separate from ordinary code execution. Start with the shared notebook first, then see AI setup and workflows.
