Windows desktop app

Appearance on Windows: what's different

The Windows app, including the Microsoft Store version, has the same ☰ Menu → 🎨 Appearance as Android. Theme, interface language, button size and the 📦 Browse shortcut work as the Appearance walkthrough describes. This page covers only what a desktop window adds.

  • Free
  • Windows desktop app
  • About 2 minutes

Notebook width

In a window at least 1000 pixels wide, notebook cells can grow to 1200 pixels. This Wide setting is the default. To change it, open ☰ Menu → 🎨 Appearance and, under Layout, choose a Notebook width:

  • Standard: the earlier 720-pixel column.
  • Wide: up to 1200 pixels (the default).
  • Full window: cells use the whole width of the window.

Narrower windows always use the standard column, whatever you choose.

Zoom

Zoom makes the page inside the window larger or smaller:

  • Zoom in: Ctrl+= or Ctrl+Shift+= (Ctrl and the plus key).
  • Zoom out: Ctrl+-. Back to 100%: Ctrl+0.
  • Hold Ctrl and turn the mouse wheel, or pinch on a touchpad.
  • In the window's menu bar: View → Zoom In, Zoom Out or Actual Size.

Windows display scaling or app zoom?

Settings → System → Display → Scale in Windows enlarges everything on the screen, including SciREPL's title bar, menu bar and dialog boxes. App zoom enlarges only the page inside the window. Windows has no scale setting for a single app, so use zoom when only SciREPL should be larger or smaller.

Both also change how big the window is for the page. At 150% scaling, for example, a 1920-pixel-wide screen is 1280 pixels wide to SciREPL. The 1000-pixel width above and the 500-pixel height below are measured after scaling and zoom.

Hiding the new-cell panel

When the window is wider than it is tall and the page is at most 500 pixels high, a ⌄ button (Hide new-cell panel) appears in the new-cell panel at the bottom. At 150–200% scaling an ordinary laptop window can be that short, and zooming in has the same effect. Click ⌄ to give the notebook the full height.

While the panel is hidden, the Sci REPL title at the top left is replaced by a small ⌃ button (Show new-cell panel). Click it to bring the panel back. Making the window taller, for example by maximising it, also brings the panel back.

The window's menu bar

On Windows, the app's window has its own menu bar above the page: File, Edit, View, Runtimes and Help, in your interface language. Press Alt to reach it from the keyboard. Runtimes contains:

  • Downloaded runtimes… shows how much space the downloaded Lua and R runtimes use, and where they are kept.
  • Clear downloaded runtimes… deletes them after you confirm; your notebooks and files are not affected. Runtimes already loaded keep working until you restart. After that, R and Lua ask again before downloading, which needs an internet connection.
  • Open application data folder opens SciREPL's data folder in File Explorer.

Android has no window menu bar. There, use ☰ Menu → 📊 Memory & Storage to check and clear storage. On Windows that panel cannot see the downloaded runtimes, so use the Runtimes menu for them.

Everything else is shared with Android: return to the Appearance walkthrough.
