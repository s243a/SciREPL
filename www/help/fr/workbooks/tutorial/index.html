Apprendre par la pratique

Explorer un classeur du catalogue

Trouvez le classeur existant Markov Groups: A Random Walk on Cube Moves, exécutez ses quatre cellules Python, raccourcissez sa marche aléatoire et enregistrez votre propre copie. L'accent est mis sur l'utilisation de SciREPL ; vous n'avez pas besoin de connaître l'algèbre matricielle ni de résoudre un Rubik's Cube.

Vous êtes ici pour découvrir l'application ? Suivez les étapes 1–5 : trouver, ouvrir, exécuter, modifier et exporter un classeur. Vous pouvez vous arrêter après l'étape 5. Les mathématiques facultatives viennent ensuite ; elles ne sont pas nécessaires pour terminer ce tutoriel.

  • Free + Pro
  • Étapes pour Android
  • Environ 15 minutes

Des captures d'écran réelles d'un téléphone montrent SciREPL Pro 1.4.0-debug sur un Samsung Galaxy S24+, capturées le 6 octobre 2026. Elles illustrent le flux de travail de classeur partagé, et non une version finale Pro. Free et d'autres versions peuvent organiser certaines commandes différemment. L'exemple est le classeur en anglais du catalogue SciREPL v0.4.0.

Tous les tutoriels

Avant de commencer

Trouver le menu

Dans SciREPL, cherchez dans la ligne d'en-tête en haut de l'application le bouton ☰ Menu. Son icône est composée de trois lignes horizontales, surlignée en jaune ci-dessous. Appuyez dessus pour ouvrir le menu de l'application ; l'étape 1 indique quel élément de menu choisir.

Étape 1

Parcourir, filtrer et rechercher

  1. Ouvrez Menu → Parcourir paquets, collections et classeurs. Dans Free, le raccourci d'en-tête facultatif 📦 ouvre le même écran lorsqu'il est visible. Le guide de l'apparence montre comment l'activer.
  2. Parcourez la liste ou utilisez ses filtres. Pour cet exemple en anglais, choisissez English sous Langue parlée et Python sous Noyau. Toutes les langues parlées et l'option Tout du noyau fonctionnent également, mais affichent davantage d'entrées.
  1. Tapez Markov Groups dans le champ de recherche. Sous Classeurs, trouvez Markov Groups: A Random Walk on Cube Moves. Vérifiez le titre complet avant de l'installer : il s'agit d'un modèle de classeur, pas d'un paquet à ajouter à Python.
  2. Si le clavier masque le résultat, utilisez son bouton pour masquer le clavier ou appuyez une fois sur Précédent d'Android pour le fermer. Gardez Browse ouvert et faites défiler jusqu'au classeur correspondant.

Qu'y a-t-il d'autre de disponible ? Parcourez la liste des classeurs sur GitHub (anglais). Les versions linguistiques d'une leçon sont des entrées distinctes, pas des leçons différentes.

Le lien GitHub affiche les derniers contenus de développement. SciREPL utilise normalement la version stable la plus récente du catalogue, de sorte que certains classeurs présentés sur GitHub peuvent ne pas encore apparaître dans Browse. Dans SciREPL, effacez la recherche et essayez CSV, Prolog, Lua ou statistics ; choisissez Tout sous Kernel lorsque vous explorez d'autres langages.

Si un avis de confidentialité apparaît : récupérer ou actualiser le catalogue distant nécessite une connexion réseau. Lisez l'avis, faites défiler dans la boîte de dialogue jusqu'en bas, et appuyez sur I Understand uniquement si vous acceptez. Fermer l'avis empêche cette actualisation réseau ; les entrées intégrées et les entrées de catalogue précédemment mises en cache peuvent toujours apparaître. Consultez confidentialité et données locales (Page de référence en anglais).

Aucun classeur correspondant ? Vérifiez les filtres de langue et de noyau, puis utilisez la commande Actualiser du catalogue. Une version plus ancienne de l'application peut ne pas avoir les mêmes commandes de catalogue. Sinon, enregistrez le fichier de classeur v0.4.0 épinglé sur votre appareil, puis choisissez Menu → Import File et sélectionnez markov-groups.srwb. Si votre navigateur affiche le fichier sous forme de texte, utilisez son action enregistrer/télécharger et conservez l'extension .srwb. Le guide d'importation manuelle de classeur présente les étapes avec le paradoxe de Simpson sur GitHub, branche main ; choisissez le fichier Markov ci-dessus pour continuer cette leçon.

Étape 2

Ouvrir le classeur et inspecter ses cellules

  1. Appuyez sur Installer sur la fiche du classeur. Si le bouton indique déjà Installé, quittez le menu Browse et choisissez plutôt le classeur existant dans le sélecteur de classeurs.
  2. Le classeur devient normalement l'onglet sélectionné. Si le menu Browse reste ouvert, quittez-le. Si le basculement automatique est désactivé, choisissez Markov Groups: A Random Walk on Cube Moves dans le sélecteur de classeurs à côté de SciREPL dans l'en-tête.
  3. Lisez le texte d'introduction, puis faites défiler les cellules. Les cellules Markdown expliquent la leçon ; les cellules Python contiennent le code que vous allez exécuter. Chaque cellule Python possède un nom pour vous aider à la trouver.

Installer ne signifie pas Exécuter. L'installation de ce classeur du catalogue distant ajoute ses cellules sans exécuter son code Python. Le modèle v0.4.0 ne contient aucune sortie Python enregistrée, examinez donc le code et exécutez-le vous-même. Aucun compte d'IA, clé API, jeu de données externe ou installation de paquet supplémentaire n'est nécessaire ; le code utilise NumPy avec SciREPL et son environnement d'exécution Python.

Étape 3

Exécutez les quatre cellules Python dans l'ordre

Pour une cellule enregistrée, appuyez sur le ✎ crayon dans l'en-tête de cette cellule, puis appuyez sur le Exécuter propre à cette cellule. Cela exécute la cellule existante ; le panneau de nouvelle cellule du bas crée une cellule différente.

Raccourci Pro : appuyez deux fois sur le code enregistré pour ouvrir son éditeur, puis appuyez, sur cette cellule, sur le bouton Exécuter. Free utilise le ✎ crayon dans ce didacticiel.

Que signifient ces noms ? cube_moves et check_moves sont des noms affichés sur les cellules, et non des commandes à saisir. Trouvez le nom correspondant, puis utilisez le crayon et Exécuter de cette cellule. Le didacticiel sur les cellules nommées et les chemins interlangues montre comment attribuer des noms et les utiliser comme références telles que /nb/cube_moves/.code.

  1. Exécutez cube_moves. Cela définit les mouvements et les fonctions d'aide. Attendez-vous à Built six clockwise quarter-turn matrices with fixed face centres.
  2. Exécutez check_moves. Cela vérifie qu'aucun autocollant n'est perdu, que les centres restent fixes et que quatre répétitions de chaque quart de tour ramènent au point de départ. Après six lignes validées, attendez-vous à All six moves passed. U and R do not commute.
  1. Exécutez show_turn. Cela affiche les cycles du mouvement U et les étiquettes des autocollants avant et après une rotation. La rangée supérieure avant passe de [19, 20, 21] à [46, 47, 48]. La comparaison U then R equals R then U: False montre que l'ordre des mouvements a de l'importance.

La longue liste des lettres de face est omise ici. Les lignes de cycle utilisent des positions commençant à un ; la comparaison des rangées montre les étiquettes des autocollants. Il s'agit de significations différentes, même si le cube résolu leur donne initialement des numéros correspondants.

  1. Exécutez random_walk. Cela affiche un total de probabilité pour un seul autocollant de 1.0, une trajectoire échantillonnée de 12 étapes, les étiquettes finales des lettres de face et un message confirmant que chaque étiquette d'autocollant et les six centres ont tous été préservés.

Les cellules Python sont déjà dans l'ordre requis. Ne les réorganisez pas : les cellules suivantes réutilisent les définitions de cube_moves. Pour exécuter plusieurs cellules à la fois, consultez Run All Below et Run All Cells.

Premier lancement plus lent ? Python peut avoir besoin de temps pour s'initialiser, et un téléchargement de l'environnement d'exécution ou une solution de secours réseau peut nécessiter votre accord. Attendez que le badge d'état revienne à prêt et vérifiez la sortie de la cellule pour repérer d'éventuelles erreurs. Si une cellule ultérieure signale un nom non défini après un redémarrage, exécutez les cellules Python depuis le début ; une sortie enregistrée n'est pas identique à des définitions Python actives.

Ce classeur affiche du texte et des listes de lettres correspondant aux faces. Il ne dessine ni n'anime de cube, et son court parcours initialisé avec une graine ne constitue pas la preuve d'un mélange uniformément réparti.

Étape 4

Raccourcir la marche et réexécuter la cellule enregistrée

  1. Trouvez random_walk et appuyez sur son ✎ crayon.
  2. Trouvez cette ligne et modifiez uniquement size=12 en size=6: 
    moves = rng.choice(MOVE_OPTIONS, size=12).tolist()

    Laissez np.random.default_rng(7) inchangé. La graine rend cet exemple reproductible.

  3. Appuyez sur le bouton Exécuter dans l'éditeur de cette cellule enregistrée. La sortie est actualisée ; la ligne Sampled moves: contient désormais six options au lieu de douze. I compte comme une option même si cela laisse le cube immobile.

Pour cette modification, réexécutez uniquement random_walk pendant que les définitions précédentes sont chargées. Si vous modifiez cube_moves à la place, réexécutez également les cellules Python ultérieures. Les sorties enregistrent leur dernière exécution ; elles ne sont pas recalculées automatiquement lorsqu'une autre cellule change.

Si vous avez ouvert l'éditeur par erreur, choisissez Annuler. Pour revenir à l'exemple d'origine, modifiez size=6 pour rétablir size=12 et réexécutez la cellule.

Étape 5

Exporter votre propre copie du classeur

  1. Laissez le classeur Markov Groups sélectionné, puis ouvrez Menu → Exporter classeurs et paquets, et non Export Document.
  2. Choisissez Classeur (.srwb) et Onglet actif uniquement.
  3. Appuyez sur Exporter et enregistrez la copie dans un emplacement sous votre contrôle. Android ouvre un flux de partage/enregistrement ; un navigateur télécharge un fichier. Conservez l'extension .srwb.

Le classeur ne nécessite aucun fichier de données distinct, une copie .srwb est donc suffisante pour cette leçon. Vous pouvez le rouvrir avec Menu → Import File ; exécutez ses cellules Python depuis le début lors du démarrage d'un nouvel environnement d'exécution.

La récupération locale n'est pas une sauvegarde. Effacer le stockage de l'application ou du site, ou désinstaller l'application, peut supprimer le travail local. Les sessions Android et de navigateur ne partagent pas automatiquement vos modifications. L'exportation ne publie pas vos modifications dans le catalogue ; elle vous donne une copie distincte.

Pour les notions de base sur la modification de cellules enregistrées, consultez la visite guidée de l'interface du premier classeur. Pour un exemple qui lit et contient un fichier de données distinct, essayez la visite guidée du classeur CSV. La référence des classeurs (Page de référence en anglais) couvre les types de cellules et les noms de cellules stables.

Exécuter tout en dessous et Exécuter toutes les cellules

  • Exécuter tout en dessous : ouvrez une cellule enregistrée avec son ✎ crayon, puis choisissez Exécuter toutes les cellules suivantes (l'icône compacte est ▶↓). Cette commande exécute cette cellule et chaque cellule située en dessous, dans l'ordre.
  • Menu → Exécuter toutes les cellules : exécute le classeur sélectionné de sa première cellule à sa dernière. Ce n'est pas une commande pour exécuter chaque onglet de classeur.

Inspectez d'abord le code et gardez ce classeur sélectionné pendant l'exécution du traitement par lot. Après une nouvelle session Python, commencez par cube_moves afin que les cellules suivantes disposent de leurs définitions. Ces actions exécutent du code ; qualifier une explication de « facultative » ne fait pas en sorte que l'application ignore ses cellules de code.

Vous avez terminé la visite guidée de SciREPL. Vous avez trouvé, ouvert, exécuté, modifié et exporté un classeur. Si vous souhaitiez uniquement découvrir l'application, vous pouvez vous arrêter ici. Lecture facultative

Les mathématiques derrière l'exemple du cube

Un peu de sens derrière la sortie

Le classeur suit 54 autocollants étiquetés individuellement, et pas seulement six couleurs. Un mouvement autorisé réorganise ces étiquettes. Quatre répétitions d'un même quart de tour reviennent à la disposition initiale, mais des rotations de faces distinctes peuvent donner des résultats différents lorsque leur ordre change.

La marche aléatoire choisit parmi 13 options : rester immobile (I), six quarts de tour et leurs six inverses. Sa matrice de probabilité 54×54 décrit l'emplacement d'un seul autocollant, et non chaque configuration complète du cube. Un total de probabilité de 1.0 signifie que la somme des probabilités d'emplacement de cet autocollant est égale à un ; cela ne prouve pas que le cube est mélangé uniformément.

Curieux de connaître l'orientation des faces ? La cellule coordinates du classeur donne les axes globaux ainsi que la normale vers la droite, vers le haut et vers l'extérieur de chaque face. Le tutoriel sur les images, diagrammes et équations montre comment intégrer ce type d'explication dans un classeur. Des diagrammes de coordonnées sont en cours d'ajout à la version de développement du catalogue ; la version figée v0.4.0 ci-dessus ne les inclut pas.

Facultatif : aperçu de l'étape 4 révisée

Les étapes et captures d'écran de téléphone ci-dessus utilisent le classeur stable v0.4.0. Le téléchargement du classeur révisé est un aperçu de développement, pas encore le catalogue stable. Importez-le avec Menu → Importer un fichier si vous souhaitez tester ses cellules d'explication et de code plus courtes et entrelacées.

Dans cet aperçu, exécutez d'abord cube_moves, check_moves et show_turn, comme ci-dessus. Ensuite :

  1. Exécutez transition_matrix. Cela construit T, la matrice de probabilité pour l'emplacement d'un autocollant après une option choisie uniformément : I, un quart de tour de face ou son inverse.
  2. Exécutez sticker_step. Cela suit l'étiquette d'autocollant 1, initialement à la position indexée à zéro 0. La somme de ses probabilités d'emplacement est égale à 1.0. Le graphique ci-dessous montre les probabilités de destination calculées par cette cellule.
