Apprendre par la pratique

Ajouter des images, des diagrammes et des équations

Un classeur peut expliquer une idée avec une image aussi bien qu'avec du code. Essayez trois façons d'afficher le même repère de coordonnées simple : une image statique en Markdown, une illustration dessinée par JavaScript et une équation composée avec KaTeX. Vous n'avez pas besoin de Python, de R, d'une installation de paquet ou d'un compte d'IA.

  • Flux de travail Free + Pro
  • Exemples vérifiés dans le navigateur
  • Environ 10 minutes

Les exemples et les captures d'écran ont été vérifiés dans la version pour navigateur SciREPL Free le 6 octobre 2026. Les captures d'écran utilisent une fenêtre de navigation étroite ; ce ne sont pas des captures Android. Les mêmes commandes sont utilisées sur Android, mais leur position peut varier. Pro et chaque version publiée de l'application n'ont pas été testées pour ce guide.

Étape 1

Ouvrir le classeur d'exemple

Le fichier d'accompagnement contient les exemples complets, y compris un PNG incorporé. Il conserve tout dans un seul petit classeur afin que vous n'ayez pas à saisir une longue chaîne d'image en Base64.

  1. Téléchargez le classeur d'exemple graphique (.srwb). Enregistrez le fichier réel, en conservant son extension .srwb. Si votre navigateur affiche du texte, utilisez son action d'enregistrement ou de téléchargement. Notez le dossier dans lequel vous l'avez enregistré.
  2. Ouvrez SciREPL. Dans l'en-tête en haut de l'application, trouvez ☰ Menu, le bouton avec trois lignes horizontales. Appuyez ou cliquez dessus.
  3. Choisissez 📂 Importer un fichier (par exemple .srwb, .ipynb, .csv, .py, .zip). Faites défiler dans le menu si nécessaire. Dans le sélecteur de fichiers de votre appareil, sélectionnez workbook-graphics.srwb depuis Téléchargements ou le dossier que vous avez choisi.
  4. Fermez le menu s'il reste ouvert, et sélectionnez le nouvel onglet Workbook Graphics dans le sélecteur de classeur. Vos onglets existants sont conservés.
  5. Trouvez les quatre cellules nommées static_axes, embedded_png, canvas_axes et math_axes. Lisez-les avant d'exécuter le code. Les diagrammes statiques et les équations apparaissent à partir de leur source Markdown ; l'image JavaScript n'apparaît qu'après avoir exécuté sa cellule.

Importer n'est pas exécuter. Une importation .srwb n'exécute pas son code, même lorsque le paramètre d'exécution automatique est activé. Seul canvas_axes nécessite une exécution JavaScript dans cette leçon. Il n'y a pas d'étape Exécuter toutes les cellules.

Besoin de plus de détails sur le téléchargement ou le sélecteur ? Suivez le tutoriel d'importation manuelle de classeur. Les noms ci-dessus apparaissent sur les cellules enregistrées ; le tutoriel sur les chemins de cellules nommées explique comment les attribuer et les utiliser. Vous pouvez également créer ces exemples dans un classeur que vous avez déjà ouvert, en suivant les étapes ci-dessous.

Étape 2 · Méthode 1

Conserver un diagramme statique dans Markdown

Pensez à une feuille de papier face à vous. r pointe vers la droite le long du papier, u pointe vers le haut le long de celui-ci, et n pointe hors du papier vers vous. Un cercle avec un point représente cette direction vers l'extérieur, comme voir la pointe d'une flèche venir vers vous.

Modifier le diagramme importé

  1. Trouvez static_axes. Appuyez sur son ✎ crayon dans l'en-tête même de cette cellule enregistrée, près de ✕. Cela ouvre la source de la cellule existante ; le panneau de nouvelle cellule créerait une autre cellule.
  2. Gardez le bouton de type de cellule réglé sur Md. Dans le texte SVG, remplacez r: right par r: across.
  3. Appuyez sur le bouton ▶ Exécuter de cette cellule pour enregistrer et effectuer à nouveau le rendu du Markdown. Pour une cellule Md, ce bouton affiche le texte ; il n'exécute pas JavaScript et ne démarre pas d'environnement d'exécution de langage.

Ou créez votre propre cellule Markdown

  1. Trouvez le panneau de nouvelle cellule où vous tapez la cellule suivante. S'il est replié, utilisez le bouton ⌃ Afficher le panneau de nouvelle cellule près du titre de l'application.
  2. Appuyez sur le bouton de type de cellule marqué code pour qu'il devienne Md. Markdown est un type de cellule, pas une entrée dans le menu déroulant des langages.
  3. Copiez le SVG complet ci-dessous dans le champ de texte, sans ajouter de délimiteurs de code Markdown (```). Laissez une ligne vide entre la prose environnante et le SVG.
  4. Appuyez sur ▶ Exécuter pour ajouter la cellule Markdown rendue. Vous devriez voir le papier et les trois étiquettes de direction.
<svg xmlns="http://www.w3.org/2000/svg"
     viewBox="0 0 360 220" width="100%" height="220"
     role="img" aria-label="Right, up and outward normal on paper">
  <title>A paper coordinate frame</title>
  <rect x="20" y="18" width="320" height="184"
        rx="6" fill="#ffffff" stroke="#526170" stroke-width="2" />
  <path d="M110 145 H280" fill="none" stroke="#075d69" stroke-width="3" />
  <polygon points="280,145 267,138 267,152" fill="#075d69" />
  <path d="M110 145 V48" fill="none" stroke="#064d91" stroke-width="3" />
  <polygon points="110,48 103,61 117,61" fill="#064d91" />
  <circle cx="110" cy="145" r="10" fill="#ffffff" stroke="#14191f" stroke-width="2" />
  <circle cx="110" cy="145" r="3" fill="#14191f" />
  <text x="204" y="168" fill="#14191f" font-size="16">r: right</text>
  <text x="124" y="62" fill="#14191f" font-size="16">u: up</text>
  <text x="42" y="190" fill="#14191f" font-size="16">n: toward you</text>
</svg>

SciREPL assainit Markdown. Cet exemple utilise des formes SVG ordinaires, du texte et des attributs fill/stroke explicites. Ses pointes de flèches sont des polygones : ne comptez pas sur marker-end="url(...)", un bloc <style>, des scripts ou des animations pour survivre à l'assainisseur.

Utiliser plutôt un PNG intégré

L'autre option statique est un PNG dont les données Base64 sont stockées directement dans la source Markdown. La syntaxe d'image standard de Markdown ressemble à ceci :

![Paper axes](data:image/png;base64,PASTE_THE_COMPLETE_BASE64_PNG_HERE)

Cette ligne montre le format, pas une image fonctionnelle : remplacez l'espace réservé par le PNG encodé complet, ou utilisez la cellule embedded_png déjà fonctionnelle. La partie située après base64, correspond aux données de l'image, pas à un nom de fichier. Conservez-la sur une seule ligne.

Pour une image qui s'adapte à la cellule sur un petit écran, la cellule embedded_png associée utilise le code HTML en ligne équivalent ci-dessous, avec width="100%". Elle reste stockée à l'intérieur de Markdown, pas comme une sortie de code :

<img alt="Paper axes" width="100%"
     src="data:image/png;base64,PASTE_THE_COMPLETE_BASE64_PNG_HERE">

Choisissez une option statique : utilisez un élément SVG en ligne pour un petit schéma modifiable, ou une image data:image/png;base64,... pour une image matricielle. Une URL de données SVG telle que data:image/svg+xml,... n'est pas identique au SVG en ligne et se trouve bloquée dans la version vérifiée. Les URL d'images distantes y sont également bloquées. Ces deux exemples autonomes ne nécessitent aucun téléchargement d'image lors de l'affichage.

Les deux exemples statiques résident dans la source Markdown. Ils peuvent être affichés après l'importation du classeur sans exécuter de code.

Étape 3 · Méthode 2

Dessiner une image avec JavaScript

Une image statique reste identique jusqu'à ce que vous modifiez sa source. Pour une image calculée ou dessinée par un programme, utilisez une cellule code et sélectionnez JS - JavaScript. Cet exemple dessine sur un canevas, le convertit en PNG et envoie cette image vers la sortie de la cellule.

  1. Dans le classeur importé, appuyez sur le ✎ crayon sur canvas_axes. Vérifiez que le type de cellule est code et que son langage est JS - JavaScript (le sélecteur compact peut afficher simplement JS).
  2. Lisez le code ci-dessous, qui constitue le programme complet dans cette cellule. Il ne nécessite aucune autre cellule, aucun fichier, aucun paquet ni aucune requête réseau.
  3. Sur cette cellule, appuyez sur ▶ Exécuter. Une image devrait apparaître sous la source JavaScript.

Pour créer plutôt une nouvelle cellule, accédez au panneau de nouvelle cellule, rétablissez Md vers code si nécessaire, et choisissez JS - JavaScript dans le menu déroulant des langages. Collez le code, puis appuyez sur ▶ Exécuter. Si JavaScript est masqué, recherchez ☰ Menu → Langues et activez-le.

(() => {
  const canvas = document.createElement('canvas');
  canvas.width = 360;
  canvas.height = 220;
  const ctx = canvas.getContext('2d');
  ctx.fillStyle = '#ffffff';
  ctx.fillRect(0, 0, 360, 220);
  ctx.strokeStyle = '#526170';
  ctx.lineWidth = 2;
  ctx.strokeRect(20, 18, 320, 184);

  function arrow(x1, y1, x2, y2, color) {
    const angle = Math.atan2(y2 - y1, x2 - x1);
    ctx.strokeStyle = color;
    ctx.fillStyle = color;
    ctx.lineWidth = 3;
    ctx.beginPath();
    ctx.moveTo(x1, y1);
    ctx.lineTo(x2, y2);
    ctx.stroke();
    ctx.beginPath();
    ctx.moveTo(x2, y2);
    ctx.lineTo(x2 - 14 * Math.cos(angle - 0.5),
               y2 - 14 * Math.sin(angle - 0.5));
    ctx.lineTo(x2 - 14 * Math.cos(angle + 0.5),
               y2 - 14 * Math.sin(angle + 0.5));
    ctx.closePath();
    ctx.fill();
  }
  arrow(110, 145, 280, 145, '#075d69'); // right
  arrow(110, 145, 110, 48, '#064d91');  // up
  ctx.fillStyle = '#ffffff';
  ctx.strokeStyle = '#14191f';
  ctx.lineWidth = 2;
  ctx.beginPath();
  ctx.arc(110, 145, 10, 0, 2 * Math.PI);
  ctx.fill();
  ctx.stroke();
  ctx.fillStyle = '#14191f';
  ctx.beginPath();
  ctx.arc(110, 145, 3, 0, 2 * Math.PI);
  ctx.fill();
  ctx.font = '16px sans-serif';
  ctx.fillText('r: right', 204, 168);
  ctx.fillText('u: up', 124, 62);
  ctx.fillText('n: toward you', 42, 190);
  window.renderImage(canvas.toDataURL('image/png'));
})();

Essayez de modifier r: right dans ctx.fillText(...), puis réexécutez la cellule. L'enveloppe de fonction (() => { ... })(); conserve les variables de cet exemple locales, de sorte que vous pouvez la réexécuter sans redéclarer de variables const de premier niveau.

L'appel d'affichage est important. Conservez window.renderImage(canvas.toDataURL('image/png')) à la fin. Renvoyer une chaîne ordinaire telle que '<svg>...</svg>' depuis JavaScript affiche du texte ; cela ne transforme pas cette chaîne en schéma en ligne. Vous n'avez pas besoin d'insérer le canevas dans la page de l'application.

Étape 4 · Méthode 3

Expliquer l'image avec des équations

Utilisez une cellule Markdown (Md) pour les mathématiques au format TeX. Les directions des schémas forment un trièdre direct : droite × haut = normale sortante. Dans la matrice ci-dessous, la première ligne est r, la deuxième est u et la troisième est n ; les indices représentent leurs composantes dans un système de coordonnées x, y, z choisi.

  1. Appuyez sur le ✎ crayon sur math_axes, ou créez une nouvelle cellule en utilisant code → Md dans le panneau de nouvelle cellule.
  2. Utilisez le texte complet ci-dessous. Les délimiteurs $$ appartiennent à la source Markdown ; ne l'entourez pas d'un bloc de code.
  3. Appuyez sur ▶ Exécuter pour enregistrer et effectuer le rendu du Markdown. Vous devriez voir une équation de produit vectoriel et une matrice à trois lignes, et non des commandes avec barres obliques inverses brutes. Aucun noyau de langage ne s'exécute pour cette cellule.
Right, up and outward normal form a right-handed frame.

$$\mathbf{r} \times \mathbf{u} = \mathbf{n}$$

Rows of the frame matrix: right, up, then outward normal.

$$
M = \begin{pmatrix}
r_x & r_y & r_z \\
u_x & u_y & u_z \\
n_x & n_y & n_z
\end{pmatrix}
$$

KaTeX n'est pas un compilateur TeX complet. Il restitue la notation mathématique prise en charge, mais ne compile pas les diagrammes TikZ ni un document LaTeX entier. Bien que KaTeX liste \includegraphics, cela nécessite une option de confiance que SciREPL n'active pas dans le moteur de rendu vérifié ; ce n'est pas une voie d'insertion d'images ici. Utilisez du SVG/PNG Markdown ou un canevas JavaScript pour les images.

Pour d'autres symboles et commandes mathématiques, consultez le tableau de prise en charge de KaTeX ; la documentation peut décrire des fonctionnalités plus récentes que la version fournie avec SciREPL. Pour un classeur utilisant ces instructions pour expliquer les mouvements du cube, consultez le guide pas à pas sur les groupes de Markov.

Étape 5

Enregistrer une copie, puis savoir quoi réexécuter

  1. Ouvrez ☰ Menu → Exporter classeurs et paquets.
  2. Choisissez Classeur (.srwb) et Onglet actif uniquement pour ce classeur, puis appuyez sur Exporter. Enregistrez le fichier dans un emplacement que vous contrôlez.
  3. Pour rouvrir cette copie, utilisez Menu → Import File. Cela ajoute un autre onglet de classeur ; cela ne remplace pas votre onglet existant.
  4. Vérifiez le SVG statique, le PNG intégré et les équations. Ils proviennent de la source Markdown enregistrée et ne nécessitent aucune exécution de code. Inspectez canvas_axes et réexécutez cette cellule JavaScript pour régénérer son image.

La sortie générée n'est pas identique à la source. Dans la version de navigateur Free vérifiée, l'exportation .srwb peut enregistrer une sortie d'image JavaScript, mais l'opération manuelle Menu → Import File ne restaure pas cette sortie de code. La source JavaScript demeure, alors réexécutez-la. Le SVG en ligne, le PNG intégré et les équations constituent la source Markdown et s'affichent lors de l'importation. N'utilisez pas une sortie précédemment visible comme preuve que le code vient de s'exécuter.

Ces vérifications couvrent les exemples de classeur ci-dessus, et non la fidélité des images dans chaque format d'exportation. Ne supposez pas que les exportations de documents PDF, DOCX, Markdown et autres préservent chaque image de la même manière ; inspectez votre document exporté. Consultez fichiers et exportation (Page de référence en anglais) pour connaître les formats disponibles.

L'exportation de votre classeur modifié crée une sauvegarde de vos modifications ; l'exemple téléchargé d'origine n'est pas mis à jour lorsque vous modifiez une cellule. Le stockage local de l'application n'est pas une sauvegarde, et les sessions Android et navigateur ne partagent pas automatiquement le travail.

Si quelque chose semble incorrect

Vérifiez le type et la source de la cellule

  • Vous voyez du code SVG au lieu d'un diagramme : vérifiez que le type de cellule est Md, supprimez tous les délimiteurs de bloc de code autour, et effectuez à nouveau le rendu de la cellule. Utilisez l'exemple complet <svg>...</svg> en ligne, et non une URL de données SVG.
  • Le PNG est manquant : utilisez la cellule embedded_png d'accompagnement, ou vérifiez que vous avez collé la chaîne data:image/png;base64,... entière sans espaces ni sauts de ligne. Un nom de fichier local ne constitue pas des données d'image intégrées.
  • Le code du canevas ne s'exécute pas : définissez son type de cellule sur code et son langage sur JS - JavaScript, et non Python. Conservez l'enveloppe de fonction entière et l'appel window.renderImage(...) final.
  • Une cellule JavaScript importée n'a pas d'image : importer ce classeur ne l'exécute pas et ne restaure pas la sortie de son code. Inspectez et réexécutez canvas_axes.
  • Vous voyez du TeX brut ou une erreur mathématique : utilisez Md, incluez à la fois l'ouvrant et le fermant $$, et vérifiez chaque barre oblique inverse et accolade par rapport à l'exemple. Chaque ligne de matrice sauf la dernière se termine par deux barres obliques inverses, \\.
  • La modification a créé une cellule supplémentaire : le panneau de nouvelle cellule ajoute des cellules. Utilisez le ✎ crayon de la cellule enregistrée pour modifier cette cellule existante, puis son propre bouton ▶ Exécuter. Utilisez Annuler si vous avez ouvert son éditeur par erreur.

Pour une présentation illustrée des cellules enregistrées, du crayon et du panneau de nouvelle cellule, consultez le guide de l'interface du premier classeur. Revenez à la référence des classeurs (Page de référence en anglais) pour un rappel concis des types de cellules.
