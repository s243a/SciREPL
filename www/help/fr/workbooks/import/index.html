Apprendre par la pratique

Importez vous-même un fichier de classeur

Vous avez déjà un fichier de classeur, ou vous ne trouvez pas de leçon dans Parcourir ? Enregistrez le fichier sur votre appareil, puis utilisez Menu → Importer un fichier pour l'ajouter à SciREPL. Ce court guide utilise Simpson's Paradox de la branche GitHub main du catalogue ; vous n'avez pas besoin d'installer de paquet ni d'écrire de code pour l'importer.

SciREPL importe deux formats de bloc-notes : .srwb, son propre format de classeur, et .ipynb, le format de bloc-notes Jupyter. Cet exemple utilise .srwb ; les remarques sur les formats ci-dessous expliquent le comportement d'exécution différent des importations Jupyter.

  • Free + Pro
  • Étapes pour Android + navigateur
  • Environ 3 minutes

La capture d'écran de Menu est une véritable capture Android sur un Samsung Galaxy S24+, montrant SciREPL Free 1.4.0-debug, et non une installation du Play Store. La capture d'écran du classeur importé est une capture distincte dans le navigateur Chromium de Free 1.4.0 avec une fenêtre d'affichage au format mobile ; ce n'est pas la preuve d'une importation via le sélecteur de fichiers Android. Les deux ont été prises le 6 octobre 2026. D'autres éditions, versions et sélecteurs de fichiers peuvent organiser les commandes différemment. L'exemple est le fichier simpsons-paradox.srwb en anglais du catalogue SciREPL, sur la branche main, tel qu'examiné pour ce guide ; cette branche peut changer. Les détails de capture et de source (Page de référence en anglais) enregistrent les dimensions exactes de l'image et le hachage du fichier examiné.

Tous les tutoriels

Étape 1

Enregistrer le fichier de classeur sur votre appareil

Sur GitHub, la branche main peut contenir des classeurs ou des mises à jour qui ne figurent pas encore dans la dernière version stable du catalogue présentée par Parcourir. Les versions du catalogue évoluent indépendamment de la version de l'application. Une importation directe de fichier vous permet d'essayer un classeur de confiance sans attendre qu'il apparaisse dans Parcourir.

  1. Afficher le paradoxe de Simpson sur GitHub, puis télécharger le fichier de classeur effectif (.srwb). Le second lien ouvre le fichier brut, et non la page web de GitHub.
  2. Si votre navigateur affiche le fichier sous forme de texte au lieu de le télécharger, utilisez l'action enregistrer/télécharger du navigateur. Enregistrez le fichier de classeur lui-même, et non une capture d'écran ou une page HTML.
  3. Conservez le nom de fichier simpsons-paradox.srwb et son extension .srwb. Notez l'emplacement où il a été enregistré : Android utilise couramment Téléchargements ; sur ordinateur, il peut s'agir de Téléchargements ou d'un dossier que vous avez choisi.

Il ne s'agit pas du téléchargement d'une version figée. main est une branche de développement : le contenu du fichier et les cellules peuvent changer après la prise de ces captures d'écran. Le fichier que vous enregistrez est une copie locale ; une modification ultérieure sur GitHub ne met pas à jour automatiquement votre onglet importé.

Télécharger n'est pas importer. L'enregistrement du fichier le place sur votre appareil ; il n'ouvre pas encore de classeur dans SciREPL. Vous n'avez pas besoin de l'ouvrir dans un éditeur de texte ni de le placer dans la vue Fichiers de SciREPL. L'étape suivante sélectionne ce fichier téléchargé.

Si vous possédez déjà un fichier .srwb de confiance provenant de quelqu'un d'autre, utilisez ce fichier à la place et sautez l'exemple de téléchargement. Le titre de son classeur et son nombre de cellules différeront des vérifications de l'étape 3.

Étape 2

Trouver Menu et choisir Importer un fichier

  1. Revenez à SciREPL. Dans la ligne d'en-tête en haut de l'application, trouvez ☰ Menu, le bouton avec trois lignes horizontales, puis touchez-le ou cliquez dessus.
  2. Choisissez 📂 Importer un fichier (par exemple .srwb, .ipynb, .csv, .py, .zip). Si le menu est plus grand que l'écran, faites défiler à l'intérieur du menu pour le trouver.
  1. Sur Android : le sélecteur de fichiers du système s'ouvre. Regardez dans Téléchargements, ou parcourez jusqu'à l'emplacement où vous avez enregistré le fichier. Sélectionnez simpsons-paradox.srwb. Le sélecteur appartient à Android, sa disposition et toute commande finale Ouvrir ou de sélection dépendent donc de votre appareil.
  2. Sur ordinateur : utilisez le sélecteur de fichiers pour trouver le dossier que vous avez choisi lors du téléchargement. Sélectionnez simpsons-paradox.srwb et confirmez la sélection. Utilisez cette méthode au lieu de chercher l'écran Téléchargements d'Android.
  3. De retour dans SciREPL, attendez que l'importation se termine. Si le menu est toujours ouvert, fermez-le pour voir le classeur.

Un classeur n'est pas un téléversement de fichier de données. L'importation d'un fichier .srwb ajoute son classeur sous la forme d'un onglet distinct, ou d'onglets distincts si le fichier contient plusieurs classeurs. Vos onglets existants sont conservés. Cela ne place pas le classeur dans la vue Fichiers et ne remplace pas votre classeur actuel.

Étape 3

Vérifier le nouveau classeur avant d'exécuter quoi que ce soit

  1. Recherchez Simpson's Paradox dans le sélecteur de classeur. Sélectionnez ce nouvel onglet s'il n'est pas déjà sélectionné. Son introduction s'intitule Simpson's Paradox: When Every Group Disagrees with the Total.
  2. Lisez l'introduction et faites défiler les cellules. La version examinée pour ces captures d'écran comporte sept cellules : trois cellules de texte, trois cellules R et une cellule JavaScript. Une version ultérieure sur main peut différer.
  3. Trouvez les cellules R nommées data, compute et viz, dans cet ordre. La cellule JavaScript est nommée js_check et constitue une vérification distincte et facultative. Lisez le texte explicatif ainsi que le code.

Importer ne signifie pas Exécuter pour les fichiers .srwb. SciREPL n'exécute pas le code lorsque vous importez un fichier .srwb, même si l'exécution automatique est activée pour d'autres importations. Inspectez le code provenant d'une source inconnue ou non fiable avant de choisir Exécuter ou Exécuter toutes les cellules.

L'importation ordinaire de fichiers .srwb supprime actuellement les sorties enregistrées des cellules de code, même lorsque le fichier les contient. Le texte Markdown est conservé et restitué, c'est pourquoi l'introduction s'affiche immédiatement. Pour régénérer des graphiques ou d'autres images générées par du code, réexécutez leurs cellules de code, avec les cellules dépendantes dans l'ordre. L'importation ne restaure pas les variables d'exécution actives de R ou d'autres environnements.

Étape 4

Facultatif : exécuter la leçon importée

Votre importation manuelle est terminée ; l'exécution du code est une étape distincte. Simpson's Paradox utilise des données pédagogiques synthétiques pour montrer comment les comparaisons au sein des groupes peuvent être en désaccord avec la comparaison globale. Pour l'explorer, appuyez sur le ✎ crayon d'une cellule de code enregistrée, inspectez le code, puis utilisez pour cette cellule le bouton Exécuter.

  1. Exécutez la cellule R data, puis lisez la cellule de texte pause et formulez sa prédiction avant d'exécuter compute. Poursuivez avec viz pour générer le graphique. Les cellules R ultérieures dépendent des précédentes. Elles utilisent le R de base ; vous n'avez pas besoin d'installer de packages R supplémentaires.
  2. Si vous souhaitez une vérification JavaScript distincte, exécutez js_check. Elle est autonome : elle ne dépend pas des cellules R et ne nécessite pas de démarrer R.

Première exécution de R : dans SciREPL, l'environnement d'exécution webR peut avoir besoin d'être téléchargé et initialisé. Un avis relatif au réseau ou à la confidentialité peut apparaître ; lisez-le et n'acceptez que si vous souhaitez continuer. Attendez que l'environnement d'exécution soit prêt et vérifiez si la cellule contient des erreurs. La seule importation du classeur n'a pas chargé ses définitions R.

Pour un autre exemple avec une présentation plus complète de l'exécution et de la modification, consultez la leçon sur les groupes de Markov. Il s'agit d'un classeur différent, comportant quatre cellules Python ; son étape d'exportation illustre également comment enregistrer une copie modifiée du classeur.

Conservez une copie que vous contrôlez. Le fichier téléchargé est la copie originale du classeur, et non une sauvegarde des modifications ultérieures. Exportez une copie du classeur pour enregistrer vos modifications. Effacer le stockage de l'application ou du navigateur peut supprimer le travail local, et les sessions Android et du navigateur ne partagent pas automatiquement vos modifications.

Autres formats et sécurité

Sachez ce que contient votre fichier

Les carnets Jupyter (.ipynb) utilisent également Menu → Importer un fichier, mais leur comportement d'exécution diffère de .srwb. Si Exécuter automatiquement les cellules à l'import du classeur est activé, une importation .ipynb peut exécuter automatiquement des cellules de code qui n'ont pas de sorties enregistrées.

N'importez des fichiers de carnet que depuis des sources fiables. Avant d'importer un .ipynb, ouvrez Menu → Paramètres → Importation et édition et assurez-vous que Exécuter automatiquement les cellules à l'import du classeur est désactivé (non coché). Il est désactivé par défaut, mais vérifiez votre paramètre actuel. Le désactiver ne garantit pas qu'un carnet arbitraire soit sûr ; inspectez le code d'un carnet fiable avant de décider explicitement de l'exécuter.

Fichiers de données séparés : une exportation normale de .srwb n'emporte pas les fichiers CSV séparés ni les autres données stockées dans le système de fichiers virtuel de SciREPL (la vue Fichiers). Cette version du paradoxe de Simpson crée ses données synthétiques dans le code, elle n'a donc pas besoin de fichier de données séparé. Pour un classeur qui lit un CSV, suivez, dans le guide CSV, l'exportation d'archive de paquet et les étapes de réouverture pour transférer et restaurer à la fois le classeur et ses données. Les archives de paquet et les importations .zip ne font pas partie de cette courte leçon sur les fichiers de classeur.

Si quelque chose semble incorrect

Vérifiez le fichier et l'onglet sélectionné

  • Le sélecteur ne trouve pas le fichier : consultez la liste des téléchargements de votre navigateur pour voir où il a été enregistré, puis accédez à ce dossier. Télécharger sur un ordinateur de bureau ne place pas le fichier dans le dossier Téléchargements de votre téléphone.
  • Le nom de fichier se termine par .txt ou .html : revenez au lien de téléchargement du classeur et enregistrez le véritable fichier avec son extension .srwb. Renommer une page HTML en .srwb n'en fait pas un classeur.
  • Vous voyez toujours votre ancien classeur : fermez le menu et vérifiez le sélecteur de classeur pour trouver le nouveau titre. Les onglets existants sont conservés.
  • Vous l'avez importé deux fois : une autre importation ajoute une autre copie ; elle ne met pas à jour et ne remplace pas l'onglet précédent. Vérifiez quelle copie vous modifiez avant d'apporter des changements.
  • Le titre ou les cellules ne correspondent pas : vérifiez que vous avez sélectionné simpsons-paradox.srwb, et non un autre téléchargement ou un fichier provenant d'une autre leçon. Le fichier sur main peut changer ; comparez votre copie avec le fichier GitHub actuel et inspectez tout code inconnu avant de l'exécuter.

Pour découvrir les bases des onglets de classeur et de la modification de cellules enregistrées, consultez le guide de l'interface du premier classeur. La référence des classeurs (Page de référence en anglais) explique la structure des classeurs et les types de cellules.
