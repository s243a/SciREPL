Application de bureau Windows

L'apparence sous Windows : ce qui change

L'application Windows, y compris la version du Microsoft Store, a le même ☰ Menu → 🎨 Apparence qu'Android. Le thème, la langue de l'interface, la taille des boutons et le raccourci 📦 Browse fonctionnent comme le décrit la présentation de l'apparence. Cette page ne traite que de ce qu'ajoute une fenêtre de bureau.

  • Free
  • Application de bureau Windows
  • Environ 2 minutes

Largeur du carnet

Dans une fenêtre d'au moins 1000 pixels de large, les cellules du carnet peuvent atteindre 1200 pixels. Ce réglage Large est celui par défaut. Pour le modifier, ouvrez ☰ Menu → 🎨 Apparence et, sous Disposition, choisissez une Largeur du carnet :

  • Standard : l'ancienne colonne de 720 pixels.
  • Large : jusqu'à 1200 pixels (par défaut).
  • Toute la fenêtre : les cellules occupent toute la largeur de la fenêtre.

Les fenêtres plus étroites utilisent toujours la colonne standard, quel que soit votre choix.

Zoom

Le zoom agrandit ou réduit la page dans la fenêtre :

  • Agrandir : Ctrl+= ou Ctrl+Shift+= (Ctrl et la touche plus).
  • Réduire : Ctrl+-. Revenir à 100 % : Ctrl+0.
  • Maintenez Ctrl et tournez la molette de la souris, ou pincez sur le pavé tactile.
  • Dans la barre de menus de la fenêtre : Affichage → Zoomer, Zoom arrière ou Taille réelle.

Mise à l'échelle de Windows ou zoom de l'application ?

Le réglage de mise à l'échelle des paramètres d'affichage de Windows (Paramètres → Système → Écran) agrandit tout ce qui est à l'écran, y compris la barre de titre, la barre de menus et les boîtes de dialogue de SciREPL. Le zoom de l'application n'agrandit que la page dans la fenêtre. Windows n'a pas de réglage d'échelle pour une seule application : utilisez le zoom quand seul SciREPL doit être plus grand ou plus petit.

Les deux modifient aussi la taille de la fenêtre vue par la page. À 150 %, par exemple, un écran de 1920 pixels de large ne fait plus que 1280 pixels pour SciREPL. La largeur de 1000 pixels ci-dessus et la hauteur de 500 pixels ci-dessous s'entendent après mise à l'échelle et zoom.

Masquer le panneau de nouvelle cellule

Quand la fenêtre est plus large que haute et que la page mesure au plus 500 pixels de haut, un bouton ⌄ (Masquer le panneau de nouvelle cellule) apparaît dans le panneau de nouvelle cellule, en bas. À 150–200 % de mise à l'échelle, une fenêtre d'ordinateur portable ordinaire peut être aussi basse, et zoomer a le même effet. Cliquez sur ⌄ pour donner toute la hauteur au carnet.

Tant que le panneau est masqué, le titre Sci REPL en haut à gauche est remplacé par un petit bouton ⌃ (Afficher le panneau de nouvelle cellule). Cliquez dessus pour faire revenir le panneau. Agrandir la fenêtre en hauteur, par exemple en la maximisant, le fait aussi revenir.

La barre de menus de la fenêtre

La fenêtre Windows a sa propre barre de menus au-dessus de l'application : Fichier, Modifier, Affichage, Environnements d’exécution et Aide, dans la langue de votre interface. Appuyez sur Alt pour l'atteindre au clavier. Environnements d’exécution contient :

  • Environnements d’exécution téléchargés… indique l'espace occupé par les environnements Lua et R téléchargés, et où ils sont conservés.
  • Effacer les environnements d’exécution téléchargés… les supprime après confirmation ; vos carnets et fichiers ne sont pas touchés. Les environnements déjà chargés continuent de fonctionner jusqu'au redémarrage. Ensuite, R et Lua demandent de nouveau avant de télécharger, ce qui nécessite une connexion Internet.
  • Ouvrir le dossier de données d'application ouvre le dossier de données de SciREPL dans l'Explorateur de fichiers.

Android n'a pas de barre de menus de fenêtre. Utilisez-y ☰ Menu → 📊 Mémoire et stockage pour vérifier et vider le stockage. Sous Windows, ce panneau ne voit pas les environnements téléchargés : utilisez pour eux le menu Environnements d’exécution.

Tout le reste est commun avec Android : revenez à la présentation de l'apparence.
