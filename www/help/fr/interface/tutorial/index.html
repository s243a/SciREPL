Apprendre par la pratique

Créez votre premier classeur

Voici le guide pratique et plus détaillé accompagnant la référence de l'interface (Page de référence en anglais). Vous exécuterez une cellule Python, la modifierez et enregistrerez une copie que vous contrôlez. Aucun compte d'IA ni clé d'API n'est nécessaire.

  • Free + Pro
  • Étapes pour Android
  • Environ 5 minutes

Les captures d'écran montrent SciREPL Free v1.3.2 sur un téléphone de la gamme Samsung Galaxy S24. La leçon s'applique également à Pro, bien que certaines commandes puissent y être différentes.

Dans cette leçon
  1. Prendre vos repères
  2. Écrire et exécuter une cellule
  3. Modifier la cellule enregistrée
  4. Exporter une copie du classeur
  5. Que tester ensuite

Tous les didacticiels

Étape 1

Prenez vos repères dans l'application

La rangée supérieure est l'en-tête. Elle comprend Menu, Aide et un badge d'état. Le sélecteur de classeur permet de choisir le classeur ouvert.

Le panneau de nouvelle cellule est l'endroit où vous saisissez la cellule suivante. Les boutons d'en-tête facultatifs peuvent disparaître lorsque l'écran est étroit ; leurs actions restent accessibles depuis le Menu ou l'Aide le cas échéant.

Étape 2

Écrire et exécuter une cellule Python

Attendez que le badge d'état indique prêt avant la première exécution.

  1. Dans le panneau de nouvelle cellule, choisissez Python dans le sélecteur de langue. Sur un téléphone étroit, le sélecteur fermé peut afficher uniquement Py.
  2. Saisissez ce court programme : 
    print("Hello from SciREPL")
  3. Appuyez sur Exécuter. Une cellule enregistrée apparaît dans le classeur. En dessous, vous devriez voir Hello from SciREPL.

La première exécution peut prendre plus de temps. L'environnement d'exécution de Python doit démarrer une fois. Attendez que l'état revienne à prêt ; les cellules Python ultérieures réutilisent généralement cet environnement d'exécution.

Si un avis de confidentialité apparaît : Python est normalement intégré, cet exemple ne devrait donc pas nécessiter le téléchargement d'un environnement d'exécution. Un environnement d'exécution réseau, tel que R ou Lua dans Free, peut d'abord afficher la politique de confidentialité de SciREPL ; Python peut aussi le faire si sa copie intégrée nécessite une solution de secours sur le réseau. Lisez-la, faites défiler dans la boîte de dialogue jusqu'en bas, et appuyez sur Je comprends si vous acceptez. Une invite distincte de téléchargement de l'environnement d'exécution peut ensuite vous demander d'appuyer sur Télécharger.

Voir un exemple de la boîte de dialogue Politique de confidentialité (Page de référence en anglais) (la capture d'écran montre son sommet ; le bouton se trouve plus bas). Dans Free 1.4.0 et Pro 1.4.0, une commande %pip install valide ouvre également cet avis si vous n'avez pas accepté la déclaration réseau actuelle, avant de tenter d'installer un paquet. Consultez confidentialité et données locales (Page de référence en anglais) avant d'utiliser les fonctionnalités réseau.

Étape 3

Modifier la cellule enregistrée

  1. Appuyez sur le crayon ✎ dans l'en-tête même de la cellule enregistrée, en haut à droite juste à gauche de ✕. Cela ouvre cette cellule pour modification ; taper dans le panneau de nouvelle cellule créerait une autre cellule.
  2. Remplacez Hello from SciREPL par Hello again.
  3. Choisissez Exécuter pour enregistrer et exécuter la modification. Vous devriez maintenant voir Hello again sous cette cellule.

Raccourci Pro : Sur un écran tactile, appuyez deux fois sur le code de la cellule enregistrée pour le modifier. Free utilise actuellement le bouton ✎.

Si vous ouvrez l'éditeur par erreur, utilisez Annuler pour le fermer sans exécuter. Le sélecteur de langue dans une cellule enregistrée modifie cette cellule ; celui pour une nouvelle cellule ne le fait pas.

Étape 4

Exporter une copie du classeur

  1. Ouvrez Menu → Exporter classeurs et paquets.
  2. Choisissez Onglet actif uniquement ou Tous les onglets, puis le format SciREPL Classeur (.srwb) lorsque vous souhaitez conserver l'état propre à SciREPL.
  3. Appuyez sur Exporter et choisissez une destination que vous contrôlez.

Pourquoi exporter ? SciREPL restaure les sessions locales, mais le stockage local ne constitue pas une sauvegarde et n'est pas partagé automatiquement entre l'application Android et un navigateur. Consultez fichiers et exportation (Page de référence en anglais) pour d'autres formats, notamment .ipynb et le format PDF.

Étape 5

Que faire ensuite

Essayez 2 + 2 dans une autre cellule Python. Utilisez ensuite le sélecteur de classeur pour changer d'onglet. Le tutoriel du classeur CSV commence par Menu → Parcourir paquets, collections et classeurs, installe un exemple et montre comment ses cellules fonctionnent avec un fichier local.

Le tutoriel sur les groupes de Markov montre comment effectuer des recherches dans le catalogue élargi, ouvrir un classeur existant sur les mouvements de cube, exécuter ses cellules dans l'ordre et modifier un paramètre.

Pour vous rappeler rapidement où se trouvent les commandes, revenez à la référence de l'interface (Page de référence en anglais). Pour apprendre un autre langage ou ajouter des paquets, poursuivez avec Langages et paquets (Page de référence en anglais).

Vous utilisez Pro ? Le flux de travail de base est identique. Pro dispose également d'un éditeur plein écran et de fonctionnalités d'IA facultatives ; consultez les flux de travail d'IA et plein écran de Pro (Page de référence en anglais) après vous être familiarisé avec les cellules ordinaires.
