Aprenda na prática

Importe você mesmo um arquivo de pasta de trabalho

Já tem um arquivo de pasta de trabalho ou não consegue encontrar uma lição em Browse? Salve o arquivo no seu dispositivo e, em seguida, use Menu → Import File para adicioná-lo ao SciREPL. Este breve passo a passo usa Simpson's Paradox do branch GitHub main do catálogo; você não precisa instalar um pacote nem escrever código para importá-lo.

O SciREPL importa dois formatos de notebook: .srwb, seu próprio formato de pasta de trabalho, e .ipynb, o formato de notebook do Jupyter. Este exemplo usa .srwb; as notas de formato abaixo explicam o comportamento de execução diferente das importações do Jupyter.

  • Free + Pro
  • Etapas para Android + navegador
  • Cerca de 3 minutos

A captura de tela do Menu é uma captura real do Android em um Samsung Galaxy S24+, mostrando SciREPL Free 1.4.0-debug, e não uma instalação da Play Store. A captura de tela da pasta de trabalho importada é uma captura separada no navegador Chromium de Free 1.4.0 em uma janela de visualização em tamanho móvel; não é uma comprovação de importação pelo seletor de arquivos do Android. Ambas foram tiradas em 6 de outubro de 2026. Outras edições, versões e seletores de arquivos podem organizar os controles de maneira diferente. O exemplo é o arquivo em inglês simpsons-paradox.srwb do catálogo do SciREPL no branch main conforme revisado para este guia; esse branch pode mudar. Os detalhes de captura e origem (Página de referência em inglês) registram as dimensões exatas da imagem e o hash do arquivo revisado.

Todos os tutoriais

Passo 1

Salve o arquivo da pasta de trabalho em seu dispositivo

No GitHub, o branch main pode conter pastas de trabalho ou atualizações que ainda não estão na versão estável mais recente do catálogo exibida em Browse. Os lançamentos do catálogo mudam independentemente do lançamento do aplicativo. Uma importação direta de arquivo permite testar uma pasta de trabalho confiável sem esperar que ela apareça em Browse.

  1. Veja o Paradoxo de Simpson no GitHub, depois baixe o arquivo real da pasta de trabalho (.srwb). O segundo link abre o arquivo bruto, não a página da web do GitHub.
  2. Se o seu navegador exibir o arquivo como texto em vez de baixá-lo, use a ação de salvar/baixar do navegador. Salve o arquivo da pasta de trabalho em si, não uma captura de tela ou uma página HTML.
  3. Mantenha o nome do arquivo simpsons-paradox.srwb e sua extensão .srwb. Observe onde ele foi salvo: o Android normalmente usa Downloads; no desktop, pode ser Downloads ou uma pasta que você escolheu.

Este não é um download de versão fixada. O branch main é uma ramificação de desenvolvimento: o conteúdo e as células do arquivo podem mudar depois que essas capturas de tela foram feitas. O arquivo que você salva é uma cópia local; uma alteração posterior no GitHub não atualiza sua aba importada automaticamente.

Baixar não é importar. Salvar o arquivo o coloca em seu dispositivo; isso ainda não abre uma pasta de trabalho no SciREPL. Você não precisa abri-lo em um editor de texto nem colocá-lo na visualização Arquivos do SciREPL. O próximo passo seleciona esse arquivo baixado.

Se você já tiver um arquivo .srwb confiável de outra pessoa, use esse arquivo e pule o download de exemplo. O título da pasta de trabalho e a contagem de células serão diferentes das verificações no Passo 3.

Passo 2

Localize o Menu e escolha Importar Arquivo

  1. Volte para o SciREPL. Na linha de cabeçalho na parte superior do aplicativo, localize o ☰ Menu, o botão com três linhas horizontais, e toque ou clique nele.
  2. Escolha 📂 Importar arquivo (por exemplo, .srwb, .ipynb, .csv, .py, .zip). Se o menu for mais alto do que a tela, role dentro do menu para encontrá-lo.
  1. No Android: o seletor de arquivos do sistema é aberto. Procure em Downloads ou navegue até o local onde você salvou o arquivo. Selecione simpsons-paradox.srwb. O seletor pertence ao Android, portanto o layout dele e qualquer controle de seleção ou Abrir final dependem do seu dispositivo.
  2. No desktop: use o seletor de arquivos para encontrar a pasta que você escolheu ao baixar. Selecione simpsons-paradox.srwb e confirme a seleção. Use esse caminho em vez de procurar a tela Downloads do Android.
  3. De volta ao SciREPL, aguarde a conclusão da importação. Se o menu ainda estiver aberto, feche-o para ver a pasta de trabalho.

Um caderno não é um envio de arquivo de dados. Importar um arquivo .srwb adiciona seu caderno como uma aba separada, ou abas separadas se o arquivo contiver vários cadernos. Suas abas existentes são mantidas. Isso não coloca o caderno na visualização Arquivos e não substitui seu caderno atual.

Passo 3

Verifique o novo caderno antes de executar qualquer coisa

  1. Procure no seletor de cadernos por Simpson's Paradox. Selecione essa nova aba se ela ainda não estiver selecionada. Sua introdução tem o título Simpson's Paradox: When Every Group Disagrees with the Total.
  2. Leia a introdução e percorra as células. A versão analisada para estas capturas de tela tem sete células: três células de texto, três células R e uma célula JavaScript. Uma versão posterior no main pode ser diferente.
  3. Encontre as células R com os nomes data, compute e viz, nessa ordem. A célula JavaScript se chama js_check e é uma verificação separada e opcional. Leia o texto explicativo, bem como o código.

Importar não significa Executar para .srwb. O SciREPL não executa o código quando você importa um arquivo .srwb, mesmo que a execução automática esteja ativada para outras importações. Inspecione o código de uma fonte desconhecida ou não confiável antes de escolher Executar ou Executar todas as células.

A importação comum de .srwb atualmente descarta as saídas salvas das células de código, mesmo quando o arquivo as contém. O texto em Markdown é mantido e renderizado, razão pela qual a introdução aparece imediatamente. Para gerar novamente gráficos ou outras imagens geradas por código, execute as células de código novamente, com as células dependentes em ordem. A importação não restaura variáveis ativas de R ou de outro ambiente de execução.

Passo 4

Opcional: execute a lição importada

Sua importação manual está concluída; executar o código é uma etapa separada. O Simpson's Paradox usa dados didáticos sintéticos para mostrar como as comparações dentro dos grupos podem discordar da comparação geral. Para explorá-lo, toque no ✎ lápis de uma célula de código salva, inspecione o código e, dessa célula, use o botão Executar.

  1. Execute a célula R data, leia a célula de texto pause e faça sua previsão antes de executar compute. Continue com viz para gerar o gráfico. As células R posteriores dependem das anteriores. Elas usam o R básico; você não precisa instalar pacotes R adicionais.
  2. Se você quiser uma verificação separada em JavaScript, execute js_check. Ela é independente: não depende das células R e não requer a inicialização do R.

Primeira execução do R: no SciREPL, o ambiente de execução webR pode precisar ser baixado e inicializado. Um aviso de rede/privacidade pode aparecer; leia-o e concorde apenas se quiser prosseguir. Aguarde até que o ambiente de execução esteja pronto e verifique se há erros na célula. Apenas importar o caderno não carregou suas definições de R.

Para outro exemplo com um passo a passo mais completo de execução e edição, consulte a lição Markov Groups. Esse é um caderno diferente, com quatro células Python; sua etapa de exportação também ilustra como salvar uma cópia editada do caderno.

Mantenha uma cópia sob seu controle. O arquivo baixado é a cópia original da pasta de trabalho, não um backup de edições posteriores. Exporte uma cópia da pasta de trabalho para salvar suas alterações. Limpar o armazenamento do aplicativo ou do navegador pode remover o trabalho local, e as sessões do Android e do navegador não compartilham suas alterações automaticamente.

Outros formatos e segurança

Saiba o que seu arquivo contém

Os cadernos do Jupyter (.ipynb) também usam Menu → Importar arquivo, mas seu comportamento de execução difere de .srwb. Se Executar células automaticamente ao importar pasta de trabalho estiver ativado, uma importação de .ipynb pode executar automaticamente células de código que não têm saídas salvas.

Importe arquivos de caderno apenas de fontes confiáveis. Antes de importar um .ipynb, abra Menu → Configurações → Importar e editar e certifique-se de que Executar células automaticamente ao importar pasta de trabalho esteja desativado (desmarcado). Ele fica desativado por padrão, mas verifique sua configuração atual. Desativá-lo não é garantia de que um caderno arbitrário seja seguro; inspecione o código de um caderno confiável antes de decidir explicitamente se deseja executá-lo.

Arquivos de dados separados: uma exportação normal de .srwb não inclui arquivos CSV separados ou outros dados armazenados no sistema de arquivos virtual do SciREPL (a visualização Arquivos). Esta versão do Paradoxo de Simpson cria seus dados sintéticos em código, portanto não precisa de um arquivo de dados separado. Para uma pasta de trabalho que lê um CSV, siga a exportação de arquivo de pacote do roteiro de CSV e as etapas de reabertura para transportar e restaurar tanto a pasta de trabalho quanto seus dados. Arquivos de pacote e importações de .zip estão fora desta breve lição sobre arquivos de pastas de trabalho.

Se algo parecer errado

Verifique o arquivo e a guia selecionada

  • O seletor não consegue encontrar o arquivo: verifique a lista de downloads do seu navegador para ver onde ele foi salvo e navegue até essa pasta. Fazer o download em um computador não coloca o arquivo na pasta Downloads do seu celular.
  • O nome do arquivo termina em .txt ou .html: retorne ao link de download da pasta de trabalho e salve o arquivo real com sua extensão .srwb. Renomear uma página HTML para .srwb não a transforma em uma pasta de trabalho.
  • Você ainda vê sua pasta de trabalho antiga: feche o menu e verifique o seletor de pastas de trabalho para encontrar o novo título. As guias existentes são preservadas.
  • Você importou duas vezes: outra importação adiciona outra cópia; ela não atualiza nem substitui a guia anterior. Verifique qual cópia você está editando antes de fazer alterações.
  • O título ou as células não coincidem: verifique se você selecionou simpsons-paradox.srwb, e não um download diferente ou um arquivo de outra lição. O arquivo no main pode mudar; compare sua cópia com o arquivo atual do GitHub e inspecione códigos desconhecidos antes de executá-los.

Para os conceitos básicos de guias de pastas de trabalho e edição de células salvas, consulte o roteiro de interface da primeira pasta de trabalho. A referência de pastas de trabalho (Página de referência em inglês) explica a estrutura da pasta de trabalho e os tipos de célula.
