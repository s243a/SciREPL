Explorar un CSV en un libro de trabajo

Comience en Explorar paquetes, colecciones y libros de trabajo. Instale un pequeño ejemplo, ejecute sus celdas, edite su CSV, luego exporte y vuelva a abrir el libro de trabajo con sus datos. Los datos son ficticios y el código de Python no necesita paquetes adicionales ni una cuenta de IA.

  • Free + Pro
  • Pasos para Android
  • Aproximadamente 15 minutos

Las capturas de pantalla se tomaron en un teléfono de la serie Samsung Galaxy S24. Las imágenes de Browse y del resultado inicial muestran Free; las imágenes del nuevo editor de archivos y de selección de paquetes muestran Pro 1.4.0 y están etiquetadas a continuación. En Pro, puede usar la descarga directa del libro de trabajo y la ruta Import File; los controles circundantes pueden diferir y es posible que esta nueva entrada de Browse no esté presente allí.

¿Aún no ve este libro de trabajo en Browse? El ejemplo está integrado en Free 1.4.0 y versiones posteriores; es posible que una aplicación instalada más antigua o una PWA en caché no lo muestre. Descargue el libro de trabajo directamente, luego use Menú → Import File para abrirlo. Ahora puede seguir el resto de esta lección.

En esta lección
  1. Instalar el ejemplo desde Browse
  2. Ejecutar sus celdas de Python
  3. Cambiar una medida en Files & Storage
  4. Importar un archivo CSV
  5. Exportar el libro de trabajo y los datos
  6. Reabrir el paquete y verificar sus datos

Paso 1

Buscar el libro de trabajo en Browse

  1. Abra Menú → Explorar paquetes, colecciones y libros de trabajo. El atajo opcional 📦 del encabezado abre la misma pantalla si está visible.
  2. Busque CSV Basics. En Libros de trabajo, busque CSV Basics: Seedling Heights. Es un ejemplo integrado en inglés, no un paquete que necesite instalarse en Python.
  3. Toque Instalar. Normalmente el libro de trabajo pasa a ser la pestaña seleccionada. Si desactivó el cambio automático, use el selector de libros de trabajo para elegirlo.

Si aparece una Política de privacidad: Browse puede verificar el catálogo verificado en línea. Lea la declaración, desplácese dentro del cuadro de diálogo hasta el final y toque I Understand solo si está de acuerdo. En su lugar, puede cerrar el aviso y seguir utilizando las entradas integradas; el catálogo remoto no estará disponible. Este ejemplo en sí no necesita ningún conjunto de datos externo ni ningún paquete de Python.

Instalar un libro de trabajo agrega sus celdas; no las ejecuta. Eso le permite inspeccionar el código antes de ejecutarlo.

Paso 2

Ejecutar las celdas en orden

El texto inicial explica el ejemplo. Las tres celdas de Python tienen cada una un nombre: create_csv, read_csv y compare_groups. Para una celda guardada, toque su ✎ lápiz para abrir el editor, luego toque Ejecutar de esa celda. En Pro también puede tocar dos veces el código de la celda para editarlo.

  1. Ejecute create_csv. Escribe seis filas ficticias en /shared/data/seedling-heights.csv. Debería ver Saved 6 fictional rows.
  2. Ejecute read_csv. Abre el archivo recién creado e imprime las seis filas.
  3. Ejecute compare_groups. Imprime una media de luz de 13.0 cm, una media de sombra de 8.0 cm y una diferencia de 5.0 cm.

El archivo también es visible en Menú → Archivos y almacenamiento. Puede leerlo allí o usar Editar y Guardar para modificarlo directamente. El siguiente paso muestra cómo.

El resultado final debería verse así:

Light mean: 13.0 cm
Shade mean: 8.0 cm
Difference: 5.0 cm

¿La primera ejecución es más lenta? Python puede tardar un momento en inicializarse. Espere a que la insignia de estado indique listo antes de juzgar si una celda terminó. Las celdas posteriores normalmente reutilizan el entorno de ejecución cargado. Si la descarga de un entorno de ejecución requiere consentimiento, lea el aviso de privacidad antes de aceptar; este libro de trabajo no llama a %pip install.

Estos valores ficticios ilustran la lectura y el cálculo, no una conclusión científica sobre la luz y el crecimiento de las plantas.

Paso 3

Cambiar un valor y volver a ejecutar

No tiene que editar la celda de Python para cambiar sus datos. Abra el propio CSV:

  1. Elija Menú → Archivos y almacenamiento (el menú puede añadir VFS / Paths al nombre).
  2. Elija / (Almacenamiento persistente) o Todos los sistemas de archivos. Desplácese hasta /shared/data/seedling-heights.csv y toque el nombre del archivo, no su icono de descarga o eliminación.
  3. Toque Editar. Cambie la fila light,14 a light,15. Mantenga el encabezado group,height_cm, las comas y las demás filas sin cambios.
  4. Toque Guardar, luego cierre Files & Storage. Guardar un archivo no ejecuta ningún código.

Vuelva a ejecutar solo read_csv y compare_groups. La media de luz es ahora de aproximadamente 13.3 cm y la diferencia de aproximadamente 5.3 cm. No vuelva a ejecutar create_csv: sobrescribiría la edición de su archivo con los valores que aún están en esa celda.

Alternativamente, edite create_csv con su ✎ lápiz, cambie su medida 14 a 15 y ejecute las tres celdas de Python en orden. Esto cambia el código que genera el archivo, en lugar de solo el archivo.

¿Por qué volver a ejecutar las celdas posteriores? Su resultado guardado es un registro de la ejecución anterior; cambiar un archivo no recalcula automáticamente los resultados anteriores. Cada celda lee el archivo cuando usted la ejecuta.

Pro: edición de archivos a pantalla completa y resaltado opcional

En la vista previa del archivo, toque Pantalla completa para obtener un editor más grande. El CSV permanece como Texto sin formato, por lo que su casilla de verificación Resaltado de sintaxis está deshabilitada.

Para los archivos de código compatibles, el resaltado de sintaxis es opcional y está desactivado de forma predeterminada. Actívelo usando la casilla de verificación en este editor de archivos, no en la configuración de apariencia del cuaderno. La extensión elige el lenguaje: por ejemplo .py es Python, .js es JavaScript, .R es R y .pl es Prolog, no Perl. Las extensiones desconocidas permanecen como texto sin formato.

Guardar escribe el archivo y mantiene abierto el editor. Use × Close para volver a Files & Storage; solicita confirmación antes de descartar cambios no guardados. Editar o guardar el archivo nunca lo ejecuta.

Vea el mismo editor a pantalla completa con el CSV abierto como texto sin formato.

Paso 4

Importar el CSV original

  1. Descargue el CSV de muestra original (Página de referencia en inglés) a una carpeta que el selector de archivos de su dispositivo pueda abrir.
  2. En SciREPL, elija Menú → Import File y seleccione seedling-heights.csv. La confirmación debería indicar que se subió a /shared/data/seedling-heights.csv.
  3. Esto reemplaza el archivo local modificado con las seis filas originales. Vuelva a ejecutar read_csv y compare_groups; las dos medias deberían volver a 13.0 y 8.0 cm.

Importante: No vuelva a ejecutar create_csv después de importar un archivo diferente con el mismo nombre a menos que tenga la intención de sobrescribirlo. Para su propio CSV, anote la ruta de confirmación exacta y cambie el path en las celdas de lectura por ese nombre de archivo. El selector de archivos puede mostrar Descargas de Android, un proveedor en la nube o ambos.

Paso 5

Guardar una copia portátil

Abra Menú → Exportar libros de trabajo y paquetes. Si solo desea las celdas, elija Libro de trabajo (.srwb) y Solo la pestaña actual. Un .srwb no incluye el CSV independiente en SharedVFS.

Para mover el libro de trabajo con sus datos, elija Paquete (archivo comprimido) y mantenga .zip. En el árbol Contenidos, seleccione:

  • El libro de trabajo CSV_Basics__Seedling_Heights.ipynb bajo notebooks/. La exportación de paquetes almacena las celdas en formato de cuaderno de Jupyter.
  • El archivo seedling-heights.csv bajo shared/data/.

Desmarque los libros de trabajo y archivos no relacionados. Despliegue las carpetas con su flecha si es necesario; no asuma que Solo la pestaña actual limita el contenido de un paquete. No necesita las copias adicionales de shared/notebooks/ para esta lección. En Pro, deje Incluir conversación de IA desmarcado a menos que desee compartirlo deliberadamente.

Toque Exportar. En Android, esto abre la hoja para compartir: guarde el archivo comprimido en algún lugar que pueda volver a encontrar, como su propia unidad o un destino para guardar de un administrador de archivos. En un navegador, descarga un archivo. El nombre de archivo sugerido es scirepl_package.zip; cambiarle el nombre a seedling-project.zip facilita su reconocimiento.

La recuperación local no es una copia de seguridad. El almacenamiento de la aplicación de Android, la PWA en Chrome y otro navegador no comparten automáticamente estos archivos. Guarde la copia exportada en un lugar que controle. Consulte Files, import, and export (Página de referencia en inglés) para ver otros formatos.

Paso 6

Reabrir el paquete y verificar ambas partes

Antes de confiar en una copia de seguridad, compruebe que puede abrirla. Puede hacer esto en otra instalación de SciREPL o perfil de navegador. Importar aquí añade otro libro de trabajo; también reemplaza archivos en las rutas de destino del paquete, así que guarde una copia independiente de cualquier archivo más reciente antes de importar un paquete más antiguo.

  1. Elija Menú → Import Package (.zip / .tar.gz) y seleccione el archivo comprimido que guardó. Para esta lección es un .zip, no la descarga independiente de CSV o .srwb.
  2. Elija el libro de trabajo CSV Basics: Seedling Heights recién importado si no se selecciona automáticamente. Si importó en la misma aplicación, es posible que las pestañas antigua y nueva tengan el mismo nombre.
  3. Abra Menú → Archivos y almacenamiento y compruebe /shared/data/seedling-heights.csv. Sus seis filas deberían coincidir con el archivo que exportó. Cierre la vista previa después de comprobarlo.
  4. Ejecute la segunda celda de Python (el código read_csv), luego la tercera celda de Python (el código compare_groups). La exportación de paquetes utiliza el formato de Jupyter y es posible que no conserve los nombres de las celdas; identifíquelas por su orden y código. Después del Paso 4 con el CSV original, espere 13.0 cm, 8.0 cm y 5.0 cm. Si en su lugar exportó el archivo light,15 editado, espere 13.3 cm, 8.0 cm y 5.3 cm.

No vuelva a ejecutar create_csv para esta comprobación de restauración. Sobrescribe los datos importados con los valores de su código. Leer primero el CSV restaurado demuestra que los datos viajaron con el libro de trabajo; los resultados guardados antiguos por sí solos no demuestran eso.

Si falta el archivo, o el libro de trabajo no está presente, vuelva al Paso 5 y compruebe que ambas entradas estaban seleccionadas. Una exportación de libro de trabajo simple no puede incluir el CSV por usted.

¿Qué hacer a continuación?

Pruebe con un CSV propio. Mantenga las columnas group y height_cm, use alturas numéricas e incluya al menos una fila light y una fila shade—o adapte los dos filtros de grupo en compare_groups. Puede inspeccionar el archivo local en Menú → Archivos y almacenamiento. Para los controles del teléfono utilizados aquí, consulte la guía paso a paso de la interfaz del primer libro de trabajo.
