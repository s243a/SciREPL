Explora un libro de trabajo del catálogo

Encuentra el libro de trabajo existente Markov Groups: A Random Walk on Cube Moves, ejecuta sus cuatro celdas de Python, acorta su paseo aleatorio y guarda tu propia copia. El objetivo es aprender a usar SciREPL; no necesitas saber álgebra matricial ni resolver un cubo de Rubik.

¿Estás aquí para aprender a usar la aplicación? Sigue los pasos 1–5: busca, abre, ejecuta, edita y exporta un libro de trabajo. Puedes detenerte después del paso 5. La sección de matemáticas opcionales viene después; no es necesaria para completar esta guía paso a paso.

  • Free + Pro

Antes de empezar

Busca el menú

En SciREPL, busca en la fila de encabezado en la parte superior de la aplicación el botón ☰ Menú. Su icono son tres líneas horizontales, resaltadas en amarillo abajo. Tócalo para abrir el menú de la aplicación; el paso 1 muestra qué elemento del menú elegir.

Paso 1

Explorar, filtrar y buscar

  1. Abre Menú → Explorar paquetes, colecciones y libros de trabajo. En Free, el acceso directo opcional del encabezado 📦 abre la misma pantalla cuando está visible. La guía de Apariencia muestra cómo activarlo.
  2. Explora la lista o usa sus filtros. Para este ejemplo en inglés, elige English en Idioma hablado y Python en Kernel. Todos los idiomas hablados y la opción Todo del kernel también funcionan, pero muestran más entradas.
  1. Escribe Markov Groups en el campo de búsqueda. En Libros de trabajo, busca Markov Groups: A Random Walk on Cube Moves. Comprueba el título completo antes de instalar: esta es una plantilla de libro de trabajo, no un paquete para agregar a Python.
  2. Si el teclado cubre el resultado, usa su botón para ocultar el teclado o presiona Atrás de Android una vez para descartarlo. Mantén Explorar abierto y desplázate hasta el libro de trabajo correspondiente.

¿Qué más hay disponible? Explora la lista de libros de trabajo en GitHub (English). Las ediciones en diferentes idiomas de una lección son entradas independientes, no lecciones distintas.

El enlace a GitHub muestra el contenido de desarrollo más reciente. SciREPL normalmente utiliza la versión estable más reciente del catálogo, por lo que algunos libros de trabajo mostrados en GitHub pueden no aparecer aún en Explorar. En SciREPL, borra la búsqueda y prueba CSV, Prolog, Lua o statistics; elige Todo en Kernel cuando explores otros lenguajes.

Si aparece un aviso de privacidad: obtener o actualizar el catálogo remoto requiere una conexión de red. Lee la divulgación, desplázate dentro del cuadro de diálogo hasta el final y toca Entiendo solo si estás de acuerdo. Cerrar el aviso impide esa actualización de red; las entradas integradas y las entradas del catálogo previamente almacenadas en caché aún pueden aparecer. Consulta privacidad y datos locales (Página de referencia en inglés).

¿No encuentras el libro de trabajo correspondiente? Comprueba los filtros de idioma y de kernel, y luego usa el control Actualizar del catálogo. Es posible que una versión anterior de la aplicación no tenga los mismos controles de catálogo. Como alternativa, guarda el archivo de libro de trabajo v0.4.0 fijado en tu dispositivo, luego elige Menú → Import File y selecciona markov-groups.srwb. Si tu navegador muestra el archivo como texto, usa su acción de guardar/descargar y conserva la extensión .srwb. La guía paso a paso de importación manual de libros de trabajo muestra los pasos usando Simpson's Paradox desde GitHub en la rama main; elige el archivo de Markov anterior para continuar con esta lección.

Paso 2

Abrir el libro de trabajo e inspeccionar sus celdas

  1. Toca Instalar en la tarjeta del libro de trabajo. Si el botón ya dice Instalado, sal del menú Explorar y elige el libro de trabajo existente en el selector de libros de trabajo.
  2. El libro de trabajo normalmente pasa a ser la pestaña seleccionada. Si el menú Explorar permanece abierto, sal de él. Si el cambio automático está desactivado, elige Markov Groups: A Random Walk on Cube Moves en el selector de libros de trabajo junto a SciREPL en el encabezado.
  3. Lee el texto inicial y luego desplázate por las celdas. Las celdas de Markdown explican la lección; las celdas de Python contienen el código que vas a ejecutar. Cada celda de Python tiene un nombre para ayudarte a encontrarla.

Instalar no significa Ejecutar. Instalar este libro de trabajo del catálogo remoto añade sus celdas sin ejecutar su código Python. La plantilla v0.4.0 no tiene salidas guardadas de Python, así que inspecciona el código y ejecútalo tú mismo. No se necesita ninguna cuenta de IA, clave de API, conjunto de datos externo ni instalación de paquetes adicionales; el código utiliza NumPy con el entorno de ejecución de SciREPL para Python.

Paso 3

Ejecutar las cuatro celdas de Python en orden

Para una celda guardada, toca el ✎ lápiz en el encabezado de esa celda, luego toca el Ejecutar de esa misma celda. Esto ejecuta la celda existente; el panel inferior de nueva celda crea una celda diferente.

Acceso directo de Pro: toca dos veces el código guardado para abrir su editor, luego toca en esa misma celda Ejecutar. Free utiliza el ✎ lápiz en esta guía paso a paso.

¿Qué significan estos nombres? cube_moves y check_moves son nombres que se muestran en las celdas, no comandos para escribir. Busca el nombre correspondiente, luego usa el lápiz de esa celda y Ejecutar. El tutorial de celdas con nombre y rutas entre lenguajes muestra cómo asignar nombres y usarlos como referencias tales como /nb/cube_moves/.code.

  1. Ejecuta cube_moves. Define los movimientos y las funciones auxiliares. Deberías ver Built six clockwise quarter-turn matrices with fixed face centres.
  2. Ejecuta check_moves. Comprueba que no se pierda ningún adhesivo, que los centros permanezcan fijos y que cuatro repeticiones de cada cuarto de giro regresen al inicio. Tras seis líneas superadas, deberías ver All six moves passed. U and R do not commute.
  1. Ejecuta show_turn. Muestra los ciclos de giro U y las etiquetas de los adhesivos antes y después de un giro. La fila superior frontal cambia de [19, 20, 21] a [46, 47, 48]. La comparación U then R equals R then U: False muestra que el orden de los movimientos importa.

La lista larga de letras de las caras se omite aquí. Las líneas de ciclos utilizan posiciones basadas en uno; la comparación de filas muestra etiquetas de adhesivos. Son significados distintos, aunque el cubo resuelto inicialmente les asigna números coincidentes.

  1. Ejecuta random_walk. Muestra un total de probabilidad de un adhesivo de 1.0, una trayectoria muestreada de 12 pasos, las etiquetas finales de las letras de las caras y un mensaje que confirma que se conservaron todas las etiquetas de adhesivos y los seis centros.

Las celdas de Python ya están en el orden requerido. No las reordenes: las celdas posteriores reutilizan definiciones de cube_moves. Para ejecutar varias celdas a la vez, consulta Ejecutar todo hacia abajo y Ejecutar todas las celdas.

¿La primera ejecución fue más lenta? Es posible que Python necesite tiempo para inicializarse, y que una descarga del entorno de ejecución o una alternativa por red requieran tu consentimiento. Espera a que el indicador de estado vuelva a listo y comprueba si hay errores en la salida de la celda. Si una celda posterior informa de un nombre no definido tras un reinicio, ejecuta las celdas de Python desde el principio; la salida guardada no es lo mismo que las definiciones activas de Python.

Este libro de trabajo imprime texto y listas de letras de las caras. No dibuja ni anima un cubo, y su trayectoria corta generada por semilla no es prueba de una mezcla uniformemente distribuida.

Paso 4

Acortar el paseo y volver a ejecutar la celda guardada

  1. Busca random_walk y toca su ✎ lápiz.
  2. Busca esta línea y cambia únicamente size=12 a size=6: 
    moves = rng.choice(MOVE_OPTIONS, size=12).tolist()

    Deja np.random.default_rng(7) sin cambios. La semilla hace que este ejemplo sea reproducible.

  3. Toca el botón Ejecutar en el editor de esa celda guardada. La salida se actualiza; la línea Sampled moves: ahora contiene seis opciones en lugar de doce. I cuenta como una opción aunque deje el cubo inmóvil.

Para este cambio, vuelve a ejecutar únicamente random_walk mientras las definiciones anteriores estén cargadas. Si en su lugar editas cube_moves, vuelve a ejecutar también las celdas posteriores de Python. Las salidas registran su última ejecución; no se recalculan automáticamente cuando cambia otra celda.

Si abriste el editor por error, elige Cancelar. Para volver al ejemplo original, cambia size=6 de nuevo a size=12 y ejecuta la celda otra vez.

Paso 5

Exportar tu propia copia del libro de trabajo

  1. Mantén seleccionado el libro de trabajo Markov Groups, luego abre Menú → Exportar libros de trabajo y paquetes, no Exportar documento.
  2. Elige Libro de trabajo (.srwb) y Solo la pestaña actual.
  3. Toca Exportar y guarda la copia en una ubicación que controles. Android abre un flujo de compartir/guardar; un navegador descarga un archivo. Conserva la extensión .srwb.

El libro de trabajo no necesita un archivo de datos independiente, por lo que una copia en .srwb es suficiente para esta lección. Puedes volver a abrirlo con Menú → Import File; ejecuta sus celdas de Python desde el principio cuando inicies un nuevo entorno de ejecución.

La recuperación local no es una copia de seguridad. Borrar el almacenamiento de la aplicación o del sitio web, o desinstalar la aplicación, puede eliminar el trabajo local. Las sesiones de Android y del navegador no comparten automáticamente tus modificaciones. Exportar no publica tus cambios en el catálogo; te proporciona una copia independiente.

Para conocer los conceptos básicos de la edición de celdas guardadas, consulta la guía de la interfaz del primer libro de trabajo. Para ver un ejemplo que lee y contiene un archivo de datos independiente, prueba la guía del libro de trabajo con CSV. La referencia de libros de trabajo (Página de referencia en inglés) cubre los tipos de celdas y los nombres estables de celdas.

Ejecutar todo hacia abajo y Ejecutar todas las celdas

  • Ejecutar todo hacia abajo: abre una celda guardada con su ✎ lápiz, luego elige Ejecutar todas las celdas siguientes (el icono compacto es ▶↓). Ejecuta esa celda y cada celda debajo de ella, en orden.
  • Menú → Run All Cells: ejecuta el libro de trabajo seleccionado desde su primera celda hasta la última. No es un comando para ejecutar todas las pestañas de libros de trabajo.

Inspecciona el código primero y mantén este libro de trabajo seleccionado mientras se ejecuta el lote. Tras una nueva sesión de Python, comienza desde cube_moves para que las celdas posteriores tengan sus definiciones. Estas acciones ejecutan código; calificar una explicación como «opcional» no hace que la aplicación omita sus celdas de código.

Has completado la guía de SciREPL. Has encontrado, abierto, ejecutado, editado y exportado un libro de trabajo. Si solo querías aprender a usar la aplicación, puedes detenerte aquí. Continúa abajo si deseas explorar las matemáticas del cubo y el libro de trabajo de desarrollo.

Lectura opcional

Las matemáticas detrás del ejemplo del cubo

Un poco de significado detrás de la salida

El libro de trabajo rastrea 54 adhesivos etiquetados individualmente, no solo seis colores. Un movimiento válido reorganiza esas etiquetas. Cuatro repeticiones de un cuarto de giro regresan a la disposición inicial, pero los giros de caras diferentes pueden dar resultados distintos cuando cambia su orden.

El paseo aleatorio elige entre 13 opciones: permanecer inmóvil (I), seis cuartos de giro y sus seis inversos. Su matriz de probabilidad de 54×54 describe la ubicación de un adhesivo, no cada configuración del cubo completo. Un total de probabilidad de 1.0 significa que las probabilidades de ubicación de este adhesivo suman uno; no demuestra que el cubo esté mezclado uniformemente.

¿Tienes curiosidad sobre las direcciones de las caras? La celda coordinates del libro de trabajo proporciona los ejes globales y las normales hacia la derecha, hacia arriba y hacia afuera de cada cara. El tutorial de imágenes, diagramas y ecuaciones muestra cómo incluir ese tipo de explicación en un libro de trabajo. Se están añadiendo diagramas de coordenadas a la copia de desarrollo del catálogo; la copia fijada v0.4.0 anterior no los incluye.

Opcional: vista previa de la etapa 4 revisada

Los pasos y las capturas de pantalla de teléfono anteriores utilizan el libro de trabajo estable v0.4.0. La descarga del libro de trabajo revisado es una versión preliminar de desarrollo, aún no el catálogo estable. Impórtalo con Menú → Import File si deseas probar sus celdas de código y explicaciones intercaladas más breves.

En esa versión preliminar, ejecuta primero cube_moves, check_moves y show_turn, como se indicó anteriormente. Luego:

  1. Ejecuta transition_matrix. Construye T, la matriz de probabilidad para la ubicación de un adhesivo después de una opción elegida uniformemente: I, un cuarto de giro de una cara o su inverso.
  2. Ejecuta sticker_step. Sigue la etiqueta de adhesivo 1, inicialmente en la posición basada en cero 0. Sus probabilidades de ubicación suman 1.0. El gráfico siguiente muestra las probabilidades de destino calculadas por esa celda.
