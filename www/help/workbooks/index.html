Workbooks and cells

  • Free + Pro
  • Android
  • Web/PWA (Free)
  • Windows preview
  • Verified: Free 1.3.2 · Pro 1.3.0

Workbook tabs

Each tab is a notebook with its own ordered cells. You can add, rename, select, and close tabs. SciREPL saves the local session automatically, including each cell’s language and supported outputs.

Cell types

  • Code cells run in their selected language runtime.
  • Markdown cells render headings, lists, links, code spans, and LaTeX-style math.
  • Source-only cells keep named TypR or Lua source available to Notebook VFS without executing it.
In Pro: AI Prompt is a cell mode, not a programming-language runtime. It sends a reviewed one-shot request and never runs generated code automatically.

Running cells

Run executes the selected cell. Run All executes ordinary runnable cells in order. AI Prompt cells in Pro are skipped by bulk Run All so an ordinary bulk action does not spend tokens.

For a hands-on example, follow the CSV workbook walkthrough: find a workbook in Browse (or import its file), run its cells, and see how saved outputs change when you rerun them.

A semicolon can suppress display output where supported. Errors remain with the cell so you can correct and rerun it.

Markdown and Formula

Markdown math uses $x$ for inline expressions and $$...$$ for display expressions. Formula mode inserts templates without changing the cell’s underlying language.

  • The Formula shortcut applies to Python and Markdown cells.
  • In Python it inserts SymPy-oriented templates such as integrate, solve, simplify, and limits.
  • In Markdown it inserts LaTeX-oriented math text.

Name cells for stable references

A cell name is easier to reuse than a position that may change. Notebook VFS accepts names such as /nb/results/.output, positions such as /nb/In[2]/.code, and relative paths such as /nb/-1/.output.

Persistence versus backup

Automatic recovery protects against normal navigation and restarts, but clearing site/app storage, uninstalling, or changing browsers can remove it. Export an .srwb file for a SciREPL-native backup.
