SciREPL Pro v1.1.9

This update gives you more control over what AI Prompt cells receive and where their answers go, while making notebook editing and first-run loading clearer. These are the changes since v1.1.8.

Review AI Prompt context before sending

  • Choose source from previous cells, a selected range, or the current workbook to include with an AI Prompt. The preview shows that source with legacy /key lines redacted; cell outputs are not included.
  • Before a run sends selected cell context to your configured AI provider, review it and confirm the request. Configuring the selection alone sends nothing.
  • Generated or replaced code also gets a short guide to the selected language's runtime and package commands; review its dependencies before running it.

Choose where AI Prompt answers go

  • Keep the answer in the prompt cell's output, create or update a linked result cell, or preview a replacement for another cell. Configure this before the first run or while editing the prompt.
  • Review the target's exact source before every replacement request; it may contain credentials, and Cancel sends nothing. Generated code then gets a separate before-and-after preview and Apply step. Changed targets need a new preview; applied replacements can be undone.
  • Generated result cells do not run automatically, so you can inspect and edit their source first.

A tidier notebook and clearer loading

  • Collapse a cell's source to make room for its output, then expand it again when needed. The source remains saved, exportable, editable, and runnable while collapsed.
  • Cold-start progress stays with the cell that requested the run. Downloading a missing bundled Python package now requires network consent, and optional R package preparation waits until after the first R result.

AI Settings now shows separate model choices for the Assistant and AI Prompt cells, plus an Autocomplete setting. Independent AI Prompt models and local autocomplete are previews only in v1.1.9: AI Prompt cells still use the Assistant model, and the autocomplete choice does not change the editor yet.
