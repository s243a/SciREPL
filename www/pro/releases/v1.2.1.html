SciREPL Pro v1.2.1

This update gives the editor room to breathe on a phone: a cell or the new-cell field can take the whole screen, code is coloured as you type, and outputs survive a restart. It also fixes two layout problems that testers reported. These are the changes since v1.2.0.

Released This is the current public release. Read about v1.3.0, now being prepared for the tester group.

Full-screen editing

  • Tap ⤢ beside the language selector, or in a cell's edit toolbar, to give the editor the whole screen above the keyboard. The frame keeps only a label, Done and Cancel.
  • Suggestion chips and the extra-keys row move into the frame with the editor, so completion and Run keep working there.
  • Back, the cell label, or Esc return to the workbook with your edit still open; Done applies it and Cancel discards it. On a keyboard, Ctrl+Shift+F toggles full screen.
  • In landscape, full screen bypasses the accessory-row limits, since the editor already has the space.

Syntax colours while typing

  • Keywords, strings and comments are coloured in the code field as you type, in the new-cell field and while editing a cell, for Python, JavaScript, R, TypR, Bash, Prolog and Lua.
  • The Appearance setting offers Auto, On and Off. Auto is on in desktop browsers and off on phones, where colouring costs some typing speed on slower devices. Cells longer than 6000 characters stay uncoloured.
  • Ghost-text completion and the caret line up with the coloured text.

Outputs survive a restart

  • Text output, tables and rendered images come back after you close and reopen the app, so a workbook no longer looks unrun after a restart. Interactive plots still need a re-run. AI Prompt cells keep their text output.

Layout fixes from tester reports

  • When the translated Run label would leave too little room for the code field, Run shrinks to an icon. The label stays available to screen readers, and an Appearance setting forces either form.
  • Header buttons and the status badge now scale with the Android system font size, so a large font no longer makes them overlap.
  • Help gains an on-screen keyboard section organised by orientation, with a Play/F-Droid availability table and the setting for the extra-keys row.

Colouring and full-screen editing are local presentation features and send nothing anywhere. ClojureScript cells are not yet coloured; that is planned for a later update.
