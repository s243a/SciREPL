SciREPL Pro v1.2.0

This update makes editing Python on a phone faster: completion now knows your installed modules and their attributes, ambiguous prefixes become tappable chips, and an optional row of extra keys sits above the keyboard. Everything runs on the device and works offline. These are the changes since v1.1.9.

Completion that knows your session

  • Python completion suggests keywords, installed module names, and names and attributes from the current session. After a cell has run, np. completes numpy attributes such as np.linalg.
  • Aliases from import numpy as np are understood even in cells that have not run yet, so completion works while you draft.
  • Decline a suggestion by tapping the editor, pressing Back, or pressing Esc. The Accept button no longer sits over Run.
  • Nothing leaves the device: completion is local, offline, and independent of any AI provider setting.

Suggestion chips and extra keys

  • When several names fit what you typed, they appear as tappable chips above the keyboard, best first, ranked from what this workbook already uses. Tap a chip to complete that name.
  • Where there is no room for the chip row, the most likely name is offered as ghost text instead.
  • An optional extra-keys row adds Esc, Tab, indent removal, arrows, Home, End, Run, and Python punctuation. Turn it on under Menu → Settings; it is off by default.
  • Choose whether chips take their own row or replace the extra keys, separately for portrait and landscape.

Landscape rows that step aside

  • In landscape, accessory rows can be Off, shown when there is room, or always shown. The default shows them only when at least eight code lines stay visible; the minimum is adjustable.
  • Importing a workbook from a tool while editing a cell no longer leaves the composer hidden.

Completion ranking learns from names used in your workbooks and keeps that table on the device only. Clear History in Settings resets it. AI-assisted completion is not part of this release.
