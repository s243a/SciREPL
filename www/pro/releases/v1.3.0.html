SciREPL Pro v1.3.0

This update brings the AI Assistant into full-screen editing without hiding what it sees or changes. Conversations can survive a restart, Ask and Edit use reviewed context, and Agent mode can revise the open draft through a small set of editor tools.

In testing This version is being prepared for the SciREPL tester group. The current public release is v1.2.1. Join the testers for access when the rollout begins.

AI conversations are saved

  • The AI Assistant keeps one bounded, text-only conversation with each workbook and a separate Global conversation. Both survive closing and reopening the app.
  • A selector in the Assistant chooses which conversation is active, and Clear deletes only the selected conversation.
  • Workbook exports omit the conversation by default. Select Include AI conversation when you deliberately want the workbook-scoped record included; the Global conversation is never exported with a workbook.

Ask and Edit from the full-screen editor

  • Ask can answer a question about the open draft using the context you choose. Edit can propose a replacement for the draft.
  • Before a request is sent, SciREPL shows the exact selected cell context, any included saved output text, and the destination selected for that request.
  • Edit results remain a proposal until you press Apply. Generated code is not run automatically.
  • The exchange is recorded in the selected AI Assistant conversation, so a later question can continue from it.

Agent mode can work on the open draft

  • Agent mode gives the in-app Assistant nine focused editor tools to inspect state, read numbered lines, find text, select a range, replace exact text or lines, insert text, replace the selection, or replace the whole source.
  • Changes appear live in the editor. The frame reports how many edits the Agent made, and Undo agent edits restores the snapshot from the start of that run.
  • The tools exist only during that full-screen Agent run and are bound to that editor session and cell. Stopping or leaving the session prevents a late tool result from editing another cell.
  • Draft text and tool receipts sent to the provider use the same credential redaction as reviewed context.

Remote Agent limitation

  • Full-screen Agent mode currently uses the direct, in-app Assistant only. It is unavailable while Remote mode is on because the Remote route cannot yet carry the reviewed editor context and draft-only tools without silently changing the safety model.
  • Ordinary Remote Assistant chat and its existing permitted notebook tools still work. Turn Remote off when you want to use full-screen Agent mode.

AI requests still use the provider, model, permissions, and review controls you configure. Saved conversations remain on your device unless you send their content to a provider or explicitly include a workbook-scoped conversation in an export.
