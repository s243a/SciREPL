# Earlier development ideas

The previous README mixed completed features and possible future work in one roadmap. The unfinished ideas are preserved here so the README can describe the current app without silently discarding them. This is an archive of ideas, **not** a prioritized or verified release plan; check the current code and issues before starting one.

- Screenshots or short videos showing R plots, cross-language data flow, and the mobile UI.
- Collapsible long cell outputs.
- Execution counters such as `In [N]` and `Out [N]`.
- Local keyword and variable completion in the cell editor.
- A variable inspector across supported kernels.
- Undo for deleted cells.
- Sharing small notebooks through a URL or gist.
- Revisit Capacitor WebView pointer and hover media-query behavior.
- Byte-level download progress for large runtimes and packages.
- Background package and workbook installation without switching the active notebook.

The earlier README also listed a dark/light theme toggle, which is already implemented in Menu → Appearance and is therefore not carried forward as an open idea.
